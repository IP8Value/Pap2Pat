## DESCRIPTION

## BACKGROUND

### Field of the Disclosure

The present invention relates to systems and methods for improving the efficiency and reducing the bias in machine learning model training through active learning techniques, particularly in the context of large-scale text classification tasks. The invention encompasses a novel computational framework that leverages uncertainty-based query strategies applied to deep learning models to generate compact, high-fidelity training datasets that retain the discriminative power of full-scale datasets while drastically reducing computational and labeling costs. This field intersects machine learning, natural language processing, and data-efficient training methodologies, with particular relevance to applications requiring rapid deployment of text classification systems under resource constraints.

### Related Art

Current approaches to training deep neural networks for text classification rely heavily on large, fully labeled datasets, which are costly and time-intensive to acquire. Active learning has emerged as a promising strategy to mitigate this burden by iteratively selecting the most informative unlabeled samples for manual annotation, thereby reducing the total number of required labels. However, prior art in active learning has been dominated by shallow models such as Naive Bayes and SVMs, where sampling bias—particularly class imbalance and feature redundancy—has been well documented. To counteract these biases, researchers have proposed expensive diversity-based sampling techniques, such as coreset selection and ensemble-based uncertainty measures, which require significant computational overhead and complex model architectures. These methods, while effective in small-scale settings, exhibit poor scalability to large datasets and often fail to generalize across model types. Furthermore, recent studies have suggested that uncertainty-based strategies in deep learning contexts perform no better than random sampling, leading to a prevailing assumption that ensemble models or diversity augmentation are necessary for high-quality sample selection. This assumption has resulted in widespread adoption of computationally prohibitive methods, despite a lack of empirical validation on large, real-world text corpora. The limitations of these approaches include high variance in sample quality, sensitivity to initial dataset selection, and inconsistent performance across query sizes, all of which hinder reproducibility and practical deployment.

## SUMMARY

The invention introduces a novel query strategy for active learning in text classification that utilizes posterior uncertainty derived from a single, fast, deep learning model—specifically FastText.zip—to select training samples with exceptional efficiency and minimal bias. The method generates a training dataset through iterative querying of an unlabeled data pool, where each query is determined by the entropy of the model’s output probabilities, without requiring ensemble averaging, Bayesian dropout, or diversity constraints. The resulting dataset exhibits high label entropy, strong alignment with support vectors of a support vector machine trained on the full dataset, and remarkable stability across variations in initial seed selection, query size, and algorithmic parameters. This dataset serves as a surrogate for the full training corpus, enabling the training of state-of-the-art deep models such as ULMFiT with up to 200-fold reductions in training time and 40-fold reductions in data volume, while maintaining or exceeding classification accuracy. The system demonstrates that uncertainty-based sampling with a single deep model not only outperforms ensemble-based and diversity-based methods in both efficiency and robustness but also eliminates the need for computationally intensive components traditionally deemed essential for high-quality sample selection.

## DETAILED DESCRIPTION

The invention comprises a machine learning system designed to construct compact, representative training datasets for text classification through an active learning framework that prioritizes sampling efficiency and algorithmic stability. The system operates by iteratively querying an unlabeled data pool using a deep learning model trained on a small initial labeled subset, where each query selects the most uncertain samples according to the entropy of the model’s predicted class probabilities. The core innovation lies in the discovery that a single FastText.zip model, when used with entropy-based uncertainty scoring, generates query sets that are not only highly efficient in reducing labeling costs but also exhibit negligible class bias, strong alignment with decision boundaries, and exceptional robustness to variations in initial conditions and query parameters. Unlike prior approaches that rely on ensembles or diversity metrics to mitigate sampling bias, the system demonstrates that such measures are unnecessary when applied to deep models, as the inherent representational capacity of the model naturally biases sampling toward informative, boundary-adjacent examples that closely resemble support vectors of a linear SVM trained on the full dataset.

The system architecture consists of four primary components: an unlabeled data pool, a deep learning classifier trained on a small initial labeled subset, an acquisition function based on entropy of predicted probabilities, and a feedback loop that incrementally adds queried samples to the training set. The classifier is implemented using FastText.zip, a lightweight, linear deep learning model optimized for text classification with sublinear training time complexity. The acquisition function computes entropy over the softmax output distribution for each unlabeled instance and selects the top-K instances with the highest entropy values for labeling. This process is repeated over multiple iterations until the desired training set size is reached. The system does not employ model ensembles, Bayesian inference, or diversity-based sampling, yet achieves superior performance compared to such methods. The resulting training dataset, referred to as the surrogate dataset, contains a fraction of the original data—ranging from 2.5% to 4% of the full corpus—yet enables training of complex models such as ULMFiT with accuracy matching or exceeding that achieved on the full dataset.

The system’s efficacy is demonstrated through extensive empirical evaluation across eight large-scale text classification datasets, comprising over 2.3K experiments with data sizes ranging from 120,000 to 3.6 million samples. Results show that the entropy-based query strategy using a single FastText.zip model consistently produces training sets with high label entropy, indicating balanced class representation across queries, and maintains this balance in the final dataset regardless of query size or initial seed. The overlap between samples selected by this method and the support vectors of a linear SVM trained on the full dataset exceeds 70% across all datasets, indicating that the system inherently identifies the most discriminative examples for classification. Furthermore, the system demonstrates remarkable stability: the intersection of training sets generated from different initial seeds exceeds 90% in most cases, and the performance of downstream models trained on the surrogate dataset remains consistent across varying query sizes and algorithmic configurations. This stability contrasts sharply with traditional models such as Multinomial Naive Bayes, which exhibit high variance and sensitivity to initial conditions.

The system further enables the rapid bootstrapping of large deep learning models such as ULMFiT. By training ULMFiT on the surrogate dataset rather than the full corpus, the system achieves training speedups of 25x to 200x, with reductions in epoch count by a factor of five and data volume by a factor of five to forty, while maintaining state-of-the-art classification accuracy. This capability transforms the economics of model development, allowing researchers and practitioners to train high-performance models on modest hardware within hours rather than days. The system also establishes a new baseline for active text classification, outperforming recent methods such as BALD and K-center coreset sampling by requiring only one-quarter of the training data to achieve equivalent or superior accuracy. The system’s implementation is fully compatible with standard machine learning libraries and can be deployed on commodity hardware, requiring no specialized infrastructure or distributed computing resources.

The system is implemented as a computer-executable process running on a general-purpose computing device, comprising a central processing unit, memory, and storage subsystems. The software components include a data preprocessing module for tokenization and vectorization, a FastText.zip classifier trained on initial labeled data, an entropy-based acquisition function, and a training loop that iteratively updates the model and selects new queries. The system is implemented in Python using the FastText and scikit-learn libraries, with hardware acceleration provided by GPU compute resources during model training. The software code is modular, allowing for easy integration with existing machine learning pipelines and adaptation to other text classification tasks beyond those demonstrated. The scope of the disclosure encompasses any system or method that employs entropy-based uncertainty sampling from a single deep learning model to generate surrogate training datasets for text classification, regardless of the specific implementation details or underlying model architecture, provided that the core principle of avoiding ensembles, diversity measures, or Bayesian approximations is maintained.
