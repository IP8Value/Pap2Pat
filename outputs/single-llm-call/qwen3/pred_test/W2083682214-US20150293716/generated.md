## TECHNICAL FIELD

The present invention relates to the field of data storage systems, particularly to methods and apparatus for encoding, rewriting, and error-correcting information stored in non-volatile memory devices such as flash memory. More specifically, the invention provides a novel coding framework that simultaneously enables multiple rewrites of stored data while correcting errors introduced by physical noise in memory cells. This framework integrates polar coding techniques with write-once memory constraints to achieve high storage efficiency, extended device longevity, and robustness against bit-flip errors during repeated data updates. The invention is particularly applicable to systems requiring frequent data modifications under stringent reliability requirements, such as solid-state drives, embedded storage systems, and long-term archival memory architectures.

## BACKGROUND

The concept of coding for rewriting has emerged as a critical enabler for improving the endurance and performance of non-volatile memory technologies. Traditional flash memory systems require costly and wear-inducing block erasures before data can be rewritten, which limits their operational lifespan and increases latency. To mitigate this, the write-once memory (WOM) model was introduced, wherein data are encoded such that cell states may only transition from a lower to a higher level, effectively prohibiting backward changes. This constraint allows multiple logical writes to be mapped onto a single physical block without triggering erasure, thereby preserving cell integrity and reducing power consumption. Early approaches to WOM coding employed linear codes, coset constructions, and geometric designs to maximize the number of rewrites achievable within a fixed number of cells. Subsequent advances demonstrated that polar codes could be adapted to achieve the theoretical capacity of binary WOM channels by exploiting channel polarization and frozen set selection. However, these prior methods assumed ideal, noiseless environments, rendering them unsuitable for real-world memory systems where physical phenomena such as charge leakage, read/write disturb, and inter-cell interference introduce hard errors that flip stored bit values. While some efforts have attempted to incorporate error correction into WOM codes, they have been limited to correcting only a small number of errors—typically one to three—and have failed to scale to the error rates and rewrite frequencies required by modern storage applications. Recent work has begun to explore the intersection of error-correcting codes and rewriting, but no prior method has established a unified framework capable of simultaneously supporting arbitrary numbers of rewrites and correcting a substantial volume of errors using a single, structured, and analytically tractable code design. The absence of such a joint solution has created a critical gap in the ability to deploy rewriting techniques in high-reliability storage systems, where both endurance and data integrity must be guaranteed over extended operational lifetimes. A fundamental challenge remains in reconciling the conflicting requirements of rewriting, which demands controlled unidirectional state transitions, with error correction, which requires the ability to detect and recover from arbitrary bit flips. This conflict has hindered the development of practical, high-capacity, multi-write memory systems that operate reliably under real-world noise conditions.

## SUMMARY

The present invention introduces a novel coding scheme that jointly enables rewriting and error correction in non-volatile memory systems through the use of polar coding techniques. The invention constructs a unified encoding and decoding framework that simultaneously satisfies the write-once constraint and corrects a significant number of bit-flip errors introduced by noisy memory channels. The core innovation lies in the integration of two frozen sets—one derived from the WOM channel characteristics and another from the error channel—such that their intersection enables a nested code structure that preserves both rewriting capability and error resilience. The code construction employs a dithered polar encoding process, wherein a pseudo-random bit sequence is combined with cell states to transform the physical WOM channel into an equivalent binary symmetric channel, allowing standard polar decoding to be applied. The encoder determines new cell levels by mapping input messages to codewords that lie above the current cell state while respecting the frozen set constraints of both the WOM and error channels. The decoder recovers the original message by first applying a successive cancellation algorithm to the dithered noisy cell values, leveraging the nested structure to infer information bits even in the presence of errors. The invention further extends to multi-level cell architectures and general noise models by adapting the frozen set selection and channel degradation analysis. A lower bound on the achievable sum-rate is derived analytically, demonstrating that the proposed code approaches theoretical capacity limits as the number of cells increases. The method supports any number of rewrites, and for each rewrite, the encoder computes the optimal cell state transitions to maximize the information density while maintaining error-correcting capability. The decoding process is robust to noise and does not require knowledge of prior writes, enabling stateless operation. A memory system embodying the invention includes a polar encoder, a WOM channel interface, and a list-decoding unit that enhances reliability through probabilistic candidate selection. The invention further introduces a modified encoding strategy for cases where the error channel’s frozen set is not fully contained within the WOM channel’s frozen set, utilizing additional memory cells to store residual information bits. The resulting system achieves high storage efficiency, extended device endurance, and strong error correction performance without requiring block erasures between writes.

## DETAILED DESCRIPTION

The following detailed description presents the invention in its preferred embodiments, with reference to the accompanying figures, which are intended to illustrate, not limit, the scope of the invention. The drawings depict functional components, signal flows, and algorithmic steps that together form a complete system for joint rewriting and error correction in non-volatile memory. The illustrative embodiments are described with sufficient specificity to enable a person skilled in the art to make and use the invention without undue experimentation. The scope of the disclosure encompasses all variations, modifications, and extensions that fall within the claims, including those that adapt the framework to multi-level cells, different noise models, or alternative polar code constructions. The invention introduces a method for joint rewriting and error correction that operates by first defining a WOM channel parameterized by the fraction of unset cells and the fraction of cells to be set during a rewrite. A dither sequence, known to both encoder and decoder, is applied to the current cell state to transform the physical WOM channel into an equivalent binary symmetric channel. The encoder then computes a set of frozen indices based on the WOM channel and the error channel, and determines which bits are constrained to fixed values and which carry information. The encoding process ensures that the new cell state dominates the previous state, satisfying the unidirectional constraint. The decoder receives a corrupted version of the cell state and applies a successive cancellation algorithm to recover the original message, using the dither to reverse the transformation and the frozen sets to infer unknown bits. The method minimizes cell level changes by selecting the minimal sufficient transition that encodes the desired message, thereby preserving cell longevity. A first probabilistic model is employed to compute new cell levels based on the frozen set of the WOM channel, while a second probabilistic model incorporates the frozen set of the error channel to refine the selection. A binary matrix AN×N is defined as the polar generating matrix, and a dither vector is generated as a pseudo-random sequence with independent, uniformly distributed bits. The vector y is computed as the XOR of the noisy cell state and the dither, and the encoded bits are derived through recursive channel polarization functions. Base cases for the polar transform are defined recursively using known formulae, and the likelihood values L_N^(i) are computed to guide decoding decisions. The WOM cell levels are defined as binary states that may only increase, and the error correction method operates by treating the dithered cell state as a noisy codeword of a polar code. The polar code generating matrix is used to map information bits to codewords, and the frozen set FWOM is determined from the WOM channel, while FC is determined from the error channel. The error distribution is modeled as a binary symmetric channel, and the binary vector properties are exploited to ensure that the encoded message lies within the valid codeword space. The polar code decoding algorithm recovers the original data values by sequentially computing the likelihood of each bit, using the known frozen values and the received noisy observations. A list-decoding algorithm is introduced to enhance reliability, maintaining a set of candidate bit sequences and updating the list based on accumulated likelihoods. The most likely element is selected from the list to recover the data bits, and the process is repeated with refined likelihoods to improve accuracy. The stored data error-correcting code is defined by the nested structure of the frozen sets, and a list size parameter controls the trade-off between complexity and performance. The matrix AN×N is applied to compute intermediate values, and the vector W_N^(i) is recursively evaluated to determine the channel polarization. The value of ui is computed using the list-decoding algorithm, and the data bits are recovered by extracting the information bits from the decoded sequence. The error-correcting code is further specified by its ability to handle erasures and multi-level cells, and the decoding process is extended to accommodate q-level cell states by applying the same principles level-by-level. The encoding and decoding methods are implemented in hardware or software, and the memory system includes a controller that manages communication with a host device, supervises data transfers, and executes the encoding and decoding algorithms. The system may be implemented as part of a computing device with a processor, system memory, and interface controllers, and the algorithms may be executed as program instructions stored in non-volatile memory. The invention enables a memory device to be rewritten multiple times while correcting errors, without requiring block erasures, thereby significantly extending the operational lifetime of the storage medium. The method is applicable to flash memory, phase-change memory, and other non-volatile technologies where unidirectional state transitions and noise resilience are critical. The invention provides a practical, scalable, and analytically grounded solution to the long-standing problem of combining rewriting and error correction in memory systems.

### VII. Additional Example Embodiments

The invention may be embodied in a data storage device configured to perform the methods described herein, wherein the device includes a memory array composed of non-volatile cells, a memory controller operatively coupled to the memory array, and a microcontroller that executes the encoding and decoding algorithms. The memory controller manages communications with the memory via a write device that enforces the unidirectional cell level transitions, and with a host device via a host interface that receives data for storage and transmits retrieved data. The controller supervises data transfers between the host and the memory, and includes a data buffer for temporarily storing values during encoding and decoding operations. An Error Correcting Code (ECC) block is integrated into the controller to maintain and apply the polar code structure during both writing and reading cycles. The controller performs error correction operations by executing the polar decoding algorithm, including list-decoding procedures, to recover data from noisy cell states. The operations for operating the data storage device include reading current cell levels, generating a dither sequence, computing new cell levels using the frozen sets, writing the new levels into memory, and decoding the stored data using the dither and the polar code structure. The encoding and decoding operations may be implemented in software executed by a processor, or as dedicated control logic within the memory controller. The processor may be a microprocessor, microcontroller, or digital signal processor, and may include multiple levels of caching, processor cores, and registers. The memory controller may be integrated into the processor or implemented as a separate component, and the system memory may include volatile and non-volatile elements. The operating system and applications running on the computing device may include the encoding and decoding algorithms as executable programs, and the program data may include the dither sequences, frozen set tables, and polar code parameters. The computing device may be a personal computer, a small-form-factor portable electronic device, or a server system, and may include a memory bus for communication between the processor and system memory. Output devices such as graphics and audio processing units may be connected via peripheral interfaces, and communication with other devices may be facilitated by a network controller. The data storage device may be removable or non-removable, and may utilize various computer storage media including flash memory, solid-state drives, or phase-change memory. The system may be configured to operate with q-level cells, and the level-by-level approach may be applied to extend the method to multi-level cell architectures. The invention may be implemented entirely in hardware, entirely in software, or as a hybrid system, and the algorithms may be stored as computer-readable instructions on tangible, non-transitory media. The memory system may be embedded in a wide range of computing platforms, including mobile devices, data centers, and automotive systems, providing enhanced endurance and reliability for applications requiring frequent data updates under noisy conditions.
