## FIELD OF THE DISCLOSURE

- The present disclosure pertains to the parsing problem in computational systems, which arises whenever structured textual input must be analyzed and transformed into a formal representation for further processing. Parsing is a foundational operation in software systems that process human-readable or machine-generated syntax, such as programming languages, configuration files, data interchange formats, communication protocols, and domain-specific languages. The importance of parsing stems from its role as the initial and often critical stage in the interpretation of syntactically structured data; errors or inefficiencies at this stage propagate throughout downstream systems, leading to security vulnerabilities, incorrect computations, or system failures. Parsing applications span nearly every domain of modern computing, including web browsers that interpret HTML and JavaScript, servers that process HTTP requests and XML payloads, database engines that parse SQL queries, network protocols that validate message formats, and compilers that translate high-level source code into executable instructions. Despite its ubiquity, existing parsing technologies suffer from critical limitations: most parser generators produce opaque, unverifiable code that is difficult to audit, lack formal guarantees of correctness or termination, and cannot ensure that the generated parser will behave predictably across all possible inputs. Conventional approaches based on context-free grammars and recursive descent parsing are prone to ambiguity, non-termination due to left-recursion, and inconsistent semantic behavior. Furthermore, the integration of semantic actions—functions that compute structured outputs from parsed inputs—is typically ad hoc, unverified, and disconnected from the formal semantics of the grammar itself. These limitations render existing parsers unsuitable for safety-critical systems where reliability, predictability, and provable correctness are non-negotiable requirements.

## BACKGROUND OF THE DISCLOSURE

- The parsing process traditionally involves the transformation of a sequence of characters into a hierarchical structure that reflects the syntactic rules of a formal language, typically through the application of a grammar and a corresponding parsing algorithm. Parser generators automate this process by accepting a grammar specification—often expressed in Backus-Naur Form or regular expressions—and producing executable code capable of recognizing and processing inputs conforming to that grammar. Context-free grammars have long served as the standard formalism for describing syntactic structure, enabling the specification of recursive and nested constructs through production rules. However, context-free grammars are inherently ambiguous, requiring external disambiguation mechanisms such as operator precedence or associativity declarations, which are neither formally integrated nor guaranteed to be consistent with the grammar’s semantics. Formal verification of parsers generated from context-free grammars remains largely unaddressed, as the generated code is typically large, complex, and opaque, consisting of massive state tables or deeply nested recursive functions that defy manual inspection or automated proof. The resulting parsers are often treated as black boxes, with correctness assumed rather than proven, leaving critical systems exposed to undetected parsing errors that may lead to injection attacks, data corruption, or denial-of-service conditions. Moreover, the integration of semantic actions into context-free grammars is not formally grounded; these actions are usually written in an unrelated programming language and executed as side effects during parsing, with no formal connection to the grammar’s logical structure. As a result, there is no mechanism to verify that semantic actions terminate, preserve type safety, or correctly map parsed fragments to their intended representations. The absence of a unified, formally verified framework for parsing that simultaneously guarantees syntactic correctness, semantic fidelity, and computational termination has created a persistent gap between theoretical rigor and practical deployment in safety-critical software.

## SUMMARY

- The invention introduces a novel parser creation system that enables the formal specification, verification, and certified extraction of parsers with total correctness guarantees. The system comprises a grammar input module that accepts a formal description of a language using extended parsing expression grammars augmented with semantic actions, a formalism module that encodes the semantics of parsing expressions and their associated semantic values in a dependently typed logical framework, a semantic action module that defines and type-checks functions responsible for computing structured outputs from parsed inputs, a checking module that performs static analysis to verify the well-formedness and termination properties of the grammar and its semantic actions, and a proof assistant module that integrates with a formal verification environment to derive mathematical proofs of correctness and termination. The system further enables the extraction of certified parser interpreters and parser generators from these verified formalizations, ensuring that the resulting code is not only functionally correct but also guaranteed to terminate on all possible inputs. The security benefits of this invention arise from the elimination of parsing-related vulnerabilities such as injection attacks, buffer overflows, and non-terminating loops, which are commonly introduced by unverified parsers. The parser generator method operates by first encoding a grammar and its semantic actions within a formal logical system, then proving that the grammar is well-formed and that all semantic actions terminate, and finally extracting executable code that is provably correct with respect to the original specification, thereby ensuring that the parser behaves exactly as intended under all conditions.

## DETAILED DESCRIPTION OF ILLUSTRATIVE EMBODIMENTS

### 1. Generals Principles of An Embodiment of the Invention

- The invention embodies a parser generator system that operates entirely within a formal logical framework, enabling the creation of parsers with mathematically proven correctness and termination properties. The system begins with a grammar input module that accepts a formal specification of a language in the form of an extended parsing expression grammar, which includes terminals, non-terminals, and parsing expressions that define how input strings are matched. The checking module performs two distinct analyses: one to verify that the grammar is well-formed, meaning that every non-terminal and parsing expression either succeeds or fails on all possible inputs without entering an infinite loop, and another to confirm that the grammar is syntactically well-formed, ensuring that all references to non-terminals are defined and that no circular or undefined dependencies exist. The semantic action module associates each parsing expression with a function that computes a semantic value, such as an abstract syntax tree or a numerical result, and ensures that these functions are well-typed and compatible with the structure of the parsed input. The formalism module encodes the operational semantics of parsing expressions using a formal language grounded in type theory, defining how each operator—sequence, choice, repetition, and predicate—behaves with respect to input strings and semantic values. The advantages of this embodiment lie in its ability to guarantee that the resulting parser will never hang, crash, or produce incorrect results, regardless of the input provided. The grammar is extended with semantic actions that are not merely appended but are formally integrated into the parsing semantics, so that every successful parse yields a value whose type and structure are logically entailed by the grammar. The termination of the entire parsing process is proven by demonstrating that the grammar is well-formed, which ensures that no left-recursive or non-terminating derivation sequences can occur. The invention introduces parsing expression grammars as the foundational formalism, defining parsing expressions as inductive constructs over terminals and non-terminals, and defining a parsing expression grammar as a finite mapping from non-terminals to parsing expressions with a designated start symbol. An illustrative example of a simple grammar for mathematical expressions includes non-terminals for expressions, terms, factors, numbers, and whitespace, with parsing expressions that match digits, operators, parentheses, and optional whitespace, all combined using prioritized choice and greedy repetition to ensure deterministic parsing behavior.

### Example 1

- An illustrative example of a simple grammar for mathematical expressions defines a parsing expression grammar with five non-terminals: ws, number, term, factor, and expr. The ws non-terminal consumes any sequence of whitespace characters, the number non-terminal matches one or more decimal digits and converts them into a numerical value, the factor non-terminal matches either a parenthesized expression or a number, the term non-terminal matches a sequence of factors separated by multiplication or division operators, and the expr non-terminal matches a sequence of terms separated by addition or subtraction operators. Each production is associated with a semantic action that computes the value of the expression: for instance, when parsing a sequence of the form factor * term, the semantic action multiplies the value of the factor by the value of the term. The grammar is designed to be right-associative to avoid left-recursion, and all operators are implemented using prioritized choice to ensure deterministic parsing. The semantic actions are typed functions that return values of appropriate types, such as integers or floating-point numbers, and are formally verified to terminate and preserve type consistency. This grammar, when processed by the invention’s system, yields a parser that not only recognizes valid mathematical expressions but also evaluates them correctly and terminates on all inputs, including malformed or malicious strings.

### 2. Description of Some Embodiments

- The invention encompasses a system and method for creating a parser generator that extends parsing expression grammars with semantic actions, enabling the generation of parsers that compute structured outputs while maintaining formal guarantees of correctness and termination. Default semantic actions are defined for basic types such as characters, lists, options, and unit values, allowing semantic values to be propagated through the parsing process without requiring explicit annotations in every production. A new construction is introduced to convert semantic values between types, enabling the coercion of values when the types of alternatives in a choice operator differ. The system defines a hierarchy of types including Type, True, char, list α, and α*β, which form the basis for the semantic values associated with parsing expressions. Parsing expressions are extended to incorporate semantic values, resulting in a family of extended parsing expressions indexed by their output type, and the set of all such expressions is denoted as Δα. The extended parsing expression grammar, or EPEG, is defined as a tuple comprising terminals, non-terminals, type assignments, parsing expressions, and a start symbol, with all components formally typed and interdependent. The termination of parsing expression grammars is proven by demonstrating that every expression either consumes input or fails, thereby preventing infinite recursion. The expression set of a grammar is defined as the collection of all sub-expressions appearing in its productions, and three classes of properties—whether an expression can succeed without consuming input, succeed after consuming input, or fail—are derived through a fixed-point iteration over the expression set. Inference rules are defined to propagate these properties, and the semantics of these properties are summarized to establish the conditions under which a grammar is considered well-formed. Well-formedness analysis is performed iteratively, beginning with an empty set and expanding it until no new expressions can be classified, and a grammar is declared well-formed if the set of all its expressions equals the set of well-formed expressions. Completeness of the grammar is proven by induction on the structure of expressions and the length of input strings, ensuring that every possible input leads to a defined outcome. An example of extending a grammar with semantic actions demonstrates how a simple arithmetic expression grammar is augmented with functions that compute the value of the expression as it is parsed. The interpretation of parsing expression grammars is formalized in a proof assistant, and a procedure is developed to check the well-formedness of any given grammar. A generic interpreter for parsing input is constructed, proven to terminate and produce correct results, and then extracted from the formalization into executable code. A certified parser interpreter is produced by extracting the interpreter from the proof assistant, and a parser generator is developed by formalizing the process of translating a textual grammar into its internal representation. A parser for parsing expression grammars themselves is constructed, enabling the system to parse grammars written in a human-readable syntax. A parser for a target language Q is developed, and the well-formedness of a given grammar is checked before parsing. The termination of semantic actions is verified using a termination checker for language Q, and a restricted language Qfin is chosen to ensure that all semantic actions are guaranteed to terminate. A standard library of parsing primitives is developed and formally verified, and the total correctness of generated parsers is proven, establishing that they are both correct and terminating. The differences between this system and prior parser generators are summarized by highlighting the formal guarantees, the integration of semantic actions into the logical framework, and the extraction of certified code rather than unverified compilation.

### 3. Summary of Three Embodiments of the Invention

- The invention comprises three distinct embodiments, each providing a progressively more powerful and self-contained mechanism for generating certified parsers. The first embodiment defines a parser interpreter with semantic actions, where a formal grammar is expressed in a proof assistant, and an interpreter is constructed that executes the grammar directly, producing semantic values as it parses. The formal semantics of the extended parsing expression grammar are defined, a procedure is developed to verify the feasibility of the grammar, and the interpreter is proven correct and terminating, then extracted into executable code with guaranteed behavior. The second embodiment defines a parser generator with semantic actions, where the grammar is specified in a high-level format, translated into an internal representation, and then compiled into a parser in a target language. The target language Q is formally defined with its own semantics, a library of basic datatypes is developed, and parsers for both the grammar format and the target language are proven correct. A termination checker for semantic actions in Q is developed, and the parser generator is proven to produce parsers that are both correct and terminating, then extracted as a certified tool. The third embodiment extends the parser interpreter to include parsing traces, where each step of the parsing process is recorded as a trace, enabling post-hoc analysis, debugging, and verification of the parsing behavior. The extended grammar includes parsing tags that annotate each production with trace metadata, and the interpreter is modified to accumulate these traces while preserving correctness and termination guarantees. Each embodiment is formally verified within the proof assistant, and the extracted code from each is guaranteed to behave exactly as specified, eliminating the possibility of parsing-related failures, security vulnerabilities, or non-terminating behavior.
