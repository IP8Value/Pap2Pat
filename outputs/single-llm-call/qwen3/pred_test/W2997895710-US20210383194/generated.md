## BACKGROUND

Event stream data arises in diverse domains where discrete occurrences unfold irregularly over continuous time, such as in social media interactions, clinical patient records, financial transaction logs, sensor networks in industrial IoT systems, and cybersecurity intrusion sequences. These data streams are inherently dynamic, non-uniform, and multivariate, with each event characterized by a type and a precise timestamp. Traditional statistical models for such data often rely on parametric assumptions about the functional form of event arrival rates, such as exponential decay in Hawkes processes or piecewise-constant intensities in graphical event models. However, these assumptions limit expressiveness and fail to capture complex, data-driven temporal dependencies that may involve delayed excitation, non-monotonic influence, or multi-scale temporal patterns. Moreover, existing approaches typically treat only the occurrence of events as informative signals, disregarding the substantial information contained in the absence of events—namely, the duration between successive events. This omission leads to incomplete representations of system behavior, particularly in high-stakes environments like healthcare monitoring or predictive maintenance, where the prolonged absence of an expected event can be as diagnostically significant as its occurrence. There exists a critical need for a modeling framework that learns the full temporal structure of event dynamics without imposing restrictive parametric forms, while simultaneously leveraging both positive and negative evidence to improve accuracy, generalization, and interpretability.

## SUMMARY

The present invention introduces a novel multi-channel neural graphical event model, referred to as MCN-GEM, for the analysis of multivariate event stream data in continuous time. The MCN-GEM system is a deep learning architecture that dynamically models the conditional intensity function of each event type by integrating recurrent neural networks with spatiotemporal attention mechanisms and a unique mechanism for encoding negative evidence through the introduction of synthetic, or “fake,” event epochs within inter-event intervals. The MCN-GEM storage medium comprises a non-transitory computer-readable medium storing program instructions that, when executed by one or more processors, cause the system to receive time-stamped event epochs, generate fake epochs to represent the absence of observable events, feed both real and fake epochs into a multi-channel long short-term memory network, compute hidden states for each event type across time, apply spatial and temporal attention to aggregate historical influences, and output a continuous-time conditional intensity function for each event label. The invention encompasses multiple distinct subject-matters, including a method for modeling event streams, a system for implementing such modeling, a computer-readable storage medium containing executable instructions, and a computer-implemented process for training and deploying the model. The combination of features—including the multi-channel internal state representation, the use of fake epochs to reinforce negative evidence, the spatiotemporal attention mechanism for selecting relevant historical events, and the non-parametric estimation of intensity functions—collectively enable a level of modeling fidelity and adaptability unattainable by prior approaches. The detailed description that follows elaborates on the architecture, training methodology, and practical applications of the MCN-GEM system, including its implementation in hardware and cloud-based environments. ## DETAILED DESCRIPTION

Event datasets consist of temporally ordered sequences of discrete events, each associated with a label indicating its type and a timestamp indicating its occurrence in continuous time. An event dataset is formally defined as a collection of tuples (l_i, t_i), where l_i belongs to a finite set L of event labels and t_i is a non-negative real number representing the time of occurrence. Streaming algorithms for such data must process events sequentially and in real time, updating internal representations as new events arrive. The fundamental challenge lies in capturing the history-dependent nature of event arrival rates, where the probability of an event occurring at any moment is influenced by the entire prior sequence of events. Conventional models often assume a fixed functional form for this dependence, such as exponential decay, which may not reflect the true underlying dynamics. The present invention overcomes this limitation by introducing a fully data-driven, non-parametric approach that learns the temporal influence structure directly from the data. The multi-channel neural graphical event model (MCN-GEM) is a deep learning architecture designed to model the conditional intensity function λ_kt|H_t for each event type k, given the strict history H_t of all prior events. The model comprises a recurrent neural network with long short-term memory cells that evolve internal states in response to each event, whether real or synthetic. To account for the continuous passage of time between events, the model introduces fake epochs—synthetic events with a dedicated label M+1—uniformly distributed within each inter-event interval. These fake epochs serve as temporal sampling points that allow the internal states to evolve during periods of no observable activity, thereby encoding negative evidence and enabling a more accurate approximation of the integral terms in the log-likelihood function. The graphical event model (GEM) framework provides the structural foundation, where event types are treated as nodes in a directed graph, and historical events influence the intensity of descendant events. The log-likelihood of the event dataset is computed under the assumption of piecewise-constant intensity between consecutive events, real or fake, and is expressed as the sum of the logarithm of the intensity at each event epoch minus the integral of the intensity over the observation period. A deep neural network, referred to as the λ-network, maps the aggregated hidden states to the conditional intensity vector. The sequence modeling approach employs LSTM cells to capture long-range dependencies, with each cell maintaining a hidden state and a cell state that are updated at every event epoch. The model represents continuous time by concatenating the one-hot encoded event label with its timestamp as the input to the LSTM. The hidden state h_ki for event type k at epoch i is computed using shared LSTM parameters across channels, allowing for efficient parameterization. Attention models are employed to determine which historical events most significantly influence the current intensity. Spatial attention captures dependencies between different event types, while temporal attention identifies which past time points are most relevant. The net hidden state for each event type is computed as a weighted average of historical hidden states stored in a memory bank, with weights derived from a learned alignment function comparing the current hidden state to each historical state. These net hidden states are then fed into two feed-forward layers with ReLU and softplus activation functions to produce the final intensity values. The training objective is the regularized log-likelihood, augmented by a classification loss to distinguish real from fake epochs and an L2 weight penalty to prevent overfitting. The system is implemented on hardware configured with processors, memory, and input/output interfaces, and may be deployed in cloud computing environments using infrastructure-as-a-service, platform-as-a-service, or software-as-a-service models. The MCN-GEM is particularly suited for integration with IoT devices, where sensors such as motion, temperature, humidity, pressure, and acoustic sensors generate event streams that benefit from the model’s ability to detect both the presence and absence of critical phenomena. The computer-readable storage medium contains instructions that, when executed, perform the steps of receiving time-stamped events, generating fake epochs, computing hidden states, applying attention, and outputting intensity functions. The invention further encompasses variations in the number of fake epochs, the size of the attention memory bank, the architecture of the λ-network, and the method of integrating spatial and temporal attention.
