## BACKGROUND

Image-Based Visual Hull (IBVH) is a widely adopted technique for reconstructing three-dimensional object geometry from a set of two-dimensional silhouette images captured from multiple viewpoints. This method leverages the principle of Shape-from-Silhouette, wherein each image contributes a cone of possible object locations defined by the projection of the object’s silhouette through the camera’s pinhole model. The intersection of these cones across all input views forms a convex approximation of the object known as the visual hull. While IBVH offers computational efficiency and high fidelity in texture synthesis compared to volumetric or mesh-based reconstruction methods, it is fundamentally constrained by its inability to represent concave features and to accurately reconstruct surfaces that lie outside the field of view of the primary imaging setup. Conventional IBVH systems require all reference images to be acquired from positions surrounding the object within a single, fixed coordinate frame. This restriction prevents the capture of under-surface geometry—such as the base of a vessel or the underside of a sculpted artifact—without physically repositioning the object, which introduces misalignment between image sets and necessitates complex registration procedures. Furthermore, when the object contains inward-curving regions, such as the interior of a cup or the recessed cavity of a container, the silhouette-based intersection process fails to distinguish between occluded concavities and protruding convexities, resulting in the erroneous filling of these regions with convex geometry. These limitations severely restrict the applicability of IBVH in domains where surface integrity is critical, including cultural heritage digitization, forensic artifact analysis, and high-fidelity virtual exhibition systems. Existing approaches that attempt to mitigate these issues through mirror-assisted imaging or multi-camera arrays either fail to resolve the concave problem entirely or require extensive calibration, specialized hardware, or post-processing that undermines the method’s original efficiency. No prior system has successfully integrated a unified, computationally lightweight framework capable of simultaneously reconstructing both the bottom surface and internal concavities while preserving the photorealistic texture synthesis and view-dependent rendering properties inherent to IBVH.

## SUMMARY

A novel method for reconstructing three-dimensional object geometry with accurate representation of concave regions and under-surfaces is disclosed, wherein a virtual inside-out imaging framework is employed to extend the conventional Image-Based Visual Hull (IBVH) technique. The method utilizes a physical imaging platform comprising a transparent planar surface and a reflective planar surface, arranged such that a single capture session yields both exterior and interior-facing silhouette data without requiring object repositioning or coordinate frame alignment. The disclosed system includes a storage medium configured to retain reference image data, virtual image data, camera calibration parameters, and silhouette boundary information, as well as a processing apparatus comprising a pre-processing module, a virtual-image synthesis module, and a point relocation module, each operatively connected to a central processor and system memory. An alternative embodiment of the apparatus integrates these modules into a single computing device with a programmable processor core, system memory, memory bus, and cache hierarchy, wherein the modules are implemented as software instructions executable by the processor to perform the reconstruction algorithm. The method further comprises the generation of virtual inside-out images by computing the mirror-symmetric camera pose relative to the reflective surface, thereby transforming a captured under-surface image into a virtual image that conforms to the same coordinate system as the primary reference images. These virtual images are then incorporated into the IBVH reconstruction pipeline as if they were physically captured from the corresponding virtual viewpoint. Additionally, for concave regions, a virtual camera is positioned internally within the object’s geometry, and a virtual silhouette image is synthesized from the perspective of this internal viewpoint, effectively creating a negative silhouette cone that, when subtracted from the aggregate visual hull, reveals the true concave topology. The method disclaims any requirement for volumetric voxelization, prior 3D mesh templates, or manual segmentation of interior surfaces, and further disclaims the necessity of multi-camera synchronization, active lighting, or depth sensors. The disclosed approach preserves the computational efficiency of boundary-based IBVH while enabling the reconstruction of previously inaccessible surface features through passive optical reflection and virtual camera synthesis.

## DETAILED DESCRIPTION

Concave object modeling, as disclosed herein, refers to the computational reconstruction of three-dimensional geometry that includes inward-curving surfaces, such as the interior of a vessel, the recessed cavity of a container, or the under-surface of an artifact, which cannot be resolved by conventional silhouette-based methods due to their occlusion from external viewpoints. The method for reconstructing an image of an object begins with the acquisition of multiple reference images from different external viewpoints, each captured using a calibrated camera, followed by the segmentation of each image into foreground silhouette and background regions. A planar glass surface is positioned above a planar mirror, and the object is placed upon the glass such that its underside is reflected in the mirror. A single additional image is captured from above, containing both the object’s top surface and its mirrored reflection, thereby providing a simultaneous capture of exterior and underside geometry. The silhouette of the underside is extracted from the reflected portion of this image and transformed via geometric mirroring to generate a virtual image that corresponds to a virtual camera positioned symmetrically below the mirror plane. This virtual image, along with its derived camera parameters, is integrated into the IBVH reconstruction process as an additional reference view, enabling the accurate reconstruction of the object’s bottom surface. For concave regions, a virtual camera is positioned within the object’s interior, aligned with the direction of a reference image captured from above the concavity. A virtual silhouette image is synthesized by projecting the silhouette of the concave region onto the image plane of this internal virtual camera, creating a negative silhouette cone that, when subtracted from the aggregate visual hull, removes the erroneously reconstructed convex bulge and reveals the true concave topology. The rendering results of conventional processing methods, as illustrated in prior art, exhibit distorted geometry at the object base, where the bottom appears as a conical protrusion, and within concave regions, where the interior surface is filled with convex geometry and lacks texture fidelity. In contrast, the disclosed approach produces a photorealistic reconstruction in which the bottom surface is rendered as a flat or contoured plane, correctly preserving texture and geometry, and concave regions are accurately delineated with their internal surface texture intact. The virtual camera is defined by its position, orientation, and intrinsic parameters, which are derived mathematically from the corresponding real camera’s parameters through reflection symmetry operations. Texture information is retrieved from the original reference images by projecting the reconstructed 3D points onto the image planes of the real cameras and applying weighted color blending based on viewing angle proximity. The silhouette processing module extracts foreground boundaries using adaptive thresholding and edge detection. The IBVH technique is implemented as a boundary-based intersection algorithm operating in image space. Shape-from-silhouette 3D reconstruction is performed via ray-casting and silhouette cone intersection. The silhouette cone is defined as the set of 3D rays emanating from the camera center through each pixel of the silhouette. The Image-Based Visual Hull process computes the intersection of these cones across all reference views. The visual hull is represented as a collection of 3D line segments corresponding to the boundaries of intersecting cones. Protuberant shaped distortion is eliminated by subtracting the virtual negative silhouette cone from the aggregate visual hull. The 3D coordinates of the concave region boundary are determined by intersecting the viewing ray with the modified visual hull after subtraction. Image segmentation is performed using background subtraction and morphological operations. Positions on the 2D reference picture are projected back to 3D space using epipolar geometry and camera calibration matrices. The position for the virtual camera is chosen to lie within the concave region, aligned with the optical axis of the capturing camera. Camera parameters of the virtual camera are derived by mirroring the rotation matrix and translating the position vector across the mirror plane. The virtual inside-out image is generated by rendering the silhouette of the concave region from the perspective of the virtual camera, using the intrinsic parameters of the original camera and the computed extrinsic parameters of the virtual camera.
