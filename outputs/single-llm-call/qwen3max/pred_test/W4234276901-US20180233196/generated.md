# DESCRIPTION

## TECHNOLOGICAL FIELD

The present invention relates generally to high-density crossbar memory arrays, and more particularly to methods and apparatus for efficiently reading data from gateless resistive random-access memory (ReRAM) crossbar arrays while mitigating the adverse effects of sneak-path currents. Crossbar memory architectures, which consist of a grid of intersecting conductive rows and columns with programmable resistive memory elements—such as memristors—at each junction, offer significant advantages in terms of scalability, density, and compatibility with back-end-of-line (BEOL) fabrication processes. These attributes make them promising candidates for next-generation non-volatile memory technologies. However, the absence of selection transistors or other gating mechanisms in high-density implementations introduces a critical challenge: parasitic current paths, known as sneak paths, that flow through unselected memory cells during read operations. These sneak paths distort the sensed signal, obscure the true state of the target memory cell, and consume significant power. The invention disclosed herein addresses these limitations by introducing a novel single-stage readout technique that leverages the spatial correlation of sneak-path currents across rows and columns, combined with adaptive thresholding and minimal auxiliary circuitry, to enable accurate, low-power, and high-throughput memory access in large-scale crossbar arrays.

## BACKGROUND

The relentless demand for higher memory density, lower power consumption, and faster access speeds has driven extensive research into emerging memory technologies beyond conventional CMOS-based solutions. Among these, resistive random-access memory (ReRAM), particularly when implemented in a crossbar architecture, presents a compelling alternative due to its simple two-terminal structure, nanoscale scalability, and potential for three-dimensional integration. In a typical ReRAM crossbar array, each memory cell comprises a memristive device whose resistance can be reversibly switched between a high-resistance state (HRS or “OFF,” representing a logical ‘0’) and a low-resistance state (LRS or “ON,” representing a logical ‘1’) by applying appropriate voltage pulses. Despite these advantages, the lack of individual cell selectivity in dense, gateless crossbar arrays leads to the so-called sneak-path problem. During a read operation, when a voltage is applied across a selected row and column to interrogate a specific target cell, unintended current flows through alternative parallel paths formed by other cells in the same row and column. This sneak-path current adds to or subtracts from the desired cell current, resulting in a sensed signal that is a composite of both contributions. Because the magnitude of the sneak-path current depends on the unknown data pattern stored across the entire array—which is inherently random—the effective resistance seen during readout becomes stochastic. Consequently, the distributions of sensed currents corresponding to ‘0’ and ‘1’ states exhibit significant overlap, rendering conventional fixed-threshold readout schemes ineffective and error-prone. Prior approaches to mitigate sneak paths include the use of nonlinear devices with high OFF/ON ratios, application of half-select voltages, and multi-stage read algorithms that iteratively estimate and cancel sneak contributions. However, these methods often incur substantial overhead in terms of power, latency, or circuit complexity, thereby undermining the inherent benefits of the crossbar architecture. There remains a pressing need for a readout technique that achieves high accuracy with minimal energy expenditure and hardware resources, especially for large-scale arrays used in modern computing systems.

## BRIEF SUMMARY

The present invention introduces a single-stage readout technique for high-density gateless crossbar memory arrays that overcomes the limitations of prior art by exploiting the locality property inherent in memory access patterns and the spatial correlation of sneak-path currents. In typical computing workloads, data is accessed in contiguous blocks due to spatial and temporal locality, meaning that multiple bits within the same row or column are read in sequence. The invention capitalizes on this behavior by recognizing that the sneak-path resistance components associated with a given row (denoted Rr) or column (denoted Rc) remain nearly constant across different cells within that row or column, respectively. This constancy arises because the relative change in parallel resistance caused by swapping a single bit is negligible in large arrays with high OFF/ON resistance ratios. The method employs a power-efficient accessing mode based on a “connected terminals” configuration, wherein all unselected rows are connected to a first common node and all unselected columns are connected to a second common node, which are then biased to predefined voltages (e.g., VB = VDD/2). This configuration simplifies the equivalent circuit model of the array and enables precise control over sneak-path behavior. The invention further provides minimal control and sensing circuitry, including a virtual-ground sense amplifier and optional analog compensation circuits, to perform accurate read operations. To read a target memory cell, the method involves identifying its row and column coordinates, connecting the remaining rows to the first common node and the remaining columns to the second common node, biasing these nodes to the predefined voltages, and measuring the total sense current. The actual value of the target memory cell is then calculated by estimating and subtracting the component of the read value caused by sneak-path current. This estimation is achieved either by performing a multi-read operation on an initial memory cell in the row to solve for both the cell resistance and the row sneak resistance, or by reading a predefined dummy memory cell with a known resistance value stored in the same row. The dummy cell approach requires only a single read to calibrate the adaptive threshold for the entire row, significantly reducing latency. The invention also encompasses an apparatus configured to execute computer-executable instructions for carrying out these operations, as well as a computer program product embodying such instructions. The apparatus includes means for reading memory cells, calculating sneak-path current components, and determining actual cell values, thereby enabling efficient, error-free readout with near-optimal power and speed characteristics.

## DETAILED DESCRIPTION

The present patent application is structured to provide a comprehensive disclosure of the invention, beginning with an analysis of the sneak-paths problem and its underlying causes, followed by a detailed exposition of the proposed readout techniques, including adaptive-threshold methods, multi-read strategies for initial bits, and the use of predefined dummy bits. The description further covers power consumption characteristics, a figure-of-merit for evaluating readout efficiency, and the operational sequence performed by a computing device to implement the disclosed method.

### Sneak Paths Analysis

The sneak-paths problem fundamentally undermines the reliability and efficiency of gateless crossbar memory arrays. When a read voltage is applied to a selected row and column to interrogate a target cell, parasitic currents flow through all possible alternative paths that connect the selected row to the selected column via other memory cells. These sneak paths arise because every unselected cell in the selected row is connected in series with every unselected cell in the selected column, forming numerous parallel conduction routes. The total sneak current is thus a complex function of the entire data pattern stored in the array, which is typically random and unknown during readout. This randomness translates into a broad distribution of possible sneak currents for any given target cell state, causing severe overlap between the sensed current distributions for ‘0’ and ‘1’ states. Consequently, direct threshold-based discrimination becomes impossible without additional processing. Crossbar arrays can be accessed in two primary modes: “floating terminals,” where unselected rows and columns are left electrically floating, and “connected terminals,” where unselected rows are tied together to a common node and unselected columns are similarly connected to another common node. The floating terminals mode suffers from poor predictability and high variability in sneak-path behavior, as the floating nodes develop undefined potentials that depend intricately on the array data. In contrast, the connected terminals mode enforces well-defined boundary conditions, leading to a tractable equivalent circuit model comprising three dominant resistance components: Rr (row sneak resistance), Rc (column sneak resistance), and Ra (array sneak resistance). Notably, when the common nodes are biased to an intermediate voltage (e.g., VDD/2), the Ra component is effectively shorted out, simplifying the model to just Rr and Rc. This controlled environment is essential for exploiting the spatial correlation properties of sneak paths.

### Sneak-Paths Correlation

The spatial correlation of sneak-path resistances is a cornerstone of the present invention. Mathematical analysis reveals that for a given row, the row sneak resistance Rr is the parallel combination of all cells in that row except the target cell. If Non denotes the number of ON-state cells in the row (excluding the target), and ρ represents the OFF/ON resistance ratio of the memristive device, then the relative change in Rr when moving from one column to an adjacent column in the same row is approximately ΔR/R ≈ 1/(ρ · Non). Given that practical memristive devices exhibit high ρ values (often >100) and typical rows contain many cells (e.g., 512 or more), this relative change is exceedingly small—on the order of 1% or less—even for worst-case data patterns. Simulation results confirm that the maximum relative change in sneak-path resistance diminishes rapidly as array size increases and remains small across a wide range of data densities (i.e., percentages of ‘1’s per row or column). Therefore, Rr can be treated as effectively constant across all columns within a single row, and similarly, Rc is nearly invariant across all rows within a single column. Critically, while Rr and Rc are constant within their respective dimensions, they remain independent random variables between different rows and columns due to data randomness. This localized constancy enables the reuse of sneak-path estimates across multiple read operations within the same row or column, forming the basis for adaptive-threshold readout.

### Adaptive-Threshold Readout

Adaptive-threshold readout leverages both the sneak-paths correlation property and the memory locality principle observed in real-world computing systems. Memory locality dictates that data is fetched from main memory in contiguous blocks (e.g., cache lines of 64 bytes), meaning that sequential reads often occur within the same row or column of the crossbar array. By defining a unique read threshold for each row (or column) based on an initial calibration step, the invention ensures accurate discrimination between ‘0’ and ‘1’ states despite the presence of sneak currents. In the connected terminals configuration with VB biasing (e.g., VB = VDD/2), the target cell experiences the full read voltage VDD, maximizing the ON/OFF current difference, while the sneak-path components Rr and Rc experience a reduced voltage (VDD − VB), minimizing their contribution. The sense current Isense measured at the read terminal comprises the desired cell current Im plus a constant offset due to either Ir (row sneak current) or Ic (column sneak current), depending on whether sensing occurs from the row or column side. Because this offset is constant for all cells in the same row (or column), a single calibration measurement suffices to establish an adaptive threshold for the entire row (or column), enabling subsequent single-stage reads with high fidelity.

### Multi-Read for Initial Bits

The multi-read approach for initial bits provides a calibration mechanism for rows that do not contain predefined dummy bits. In this strategy, the first bit accessed in a given row—termed the “initial bit”—is read using a multi-stage technique capable of simultaneously solving for both the target cell resistance Rm and the row sneak resistance Rr. Such multi-stage methods, known in the art, may involve iterative voltage sweeps or write-verify cycles to isolate the cell’s intrinsic characteristics. Once Rr is estimated from the initial bit readout, it is stored and reused as a constant offset for all subsequent “regular bits” in the same row. Each regular bit is then read in a single stage: the sense current is measured, the precomputed Ir component is subtracted, and the residual current is compared against a fixed reference to determine the bit value. The readout sequence proceeds row-wise (or column-wise, depending on sensing orientation), with each new row requiring one initial bit calibration. Although this method incurs extra latency for the initial bit, the overhead is amortized over the entire row, especially for large block transfers typical in memory hierarchies.

### Predefined Dummy Bits

The predefined dummy bits approach offers a more time-efficient alternative to multi-read initial bits. Here, each row includes a dedicated dummy memory cell programmed during fabrication to a known resistance state (e.g., always ‘0’ or always ‘1’). Since the dummy cell’s resistance Rm is known a priori, a single read operation yields a direct measurement of the row sneak current Ir (or Rc, if column-oriented). This measured sneak current serves as the adaptive threshold offset for all regular bits in the row. The dummy cell may be implemented as a static resistor rather than a programmable memristor, eliminating variability concerns and ensuring long-term stability. The organization of dummy bits is flexible; they may be placed in a dedicated column or interleaved within the data array. Simulation results demonstrate that for practical array sizes (≥256 kb) and typical cache line lengths (≥512 bits), the average number of read operations per data bit converges rapidly to one, with only minor ripples caused by the occasional dummy bit access at row boundaries. The area overhead is negligible, as dummy bits constitute a tiny fraction of the total array (e.g., 1/512 for a 512-column array). Moreover, analog compensation circuits can be employed to directly compare the dummy cell current with the target cell current using capacitive sampling, eliminating the need for analog-to-digital conversion and further reducing circuit complexity and power.

### Crossbar Power Consumption

Sneak-path currents contribute significantly to the static power consumption of crossbar arrays during read operations. The connected terminals technique with VB = VDD/2 biasing dramatically reduces this undesirable power draw by exploiting the nonlinear I-V characteristics of memristive devices. At sub-threshold voltages (e.g., VDD/2), the resistance of OFF-state devices increases exponentially due to saturation effects, thereby suppressing sneak currents through high-resistance paths. Simulations confirm that this method achieves power consumption comparable to the floating terminals baseline while providing vastly superior readout accuracy. In contrast, grounded terminals techniques—which tie unselected lines to ground—result in much higher power dissipation due to larger voltage drops across sneak paths. The power savings of the present invention are particularly pronounced in large arrays, where metal line resistances begin to dominate and limit further increases in total power.

### Figure-of-Merit

To quantitatively evaluate the efficiency of various readout techniques, the invention defines a figure-of-merit (FoM) that combines density, power, and speed considerations. Specifically, FoM = (Array Density) / (Read Energy × Read Latency). Comparative analysis demonstrates that the disclosed adaptive-threshold methods achieve a FoM that is 7 to 24 times superior to existing gateless techniques, primarily due to their single-access-per-bit capability and minimal energy overhead. This metric underscores the invention’s ability to deliver high performance without sacrificing the density advantages of the crossbar architecture.

### Operations Performed by a Computing Device to Efficiently Perform Readout Operations

A computing device implementing the invention executes a sequence of operations to perform efficient readout. First, it identifies the row and column indices of the target memory cell. It then configures the array by connecting all unselected rows to a first common node and all unselected columns to a second common node. These nodes are biased to predefined voltages (e.g., VDD/2). The device reads the target cell’s sense current and, depending on the calibration strategy, either reads an initial bit using a multi-stage algorithm or reads a dummy bit with a known value. From the dummy or initial bit readout, it calculates the sneak-path current component (Ir or Ic). This component is subtracted from the target cell’s sense current to yield the actual cell current, which is then compared against a reference to determine the stored bit value. The process repeats for each cell in the access block, reusing the calibrated sneak-path estimate for all cells in the same row or column. The apparatus performing these operations includes sense amplifiers, voltage biasing circuits, and digital logic for threshold calculation and comparison. The key advantages of this technique include near-optimal throughput (approaching one read per bit), minimal hardware overhead, robustness to device variability, and significant power savings compared to prior art.
