## BACKGROUND

Event stream data arises naturally in numerous real-world systems where discrete occurrences—such as user actions in digital platforms, clinical interventions in electronic health records, sensor triggers in industrial environments, or geopolitical interactions in international relations—are recorded with precise timestamps. These events are typically multivariate, meaning they belong to a finite set of types or labels, and occur asynchronously over continuous time. The ability to model the stochastic dynamics governing such event sequences is critical for tasks ranging from anomaly detection and risk forecasting to causal inference and system optimization. Traditional approaches to modeling event streams have relied on parametric point process frameworks, such as Hawkes processes, Poisson networks, or piecewise-constant intensity models, which impose strong structural assumptions about how past events influence future ones—often assuming exponential decay of influence or fixed temporal windows of dependency. While mathem as these models provide interpretability, their rigidity limits their capacity to capture complex, non-stationary, or multi-scale temporal dependencies observed in empirical data. More recent deep learning methods, including recurrent marked temporal point processes (RMTPP) and neural Hawkes processes (NHP), have introduced greater flexibility by using recurrent neural networks (RNNs) to encode historical context. However, these models still embed implicit functional constraints—such as monotonic decay or uniform influence propagation—that may not reflect the true generative mechanisms of real-world event streams. Moreover, existing models largely ignore the informational value of *negative evidence*: the absence of events during inter-event intervals, which carries significant signal about the underlying intensity landscape. This omission leads to coarse approximations of the conditional intensity function and suboptimal likelihood estimation. Consequently, there exists a pressing need for a fully non-parametric, data-driven framework capable of modeling continuous-time event dynamics without restrictive assumptions, while explicitly leveraging both positive (event occurrences) and negative (non-occurrences) evidence to learn rich, adaptive representations of temporal dependence.

## SUMMARY

The present invention introduces a novel computational methodology termed the Multi-Channel Neural Graphical Event Model (MCN-GEM), designed to overcome the limitations of prior art in modeling multivariate event stream data in continuous time. The MCN-GEM method provides a non-parametric deep learning architecture that learns history-dependent conditional intensity functions directly from data, without imposing predefined functional forms such as exponential decay or fixed lag structures. Central to the invention is the incorporation of *negative evidence* through the strategic insertion of synthetic “fake epochs” between real event occurrences, thereby enabling the model to refine its internal state representation during inter-event intervals and more accurately approximate the integral terms in the log-likelihood objective. The MCN-GEM system comprises a multi-channel recurrent neural network, spatial and temporal attention mechanisms, and a λ-network for intensity estimation, all integrated into a unified framework aligned with the principles of graphical event models (GEMs). Additionally, the invention encompasses a non-transitory computer-readable storage medium encoded with program instructions that, when executed by a processor, cause the implementation of the MCN-GEM method. The subject matter of the invention spans multiple technical domains: machine learning, temporal modeling, neural architectures, and real-time data processing systems. The combination of features—including fake epochs for negative evidence reinforcement, multi-channel hidden state partitioning, spatio-temporal attention, and continuous-time LSTM dynamics—yields synergistic improvements in model expressiveness and predictive accuracy unattainable by any single component alone. ## DETAILED DESCRIPTION

The invention operates on event datasets comprising temporally ordered sequences of discrete occurrences, each annotated with a type label and a precise timestamp. An event dataset is formally defined as \( \mathcal{D} = \{(l_i, t_i)\}_{i=1}^N \), where \( l_i \in \mathcal{L} \) denotes the event label from a finite set \( \mathcal{L} \) of size \( M \), and \( t_i \in \mathbb{R}^+ \) represents the occurrence time, with \( t_1 < t_2 < \dots < t_N \) and total observation window \( [0, T] \). Streaming algorithms process such datasets incrementally, making them suitable for real-time applications. A key insight motivating the invention is that the *absence* of events during inter-event intervals constitutes valuable negative evidence about the underlying intensity process; ignoring this information leads to biased or incomplete models. To address this, the invention introduces the Multi-Channel Neural Graphical Event Model (MCN-GEM), a deep neural architecture that integrates graphical modeling principles with modern sequence learning techniques. At its core, MCN-GEM builds upon the framework of Graphical Event Models (GEMs), which represent conditional independence relationships among event types via directed graphs, where the instantaneous rate of a child process depends only on the history of its parent nodes. The log-likelihood (LL) of an event dataset under a GEM is given by \( \sum_{i=1}^N \log \lambda_{l_i}(t_i | \mathcal{H}_{t_i}) - \sum_{k \in \mathcal{L}} \int_0^T \lambda_k(t | \mathcal{H}_t) dt \), where \( \lambda_k(t | \mathcal{H}_t) \) is the conditional intensity of type \( k \) at time \( t \) given history \( \mathcal{H}_t \).

To compute \( \lambda_k(t | \mathcal{H}_t) \), MCN-GEM employs a deep neural network that maps historical context to intensity values. This is achieved through a sequence modeling approach using Recurrent Neural Networks (RNNs), specifically Long Short-Term Memory (LSTM) cells, which maintain internal states that evolve with each event. Each input token consists of a one-hot encoded event label concatenated with its timestamp, enabling the LSTM to jointly process categorical and temporal information. The hidden state \( h_i^k \) for event type \( k \) at epoch \( i \) is computed via shared LSTM parameters across all channels, initialized to zero vectors. Figure 2(a) illustrates a basic model where recurrent cells process event epochs, and a downstream λ-network outputs intensities based on the latest hidden state and elapsed time since the last event. However, this basic model treats internal states as static between events, failing to capture continuous-time dynamics.

To model continuous time more faithfully, the invention introduces *fake epochs* as a mechanism to reinforce negative evidence. An auxiliary “fake” label \( M+1 \) is added to \( \mathcal{L} \), and \( K \) uniformly spaced fake epochs are inserted into each inter-event interval \( (t_i, t_{i+1}) \). These fake epochs participate in LSTM computations, allowing internal states to evolve discretely within dead-space intervals. As shown in Figure 2(b), this yields refined state trajectories \( (\tilde{h}_i, \tilde{c}_i) \) that better reflect temporal passage. The fake epochs also enable numerical quadrature for the integral term in the LL, using fake timestamps as sampling points. Although the fake label’s intensity does not contribute to the primary LL, it supports regularization via target-label reconstruction or real-vs-fake classification, akin to adversarial training.

The invention further enhances expressiveness through a *multi-channel view*. The hidden state dimension is set to \( m(M+1) \), partitioned into \( M+1 \) sub-vectors of size \( m \), one per label (including fake). This enables label-specific state evolution, aligning with GEM’s parent-child semantics. Building on this, *spatio-temporal attention* models are employed to identify which historical events—both in terms of type (spatial) and timing (temporal)—most influence current intensities. A memory bank stores the most recent \( J \) hidden states per label, yielding \( J \times M \) vectors. Attention weights \( \alpha_{im}^k \) are computed by comparing the current hidden state \( h_i^k \) to each memory entry \( h_m \), producing a context vector \( c_i^k = \sum_m \alpha_{im}^k h_m \). The net hidden state \( h_{\text{net},i}^k = \tanh(W_C [h_i^k; c_i^k]) \) is then fed into feed-forward layers with ReLU and softplus activations to ensure positive intensities \( \lambda_k^{t_{i+1}} \).

Figure 3 visualizes this attention mechanism for \( J=3 \), showing how raw hidden states are aggregated into net states for intensity prediction. Figure 4 depicts an event dataset augmented with fake labels, while Figure 5 illustrates the basic recurrent-intensity architecture. Figure 6 demonstrates spatio-temporal attention, with spatial attention capturing inter-type dependencies (e.g., event A excites event B) and temporal attention identifying influential time lags (e.g., influence peaks after 2 hours). During training, the regularized objective combines LL, next-label prediction loss \( L_p \) (cross-entropy), and L2 weight decay \( L_w \): \( \mathcal{L} = \text{LL} + \gamma_p L_p + \gamma_w L_w \).

The invention is implemented in a computing system comprising processors, memory, and I/O interfaces, configurable in cloud environments supporting Infrastructure-as-a-Service (IaaS), Platform-as-a-Service (PaaS), and Software-as-a-Service (SaaS) models, deployable across private, public, or hybrid clouds. The system integrates with IoT devices equipped with diverse sensors—position, motion, temperature, chemical, acoustic, etc.—which generate time-stamped event epochs. These epochs, along with generated fake epochs, are processed by LSTM cells to compute hidden states, which are then attended over spatially and temporally to produce net hidden states for intensity estimation. The resulting causal graphs, derived from averaged attention weights, reveal interpretable dependencies.
