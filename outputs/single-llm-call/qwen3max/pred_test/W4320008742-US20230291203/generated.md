# DESCRIPTION

## FIELD

The present invention relates generally to the field of photovoltaic (PV) array operation, and more specifically to systems and methods for dynamically reconfiguring the electrical topology of a photovoltaic array in response to partial shading conditions to maximize power output. The invention leverages deep neural network-based predictive modeling trained on synthetic irradiance data to identify optimal array topologies—including series-parallel (SP), bridge-link (BL), honeycomb (HC), and total-cross-tied (TCT)—without requiring additional hardware or external panels, thereby enabling real-time, scalable, and efficient energy optimization in cyber-physical solar energy systems.

## BACKGROUND

Photovoltaic energy systems have become a cornerstone of renewable energy infrastructure, yet their efficiency is significantly compromised under partial shading conditions caused by environmental obstructions such as clouds, trees, buildings, or dust accumulation. When individual panels within a PV array receive non-uniform irradiance, current and voltage mismatches arise across series-connected strings, leading to disproportionate power losses, hot-spot heating, and reduced inverter uptime. These mismatch losses can diminish overall system output by more than 50% in severe cases, undermining grid stability and economic viability. Traditional PV arrays employ fixed electrical topologies—most commonly the series-parallel (SP) configuration—which offer simplicity but lack adaptability to dynamic shading patterns. While alternative topologies such as bridge-link (BL), honeycomb (HC), and total-cross-tied (TCT) have demonstrated superior performance under specific shading scenarios by redistributing current paths and equalizing string voltages, manually or exhaustively selecting the optimal topology in real time remains computationally prohibitive, especially for large-scale arrays. Existing approaches to mitigate shading effects include static reconfiguration strategies like SuDoKu-based panel rearrangement or adaptive banking using auxiliary panels, but these either require physical intervention or additional hardware, limiting deployability and increasing system complexity. Dynamic reconfiguration methods that electrically alter interconnections via switch banks offer greater flexibility, yet prior algorithms rely on iterative simulation or rule-based heuristics that scale poorly with array size and fail to generalize across arbitrary irradiance distributions. Consequently, there exists a critical need for an intelligent, automated, and hardware-efficient solution capable of rapidly determining and implementing the optimal PV array topology under real-world partial shading conditions without external resources.

## DETAILED DESCRIPTION

### Approach

The present invention addresses the limitations of conventional photovoltaic systems by introducing an automated, data-driven approach to topology reconfiguration that maximizes power output under partial shading without requiring additional panels or manual intervention. Conventional methods for mitigating shading losses—such as fixed topologies, exhaustive simulation-based selection, or puzzle-inspired static rearrangements—are either inflexible, computationally intensive, or impractical for real-time deployment in modern cyber-physical PV systems. In contrast, the disclosed system employs a deep neural network trained to map real-time panel-level irradiance measurements directly to an optimal array topology among a predefined set, including SP, BL, HC, and TCT. The system architecture comprises a central computing unit communicatively coupled to smart monitoring devices (SMDs) integrated with each photovoltaic panel, where each SMD includes irradiance sensors and relay actuators capable of modifying electrical connections between adjacent panels. This architecture enables continuous data acquisition, centralized decision-making, and distributed actuation, forming a closed-loop control system for dynamic reconfiguration. The system operates by first collecting irradiance data from all panels, formatting it into a structured input vector, and feeding it into a pre-trained neural network model that outputs a probability distribution over candidate topologies. The topology with the highest predicted probability is then selected, and corresponding control signals are transmitted to the SMDs to reconfigure the switch bank accordingly. Critically, the system achieves scalability because the neural network inference time remains constant regardless of array size, and deployability is enhanced by eliminating the need for auxiliary panels or complex mechanical repositioning. Furthermore, the system supports static reconfiguration scenarios—where shading patterns remain stable over extended periods—as well as dynamic transitions, making it suitable for both residential and utility-scale installations. By operating solely on the existing array infrastructure and leveraging learned irradiance-topology relationships, the invention provides a lightweight, robust, and economically viable solution for real-time power optimization.

### Neural Network Model

The core of the invention resides in a regularized deep neural network model specifically designed for photovoltaic topology classification. The model is introduced as a six-layer feed-forward architecture with neuron counts of 64, 64, 128, 256, 64, and 64 across successive layers, culminating in a four-neuron output layer corresponding to the four target topologies: SP, BL, HC, and TCT. The input to the neural network model consists of a 25-dimensional vector representing panel-level irradiance values for a 5×5 photovoltaic array, though the architecture is extensible to other dimensions. Each hidden layer of the neural network model performs an affine transformation followed by a Rectified Linear Unit (ReLU) non-linear activation function, ensuring the model can capture complex, non-linear relationships between shading patterns and optimal topologies. To mitigate overfitting and enhance generalization—critical for reliable performance under unseen irradiance conditions—the model incorporates advanced regularization techniques. Specifically, a dropout policy is applied during training, wherein 20% of neurons in layers two through five are randomly deactivated at each iteration, preventing co-adaptation and promoting feature redundancy. Additionally, batch normalization (batchnorm) is implemented in the same layers to standardize layer inputs across mini-batches, reducing internal covariate shift and accelerating convergence. The output layer of the neural network model employs a softmax activation function, which converts raw logits into normalized probabilities that sum to one, enabling probabilistic interpretation of topology predictions. The training framework comprises three integrated modules: a simulation module, a training module, and a synthetic data generation pipeline. Synthetic irradiance data is generated using a binary mapping scheme where each panel is labeled as shaded (1) or unshaded (0), with actual irradiance values sampled from uniform distributions—unshaded panels drawn from [586, 1000] W/m² and shaded panels from [0, 586] W/m², reflecting realistic atmospheric conditions validated against National Solar Radiation Database (NSRDB) records. This yields 8,000 unique irradiance instances covering diverse partial shading scenarios. Each instance is processed through a high-fidelity PV array simulation model implemented in MATLAB-Simulink, which incorporates bypass diodes per panel and models wiring losses using resistors: 0.01 Ω between adjacent strings and 0.005 Ω within strings. The simulation evaluates all four topologies under each irradiance profile and assigns a label to the instance based on which topology yields the maximum power point (MPP). This transforms the problem into a supervised classification task. The dataset is split into 90% training and 10% testing subsets, with inputs standardized to zero mean and unit variance. The model is optimized using categorical cross-entropy loss and the Adam optimizer over 200 epochs with a learning rate of 10⁻⁴. The resulting design ensures adaptability to real-world conditions, robustness against noise, and compatibility with embedded deployment due to its parameter efficiency and regularized structure.

### Results and Discussion

Experimental evaluation demonstrates the efficacy and practical merit of the disclosed system. The trained neural network achieves an average test accuracy of 81.1% and a macro-average F1 score of 0.74, outperforming baseline machine learning algorithms including K-Nearest Neighbors, Support Vector Machines, Random Forests, and XGBoost. The confusion matrix reveals strong diagonal dominance, indicating consistent correct classification across all four topology classes, with minimal misassignment between structurally similar configurations like BL and HC. More importantly, the system delivers tangible power improvements: when reconfiguring from the default SP topology to the neural network-predicted optimal topology, an average power gain of approximately 11% is observed across the test dataset. Further analysis shows that in 38.2% of cases, switching to TCT yields power improvements exceeding 50 W; similarly, 29.7% and 32.1% of instances benefit significantly from BL and HC, respectively. These results confirm that topology reconfiguration is not merely a theoretical exercise but a practically viable strategy for enhancing energy yield. Demonstrative P-V curves illustrate how reconfiguration redistributes operating points away from local maxima induced by shading, recovering substantial lost power even in the presence of modeled wiring losses. The system’s ability to generalize across arbitrary shading patterns—without relying on additional panels or exhaustive search—validates its suitability for integration into modern cyber-physical solar farms, where low-latency, accurate decisions directly translate to increased revenue and grid reliability.

## Methods

The invention further encompasses computer-implemented methods for photovoltaic topology reconfiguration. Method 600 begins by receiving operating data—specifically, a vector of panel-level irradiance measurements—as input to a neural network model. The model generates a prediction probability for each candidate topology configuration via a sequence of operations: the input is received at a first input layer; each subsequent hidden layer receives the output of the previous layer, applies an affine transformation and a ReLU activation function, enforces a dropout policy (e.g., 20% neuron deactivation during training), and performs a batchnorm operation to stabilize activations. The final hidden layer feeds into an output layer, which applies a softmax activation function to produce normalized prediction probabilities for each topology. The topology with the highest probability is selected and communicated to the photovoltaic array via control signals, which configure electromechanical or solid-state linkages to realize the chosen electrical topology. Complementary method 700 generates labeled synthetic irradiance data by first creating random binary shading masks, assigning irradiance values from empirically grounded uniform distributions, applying this synthetic irradiance data to a detailed PV array simulation model that includes wiring losses and bypass diodes, simulating all candidate topologies, identifying the configuration yielding maximum power output, and assigning that topology as the ground-truth label. Method 800 trains the neural network by ingesting the labeled dataset, optimizing model parameters via backpropagation using categorical cross-entropy loss and the Adam optimizer, and validating performance on held-out test data to ensure generalization. Together, these methods enable end-to-end automation of intelligent, loss-aware, and hardware-efficient PV array reconfiguration.
