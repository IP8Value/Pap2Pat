# DESCRIPTION

## TECHNICAL FIELD

The present invention relates to an encrypted data processing system configured to perform secure and efficient comparison of encrypted digital identities without revealing the underlying plaintext information. More specifically, the invention pertains to a verifiable encryption (VE)-based architecture that enables a server or third-party computing entity to compute a comparison metric—such as a Hamming distance—between two encrypted data items, while ensuring that neither the server nor any external observer gains access to the original plaintext values or the secret cryptographic keys used in the process. The system is particularly suited for authentication scenarios involving Internet of Things (IoT) devices, cloud-based identity verification, and network-mediated unlocking of local hardware where computational resources are constrained, yet strong security against eavesdropping and plaintext attacks must be maintained. By leveraging cryptographic primitives that support operations directly on ciphertexts—specifically within the class of verifiable encryption schemes—the invention achieves a balance between performance, usability, and confidentiality that surpasses conventional approaches relying on public key infrastructure (PKI), interactive zero-knowledge proofs, or full homomorphic encryption.

## BACKGROUND ART

Prior art in the domain of encrypted data processing has long sought methods to enable computation over encrypted information without compromising data secrecy. Searchable symmetric encryption (SSE) emerged as a prominent technique allowing keyword searches on encrypted documents stored in the cloud, thereby preserving privacy while enabling limited query functionality. However, traditional SSE systems often require substantial computational overhead, complex indexing structures, or leakage profiles that may expose metadata about search patterns. Another line of research involves homomorphic encryption, exemplified by RSA, ElGamal, and fully homomorphic encryption (FHE) schemes, which permit arithmetic operations—such as addition or multiplication—on ciphertexts such that the decrypted result matches the operation performed on the corresponding plaintexts. While theoretically powerful, FHE remains impractical for real-time applications due to prohibitive latency and memory demands, especially on resource-constrained IoT endpoints.

Authentication protocols based on zero-knowledge proofs, such as the Fiat-Shamir and Schnorr algorithms, offer strong security guarantees by allowing one party to prove knowledge of a secret without revealing it. These methods typically involve multiple rounds of interaction and rely on trusted third parties like certificate authorities (CAs) for initial key distribution, introducing both latency and systemic dependencies. In contrast, local device unlocking mechanisms—such as fingerprint or facial recognition on smartphones—often bypass encryption entirely during verification, storing biometric templates in plaintext or weakly protected forms on the device. This approach prioritizes speed and user convenience but creates significant vulnerabilities if the device is lost, stolen, or compromised, as the raw digital identity becomes directly accessible.

Japanese Patent Application Laid-Open No. 2015-192446 discloses a system wherein encrypted user data is compared on a server using pre-shared keys, but this method still requires the transmission of decryption-capable keys or exposes intermediate values that could facilitate plaintext attacks. Moreover, existing solutions generally fail to address the specific use case of “unlocking local devices via the network,” where a shared physical device (e.g., a smart door or kiosk) must authenticate multiple users through a remote server without exposing their sensitive identity data. Conventional systems either sacrifice security for speed or impose unsustainable computational burdens, leaving a critical gap in secure, lightweight, and non-interactive authentication for distributed environments. Thus, there remains a pressing need for an encrypted data processing system that ensures end-to-end confidentiality of digital identities while enabling efficient, deterministic comparison operations on encrypted data with minimal client-side resources.

## SUMMARY OF INVENTION

### Technical Problem

A fundamental technical problem addressed by the present invention is the lack of secrecy in the comparison result when performing authentication or identity verification over encrypted data in networked environments. In conventional systems, even when data is encrypted during transmission, the comparison process often necessitates partial or full decryption at an intermediary server, thereby exposing the plaintext or derived features to potential eavesdroppers or malicious insiders. Furthermore, many existing protocols leak information through side channels, require repeated interactive exchanges, or depend on centralized trust infrastructures that introduce single points of failure. This compromises user privacy, especially when sensitive biometric or personal identifiers are involved, and renders the system vulnerable to impersonation, replay, or chosen-plaintext attacks. The problem is exacerbated in IoT and edge computing contexts where devices lack the computational capacity to execute complex cryptographic protocols yet must operate securely over untrusted networks.

### Solution to Problem

The present invention solves this problem by introducing an encrypted data processing system based on verifiable encryption (VE), a novel cryptographic framework that allows a comparison metric between two plaintexts to be computed directly on their ciphertexts and subsequently decrypted only by an authorized party possessing the correct keys. The system comprises an encrypting section that generates ciphertexts from plaintext digital identities using secret keys; a comparison section, typically residing on a remote server, that applies a cipher comparison function to the ciphertexts to produce an encrypted comparison result; and a comparison result decrypting section that uses the original keys to recover the actual comparison value—such as a Hamming distance—without ever exposing the plaintexts or keys to the server.

In a second aspect, the invention employs a one-time key mechanism wherein each verification session uses a unique, ephemeral key that is discarded after use, thereby mitigating risks associated with key reuse and enhancing forward secrecy. A third aspect specifies that the plaintext space includes biometric data, passwords, or other digital identity types, with the comparison function tailored to compute relevant similarity metrics (e.g., Hamming distance for binary templates). A fourth aspect incorporates hashing or modulation coding of plaintexts prior to encryption to normalize input formats and reduce entropy leakage. A fifth aspect associates each registered ciphertext with a registration ID, enabling scalable user management in multi-tenant systems. A sixth aspect includes a secure key storage section on the client device that isolates cryptographic material from general-purpose memory, preventing extraction by malware. Seventh and eighth aspects extend the invention to a method and a computer program product, respectively, enabling deployment across diverse hardware and software platforms.

### Advantageous Effects

The system configuration of the present invention achieves a synergistic combination of high performance, strong security, and operational simplicity. By confining all decryption and key handling to the trusted client device and delegating only ciphertext-compatible operations to the untrusted server, the invention ensures that no plaintext information—nor any information sufficient to reconstruct it—is ever exposed during transmission or processing. This design eliminates the need for public key infrastructure, certificate authorities, or interactive proof rounds, drastically reducing latency and computational overhead. Empirical evaluations demonstrate that authentication completes in under 0.003 milliseconds even for 8192-bit inputs, making the system suitable for real-time IoT applications. Moreover, the use of one-time keys and secure local key storage renders the system resilient against both plaintext and impersonation attacks, offering a robust solution for secure, scalable, and user-friendly authentication in ubiquitous computing environments.

## DESCRIPTION OF EMBODIMENTS

Motivated by the growing demand for searchable secure encryption in cloud and IoT ecosystems, the present disclosure introduces a practical implementation of verifiable encryption that overcomes the limitations of existing approaches. Traditional searchable symmetric encryption (SSE) schemes, while enabling keyword retrieval on encrypted data, often suffer from high storage overhead, complex trapdoor generation, and inherent leakage of access patterns. Fully homomorphic encryption, though theoretically capable of arbitrary computations on ciphertexts, remains computationally infeasible for real-world deployment due to exponential time and memory requirements. The object of the present disclosure is therefore to provide an encrypted data processing system that supports efficient, deterministic comparison of encrypted digital identities—such as biometrics or credentials—without decryption, interactive protocols, or reliance on trusted third parties, while maintaining strict confidentiality against untrusted servers and network adversaries.

### Outline of Exemplary Embodiments of Present Disclosure

The exemplary embodiments disclosed herein are designed to fulfill this object by leveraging the mathematical properties of verifiable encryption, particularly as instantiated through stream ciphers like the one-time pad. The application spans scenarios including cloud-based identity verification, shared-device authentication (e.g., smart locks, kiosks), and edge-computing environments where low-latency, high-security authentication is required without burdening resource-constrained devices.

### Principles of Exemplary Embodiments of Present Disclosure

The principles of the exemplary embodiments rest on a two-step protocol: registration and comparison. Let the plaintext space \( P \) consist of binary strings representing digital identities (e.g., 128-bit biometric templates). Two secret keys \( k_1 \) and \( k_2 \) are generated locally on the client device. The encryption function \( E_k(p) = p \oplus k \) (bitwise XOR) defines the one-time pad scheme, and the decryption function is identical: \( D_k(c) = c \oplus k \). The comparison function \( g(p_1, p_2) = p_1 \oplus p_2 \) computes the bitwise difference, whose Hamming weight yields the distance metric \( V(p_1, p_2) \). Critically, the cipher comparison function \( F(c_1, c_2) = c_1 \oplus c_2 \) satisfies \( D_{k_1,k_2}(F(c_1, c_2)) = (c_1 \oplus c_2) \oplus (k_1 \oplus k_2) = (p_1 \oplus k_1 \oplus p_2 \oplus k_2) \oplus (k_1 \oplus k_2) = p_1 \oplus p_2 = g(p_1, p_2) \), thereby enabling correct distance recovery without plaintext exposure.

In Step 1 (registration), illustrated in FIG. 1, the user submits plaintext \( p_1 \) to the client device, which generates key \( k_1 \), computes \( c_1 = E_{k_1}(p_1) \) per Equation (1), and transmits \( c_1 \) to the server for storage. In Step 2 (comparison), shown in FIG. 2, during verification, the user provides \( p_2 \); the device generates a fresh one-time key \( k_2 \), computes \( c_2 = E_{k_2}(p_2) \) per Equation (2), sends \( c_2 \) to the server, which then computes \( c_d = F(c_1, c_2) \) and returns it. The device decrypts \( c_d \) using \( k_1 \) and \( k_2 \) to obtain \( \alpha = V(p_1, p_2) \), and grants access if \( \alpha \leq s \) for a predefined threshold \( s \).

The system architecture includes an input device (2) for user data entry, an encryption device (3) housing the encrypting section (30), a reading device (4) for biometric capture, a control mechanism (5) coordinating operations, a server (6) executing comparison logic, and a communication section (20) managing data flow. The encrypting section (30) interfaces with a key storage section (32) that securely retains \( k_1 \) and generates ephemeral \( k_2 \), while the comparison result decrypting section (34) performs the final distance validation. Server (6) comprises storage for registered ciphertexts and a processor for executing \( F \).

Operation proceeds as follows: during registration, the device encrypts the user’s identity and uploads the ciphertext; during verification, it encrypts the presented identity, requests a comparison from the server, decrypts the result, and makes an access decision—all without transmitting keys or plaintexts beyond the trusted device boundary. This workflow is replicated in second and third exemplary embodiments with enhanced key management (e.g., per-session key isolation) and registration ID tagging for multi-user scalability.

Comparative analysis against JP-A No. 2015-192446 reveals that the prior art requires the server to possess decryption capability or intermediate secrets, whereas the present disclosure ensures the server never accesses keys or plaintext-equivalent data. Modifications include integrating hashed modulation codes for input standardization and referencing co-pending Japanese Patent Application No. 2017-246716 for advanced pseudorandom key generation. The invention thus establishes a new paradigm in secure, efficient, and deployable encrypted data comparison.
