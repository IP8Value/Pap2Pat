# DESCRIPTION

## FIELD OF INVENTION

The present invention relates to medical imaging and radiotherapy planning, particularly in the context of image segmentation for anatomical structure delineation. More specifically, the invention provides a novel interactive contouring method that leverages deep learning models trained on diverse anatomical structures to enable accurate, efficient, and generalizable segmentation of both known and previously unseen structures in three-dimensional (3D) medical images such as computed tomography (CT) or magnetic resonance (MR) scans. The invention is particularly suited for clinical applications where precise delineation of tumors and surrounding healthy tissues is critical, such as in radiation therapy planning, surgical navigation, and diagnostic imaging workflows.

## BACKGROUND OF INVENTION

### Image Segmentation

Image segmentation is a fundamental task in medical image analysis, involving the partitioning of an image into meaningful regions corresponding to anatomical structures or pathological entities. In clinical practice, segmentation is essential for treatment planning, disease monitoring, and quantitative assessment of anatomical changes over time. A key output of segmentation is the generation of contours—closed curves that delineate the boundary of a structure of interest in two-dimensional (2D) image slices. A set of such contours across multiple contiguous slices constitutes a 3D contour set, which defines the volumetric representation of the anatomical structure. Manual contouring, traditionally performed by radiologists or radiation oncologists, remains the clinical gold standard but is highly time-consuming, labor-intensive, and prone to inter- and intra-observer variability. These limitations have motivated the development of automated and semi-automated segmentation techniques to improve efficiency, consistency, and reproducibility.

Atlas-based auto-segmentation emerged as an early solution, leveraging pre-labeled reference images (atlases) that are registered to a new patient’s image to propagate labels. However, this approach suffers from registration inaccuracies, especially in the presence of anatomical deformations or pathologies. More recently, machine learning (ML)-based approaches, particularly deep learning models such as convolutional neural networks (CNNs), have demonstrated remarkable success in fully automatic segmentation tasks. These models can learn complex image features from large annotated datasets and generate segmentations that rival human performance for specific anatomical structures. Despite these advances, fully automatic methods often fail when applied to structures with high morphological variability, such as tumors, or when encountering anatomical configurations not represented in the training data. This limitation underscores the continued need for interactive segmentation methods that combine the speed and consistency of automation with the adaptability and contextual reasoning of human experts.

### The Need for Interactive Segmentation

Interactive segmentation addresses the shortcomings of fully automatic techniques by incorporating user input to guide the segmentation process. Unlike purely automatic systems, interactive methods allow clinicians to provide initial annotations—such as a contour on a single slice—which the system then uses as prior information to propagate segmentation to other slices. This approach enhances robustness, particularly for structures with unpredictable appearance or location, and enables adaptation to individual patient anatomy. Semi-automatic methods based on user interaction have been shown to improve both segmentation accuracy and inter-observer consistency compared to manual contouring alone.

However, existing interactive techniques face significant challenges. One major issue is the difficulty of designing intuitive and efficient interaction mechanisms. Many systems rely on low-level inputs such as foreground/background strokes or seed points, which require users to understand the underlying algorithm and may lead to suboptimal results if poorly placed. Moreover, most interactive tools operate in 2D, requiring users to correct contours slice-by-slice, which undermines the efficiency gains of automation. While some 3D interaction paradigms exist, they often suffer from computational complexity or poor usability. Contour-based interaction—where the user directly draws or edits a contour—offers a more natural and clinically familiar interface. When combined with spatial context, such as the relationship between adjacent image slices, contour-based interaction can enable intelligent propagation of segmentations through a volume. The present invention introduces a novel interactive contouring method that leverages deep learning to interpret contextual information from user-provided contours and adjacent image slices, enabling fast, intuitive, and accurate 3D segmentation of arbitrary anatomical structures.

### Application Examples of Segmentation:

In current clinical practice, manual contouring involves a clinician reviewing each 2D image slice in a 3D volume and manually drawing the boundary of the target structure using a graphical interface. This process can take hours for complex cases, such as head-and-neck radiotherapy planning involving dozens of organs at risk. Semi-automatic contouring, by contrast, begins with the user delineating the structure on one or a few representative slices. The system then automatically propagates this contour to neighboring slices using interpolation, registration, or machine learning. The user subsequently reviews and corrects the propagated contours as needed. While faster than full manual contouring, traditional semi-automatic methods often produce inaccurate results for slices far from the initial input or for structures with irregular shapes, necessitating extensive manual correction. The invention described herein significantly improves upon this workflow by using a deep learning model that learns from diverse anatomical contexts to accurately predict contours on distant slices, even for structures not seen during training, thereby reducing the need for manual intervention and accelerating the overall contouring process.

## PRIOR ART

### Fully Automated Segmentation Using ML

Prior art includes fully automatic segmentation methods based on machine learning. For example, China et al. developed a deep learning system for organ segmentation in CT images using a 3D U-Net architecture trained on a large dataset of annotated scans. Similarly, international patent application WO2017/091833 discloses a method for automatic tumor segmentation using a CNN trained on multi-institutional data. While these methods achieve high accuracy for structures well-represented in their training sets, they exhibit significant performance degradation when applied to anatomical variants, rare pathologies, or structures absent from training data. This brittleness limits their clinical utility in real-world scenarios where patient anatomy is highly variable and comprehensive training data may be unavailable.

### Interactive 2D Image Segmentation Approaches

Interactive 2D segmentation approaches, such as those based on graph cuts or random walks, allow users to provide foreground and background markers to guide segmentation. These methods are effective in 2D but do not inherently account for 3D anatomical continuity, requiring repetitive user input across slices and failing to leverage volumetric context.

### Interactive 3D Segmentation in Medical Images

Some prior art attempts to extend interactivity to 3D, such as using 3D scribbles or volumetric seeds. However, these methods are often computationally intensive, difficult to use, and still rely on assumptions about shape or intensity that may not hold for all structures. Their performance degrades significantly for complex or irregular anatomies.

### Interactive Contour Propagation Methods

Interactive contour propagation methods aim to transfer a user-drawn contour from one slice to others using deformation models or interpolation. Léger et al. proposed a machine learning model that uses a single annotated slice to predict contours on adjacent slices, while Zheng et al. developed a recurrent neural network for sequential slice-wise segmentation. However, these models are typically trained on a single structure or a limited set of structures and fail to generalize to unseen anatomies. In experiments, a model trained solely on heart segmentation performed poorly on lung tumors, pancreatic tumors, and other organs not included in its training set. Even when tested on different organs within the same modality, such models exhibited high relative added path lengths, indicating extensive manual correction was required. State-of-the-art tools, while offering automated deep learning contouring, remain constrained by their training scope and lack mechanisms for intuitive, context-aware interaction. There is thus a clear need for a fast, intuitive, and generalizable interactive contouring method that maintains high contour quality while minimizing user effort.

The disclosed interactive contouring method addresses this need by receiving as input a 2D image slice and a corresponding user-provided contour, then predicting target contour data for another slice using a machine learning model. Crucially, the model is provided with contextual information derived from the input image and contour, and it learns this context from a diverse training dataset encompassing multiple anatomical structures. The model utilizes consecutive image slices to infer spatial relationships and can be updated based on user edits to improve subsequent predictions. Finally, individual 2D predicted contours are assembled into a coherent 3D contour, enabling efficient volumetric segmentation guided by minimal user input.

## DETAILED DESCRIPTION

The present invention introduces a deep learning contouring system that overcomes the limitations of prior art by enabling interactive, context-aware segmentation of arbitrary anatomical structures in 3D medical images. Unlike conventional methods that are restricted to predefined structures, the disclosed approach leverages a machine learning model trained on a diverse set of anatomical structures to generalize to previously unseen targets based solely on user-provided contextual cues.

The core innovation lies in the use of contextual information. The system receives three inputs: a target image slice to be contoured, a source image slice containing a user-drawn contour, and a binary mask representing that contour. Notably, the mask does not include semantic labels (e.g., “heart” or “tumor”); instead, the model learns to infer what to segment based on the spatial and visual relationship between the source image and its contour. This design enables the model to segment any structure, provided a user supplies an initial contour on one slice.

The system comprises a medical image database storing 3D volumes (e.g., CT or MR scans), a contour prediction engine implementing the machine learning model, and a user interface for manual contouring and editing. During operation, a clinician loads a patient’s 3D image, selects an initial 2D slice, and draws a contour around the structure of interest. The system then identifies a target slice—either adjacent (for iterative propagation) or distant (for direct propagation)—and feeds the source image, source contour, and target image into the model. The model, implemented as a modified U-Net with attention gates and residual recurrent connections, processes these inputs through a multi-channel architecture and outputs a predicted contour for the target slice. This prediction is displayed to the user, who may accept it or make edits; edited contours can be fed back into the system as new source inputs for further propagation.

The model is trained on a dataset comprising 19 distinct anatomical structures from publicly available repositories, including organs and tumors of varying sizes and appearances. Training data is carefully curated to ensure that source and target slices are separated by variable distances relative to structure size, preventing the model from merely copying contours and instead forcing it to learn meaningful contextual transformations. Data augmentation—including random translations, rotations, and scaling—enhances robustness. Evaluation using the Dice similarity coefficient, Hausdorff distance, and relative added path length demonstrates that models trained on multiple structures significantly outperform single-structure models, not only on seen structures but also on unseen ones like the spleen, which was excluded from training. For instance, a multi-structure model achieved a relative APL of 0.35 for the spleen, compared to 0.85 for a heart-only model, indicating dramatically reduced editing effort.

The system supports both iterative propagation (where each predicted contour becomes the source for the next slice) and direct propagation (using a fixed source slice for all targets). Iterative propagation proves superior for unseen structures, as it accumulates less error over distance than direct prediction. The workflow is intuitive: after loading a 3D image, the user contours one slice, selects a propagation mode, and reviews/edit predicted contours as needed. The final output is a complete 3D contour set ready for clinical use.

This invention is embodied in a computer program executable on a standard workstation, stored on a non-transitory computer-readable medium, and implemented via a computer process running under a conventional operating system. The system architecture includes logic blocks for image rendering, contour prediction, and user interaction, all operably connected to enable seamless overlapping operations. Modifications may include support for additional imaging modalities (e.g., PET, ultrasound) or integration with treatment planning systems. The claims define the invention in terms of its functional components—contour prediction engine, contextual information provision, multi-structure training—and their cooperative interaction, ensuring broad protection for this generalized, interactive deep learning contouring methodology.
