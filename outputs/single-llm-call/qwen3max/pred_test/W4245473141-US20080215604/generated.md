# DESCRIPTION

## TECHNICAL FIELD

The present invention relates generally to the field of computational genetics and, more specifically, to hardware-accelerated methods and devices for processing pedigree data structures. The invention provides a novel architecture implemented on reconfigurable hardware—particularly Field Programmable Gate Arrays (FPGAs)—for the efficient parallel simulation and analysis of genetic inheritance patterns across multi-generational pedigrees. Unlike traditional software-based approaches executed on general-purpose central processing units (CPUs), the disclosed device leverages the inherent regularity and hierarchical structure of pedigree data to enable fine-grained parallelism at the level of individual meiosis events and allele transmissions. This technical field intersects digital electronics, bioinformatics, statistical genetics, and high-performance computing, with applications in human medical genetics, livestock breeding, and evolutionary biology where rapid estimation of identity-by-descent (IBD) probabilities, inbreeding coefficients, haplotype reconstruction, and genotype likelihoods is essential.

## BACKGROUND ART

In diploid organisms, each individual inherits one allele from each parent at every genetic locus, a process governed by meiosis. The complete set of ancestral relationships among individuals in a population or family is represented as a pedigree, a directed acyclic graph where nodes denote individuals and edges denote parent-offspring relationships. Within this framework, an *allele* refers to one of two alternative forms of a gene at a specific locus, while a *haplotype* denotes the combination of alleles present on a single chromosome across multiple linked loci. Pedigree data structures encode not only kinship but also observed genotypic or phenotypic information, enabling the disentanglement of genetic from environmental effects. Traditional computational methods for analyzing such data rely on sequential algorithms that iterate through individuals and loci using nested loops, often employing maximum likelihood or Bayesian inference to estimate unobserved genotypes or IBD states. These methods become computationally prohibitive for large or complex pedigrees—especially those containing inbreeding loops or marriage cycles—due to the combinatorial explosion of possible meiosis configurations. Although cluster-based parallelization can distribute outer-loop iterations across multiple CPUs, it fails to exploit the intrinsic parallelism within the pedigree structure itself. Moreover, existing software implementations are constrained by the von Neumann bottleneck and sequential execution model of general-purpose processors, limiting their ability to scale efficiently with pedigree size. Consequently, there exists a long-felt but unsolved need for a computational paradigm that maps the hierarchical, layered nature of pedigrees directly onto hardware to achieve orders-of-magnitude acceleration in genetic probability estimation.

## DISCLOSURE OF INVENTION

The present invention discloses a specialized device for representing and processing pedigree data structures using reconfigurable logic hardware, specifically Field Programmable Gate Arrays (FPGAs). The device comprises an array of logic cells interconnected via programmable electrical connections, wherein each logic cell is configured to represent an individual in the pedigree. Input circuitry supplies founder allele data and meiosis indicators, while output circuitry collects results such as allele counts, validity flags, and probability estimates. Critically, the device enables true parallel processing of pedigree data: all individuals within a generation layer perform computations simultaneously during each clock cycle, with data propagating synchronously through successive layers in a pipelined fashion. A subset of the pedigree data structure may be processed independently when the full pedigree exceeds available hardware resources. In one embodiment, the device generates an entire multi-generational pedigree de novo during operation; in another, it processes only a partial generation; in yet another, it handles all generations concurrently. To support iterative sampling algorithms, the device maintains duplicate copies of the pedigree data structure in memory buffers, allowing overlapping sample generations. A sampling cycle is defined as the interval between successive complete traversals of alleles from founders to terminal descendants, occurring once per clock cycle. Each individual is represented by a dedicated module containing storage for paternal and maternal alleles, meiosis selectors, and computational units. Data counters track valid allele configurations, while an authenticator verifies consistency with observed genotypes. A filter rejects inconsistent samples by asserting a global validity signal only when all individuals satisfy observational constraints. A generator produces founder alleles according to specified distributions, and an inheritance generator simulates meiosis events using pseudo-random number streams. Generated samples may be weighted based on likelihood components, enabling importance sampling or Metropolis-Hastings schemes. The FPGA is dynamically reconfigurable, allowing adaptation to different pedigree topologies without hardware replacement. The method for processing pedigree data involves initializing founder modules, propagating alleles through descendant layers in parallel, validating the resulting genotype configuration, and accumulating statistics for probability estimation. Key advantages include constant-time sample generation independent of pedigree size, elimination of loop overhead, massive spatial parallelism, and energy-efficient integer/bit-level operations—all leading to speedups exceeding two orders of magnitude over CPU-based implementations.

## BEST MODE FOR CARRYING OUT THE INVENTION

The best mode for implementing the invention utilizes a Xilinx Spartan-3 XC3S400 FPGA operating at 50 MHz, though higher-performance FPGAs such as the Virtex-4 series are contemplated for larger pedigrees. The FPGA’s internal structure consists of configurable logic blocks (CLBs) interconnected by a programmable routing matrix, forming a two-dimensional grid of reprogrammable logic cells. Each logic cell is configured via VHDL code to instantiate a module representing an individual in the pedigree. These modules are arranged in discrete layers corresponding to biological generations: layer 0 contains founder modules (individuals with no recorded parents), while layers 1 through m contain descendant modules. Founders are assigned initial allele pairs either deterministically (e.g., unique identifiers for inbreeding estimation) or stochastically sampled from a multinomial distribution reflecting population allele frequencies. Descendants receive one allele from each parent module during each clock cycle via hardwired electrical connections that mirror the pedigree topology. For individuals who reproduce across multiple generations, special “holder” modules store alleles temporarily, acting as delay elements to maintain synchronization in the pipeline. Allele transmission follows the rules of Mendelian inheritance: at each locus, a descendant randomly selects one of two paternal alleles and one of two maternal alleles, simulating meiosis. This process is accelerated by embedding a cellular automata-based pseudo-random number generator within each module to produce meiosis indicators in real time. Over successive clock cycles, alleles “drop” through the layers until they reach terminal descendants in layer m, completing one sample of the entire pedigree. The gene dropping algorithm is thus transformed into a fully pipelined hardware process, yielding one complete pedigree-wide sample per clock cycle. For inbreeding coefficient estimation, each descendant module includes a comparator that checks if its two inherited alleles are identical by descent (IBD); if so, a local counter increments. After many cycles, the inbreeding coefficient F for an individual is estimated as the ratio of IBD counts to total samples. In genotype probability estimation, a validity tester in each module compares simulated genotypes against observed data; only samples where all individuals match observations contribute to allele counters located in a terminal layer beneath layer m. A master valid flag—generated by AND-ing all individual validity signals—gates the counting process. Experimental comparisons show the FPGA implementation achieves 166× speedup over a 3 GHz Pentium 4 CPU for a 60-individual pedigree. Alternative embodiments partition large pedigrees into subsets processed sequentially on the same FPGA, with inter-subset coordination managed by a Supervisor soft processor (e.g., PicoBlaze) embedded in the FPGA fabric. This processor handles data passing, ready flags, and parameter updates for advanced sampling schemes like Metropolis-Hastings, where weighted samples are accepted or rejected based on likelihood ratios. Modified inheritance generators incorporate recombination models for multi-locus data, simulating crossover events between linked loci using binomial samplers. In a dual-FPGA configuration, separate devices handle paternal and maternal lineages, with outputs combined via validity testers and AND gates to produce a Master Sample Valid Flag. Specialized modules are designed for sires, dams, and terminal individuals to optimize resource usage. A central meiosis module may serve multiple descendants, using allele selection tables and shared counters to reduce redundancy. Overall, this architecture accelerates allele probability estimation by mapping the pedigree’s natural parallelism onto hardware, achieving throughput limited only by clock frequency—not pedigree complexity.
