# DESCRIPTION

## TECHNICAL FIELD

The present invention relates to machine learning systems for document summarization, and more specifically to abstractive summarization systems that generate fluent and salient summaries while preserving factual consistency with the source document. The invention further pertains to methods and systems for improving the faithfulness of generated summaries by reducing hallucinated content—particularly at the entity level—through the use of controllable mechanisms based on entity coverage precision metrics. Additionally, the invention encompasses techniques for zero-shot summarization across diverse domains by leveraging intermediate pre-training on pseudo-labeled data derived from large-scale corpora such as Wikipedia, thereby enabling generalization without domain-specific fine-tuning.

## BACKGROUND

Traditional document summarization systems have historically relied on extractive approaches, which select and concatenate salient sentences or phrases directly from the source document. While these methods guarantee factual consistency, they often produce summaries that lack fluency, coherence, and conciseness. In recent years, abstractive summarization—enabled by advances in sequence-to-sequence (seq2seq) neural architectures and large pre-trained language models—has emerged as a powerful alternative capable of generating human-like, paraphrased summaries. However, a significant limitation of current abstractive summarization systems is their tendency to generate unfaithful or hallucinated content, wherein the summary contains information not supported by the source document. Such hallucinations may manifest as fabricated entities, incorrect relationships, or entirely extraneous facts, thereby undermining the reliability and utility of the generated summaries in real-world applications such as news reporting, scientific literature review, or clinical documentation.

Prior attempts to address this issue have included post-processing correction methods that replace hallucinated entities with plausible alternatives from the source document, as well as data filtering techniques that remove training examples with low faithfulness. However, these approaches suffer from critical drawbacks: post-processing may introduce new errors or reduce summary fluency, while data filtering sacrifices valuable training data and can degrade overall summary quality. Moreover, existing methods often fail to generalize across domains, requiring separate models or extensive retraining for each new application context. Consequently, there remains a pressing need for a robust, controllable, and generalizable approach to abstractive summarization that ensures high faithfulness without compromising salience or fluency.

## DETAILED DESCRIPTION

### Systems for Abstractive Summarization

The present invention introduces a system for abstractive summarization that integrates multiple novel components to enhance the faithfulness and cross-domain generalizability of generated summaries. At the core of the system is a pre-processing module that prepares input documents and reference summaries for training by identifying named entities using state-of-the-art natural language processing (NLP) toolkits. For general-domain text, the system employs the Stanza NLP toolkit trained on the OntoNotes corpus, while for biomedical or scientific documents, it utilizes the scispaCy toolkit optimized for domain-specific entity recognition.

A key innovation of the system is the entity coverage precision module, which computes a faithfulness metric—referred to herein as entity coverage precision (prec_en)—for each document-summary pair in the training dataset. This metric is defined as the ratio of named entities in the reference summary that are also present in the source document, thereby quantifying the extent to which the summary adheres to the factual content of the source. Formally, if N(t) denotes the set of named entities in a text t, then prec_en = |N(summary) ∩ N(document)| / |N(summary)|.

To enable controllable generation, the system includes a pseudo labeling module that discretizes the continuous entity coverage precision values into k bins (e.g., k=3), each representing a distinct level of faithfulness (e.g., low, medium, high). These bins are designed to be balanced in terms of the number of training instances they contain, ensuring uniform representation during model training. Each bin is associated with a unique special token—such as <FF-low>, <FF-mid>, and <FF-high>—which serves as a control code.

The summarization module comprises a sequence-to-sequence model, preferably implemented as a BART (Bidirectional and Auto-Regressive Transformer) abstractive summarization model, which is a denoising autoencoder based on the transformer architecture. During training, the control code corresponding to the computed entity coverage precision of a given document-summary pair is prepended to the input document. This conditions the model to learn generation patterns associated with different levels of faithfulness. At inference time, the system prepends the high-faithfulness control code (<FF-high>) to all input documents, thereby guiding the model to produce summaries with minimal entity hallucination.

The training process utilizes a cross-entropy loss function to optimize the model parameters. The transformer encoder processes the input sequence—including the control code and the source document—into contextualized representations, which are then decoded by the transformer decoder to generate the summary token-by-token. The training objective is to maximize the likelihood of the reference summary given both the source document and the control code.

To extend the system’s capabilities to zero-shot summarization across diverse domains, the invention further incorporates a controllable intermediate pre-training pipeline. This pipeline generates pseudo document-summary pairs from the Wikipedia corpus by selecting articles and their introductory paragraphs (or lead sections) that match target datasets in terms of document length, summary length, and abstractiveness level. Each pseudo dataset is assigned a domain-specific control code (e.g., <NEWS>, <SCIENTIFIC>, <DIALOG>), which is prepended during training. This enables the model to learn domain-adaptive summarization patterns without requiring labeled data from the target domain. Crucially, the entity coverage control codes and domain control codes are stackable, allowing simultaneous control over both faithfulness and domain style during inference.

The resulting system demonstrates strong generalizability across domains, as validated on benchmark datasets including XSum (news), PubMed (scientific papers), and SAMSum (dialogues). By integrating entity-level faithfulness control with domain-aware intermediate pre-training, the invention achieves state-of-the-art performance in both supervised and zero-shot settings, significantly reducing hallucination while maintaining or improving summary quality.

## EXAMPLES

### Example 1: Experimental Methods and Results

The experimental validation of the present invention was conducted using a comprehensive setup involving multiple benchmark datasets and evaluation metrics. Three primary datasets were employed: XSum, a news summarization dataset characterized by high abstractiveness and frequent hallucination; PubMed, a collection of scientific article abstracts; and SAMSum, a dialogue summarization dataset. Baseline comparisons included standard BART-large, post-processing correction methods (Chen et al., 2021), and data filtering approaches (Nan et al., 2021), as well as WikiTransfer for zero-shot evaluation.

Evaluation metrics encompassed both automatic and human assessments. Automatic metrics included ROUGE (Recall-Oriented Understudy for Gisting Evaluation) for measuring salience and fluency, BERTScore for semantic similarity, Entity Coverage Precision for faithfulness at the entity level, and FEQA (Fact Extraction and Verification via Question Answering) for factual consistency. Human evaluation was performed by four expert annotators who assessed 50 randomly sampled summaries from XSum across three faithfulness categories (faithful, intrinsic hallucination, extrinsic hallucination) and three quality levels (low, medium, high).

The implementation leveraged Huggingface libraries and the BART-large model, fine-tuned on 8 Tesla A100 GPUs with a learning rate of 5e-5. Entity recognition was performed using Stanza for general text and scispaCy for PubMed. The entity coverage precision thresholds were set at 0.33 and 0.66 for XSum and SAMSum, and 0.36 and 0.5 for PubMed, yielding three balanced bins.

Results demonstrated that the proposed Entity Coverage Control (ECC) method significantly increased entity coverage precision compared to baseline BART—by up to 15% on XSum—without degrading ROUGE scores. In zero-shot settings, the controllable intermediate pre-training approach outperformed WikiTransfer in both ROUGE and entity coverage precision, confirming its cross-domain generalizability. Human evaluation corroborated these findings: ECC-generated summaries were rated as more faithful than baselines, with no reduction in quality.

An illustrative example from XSum involved a BBC article about a teenage science competition streamed on YouTube. The baseline BART model hallucinated the platform as “Gumtree,” while the ECC model correctly generated “YouTube” when conditioned on the <FF-high> control code. Another example showed that decoding with different control codes produced summaries of varying faithfulness: the <FF-low> output mentioned “Spain” generally, while the <FF-high> output specified “Andalucia,” matching the source document.

Analysis confirmed that the ECC model did not achieve higher faithfulness by under-generating entities; the distribution of entity counts in generated summaries closely matched that of the baseline. Furthermore, probing experiments revealed that BART’s hallucinations often stem from pre-trained knowledge priors (e.g., generating “Gary Anderson” instead of the less common “Steven Anderson”), which the control code mechanism effectively suppresses by anchoring generation to source-derived entities.

These results collectively validate the efficacy, robustness, and practical utility of the present invention in producing faithful, high-quality abstractive summaries across diverse domains.
