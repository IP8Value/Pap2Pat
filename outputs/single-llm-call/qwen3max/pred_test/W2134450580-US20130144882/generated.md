# DESCRIPTION

## BACKGROUND OF THE INVENTION

The present invention resides in the field of computational biology and bioinformatics, particularly in the domain of network-based gene expression analysis for disease classification, biomarker discovery, and systems-level interpretation of molecular data. More specifically, the invention relates to a novel method and system for transforming high-dimensional gene expression profiles into integrative, knowledge-supervised features by leveraging topological properties of protein-protein interaction (PPI) networks reordered through bio-inspired optimization algorithms. This approach enables improved accuracy in distinguishing biological states—such as healthy versus diseased conditions—and facilitates the identification of functionally coherent gene modules that may be overlooked by conventional differential expression analyses.

Current approaches to gene expression profiling, including microarray and RNA-Seq technologies, typically assess individual genes in isolation when identifying potential biomarkers or classifying disease states. While these methods have yielded valuable insights, they suffer from significant limitations. First, they often disregard the functional context in which genes operate, treating each transcript as an independent variable despite well-established evidence that genes act in coordinated pathways and complexes. Second, weakly differentially expressed genes—those whose individual fold-changes fall below arbitrary statistical thresholds—are routinely discarded as noise, even though their collective behavior within biologically relevant networks may carry critical diagnostic or prognostic information. Third, existing network-based methods either rely on simplistic ranking schemes (e.g., PageRank or random walk models) or unsupervised clustering techniques that fail to impose a meaningful linear order on network nodes, thereby limiting their utility in generating continuous, interpretable expression profiles suitable for machine learning classifiers. These shortcomings hinder the development of robust, generalizable diagnostic tools, especially in complex multifactorial diseases like Alzheimer’s disease, where dysregulation is distributed across many modest-effect genes rather than dominated by a few highly differentially expressed markers.

There is therefore a pressing need for a new analytical framework that integrates prior biological knowledge—encoded in molecular interaction networks—with quantitative gene expression data in a manner that preserves both local and global topological structure. Such a framework must be capable of transforming sparse, noisy expression vectors into dense, biologically informed features that reflect the systemic perturbations underlying disease. Moreover, it should enable the detection of subtle but coordinated expression shifts among functionally related genes, thereby uncovering hidden patterns that traditional univariate analyses miss. The present invention addresses this unmet need by introducing a computationally rigorous, biologically grounded methodology that reorders disease-specific PPI networks using an ant colony optimization reordering (ACOR) algorithm and subsequently integrates gene expression values along this optimized sequence to generate what is termed a MIXP (Microarray-based Integrative eXpression Profile). This innovation not only enhances classification performance but also provides a systems-level lens through which to interpret molecular pathology.

## SUMMARY OF THE INVENTION

The present invention introduces a novel computational methodology referred to herein as the MIXP (Microarray-based Integrative eXpression Profiling) approach, which constitutes a knowledge-supervised feature transformation technique designed to improve the accuracy and biological interpretability of disease classification based on gene expression data. Central to the invention is the integration of gene expression measurements with a disease-specific protein-protein interaction (PPI) network that has been systematically reordered using a bio-inspired optimization algorithm—specifically, the Ant Colony Optimization Reordering (ACOR) algorithm. This reordering process arranges network nodes (proteins/genes) in a sequence that reflects both their functional relatedness and topological centrality, thereby enabling the generation of a one-dimensional integrated expression profile that captures system-wide transcriptional dynamics.

The MIXP approach is founded on the principle that functionally related genes, even if individually weakly differentially expressed, exhibit coordinated expression patterns when considered within the context of a biologically meaningful network topology. Traditional gene expression analyses treat each gene independently, discarding low-magnitude signals as noise; in contrast, the present invention leverages network connectivity to amplify these subtle signals through spatial integration along an optimized node ordering. This is achieved by first constructing a disease-relevant PPI network using seed genes derived from authoritative databases such as AlzGene and OMIM, followed by expansion via nearest-neighbor algorithms applied to comprehensive interaction repositories like HAPPI. The resulting network is then subjected to the ACOR algorithm, which simulates the emergent behavior of ant colonies to determine an optimal linear arrangement of nodes that reveals fractal-like structural patterns indicative of modular organization.

The core of the MIXP method involves four sequential steps: (1) selection of seed molecules associated with a target disease; (2) reconstruction of a disease-specific PPI network through iterative neighbor expansion; (3) reordering of the network adjacency matrix using the ACOR algorithm to produce a biologically informed gene sequence; and (4) integration of sample-specific gene expression values onto this ordered sequence using a one-dimensional Gaussian influence function, yielding a continuous MIXP(t) profile for each biological sample. This profile serves as a transformed feature vector that can be input into standard machine learning classifiers—such as Support Vector Machines (SVM)—to distinguish between health states with significantly improved accuracy compared to raw expression data or alternative network-based transformations.

The invention further encompasses specific algorithms for network analysis, including implementations of ant colony optimization adapted for graph reordering, statistical normalization procedures for microarray data, and methods for mapping expression values onto reordered networks. Additionally, the invention includes a database creation methodology wherein disease-associated proteins are mined from public resources and integrated into a unified PPI framework, enabling reproducible and scalable application across multiple pathologies. The system for determining health situation propensity operates by comparing a subject’s MIXP profile against reference profiles derived from training cohorts, thereby providing a quantitative measure of disease likelihood or progression stage.

It is to be understood that the drawings referenced herein are provided for illustrative purposes only and do not limit the scope of the claimed invention. The algorithms, data structures, and computational workflows described are implemented in software executed on general-purpose computing systems, and their efficacy has been demonstrated in blinded classification tasks involving Alzheimer’s disease microarray datasets, where the MIXP approach outperformed both conventional expression signatures and alternative network-based methods.
