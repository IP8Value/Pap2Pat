# DESCRIPTION

## TECHNICAL FIELD

The present invention relates to electric power grids, and more particularly to systems, methods, and apparatus for predicting disturbance events—such as electrical faults—in transmission and distribution networks. The invention leverages machine learning techniques applied to historical and real-time operational data derived from existing grid instrumentation, without requiring the deployment of additional sensors or intrusive monitoring infrastructure. The disclosed technology is especially suited for integration within smart grid architectures that utilize Industrial Internet of Things (IIoT) principles, edge computing, and cloud-based analytics platforms to enhance the reliability, safety, and efficiency of electrical power delivery systems.

## BACKGROUND ART

Modern electric power systems are increasingly complex, integrating diverse generation sources, dynamic load profiles, and aging infrastructure across generation, transmission, and distribution segments. This complexity has elevated the frequency and impact of electrical disturbances, including short circuits, insulation failures, and equipment malfunctions, which can lead to service interruptions, equipment damage, and significant economic losses. Traditional approaches to fault detection have largely been reactive, relying on protective relays and circuit breakers to isolate faults after they occur. While effective for immediate safety, such methods do not prevent faults or mitigate their precursors.

In response, the concept of the "smart grid" has emerged, incorporating digital communication, automation, and real-time data analytics to enable proactive grid management. Central to this evolution is the application of big data analytics, wherein vast streams of operational data—such as voltage, current, switch statuses, and event logs—are collected, stored, and analyzed to uncover patterns indicative of system degradation. However, existing predictive methods face significant limitations. Partial discharge analysis, though useful for insulation-related faults, requires specialized high-frequency sensors and is ineffective for underground or underwater cables. Thermal monitoring via aerial drones or fixed sensors is similarly constrained by line-of-sight requirements and inability to detect non-thermal fault origins. Moreover, these approaches often necessitate costly hardware retrofits and high-bandwidth data pipelines, limiting scalability.

Consequently, there remains a critical need for a scalable, sensor-free, and computationally efficient method capable of predicting a broad spectrum of grid faults—including those arising from mechanical damage, environmental exposure, animal intrusion, or vegetation contact—using only data already available through standard substation instrumentation and communication protocols.

## SUMMARY

The present invention introduces a novel fault prediction method for electric power grids that overcomes the limitations of prior art by employing a machine learning-based approach trained on historical disturbance recordings. The method begins by receiving events generated by intelligent electronic devices (IEDs) in the grid, each event accompanied by precise time information. These events are input into a trained predictor model, which outputs predictions indicating the likelihood of a future disturbance event—such as a fault—occurring within a defined prediction horizon, typically up to one week.

The predictions are displayed to grid operators via a user interface, enabling timely intervention. The display includes time windows of varying lengths to contextualize the prediction, and explicitly indicates the estimated occurrence time of the predicted disturbance event. To enhance prediction accuracy, the method maintains a set of predefined event categories—such as overcurrent, undervoltage, harmonic distortion, or breaker operation—and determines the category of each incoming event based on its characteristics. This event category is then provided as an input feature to the trained predictor.

Additionally, the method maintains a set of event weight values that reflect the relative significance or anomaly level of different event types. For each received event, an event weight value is determined—either through rule-based logic or learned association—and this weight value is also input to the trained predictor to modulate the influence of the event on the final prediction. All events, along with their associated time information, are stored in a centralized data repository, and this time information is used by the predictor to model temporal dependencies.

The inputting of events to the predictor is performed periodically—e.g., hourly—to enable near real-time monitoring. Complementing the prediction functionality, the invention further introduces an event pattern extraction process. This process acquires historical event data from storage, extracts recurring or anomalous sequences of events (event patterns), and inputs these patterns into a machine learning model during a training phase. The model is trained to recognize patterns that precede actual disturbance events, and once trained, it is stored as the predictor used in operational mode.

To improve training efficiency and model relevance, the method filters event patterns associated with testing or commissioning activities, which may not reflect normal operational conditions. Event categories and weight values are embedded within each event pattern to preserve contextual richness. Furthermore, events with low weight values—indicating minimal operational significance—are filtered out during pattern extraction to reduce noise. The invention also encompasses an apparatus specifically configured to execute the aforementioned fault prediction method, integrating data ingestion, preprocessing, prediction, and visualization capabilities within a unified architecture.

## DETAILED DESCRIPTION OF SOME EMBODIMENTS

The following description sets forth specific embodiments of the invention to provide a thorough understanding of its structure, function, and advantages. It should be understood that the use of the terms “an,” “one,” or “some” embodiment(s) throughout this disclosure refers to one or more particular implementations of the invention and does not limit the scope of the claims to only those examples. The invention may be embodied in single units, integrated models, standalone devices, or distributed systems comprising multiple memory and processing components.

In modern implementations, the invention may leverage cloud computing and virtualization technologies to decouple computational tasks from physical hardware, enabling scalable and resilient deployment across utility IT infrastructures. Referring to FIG. 1, a system architecture 100 is illustrated, comprising a power distribution grid 110 equipped with multiple intelligent electronic devices (IEDs) 111. These IEDs—such as protective relays, reclosers, or meters—continuously monitor electrical parameters and generate event records upon detecting anomalies or state changes. Each event includes measured data (e.g., voltage and current waveforms sampled at 4 kHz) and precise time stamps, compliant with IEC 61850-9-2LE and IEC 61850-8-1 communication standards.

Events are transmitted to a cloud platform 102, where they are stored in a data storage module 121 as historic event data. This data is structured to include event type, timestamp, feeder identifier, phase information, and derived features such as RMS values, impedance, harmonics, and power metrics. The storage implementation may utilize relational databases, time-series databases, or distributed file systems, depending on scale and performance requirements.

A control center 130 interfaces with the cloud platform and includes a computing apparatus 132, a user interface 131, and a predictor unit 133. The predictor unit executes a trained machine learning model 133-1—typically a deep neural network incorporating a filtering component, an LSTM layer, and a classification head—to analyze incoming event sequences and output a probability score between 0 and 1, representing the likelihood of a fault occurring within the next week. Predictions are displayed on the user interface with visual indicators, time windows, and alert notifications to support operator decision-making.

An offline apparatus 140 houses a trainer unit 116 responsible for model development. As shown in FIG. 2, the trainer acquires historic event data, performs feature engineering to extract ~300 scalar descriptors per event, and applies windowing to construct multidimensional time series spanning one-week intervals. These sequences, labeled with binary targets indicating subsequent faults, are used to train the machine learning model. Irrelevant events—such as those from commissioning or with low weight values—are filtered out to enhance signal-to-noise ratio. The trained model is stored and subsequently downloaded to the predictor unit.

FIG. 3 illustrates the operational flow: events are received, categorized, weighted, buffered over a sliding time window, and periodically fed into the predictor. Outputs are post-processed and displayed, as exemplified in FIGS. 4 and 5. FIG. 6 details the training workflow, including data augmentation (e.g., phase permutation) to expand dataset variability.

This code, when executed, configures the apparatus to perform all described functions. The carrier of the program may be a non-transitory medium such as a hard drive, SSD, or semiconductor memory. Hardware implementations may include microprocessors, chipsets, logic gates, ASICs, or FPGAs, all configured to embody the predictor and trainer units as disclosed.
