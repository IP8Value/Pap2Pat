# DESCRIPTION

## FIELD

The present invention relates to automated spoken language understanding. More particularly, the invention pertains to systems and methods for performing intent determination and slot filling in spoken dialogue systems using a neural generative model that integrates sequence-to-sequence learning with a pointer network mechanism to address out-of-vocabulary (OOV) challenges without reliance on word-level annotations or manually engineered rules.

## BACKGROUND

Spoken language understanding (SLU) is a critical component of modern conversational agents and virtual assistants, enabling machines to interpret human utterances in natural language and extract actionable semantic content. At its core, SLU involves two primary subtasks: intent determination, which identifies the user’s goal or purpose (e.g., “find a restaurant”), and slot filling, which extracts specific pieces of information relevant to that intent (e.g., “pricerange=moderate”, “food=Italian”). Traditionally, slot filling has been formulated as a sequence labeling problem, where each word in an utterance is tagged with a corresponding slot label using schemes such as BIO (Begin, Inside, Outside). This approach has been implemented using statistical models like conditional random fields (CRFs) or recurrent neural networks (RNNs), which require fine-grained, word-level annotations for training.

However, obtaining such annotations is labor-intensive and often impractical, especially when scaling to new domains or languages. Many real-world datasets provide only sentence-level semantic annotations—specifying slot-value pairs without indicating which words in the utterance correspond to those values. To bridge this gap, prior systems have resorted to heuristic alignment rules or word alias dictionaries to infer word-level labels, but these methods are brittle, domain-specific, and prone to error, particularly when applied to noisy speech recognition outputs. Moreover, even when alignment is achieved, conventional classification-based approaches to slot filling face significant limitations when dealing with non-enumerable slots—those with open-ended or unbounded value sets, such as restaurant names, street addresses, or cuisine types. These slots frequently contain out-of-vocabulary (OOV) terms not observed during training, leading to poor generalization and high error rates.

To mitigate these issues, joint training models have been proposed that simultaneously predict intent and slots, often leveraging attention mechanisms to dynamically focus on relevant parts of the input sequence. Attention allows the model to weigh the importance of each input word when making predictions, improving contextual awareness. In slot-filling operations, this enables more accurate mapping between utterance tokens and semantic slots. Despite these advances, existing SLU systems remain fundamentally constrained by their dependence on predefined vocabularies and annotated training data, limiting their adaptability and robustness in real-world applications where OOV terms are pervasive and annotation resources are scarce. There is therefore a compelling need for an improved SLU architecture that can operate effectively on unaligned, sentence-level annotated data, handle OOV slot values natively, and eliminate reliance on manual feature engineering or domain-specific rules.

## SUMMARY

The present invention introduces a novel neural generative model for spoken language understanding that overcomes the limitations of prior-art systems by integrating sequence-to-sequence (Seq2Seq) learning with a pointer network mechanism. Unlike traditional approaches that require word-level annotations, the disclosed model operates directly on sentence-level semantic labels, predicting sequences of slot values from raw utterances without intermediate alignment steps. The model employs a Seq2Seq framework with an attention mechanism, wherein an encoder processes the input utterance into a sequence of hidden states, and a decoder generates slot values token by token.

Critically, the invention incorporates a pointer network that enables the system to either generate a token from a fixed slot vocabulary or directly copy a word from the input utterance. This dual-mode operation—combining generation and pointing—effectively addresses the out-of-vocabulary (OOV) problem by allowing the model to select rare or unseen slot values directly from the user’s spoken phrase, even if those values were never encountered during training. The final prediction at each decoding step is a weighted combination of the probabilities from the generative component and the pointer component, with the weighting factor dynamically computed based on the current decoder state, input, and context vector.

The neural generative model of the invention does not require any manually annotated word-level labels, handcrafted alignment rules, or domain-specific dictionaries, making it highly portable across domains. It simultaneously identifies user intent and predicts slot types and values within a unified framework, though it may also be integrated into a pipeline architecture where slot prediction precedes intent and slot-type classification. By leveraging the pointer mechanism, the system achieves superior precision and recall in slot assignment, particularly for non-enumerable slots with high cardinality or OOV terms. This results in a more robust, accurate, and scalable SLU system suitable for real-world spoken dialogue applications.

## DETAILED DESCRIPTION

The present patent application describes a system and method for automated spoken language understanding that significantly improves the accuracy and robustness of intent determination and slot filling, particularly in the presence of out-of-vocabulary (OOV) terms and limited annotation resources. Reference is made to the accompanying drawings, which form a part hereof and illustrate exemplary embodiments of the invention. A Recurrent Neural Network (RNN) forms the backbone of the disclosed architecture, specifically implemented using Gated Recurrent Units (GRUs), though other RNN variants such as Long Short-Term Memory (LSTM) units may be substituted. The system employs an RNN encoder/decoder network, where the encoder transforms an input sequence of word embeddings into a sequence of internal hidden states that capture contextual and semantic information. The decoder then uses these representations to generate an output sequence of slot values.

Out-of-vocabulary (OOV) words—those not present in the training vocabulary—pose a persistent challenge in SLU. To address this, the invention utilizes both uni-directional and bi-directional RNNs; the encoder is preferably a single-layer bi-directional GRU, which processes the input sequence in both forward and backward directions, yielding a richer contextual representation. The bi-directional RNN output at each time step is the concatenation of the forward and backward hidden states. An attention mechanism, implemented using a score function such as the additive attention of Bahdanau et al., computes attention weights that reflect the relevance of each input word to the current decoding step. These weights are normalized via a softmax function to produce a probability distribution over the input positions, which is then used to compute a context vector—a weighted sum of the encoder hidden states. This context vector, combined with the decoder state, forms the attention vector that informs the next prediction.

The invention further introduces a pointer network, which at each decoding step produces a probability distribution over the positions of the input sequence rather than over a fixed vocabulary. The pointer network output enables direct selection of words from the utterance, crucial for handling OOV slot values. The system combines the outputs of the RNN decoder (which generates from a fixed slot vocabulary) and the pointer network (which copies from input) into a unified probability distribution over an extended vocabulary—the union of the fixed slot vocabulary and all words in the current input utterance. This combination is governed by a dynamically computed switching parameter p_t ∈ [0,1], derived via a sigmoid function of the decoder input, state, and context vector, with trainable weights.

The SLU system 100 includes an audio input device 104 for receiving spoken utterances, which are converted to text by a speech recognizer 136. Processed results are delivered via an output device 112, such as a display or speaker. A processor 128 executes programmed instructions 134 stored in memory 132 to implement the core SLU functions. These include an intent classifier 138, an RNN encoder 140, a slot word decoder 144 comprising an RNN decoder 146 and a pointer network 148, an extended slot vocabulary database 162, and a slot database 166 containing predefined enumerable slot values. The speech recognition process yields a word sequence, which the RNN encoder 140 encodes into hidden states. The slot word decoder 144 then generates a sequence of slot words by iteratively producing probability distributions over the extended vocabulary, combining RNN and pointer outputs, and selecting the most probable token at each step until a stopping criterion (e.g., end-of-sequence token) is met.

The resulting slot words are used in slot-filling operations, where a slot classifier assigns each predicted value to a slot type (e.g., “moderate” → pricerange). Intent is identified separately, often using a convolutional neural network (CNN) that classifies the utterance into one or more dialog acts. The slot words serve as parameters for executing the user’s command—e.g., generating a database query for restaurants with pricerange=moderate and food=Italian. Experimental evaluation on the DSTC2 benchmark demonstrates that the system achieves state-of-the-art F1 scores for both slot value prediction and full SLU, with particular gains in high-OOV scenarios. Variants of the system may employ different RNN architectures, attention formulations, or integration frameworks (joint vs. pipeline). Applications span voice assistants, customer service bots, and smart home controllers. The invention’s rule-free, annotation-efficient design enables rapid deployment in new domains, and its robust handling of OOV terms ensures reliable performance in real-world conditions. The intended scope of the claims encompasses all such modifications, improvements, and unforeseen alternatives that fall within the spirit and scope of the disclosed technology.
