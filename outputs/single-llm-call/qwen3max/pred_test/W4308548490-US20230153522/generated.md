# DESCRIPTION

## BACKGROUND

Natural language processing (NLP) is a field of artificial intelligence that focuses on the interaction between computers and human language. It encompasses a wide range of tasks, including speech recognition, natural language understanding, and natural language generation. In recent years, NLP has seen significant advancements due to the integration of deep learning techniques, which enable machines to process and generate human-like text with increasing fluency and contextual relevance. One particularly important application of NLP is in the domain of image captioning, where systems are trained to automatically generate textual descriptions of visual content. This capability bridges the gap between visual perception and linguistic expression, enabling applications such as assistive technologies for the visually impaired, content-based image retrieval, and automated metadata generation for large-scale image databases.

Machine learning algorithms have become the cornerstone of modern NLP systems, especially those based on neural networks. These algorithms learn patterns from vast amounts of data and generalize to unseen inputs, making them highly effective for complex tasks like language modeling and multimodal reasoning. In the context of image captioning, machine learning models typically combine computer vision components—such as convolutional neural networks (CNNs)—with sequence modeling architectures—like recurrent neural networks (RNNs) or transformers—to jointly encode visual information and decode it into coherent sentences. The success of these models depends heavily on the quality and diversity of training data, as well as the design of objective functions that guide the learning process toward generating accurate, informative, and grammatically correct captions.

Search indexing plays a critical role in enabling efficient retrieval of images based on textual queries. Traditional approaches rely on manually annotated tags or keywords associated with each image, but this method is labor-intensive and does not scale well to massive datasets. To overcome these limitations, researchers have developed automatic image captioning systems that can generate descriptive text for unlabeled images, thereby creating searchable textual representations without human intervention. These generated captions serve as rich semantic keys that facilitate more nuanced and flexible querying compared to simple keyword matching. However, the effectiveness of such systems hinges on the fidelity and distinctiveness of the captions they produce; generic or vague descriptions offer little value for precise search operations.

Despite substantial progress, conventional image captioning methods suffer from several key limitations. Most notably, models trained using standard maximum likelihood estimation (MLE) or similarity-based metrics like CIDEr tend to prioritize common, salient objects while neglecting fine-grained details that distinguish one image from another. This results in captions that are often overly generic and fail to capture unique aspects of the scene, such as subtle background elements, object attributes, or spatial relationships. Moreover, because these models are optimized against reference captions—which themselves may be incomplete or biased—the resulting outputs inherit these deficiencies. Additionally, some reinforcement learning-based approaches introduce exposure bias or require careful balancing between multiple reward signals, complicating the training process and limiting robustness. These shortcomings underscore the need for novel training strategies that encourage the generation of more distinctive, detailed, and grammatically sound captions without relying on potentially flawed reference texts.

## SUMMARY

The present invention introduces an innovative image captioning network designed to generate highly descriptive and grammatically correct captions by leveraging a multi-modal reward function derived from a pre-trained contrastive language-image model, specifically CLIP (Contrastive Language–Image Pretraining). Unlike conventional approaches that optimize caption similarity against fixed reference texts, the disclosed system uses the multimodal alignment score between an image and its generated caption—as computed by CLIP—as a direct reward signal during training. This approach encourages the captioning model to produce descriptions that are not only semantically aligned with the input image but also rich in distinguishing details that enhance text-to-image retrieval performance.

The training process involves optimizing the parameters of the image captioning network using a self-critical reinforcement learning framework, wherein the reward is normalized relative to a baseline generated via greedy decoding. By maximizing the CLIP-based reward, the model learns to emphasize image-specific features that improve cross-modal correspondence, even when those features are absent from traditional reference captions. Furthermore, to address grammatical degeneracies—such as word repetition—that may arise from training solely on CLIP rewards, the invention incorporates a grammar-aware fine-tuning strategy for the CLIP text encoder. This strategy utilizes synthetically generated negative caption samples, created through token-level perturbations (e.g., repetition, deletion, insertion, swapping, shuffling), to inject linguistic structure into the encoder without requiring additional annotated data.

An exemplary application of the disclosed image captioning system lies in advanced image search engines. By generating high-quality, distinctive captions for unlabeled images, the system enables more accurate and semantically meaningful text-to-image retrieval. Users can input natural language queries, and the system retrieves relevant images based on the semantic alignment between the query and the stored captions, all of which were produced by the trained captioning network. This capability significantly enhances the usability and precision of large-scale visual databases, particularly in domains where manual annotation is impractical.

In one embodiment, the image captioning system comprises an image encoder (e.g., a ResNet-50 backbone integrated with a transformer architecture), a language decoder (e.g., a transformer-based sequence generator), and a multi-modal reward computation module based on a fine-tuned CLIP model. The system is trained end-to-end using a combination of CLIP-guided reinforcement learning and contrastive fine-tuning of the text encoder with synthetic negatives. The resulting model generates captions that outperform prior art in both automatic metrics and human evaluations across multiple dimensions, including overall quality, background description, object identification, attribute specification, and relational understanding.

In summary, the disclosed image captioning method overcomes the limitations of reference-dependent training by employing a reference-free, multi-modal reward mechanism grounded in large-scale contrastive pretraining. Through strategic fine-tuning of the language encoder using synthetic grammatical violations, the system ensures that generated captions are not only distinctive and informative but also fluent and structurally sound. This dual innovation—combining CLIP-based reward optimization with grammar-aware encoder adaptation—represents a significant advancement in the field of automated image description and enables new capabilities in semantic image search and accessibility technologies.

## DETAILED DESCRIPTION

Image captioning refers to the task of automatically generating natural language descriptions of visual content. While early systems relied on template-based or rule-driven approaches, modern solutions predominantly employ deep neural networks that learn to map visual inputs to linguistic outputs through supervised or reinforcement learning paradigms. Despite their success, conventional image captioning models exhibit notable limitations: they often produce generic, non-distinctive captions that focus only on dominant objects while omitting finer contextual details such as background scenery, object attributes (e.g., color, texture), or spatial relations between entities. This deficiency stems largely from the reliance on reference captions during training, which themselves may lack comprehensive detail due to dataset biases or annotation constraints.

To address these shortcomings, the present invention motivates the use of a multi-modal reward function derived from CLIP, a large-scale contrastively trained model that aligns image and text embeddings in a shared latent space. Unlike traditional metrics that measure n-gram overlap or syntactic similarity with reference texts, the CLIP-based reward evaluates the semantic coherence between an image and its caption directly, without requiring ground-truth references. This enables the captioning model to learn from the intrinsic visual-textual alignment signal, promoting the generation of captions that are uniquely descriptive of the input image.

The core machine learning model of the invention integrates an image encoder (e.g., ResNet-50 or Vision Transformer) with a language decoder (e.g., transformer or LSTM) to form an end-to-end captioning architecture. During training, the model is optimized not via maximum likelihood alone, but through a reinforcement learning objective that maximizes the expected CLIP similarity score between the generated caption and the input image. Specifically, the gradient is approximated using the self-critical policy gradient method, where rewards from beam-searched captions are normalized against a baseline obtained from greedy decoding to reduce variance.

A key advantage of this approach is its ability to generate captions that achieve higher text-to-image retrieval accuracy than even the original reference captions, demonstrating superior distinctiveness. Moreover, by eliminating dependence on reference texts for reward computation, the system avoids propagating dataset biases and instead learns to emphasize image-specific details that enhance cross-modal retrieval.

To further refine output quality, the invention introduces grammar score-based training. Since CLIP was not trained with a language modeling objective, captions optimized solely on CLIP rewards may suffer from grammatical errors such as repetitive phrasing. To mitigate this, the CLIP text encoder is fine-tuned using a contrastive learning framework that distinguishes between original (positive) captions and synthetically corrupted (negative) versions. Negative samples are generated by applying stochastic token-level perturbations—including repetition, removal, insertion, swapping, and shuffling—to reference captions, thereby simulating common grammatical violations.

This negative training sample-based training strategy injects implicit grammatical knowledge into the text encoder without requiring external linguistic annotations. As a result, the captioning model produces outputs that are not only semantically aligned with the image but also linguistically fluent.

The multi-modal text and image encoder neural networks are implemented using CLIP’s dual-encoder architecture, where images and texts are independently projected into a shared embedding space. During caption generation, the image encoder processes the input image to produce a visual representation, which is then used by the language decoder to autoregressively generate tokens. The entire system is trained to maximize the cosine similarity between the final image embedding and the caption embedding produced by the fine-tuned CLIP text encoder.

Applications in image searching benefit directly from this enhanced caption quality. By encoding images and generating high-fidelity captions at scale, the system populates a searchable database where users can retrieve images using natural language queries. The semantic richness of the captions enables more precise matching than keyword-based systems, supporting complex queries involving object attributes, scene context, or relational descriptions.

### Image Search System

The image search system of the present invention provides a robust framework for retrieving images based on natural language queries by leveraging automatically generated, high-quality captions. The system begins with a user interface that allows individuals to input textual search terms via a user device, such as a smartphone, tablet, or desktop computer. This input component captures the user’s query and transmits it to a centralized image search apparatus hosted on a remote server or cloud infrastructure.

The image search apparatus comprises several key functional modules: a training component, a search component, a machine learning model (specifically, the image captioning network), a processor unit, and a memory unit. The processor unit executes program instructions stored in the memory unit to perform caption generation, encoding, storage, and retrieval operations. Communication between the user device and the image search apparatus occurs over a network (e.g., the Internet), enabling real-time interaction with a remote database containing encoded images and their associated captions.

In a server implementation, the system first encodes a large corpus of images using the trained image captioning network. For each image, the network generates a descriptive caption, which is then processed by the fine-tuned CLIP text encoder to produce a text embedding. Simultaneously, the image is encoded by the CLIP image encoder to yield a corresponding visual embedding. Both embeddings—and optionally the raw caption text—are stored in a structured database, forming an index that supports efficient similarity-based retrieval.

When a user submits a search query, the system receives the textual input at the search component. The query is encoded using the same CLIP text encoder, and the resulting embedding is compared against all stored image embeddings via cosine similarity or another distance metric. The top-k most similar images are retrieved, along with their generated captions, and presented to the user through the interface on their device.

Underlying this functionality is an artificial neural network (ANN) composed of interconnected nodes (neurons) and weighted edges that propagate signals through layers of computation. The ANN includes hidden layers that transform raw inputs into abstract representations, enabling the model to capture complex patterns in both visual and textual data. During training, the loss function combines reinforcement learning rewards (from CLIP similarity) and contrastive learning objectives (from positive/negative caption pairs) to jointly optimize caption distinctiveness and grammaticality.

Cloud computing infrastructure supports scalable deployment, allowing the system to handle millions of images and concurrent user requests. The database schema organizes records by image identifiers, embeddings, and metadata, facilitating rapid lookup during search operations. Text-to-image searching is thus enabled through dense vector comparisons rather than brittle keyword matching.

The training component implements a multi-stage process: it receives training images from the database, generates candidate captions, encodes both modalities, computes a multi-modal reward (augmented with grammar scores), and updates network parameters via backpropagation. Reinforcement learning drives the optimization, with the reward function incorporating both CLIP similarity and grammatical correctness as measured by the fine-tuned encoder’s ability to discriminate real from synthetic captions.

Attribute-specific caption selection further refines training by emphasizing certain semantic aspects (e.g., color, spatial relations). Negative samples for such attributes are generated by removing relevant words, forcing the model to learn discriminative features. Multi-modal encoder training uses contrastive loss to pull positive pairs closer and push negative pairs apart in embedding space.

Ultimately, the image search system delivers a seamless experience where users obtain visually relevant results based on expressive, natural language descriptions—made possible by an image captioning network trained with a novel combination of CLIP-guided rewards and grammar-aware fine-tuning.
