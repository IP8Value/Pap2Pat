# DESCRIPTION

## BACKGROUND

The ever-increasing computational and memory demands of deep neural networks (DNNs) have spurred significant interest in reduced-precision implementations to enable efficient deployment on resource-constrained hardware. Quantization, the process of mapping high-precision numerical representations—typically 32-bit floating-point values—to lower-precision formats such as 8-bit, 6-bit, or even 4-bit integers, has emerged as a cornerstone technique for reducing both model size and computational complexity. However, aggressive quantization introduces quantization noise, which can severely degrade model accuracy if not carefully managed. A critical aspect of quantization fidelity lies in the selection of an appropriate quantization range, often defined by a clipping scalar that determines the interval over which data is discretized. Traditional approaches, such as max-scaling—which sets the quantization range to span from the minimum to the maximum value in a tensor—suffer from poor noise characteristics due to the presence of outliers that inflate the quantization step size, thereby reducing resolution for the majority of values concentrated near zero. Alternative strategies involve clipping the data to a narrower range, but determining the optimal clipping scalar that minimizes quantization error remains a non-trivial challenge. Prior methods either rely on heuristic calibration using percentiles of activation distributions, introduce learnable parameters that complicate training and reduce reproducibility, or perform exhaustive brute-force searches that are computationally prohibitive for dynamic adaptation during training. These limitations underscore the need for a principled, efficient, and theoretically grounded method to compute optimal clipping scalars on-the-fly, enabling high-accuracy quantization-aware training without modifications to standard training recipes or reliance on hyperparameter tuning.

## SUMMARY

The present invention introduces novel systems and methods for quantizing tensors in neural networks with minimal quantization noise through the use of optimally clipped quantization ranges. Central to the invention is a fast recursive algorithm, termed Optimally Clipped Tensors And Vectors (OCTAV), which computes clipping scalars that minimize the mean squared error (MSE) between original and quantized tensors. The invention further encompasses improved gradient estimation techniques for quantization-aware training (QAT), specifically a magnitude-aware derivative (MAD) that mitigates gradient explosion and premature convergence stoppage observed in conventional estimators. The disclosed quantization systems operate by dynamically or statically determining optimal clipping scalars for each tensor—whether weights or activations—based on empirical data distributions, thereby enabling high-fidelity low-bitwidth neural network training and inference. The method for quantizing tensors involves iteratively refining an initial guess for the clipping scalar using a Newton-Raphson-based update rule derived from the analytical expression of quantization MSE, converging rapidly to the global optimum. This approach is applicable across various quantization granularities, including per-tensor, per-channel, and per-feature scaling, and integrates seamlessly into existing deep learning frameworks without requiring changes to baseline training procedures.

## DETAILED DESCRIPTION

The invention introduces the concept of optimally clipped tensors and vectors, wherein the quantization range is adaptively narrowed to exclude extreme outliers while preserving fine-grained resolution for the bulk of the data distribution. This is achieved by defining a clipping scalar *s* that bounds the quantization interval to [−*s*, *s*], with values outside this range saturated to the nearest bound prior to discretization. Quantization-aware training (QAT) is a methodology wherein quantization operations are simulated during the forward pass of neural network training, allowing the model to adapt to the distortions introduced by low-precision arithmetic. Dynamic quantization refers to schemes where quantization parameters, such as the clipping scalar, are computed on-the-fly for each input batch or training iteration, making it suitable for scenarios with non-stationary tensor statistics, such as training-from-scratch or fine-tuning. In contrast, static quantization fixes quantization parameters after an initial calibration phase using a representative dataset, which is effective when tensor distributions remain relatively stable, as in short retraining sessions. Conventional quantization techniques suffer from significant limitations: max-scaling, while simple and reproducible, incurs excessive quantization noise due to large step sizes dictated by outliers; learned clipping approaches like PACT introduce additional hyperparameters and training instability; and percentile-based calibration lacks theoretical optimality guarantees. To address these issues, the invention introduces max-scaling as a baseline uniform quantization strategy where the quantization range matches the full dynamic range of the tensor, but demonstrates its suboptimality due to high discretization noise. The advantages of max-scaling include its deterministic nature and ease of implementation, yet its limitations become pronounced at low bit-widths (e.g., 4-bit), where accuracy degrades significantly. Data clipping is then introduced as a refinement, narrowing the quantization interval to reduce step size and improve resolution. A calibration strategy is employed in static quantization to estimate clipping scalars from a representative data sample, typically using statistical measures like percentiles or MSE minimization. B-bit quantization maps real-valued data to one of 2^B discrete levels uniformly spaced within the clipping interval. The quantization noise is metricized via the mean squared error (MSE), which decomposes into discretization noise within the interval and clipping error for out-of-range values. The Lloyd-Max algorithm provides the optimal non-uniform quantizer minimizing MSE but is impractical for hardware due to irregular level spacing; thus, the invention focuses on uniform quantizers with optimized clipping. The max-scaled quantization operation is formally defined, and its MSE is derived under an additive noise model. Data clipping is shown to reduce MSE by balancing discretization and clipping errors, with an optimal clipping scalar *s** that minimizes the total error. The clipping scalar optimization problem is formulated analytically, leading to a recursive expression derived via the Newton-Raphson method applied to the MSE function. Empirical evaluation confirms the analytical MSE closely matches measured error, and plots of MSE versus clipping scalar reveal a convex trade-off with a clear global minimum. Observations from these graphs validate that OCTAV converges to this optimum efficiently. The invention is embodied in a neural network architecture comprising layer processing units that apply quantized operations. Each unit includes quantizing logic that applies the clipping and discretization functions, a clipping scalar optimization unit that computes *s** via OCTAV, and a quantization unit that performs the actual mapping to discrete levels. The optimal clipping scalar computation leverages the Newton-Raphson algorithm, which exhibits rapid convergence—typically within 10 iterations—and is insensitive to initialization, supporting robust deployment. The recursive OCTAV update rule is derived explicitly for empirical tensor data, replacing expectations with sample averages and excluding zero elements to avoid noise overestimation in sparse tensors. This formulation enables application to both weight and activation tensors across arbitrary layers. The OCTAV algorithm is computationally efficient, relying only on element-wise operations and reductions, and is fully compatible with GPU acceleration via standard deep learning libraries. A flowchart of the tensor quantization method illustrates processing inputs through the neural network, computing initial clipping scalars, adjusting tensors based on MSE feedback, updating clipping scalars iteratively, and repeating for subsequent inputs. Brute-force search comparisons demonstrate OCTAV’s superior speed and accuracy, particularly in identifying favorable local minima in non-convex MSE landscapes caused by outliers. The benefits of OCTAV include state-of-the-art QAT accuracy without training recipe modifications, applicability to dynamic and static regimes, and seamless integration into existing pipelines.

### QAT Gradient Estimation

Quantization-aware training fundamentally requires estimating gradients through discontinuous quantization operations, necessitating surrogate gradient functions. The invention introduces QAT with minimal noise enabled by OCTAV and addresses the critical role of gradient estimation in convergence stability. The gradient for a layer is defined as the partial derivative of the loss with respect to layer inputs or weights. Common gradient estimators include the Straight-Through Estimator (STE) and Piece-Wise Linear (PWL) approximations, both of which exhibit significant limitations. STE, which assumes a unit gradient everywhere, suffers from gradient explosion due to unattenuated back-propagation through clipped regions, as proven by variance analysis showing exponential growth with network depth. PWL, which zeroes gradients outside the clipping interval, causes partial premature stoppage of convergence by freezing updates to clipped parameters, effectively reducing model capacity. To overcome these issues, the invention introduces the Magnitude-Aware Derivative (MAD), which models clipping as a magnitude-dependent attenuation rather than a hard threshold. MAD formulates the gradient as a continuous function that scales inversely with input magnitude beyond the clipping bound, ensuring all parameters receive non-zero gradients and preventing early convergence halt. Compared to PWL, MAD preserves parameter learnability while avoiding STE’s instability. For activations, PWL’s gradient zeroing may provide beneficial regularization akin to Dropout, leading to a hybrid approach (MPH) using MAD for weights and PWL for activations. A block diagram of the neural network system illustrates the integration of OCTAV and MAD within the QAT pipeline. The benefits of OCTAV-enabled QAT include enhanced training stability, higher final accuracy, and robustness across diverse architectures and tasks.

### Parallel Processing Architecture

The invention is implemented within a parallel processing unit (PPU) 400, a specialized hardware accelerator designed for neural network computation. PPU 400 embodies the neural network model in both software-configurable logic and dedicated hardware circuits. It features a multi-threaded processor architecture optimized for data-parallel workloads common in deep learning. While originally developed for graphics rendering, the PPU 400 leverages its general-purpose computation capabilities for machine learning through programmable shader cores and tensor operations. Applications span scientific simulation, autonomous systems, and AI inference. The I/O unit 405 handles command decoding and routing from the host CPU. The front end unit 415 manages command stream ingestion and preprocessing. The scheduler unit 420 orchestrates task management and execution tracking across processing clusters. The work distribution unit 425 dispatches computational tasks to available resources. XBar 470 serves as a high-bandwidth interconnect network linking processing units and memory. General Processing Clusters (GPCs) 450 execute assigned tasks and generate results using SIMD/SIMT execution models. Memory partition units 480 interface with external memory, managing access requests and data movement. An integrated memory management unit with Translation Lookaside Buffers (TLBs) handles virtual-to-physical address translation. The Raster Operations (ROP) unit, though graphics-oriented, shares infrastructure with compute units. A multi-level cache hierarchy includes Level Two (L2) cache for shared data and Level One (L1) cache per processing unit. High Bandwidth Memory (HBM) interfaces provide massive data throughput. Error correction via SECDED ECC ensures data integrity. Unified memory allows CPU and PPU to share a single address space, with hardware page faulting and copy engines handling data migration. Tensor cores accelerate matrix-multiply-accumulate operations fundamental to DNNs. Special Function Units (SFUs) handle transcendental math, while texture units support spatial filtering. Load-Store Units (LSUs) manage register file interactions. Shared memory provides low-latency intra-cluster communication. The Cooperative Groups programming model enables flexible thread synchronization and collective operations. This architecture efficiently executes the OCTAV algorithm and QAT workloads through massive parallelism and optimized memory access.
