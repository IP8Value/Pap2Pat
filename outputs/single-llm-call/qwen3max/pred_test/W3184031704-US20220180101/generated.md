# DESCRIPTION

## TECHNICAL FIELD

The present invention relates to self-supervised semantic learning, particularly in the domain of video representation learning. More specifically, the invention provides a novel framework for learning high-level semantic representations from unlabeled video data by leveraging multiple complementary views of the same input sequence through a cooperative contrastive learning mechanism. The technical field encompasses machine learning, computer vision, and artificial intelligence, with particular relevance to applications requiring robust understanding of human actions, object interactions, and temporal dynamics in video without reliance on manually annotated labels. The invention improves upon existing self-supervised learning paradigms by enabling cross-view consistency enforcement that facilitates the emergence of semantically meaningful features, thereby enhancing performance on downstream tasks such as action recognition, video classification, and semantic alignment. This approach is especially advantageous in scenarios where labeled data is scarce or expensive to obtain, yet rich multimodal or multi-perspective information is inherently available within the input data itself.

## DESCRIPTION OF RELATED ART

Video labeling approaches have traditionally relied on supervised learning methods that require extensive human annotation to assign semantic labels to video clips. These approaches, while effective when sufficient labeled data is available, suffer from significant limitations in scalability, cost, and generalizability across diverse domains. To address these challenges, researchers have increasingly turned to self-supervised methods that exploit the inherent structure of video data to generate supervisory signals without manual labeling. Early self-supervised video learning techniques focused on proxy tasks such as predicting future frames, solving temporal jigsaw puzzles, or enforcing temporal coherence between consecutive frames. These methods demonstrated promising results but often learned representations that were overly sensitive to low-level visual features rather than high-level semantic content.

The motivation for self-supervised methods stems from the observation that videos contain rich temporal and structural information that can serve as a natural source of supervision. For instance, the temporal continuity between adjacent frames provides strong constraints on what constitutes a valid video sequence, enabling models to learn meaningful representations by distinguishing between temporally coherent and incoherent sequences. Similarly, spatial relationships between different regions of a video frame can provide additional supervisory signals. However, despite these advances, current self-supervised methods still face significant limitations in their ability to capture high-level semantic relationships that are crucial for complex downstream tasks such as fine-grained action recognition or cross-domain generalization.

Multi-view learning approaches have emerged as a promising direction to address these limitations by leveraging multiple complementary perspectives or representations of the same underlying data. In the context of video analysis, different views might include RGB frames, optical flow fields, pose keypoints, or semantic segmentation masks. These views provide complementary information about the same scene, with each view capturing different aspects of the visual content. For example, RGB frames capture appearance information, optical flow captures motion dynamics, and pose keypoints capture human body configuration. Multi-view learning approaches typically aim to maximize the mutual information between different views or enforce consistency constraints across views to learn more robust and semantically meaningful representations.

However, existing multi-view learning approaches suffer from several critical limitations. First, they often rely on contrastive losses that treat all instances from different videos as negative pairs, even when those videos contain semantically similar content. This leads to representations that are overly discriminative at the video level rather than the semantic level, preventing the model from recognizing that different videos might depict the same action or concept. Second, many multi-view approaches fail to effectively leverage the implicit relationships between instances that can be inferred from the consistency patterns across different views. Third, existing methods typically do not account for the fact that different views may have varying levels of reliability or noise, particularly when some views are derived from other views using imperfect computer vision models. Finally, most multi-view approaches do not provide mechanisms for dynamically adjusting the influence of different views based on their relative confidence or consistency with other views, limiting their ability to handle noisy or unreliable view information.

## BRIEF SUMMARY OF THE DISCLOSURE

The present invention introduces a novel framework called Multi-View Cooperative Contrastive Self-Supervised Learning (CoCon) that addresses the limitations of existing self-supervised and multi-view learning approaches. The method begins by receiving video sequences that may contain multiple complementary views of the same underlying content, such as RGB frames, optical flow, pose keypoints, or semantic segmentation masks. These views may be directly available from the input data or derived from the original input using computer vision models.

The method then derives embeddings for each view using view-specific deep encoders that are trained to capture the unique characteristics and information content of each view. These embeddings represent the semantic content of the video sequences in a compact, high-dimensional space that is suitable for downstream tasks. The method determines distances between embeddings from different instances within each view, typically using cosine distance as a similarity measure. These distances reflect the semantic relationships between different video instances as perceived by each individual view.

A key innovation of the present invention is the method for detecting inconsistencies between the distance patterns observed across different views. When different views disagree about the semantic relationships between instances, these inconsistencies provide valuable information about which views might be more reliable or which instances might be particularly challenging to classify. The method leverages these inconsistencies to improve the overall quality of the learned representations by encouraging the distance patterns to become more consistent across all views.

The method for predicting semantics involves using the cooperative learning framework to infer high-level semantic relationships between video instances without explicit supervision. By enforcing consistency across multiple views while respecting the unique information content of each view, the method enables the emergence of semantically meaningful representations that capture the underlying concepts and actions depicted in the videos.

Additional embodiments of the invention include various extensions and applications of the core CoCon framework. These include using the learned representations for downstream tasks such as action classification, video retrieval, and semantic alignment; incorporating additional views derived from off-the-shelf computer vision models; adapting the framework to different types of input data beyond video; and combining the CoCon approach with other self-supervised learning techniques to achieve even better performance.

## DETAILED DESCRIPTION

Self-supervised visual representation learning has emerged as a powerful paradigm for learning meaningful features from unlabeled data by exploiting the inherent structure and relationships within the data itself. In the context of video analysis, this approach leverages the rich temporal and spatial structure present in video sequences to generate supervisory signals without requiring manual annotation. The fundamental challenge in self-supervised learning is to design pretext tasks that encourage the model to learn representations that capture high-level semantic content rather than merely low-level visual features.

Data-driven sampling plays a crucial role in leveraging implicit relationships between different instances in the training data. Rather than relying solely on explicit structural constraints such as temporal proximity, the present invention utilizes a more sophisticated approach that considers the relationships between instances as inferred from multiple complementary views. This enables the model to discover implicit semantic relationships that might not be apparent from any single view alone.

The Cooperative Contrastive Learning (CoCon) technique represents a significant advancement over existing self-supervised learning methods. Unlike traditional contrastive learning approaches that treat all instances from different videos as negative pairs regardless of their semantic content, CoCon leverages the complementary information available across multiple views to identify potentially similar instances that should be treated as positive pairs. This approach overcomes the fundamental shortcoming of multi-view learning methods that fail to recognize semantic similarities between instances from different videos.

Inter-view information utilization is central to the CoCon framework. Each view provides a unique perspective on the same underlying content, and by comparing the similarity patterns across different views, the method can identify instances that are consistently judged as similar across multiple views. This provides strong evidence that these instances share genuine semantic similarities, even if they come from different videos. The CoCon framework leverages this inter-view information to guide the learning process and improve the quality of the learned representations.

To illustrate the CoCon approach, consider an example with two images and multiple views. Suppose we have two video clips showing people performing squats, captured from different angles or under different lighting conditions. The RGB view might show significant differences in appearance due to the different viewing conditions, making the clips appear dissimilar. However, the optical flow view and pose keypoints view might show very similar patterns of motion and body configuration, indicating that the underlying actions are indeed the same. CoCon leverages these inconsistencies by encouraging the distances in all views to become more similar, effectively using the consistent similarity judgments from the motion and pose views to guide the RGB view toward recognizing the semantic similarity.

View-specific deep encoders are employed to process each view independently, allowing the model to capture the unique characteristics and information content of each view. These encoders are designed to be specialized for their respective input modalities, ensuring that each view is processed in a way that maximizes its contribution to the overall learning objective.

The method leverages inconsistencies between views as a source of valuable information rather than treating them as noise to be eliminated. When different views disagree about the similarity between instances, this disagreement provides insights into which views might be more reliable for particular types of content or which instances might be particularly challenging to classify. By analyzing these inconsistencies, the method can adaptively weight the contributions of different views and improve the overall robustness of the learned representations.

Cosine distance is used to determine embedding distances because it provides a normalized measure of similarity that is invariant to the magnitude of the embeddings. This is particularly important in self-supervised learning contexts where the absolute scale of the embeddings may vary significantly across different views or training iterations. By using cosine distance, the method ensures that the similarity comparisons are based purely on the directional alignment of the embeddings rather than their magnitudes.

Contrastive loss learning forms the foundation of the self-supervised training framework. The method employs Noise Contrastive Estimation (NCE) to construct a binary classification task that distinguishes between real and noisy samples. This approach allows the model to focus on learning high-level semantic features rather than attempting to reconstruct exact pixel values, which would be unnecessarily complex and potentially counterproductive for downstream tasks.

Combining multiple views leads to better representations because each view provides complementary information about the same underlying content. While no single view may be sufficient to capture all aspects of the semantic content, the combination of multiple views provides a more complete and robust representation that is less susceptible to the limitations or biases of any individual view.

Each view is analyzed to provide specific patterns that are characteristic of that particular modality. For example, the RGB view provides rich appearance information, the optical flow view captures motion dynamics, the pose keypoints view reveals human body configuration, and the semantic segmentation view identifies object boundaries and categories. By analyzing these specific patterns, the method can identify the unique contributions of each view and leverage them effectively in the cooperative learning process.

Inter-view information is leveraged to infer relationships between instances that might not be apparent from any single view alone. When multiple views consistently indicate that two instances are similar, this provides strong evidence that the instances share genuine semantic similarities, even if they come from different videos or have different appearances in any single view.

Multiple embeddings are used to infer relationships by comparing the similarity patterns across different views. This multi-view consensus approach provides a more reliable basis for relationship inference than relying on any single view, as it reduces the impact of view-specific noise or biases.

The method motivates using available views of input data by recognizing that many complementary views can be derived from the original input without requiring additional annotation or specialized sensors. For example, optical flow can be computed from RGB frames, pose keypoints can be extracted using off-the-shelf detectors, and semantic segmentation masks can be generated using pre-trained models. This makes the CoCon framework applicable to a wide range of existing video datasets without requiring specialized data collection procedures.

High-level inferred semantics are used as additional views by treating the outputs of computer vision models as noisy but informative representations of the underlying content. Even though these derived views may contain errors or inaccuracies, they still provide valuable complementary information that can improve the overall quality of the learned representations when combined with other views through the cooperative learning framework.

The example process for cooperative contrastive learning involves several key steps. First, features are computed using view-specific encoders for each available view. Then, distances are determined in the resultant embeddings using cosine distance as the similarity measure. Inconsistencies in these distances across different views are identified and used to guide the learning process. The method encourages the distances in all embeddings to become more similar through a consistency loss that penalizes disagreements between views.

When applied to video sequences, the cooperative contrastive learning framework constructs a binary classification task for self-supervised training. The video sequence is partitioned into disjoint blocks, and each block is transformed into a latent representation using a non-linear encoder. A context representation is generated by aggregating the latent representations of previous blocks, and this context representation is used to predict future blocks. This predictive coding framework enables the model to learn effective representations that capture both local and global temporal dependencies.

The dense predictive coding framework is used for self-supervised learning by defining a prediction task that captures contextual semantics. Rather than attempting to reconstruct exact future frames, the model predicts high-level feature representations of future blocks, which encourages it to focus on learning semantically meaningful features rather than low-level visual details.
