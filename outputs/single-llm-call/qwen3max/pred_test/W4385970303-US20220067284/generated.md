## TECHNICAL FIELD

The present invention relates generally to the field of natural language processing and artificial intelligence, and more specifically to systems and methods for controllable abstractive text summarization using neural network models conditioned on user-specified control signals such as keywords, prompts, or combinations thereof. The invention further pertains to computer-implemented architectures that enable personalized, adaptive, and task-specific summarization of textual documents across diverse domains including news articles, scientific literature, patent filings, and other structured or unstructured textual data sources.

## BACKGROUND

Text summarization is a fundamental task in natural language processing that aims to condense lengthy source documents into concise, coherent, and informative summaries while preserving essential content. Traditional summarization approaches fall into two broad categories: extractive methods, which select and concatenate salient sentences or phrases directly from the source document, and abstractive methods, which generate novel paraphrased content that captures the essence of the original text. While significant progress has been made in developing neural abstractive summarization models—particularly those based on sequence-to-sequence architectures with attention mechanisms—these systems typically produce generic summaries that reflect the model’s internal biases rather than the specific informational needs or preferences of individual users. In real-world applications, however, users often require summaries tailored to particular aspects of interest, such as focusing on certain entities (e.g., persons, organizations, or products), controlling summary length for display constraints, highlighting technical contributions in scientific papers, distilling the purpose of an invention from a patent, or answering specific questions about the source content. Conventional summarization systems lack the flexibility to accommodate such dynamic user requirements without retraining or architectural modifications, thereby limiting their utility in interactive and personalized information retrieval scenarios. This limitation motivates the development of a unified, flexible, and efficient framework for controllable summarization that decouples user intent from model training and enables adaptation to multiple control dimensions through a consistent interface.

## DETAILED DESCRIPTION

### Controllable Summarization Overview

Traditional unconstrained neural summarization models operate by learning a conditional probability distribution p(y|x), where x denotes the input source document and y represents the generated summary. These models, while effective at producing fluent and general-purpose summaries, offer no mechanism for users to influence the content selection or stylistic properties of the output. In contrast, the present invention introduces a controllable summarization system that extends this formulation to p(y|x, z), where z is a set of control tokens—such as keywords or prompt phrases—that encode user preferences or task-specific instructions. This conditioning allows the same trained model to generate diverse summaries from a single source document based on varying values of z, without requiring retraining or parameter updates. The system architecture comprises three core components: (1) an automatic keyword extraction module that identifies salient terms from training data pairs (x, y) to construct z during model training; (2) a neural sequence-to-sequence model (e.g., based on the BART architecture) that learns to generate summaries conditioned on both x and z; and (3) a control function g_control(x, c) that maps a user-provided control signal c (e.g., an entity name, desired length bucket, or natural language prompt) into an appropriate keyword sequence z at inference time. During training, keywords are extracted by first selecting sentences from x that maximize ROUGE overlap with the reference summary y, then identifying longest common subsequences between these sentences and y, and finally filtering out duplicates and stop words to retain content-rich tokens. At inference, when no explicit user control is provided (c = ∅), an auxiliary BERT-based sequence tagger is employed to automatically extract keywords from x using token-level selection probabilities, enabling high-quality unconstrained summarization. The workflow begins with receipt of a source document and optional user control signal; the control function then generates or modifies the keyword set z accordingly; this z is prepended to x (separated by a special delimiter token) to form the final input to the summarization model, which outputs a controlled summary y' reflecting the specified intent. User interaction occurs via a control center interface where users may input entities, length preferences, natural language prompts (e.g., “the main contributions of this paper are:”), or combinations thereof. Control tokens serve as both encoder-side guidance (via keyword inclusion) and decoder-side priming (via prompt-style prefixes), enhancing focus and coherence. The system exhibits remarkable flexibility: it supports entity-centric summarization by inserting named entities as keywords, length control by modulating the number of extracted keywords, contribution/purpose summarization via fixed prompt-keyword hybrids, and question-answering through QA-formatted prompts like “Q: [question]? A:”. For example, given a news article about multiple NBA games, a fan interested only in Stephen Curry can specify “Stephen Curry” as the control signal, resulting in a summary exclusively covering his performance, whereas another user requesting a one-sentence patent summary via the prompt “the purpose of the present invention is” receives a concise statement of the invention’s objective, omitting technical implementation details.

### Controllable Summarization Work Flows

The training process for the keyword-based summarization model begins with a dataset of (document, summary) pairs. For each pair, the system selects sentences from the source document that maximize ROUGE scores against the ground-truth summary, ensuring alignment with human judgment of importance. From these selected sentences, the longest subsequences matching content in the reference summary are identified, and duplicate words along with standard stop words are removed to yield a keyword sequence z that captures core semantic elements without redundancy. This z is then prepended to the original document x, separated by a special token (e.g., “=>”), forming the composite input “[z] => [x]” used to train the neural model to maximize the likelihood p(y|x, z). A key innovation is the application of keyword dropout regularization during training: a random subset of keywords is omitted from z in each training instance to prevent the model from over-relying on z and ignoring contextual information in x, thereby improving robustness and factual consistency. At inference time, the workflow adapts based on user input. When generating a controlled summary, the system first receives a source document x and a control signal c (e.g., an entity name, length code, or natural language prompt). If c specifies an entity, g_control directly returns the entity as z; if c indicates a desired length (encoded as a bucket index 0–4), g_control uses the BERT tagger to compute token selection probabilities over x, selects the top K_l keywords (where K_l is the average keyword count for that length bucket in training data), and forms z from them. For prompt-based controls like contribution or purpose summarization, g_control outputs a fixed guiding sequence (e.g., “the main contributions of this paper are: (1)”) as both keyword and prompt. The resulting z is combined with x and fed to the trained model to produce y'. Entity control ensures summaries mention specified entities, while length control modulates summary brevity by adjusting keyword quantity. Prompts enable multi-purpose generation: for scientific papers, the prompt triggers contribution-focused output; for patents, it yields purpose statements; in reading comprehension settings, QA-formatted prompts (“Q: …? A:”) elicit answer-containing summaries. This unified workflow supports diverse applications without model retraining, demonstrating the framework’s generality.

### Example Performance

Qualitative evaluation demonstrates the system’s ability to generate distinct summary variants from a single source. For instance, a news article describing multiple NBA games yields a generic summary listing all team results, but when controlled by “Stephen Curry,” produces a focused account of his scoring and assists; similarly, specifying “LeBron James” shifts emphasis to his performance. Re-summarization via different prompts further illustrates adaptability: the same patent document generates a technical abstract when uncontrolled, but responds to “the purpose of the present invention is” with a single-sentence objective statement. Quantitative assessment across datasets—CNN/DailyMail (news), arXiv (scientific papers), and BIGPATENT (patents)—confirms efficacy. On entity control tasks, the system achieves a 95% success rate in including requested entities, significantly outperforming prior art (61.2%), with high factual consistency (87% correctness per human evaluation). Length control exhibits strong correlation (Pearson r > 0.9) between input length codes and actual output lengths, reducing median absolute deviation by 30% versus baselines. Contribution summarization on arXiv papers, evaluated against author-written bullet points, shows ROUGE-2 gains of 2.1 points over prompt-only BART, while purpose summarization on patents improves ROUGE-L by 1.8 points, with higher precision due to keyword-guided focus. Question-guided summarization on NewsQA and SQuAD benchmarks—despite zero-shot training—achieves F1 scores within 5 points of supervised models, validating the summarization-to-QA transfer hypothesis. Unconstrained performance matches or exceeds BART and PEGASUS baselines on ROUGE and BERTScore, confirming that keyword conditioning enhances rather than degrades general capability. Human evaluations on entity and purpose control show statistically significant improvements in control relevance (p < 0.01), with CTRLSUM summaries better excluding irrelevant content. Factual consistency remains high (>85%) across tasks, and toxicity mitigation strategies (e.g., replacing malicious keywords with automatic ones) preserve safety. Overall, the system delivers state-of-the-art controllable summarization across five dimensions with a single model, demonstrating unprecedented flexibility and performance.
