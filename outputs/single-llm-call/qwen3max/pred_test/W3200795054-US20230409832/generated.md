# DESCRIPTION

## STATEMENT REGARDING PRIOR DISCLOSURES BY THE INVENTOR OR A JOINT INVENTOR (IF APPLICABLE)

The present invention builds upon foundational work in the field of explainable artificial intelligence, particularly in the domain of natural language processing. Prior art includes methods such as LIME (Ribeiro et al., 2016), SHAP (Lundberg and Lee, 2017), and Integrated Gradients (Sundararajan et al., 2017), which provide feature attribution for model predictions. Additionally, contrastive explanation frameworks such as those proposed by Wachter et al. (2017) and Dhurandhar et al. (2018) have established the theoretical basis for counterfactual reasoning in machine learning. More recent works, including Generate Your Counterfactuals (GYC) by Madaan et al. (2021) and Minimal Contrastive Editing (MICE) by Ross et al. (2021), have advanced text-based counterfactual generation through language model perturbations and word masking, respectively. However, these prior methods lack the integration of semantically meaningful attributes to guide and interpret the generation of contrastive examples. The inventors acknowledge that while elements of controlled text generation, attribute modeling, and counterfactual reasoning exist in isolation in the prior art, the specific combination, architecture, and objective function disclosed herein—wherein attribute classifiers derived from auxiliary or same-domain data are used to regularize and interpret contrastive text generation—constitutes a novel and non-obvious contribution not previously disclosed in any single prior reference.

## BACKGROUND OF THE INVENTION

The increasing deployment of deep learning models in high-stakes decision-making systems—such as automated customer service chatbots, content moderation, medical triage, and financial risk assessment—has intensified the need for transparency and trustworthiness in artificial intelligence. Natural language processing (NLP) models, in particular, often operate as “black boxes,” rendering predictions without revealing the underlying rationale. This opacity undermines user trust, complicates model debugging, and poses regulatory and ethical risks, especially when biased or erroneous decisions occur. While post-hoc explanation methods have been developed to interpret model behavior, many focus on local feature importance or exemplar similarity, which may not suffice for understanding why a model assigned a particular class label over another. Contrastive explanations address this gap by answering the question: “Why was instance X classified as class A and not class B?” through the generation of a minimally perturbed version of X that is reclassified as B. However, existing contrastive methods for text suffer from several limitations: they often produce unnatural or grammatically flawed perturbations, require costly fine-tuning of language models per dataset, fail to automatically select the target contrast class, and—most critically—do not provide interpretable semantic context for why the perturbation led to a class change. The present invention addresses these shortcomings by introducing a novel framework that leverages external or intrinsic semantic attributes to guide the generation of fluent, minimal, and interpretable contrastive text, thereby enabling users not only to see what changed but also to understand which underlying topics or concepts were added or removed to cause the model’s decision shift.

## SUMMARY

The present invention discloses a method and system for generating perturbed text that serves as a contrastive explanation for a black-box text classification model. The core innovation lies in the use of a set of attribute classifiers—trained on auxiliary or task-relevant datasets—to evaluate and guide the generation of candidate perturbations. The method begins by receiving an input text and identifying important words using feature attribution techniques. These words are masked, and a pre-trained masked language model generates candidate replacements or insertions. Each candidate perturbation is then evaluated using an objective function that balances multiple criteria: (1) successful flipping of the original prediction to a different class, (2) measurable change in the scores of one or more attribute classifiers (indicating addition or removal of semantic attributes), (3) minimality of the number of changed attributes for interpretability, (4) fluency of the generated text as measured by language model likelihood, and (5) minimal edit distance from the original text. The candidate perturbation that maximizes this objective function is selected as the final contrastive explanation. Crucially, the output includes not only the perturbed text but also a list of attributes that were significantly added or removed, providing users with semantically meaningful insight into the model’s decision boundary. This approach eliminates the need for dataset-specific fine-tuning, supports automatic selection of the contrast class, and produces more intuitive and trustworthy explanations than prior art.

The CAT program functionality centers on generating perturbed text that explains a classifier’s decision by altering semantic attributes. The method begins by receiving a text input. Classifiers for text data—including the primary black-box classifier and a set of attribute classifiers—are then determined. Important words in the input text are identified using feature attribution methods such as Integrated Gradients, and masks are inserted at these locations. A pre-trained masked language model, such as BERT, generates candidate perturbations by filling the masks. For each candidate, the edit distance from the original text is computed using the word-level Levenshtein distance. The fluency of each candidate is quantified by its likelihood under a language model, such as GPT-2. An objective function evaluates each candidate based on prediction flip, attribute change, attribute sparsity, fluency, and edit distance. The candidate that maximizes this objective function is selected.

The objective function, denoted as E.1, is defined as follows: it includes a term that encourages at least one attribute to be added or removed (based on thresholded changes in attribute classifier scores), a term that penalizes the total number of changed attributes to ensure interpretability, a contrastive score term that rewards successful prediction flipping, a fluency term based on language model likelihood, and an edit distance penalty term. Attribute classifiers are trained on datasets such as HuffPost News or 20 Newsgroups to predict the presence of semantic topics like “politics,” “electronics,” or “sports.” Edit distance is calculated as the minimum number of insertions, deletions, or substitutions required to transform the original text into the perturbed text, normalized by the original text length. Fluency is quantified as the ratio of the masked language modeling loss of the perturbed text to that of the original, with values closer to 1.0 indicating higher fluency. Hyperparameters in the objective function—including weights for each term and thresholds for attribute change—are tuned once per dataset using a small set of validation examples.

In an embodiment of the CAT program, the system receives a news headline classified as “Sci-Tech” and generates a contrast classified as “Business” by replacing “File” with “Salary,” while reporting that the attributes “Baseball” and “Hockey” were added and “Cryptography” was removed. The operational process involves: (1) receiving text input, (2) determining relevant classifiers, (3) inserting masks at important words, (4) generating candidate perturbations, (5) computing edit distance and fluency, (6) selecting the candidate that maximizes the objective function, and (7) providing the perturbed text along with added/removed attributes.

The system architecture includes modules for word importance scoring, masking, language model inference, attribute classification, and objective function optimization. Important words are identified via gradient-based attribution. Perturbation is applied only to these words to maintain content relevance. The language model is evaluated to ensure grammatical correctness. The perturbed text is reclassified by the original black-box model to confirm the prediction flip. Components of the computing device include a central processing unit (CPU), graphics processing unit (GPU) for accelerated inference, volatile memory (RAM) for active data, and non-volatile storage (SSD/HDD) for models and data. Computer-readable storage media store the CAT program, language models, and attribute classifiers, enabling repeatable and scalable deployment of contrastive explanations.
