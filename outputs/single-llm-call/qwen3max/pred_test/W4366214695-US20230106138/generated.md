# DESCRIPTION

## FIELD OF INVENTION

The present invention relates to a computing system configured for the continuous monitoring, detection, and prediction of surgical site infections (SSIs) in post-operative patients. More specifically, the invention encompasses an integrated cloud-based computing architecture that receives multi-modal physiological data from wearable sensing units deployed at or near surgical wound sites, processes such data through a series of algorithmic modules, and applies artificial intelligence models to generate actionable clinical insights regarding infection status. The system is designed to operate in both inpatient and outpatient settings, thereby addressing critical gaps in current post-discharge surveillance protocols. By leveraging real-time bio-signal acquisition, advanced feature extraction, and machine learning inference, the invention provides a scalable, secure, and clinically validated platform for early intervention in SSI cases, ultimately reducing morbidity, mortality, and healthcare expenditures associated with delayed diagnosis.

## BACKGROUND

Surgical site infections remain among the most prevalent and costly complications following surgical procedures, affecting hundreds of thousands of patients annually in the United States alone. Despite stringent perioperative prophylactic measures, SSIs continue to impose a significant burden on patients and healthcare systems, extending hospital stays by nearly ten days on average and increasing mortality risk by up to eleven-fold. The economic impact is staggering, with individual SSI cases generating excess costs exceeding $25,000 and collectively contributing over $10 billion in avoidable expenditures each year. A particularly pressing challenge arises from the shift toward outpatient surgery and early hospital discharge, which has resulted in approximately 69% of SSIs being diagnosed only after the patient has left the clinical environment. Current post-discharge surveillance methods—such as telephone interviews, patient questionnaires, and clinic follow-ups—are unstructured, subjective, and prone to significant delays in detection. Critically, a delay of just 45 hours in initiating treatment can increase infection-related mortality odds by nearly fourfold. Conventional diagnostic approaches rely heavily on visual inspection and patient-reported symptoms, which often manifest only after infection is well-established. Although prior research has demonstrated that physiological changes—such as alterations in tissue oxygenation, temperature, and bioimpedance—precede clinical signs of infection, existing technologies lack the integration, automation, and predictive analytics necessary for reliable, real-time monitoring. Thus, there exists an urgent need for an improved system that can objectively, continuously, and remotely assess wound healing status using multi-modal biosensors coupled with intelligent data processing to enable early and accurate SSI detection and prediction.

## SUMMARY

The present invention introduces a cloud computing system comprising one or more hardware processors and memory units operatively connected to execute a suite of specialized software modules. The system includes a data receiver module configured to ingest heterogeneous data streams from wearable devices and sensing units positioned at wound and reference anatomical sites. A parameter determination module processes this raw input to derive desired parameters, including primary physiological signals such as tissue oxygen saturation (StO₂), local temperature, and bioimpedance, as well as derived physiological signals like rate-of-change metrics and signal variability indices. These parameters are then passed to a feature extraction module, which computes a comprehensive set of quantitative features—including statistical moments, spectral characteristics, and temporal dynamics—over defined time windows. An inference module applies these extracted features to a trained artificial intelligence (AI) model, which may be implemented as a bagged, stacked, and balanced ensemble logistic regression classifier or other machine learning architecture, to detect the presence of an active surgical wound infection, predict the likelihood of infection onset within 24 or 48 hours, and generate a standardized wound infection score reflecting infection probability. A data management module orchestrates data flow, ensures secure storage, facilitates alert generation, and transmits actionable outputs to healthcare providers via secure communication channels. The invention further encompasses a method for detecting and predicting surgical wound infections, comprising the steps of receiving multi-source physiological and contextual data, determining desired parameters, extracting discriminative features, applying the features to a trained AI model, and outputting a wound infection score along with medical recommendations. This integrated approach replaces conventional manual inspection with an objective, data-driven, and remote monitoring solution that significantly enhances clinical responsiveness and patient outcomes.

The feature extraction module computes features such as mean, variance, skewness, entropy, and cross-correlation coefficients from the desired parameters. These features are applied to a trained AI-based data model, which detects infection presence, predicts likelihood, and generates a wound infection score on a calibrated scale (e.g., 0–100). Distributed processing enables real-time analysis while conserving device battery life. The cloud computing system architecture includes hardware processors (e.g., multi-core CPUs or GPUs), volatile and non-volatile memory, and a storage unit for archival and model training. The data receiver module ingests wound site data (from sensors adjacent to incision), ambient data (room temperature, humidity), reference site data (from contralateral or distant healthy skin), and auxiliary data (activity level from IMU, medication logs). Received data is segmented temporally (e.g., into 10-minute bursts) for batch processing. Wound site data captures localized physiological changes; reference site data provides baseline normalization; ambient data contextualizes environmental influences; auxiliary data enriches clinical interpretation. Data security employs end-to-end encryption, role-based access control, and audit logging. Primary physiological signals are directly measured; derived signals are mathematically computed (e.g., dT/dt). Local wound parameters reflect tissue-level pathology; systemic parameters indicate whole-body response (e.g., fever). The feature extraction module outputs features including R-value (a normalized oxygenation metric), signal entropy, and inter-signal coherence. The sensing module comprises the physical sensor array.
