# DESCRIPTION

## TECHNICAL FIELD

The present invention relates to deep-learning-based methods and systems for reliable data transmission over noisy communication channels. More specifically, the invention pertains to a novel autoencoder architecture that integrates list decoding principles from classical coding theory into a deep neural network framework to enhance error correction performance. The invention further encompasses encoder-decoder systems trained using specialized loss functions tailored to list decoding, as well as hardware and software implementations of such systems in electronic communication devices. This technical field lies at the intersection of information theory, machine learning, and digital communications, with particular relevance to next-generation wireless systems, satellite communications, and any application requiring robust transmission under channel uncertainty or non-standard noise conditions.

## SUMMARY

Reliable transmission of digital information over noisy channels is a fundamental challenge in modern communication systems. To ensure data integrity, channel coding introduces structured redundancy into transmitted signals, enabling the receiver to detect and correct errors introduced by the channel. Claude Shannon’s landmark work established the theoretical limits of reliable communication, proving that for any channel with a defined capacity, there exists a code capable of achieving arbitrarily low error rates below that capacity. However, constructing practical codes that approach this theoretical limit has remained a significant engineering challenge. Among the most successful classical approaches are Turbo codes, Low-Density Parity-Check (LDPC) codes, and polar codes—each representing major milestones in coding theory.

Despite these advances, traditional code design relies heavily on mathematical analysis and assumes a well-defined channel model, such as the additive white Gaussian noise (AWGN) channel. This limits adaptability to real-world scenarios where channel characteristics may be unknown, time-varying, or too complex to model analytically. Deep learning offers a promising alternative by enabling end-to-end optimization of encoder and decoder pairs without explicit reliance on channel models. In this context, the present invention introduces a system embodiment comprising an encoder circuit, a communication channel, and a receiver circuit incorporating a novel decoder circuit based on a list autoencoder (listAE) architecture.

The receiver circuit includes a decoder neural network configured to output a list of candidate message words rather than a single estimate. This mimics the concept of list decoding in classical coding theory, where multiple plausible decodings are considered to improve reliability. The decoder circuit is trained using a specialized loss function that simulates the operation of a genie-aided (GA) decoder—one that perfectly selects the correct message from the list if it is present. During training, the loss function is computed as the minimum binary cross-entropy (BCE) between the transmitted message word and any candidate in the output list. This formulation avoids the non-differentiable operations inherent in exact genie emulation while effectively guiding the network toward high list accuracy.

The BCE loss function is applied after each candidate in the list passes through a sigmoid activation, ensuring outputs are bounded between 0 and 1 for gradient-based optimization. In certain embodiments, the decoder comprises multiple sub-decoders arranged in an iterative architecture, where each sub-decoder processes subsets of the received signal and refines the candidate list. The training process involves alternating optimization of encoder and decoder weights, with power normalization applied to codewords to satisfy physical transmission constraints. Candidate selection during inference may be performed using cyclic redundancy check (CRC) codes, eliminating the need for a true genie while preserving the benefits of list decoding. The invention thus provides a robust, trainable, and model-agnostic framework for channel coding that outperforms existing deep learning and classical approaches, particularly at small list sizes.

Channel code design according to the invention departs from classical approaches by jointly optimizing encoder and decoder neural networks within a deep learning framework. The encoder maps K-bit message words to N-dimensional real-valued codewords, while the decoder maps received noisy signals back to message estimates. The autoencoder (AE) architecture treats this as a reconstruction task, with the channel acting as a corrupting layer.

Under-complete AEs reduce dimensionality for representation learning, whereas over-complete AEs—relevant here—expand dimensionality to add redundancy for error correction. Convolutional neural networks (CNNs) and recurrent neural networks (RNNs) have been employed to mimic Turbo code structures, yielding the TurboAE architecture. The present invention generalizes this via the list autoencoder (listAE) framework, wherein the decoder outputs L candidates. The listAE loss function minimizes the BCE between the true message and the closest candidate in the list, enabling effective training without discrete operations.

A genie-aided (GA) decoder assumes perfect knowledge of whether the transmitted word is in the list, defining block error rate (BLER) as the probability it is not. To avoid non-differentiability, the loss function uses min_l BCE(u, û_l), which is differentiable almost everywhere. Alternative loss functions, including those based on log-sum-exp approximations, are also contemplated. The incremental redundancy listAE (IR-listAE) architecture further enhances performance by arranging decoding blocks in order of decreasing rate (e.g., 1/1, 1/2, 1/3), allowing early blocks to provide coarse estimates refined by later, more powerful decoders.

In the CRC-aided listAE (CA listAE), a CRC checksum is appended to the message prior to encoding. At decoding, only candidates passing the CRC are considered valid, emulating the GA without rate penalty if CRC bits are treated as part of the message during training. Power normalization ensures codewords meet energy constraints, with batch-wise normalization preferred: codewords in a batch are normalized to zero mean and unit variance across all symbols. Training employs scheduled alternation—updating encoder weights while freezing decoder, and vice versa—with CNN-based models showing superior convergence over fully connected or RNN alternatives.

Simulation results demonstrate that IR-listAE outperforms TurboAE at small list sizes (e.g., L=8) and matches it at large sizes (L=64), while surpassing polar codes in BLER at high SNR.
