## TECHNICAL FIELD

The present invention relates generally to the field of natural language processing and machine learning, and more specifically to systems and methods for efficient zero-shot text classification using a conformal prediction framework to reduce computational overhead while maintaining statistical validity and predictive accuracy.

## BACKGROUND

Text classification is a foundational task in natural language processing with applications ranging from customer support automation and content moderation to medical record triage and legal document analysis. In many real-world scenarios, labeled training data for all possible classes may not be available at deployment time, necessitating the use of zero-shot classification models that can generalize to unseen categories without explicit supervision. Zero-shot models typically leverage pre-trained language models (PLMs) to infer semantic relationships between input text and candidate class labels, often by reformulating the task as natural language inference (NLI) or next sentence prediction (NSP). While these approaches achieve high accuracy, they suffer from significant computational inefficiencies, particularly when the number of candidate labels is large. Each label requires a separate forward pass through the model when using cross-encoder architectures, leading to linear scaling of inference time with the number of labels. This inefficiency becomes prohibitive in latency-sensitive applications or when deployed on resource-constrained devices. Moreover, existing zero-shot models do not provide formal guarantees regarding prediction reliability, making them unsuitable for safety-critical domains. There is therefore a need for a method that improves the efficiency of zero-shot text classification without compromising coverage guarantees or overall performance.

## DETAILED DESCRIPTION

The present invention provides a novel framework for efficient zero-shot text classification by integrating a conformal predictor (CP) with a fast base classifier to generate a reduced set of candidate labels prior to applying a computationally expensive zero-shot model. The core insight is that not all candidate labels are equally plausible for a given input text, and filtering out unlikely labels can significantly reduce the computational burden of the final classification step. The network underlying the invention comprises a computing device configured to execute an efficient zero-shot classification module that implements the CP framework. This module includes a base classifier, a calibration dataset, a non-conformity scoring mechanism, and a quantile-based thresholding component. Zero-shot classification models, such as those based on NLI or NSP formulations, map input text and label descriptions into a shared semantic space to compute compatibility scores. However, these models require recomputing contextual representations for each label-text pair, resulting in high latency. The limitations of existing models include their linear dependence on the number of labels, lack of uncertainty quantification, and inability to provide statistically valid prediction sets. To address these shortcomings, the invention introduces a CP framework that operates as a preprocessing filter. The CP framework consists of three main components: a fast base classifier, a calibration dataset, and a non-conformity score function. The base classifier is selected to be computationally lightweight relative to the zero-shot model. A calibration dataset, which may be labeled by the zero-shot model itself in the absence of human annotations, is used to compute empirical non-conformity scores. These scores measure the degree of disagreement between the base classifier’s predictions and the true (or pseudo-labeled) class labels. A non-conformity threshold is then computed as the ⌈(n + 1)(1 − α)⌉/n empirical quantile of the calibration scores, where α is a user-specified error rate. For a new test input, the base classifier generates predictions over all candidate labels, and non-conformity scores are computed for each label. Labels with scores below the threshold are retained to form a reduced label set, which is then passed to the zero-shot model for final classification. The invention further describes several embodiments of the base classifier, including a token overlap method (CP-Token), a cosine similarity method using GloVe embeddings (CP-Glove), a distilled BERT-base model (CP-Distil), and a fine-tuned classifier (CP-CLS). The CP framework is model-agnostic and can be applied to any zero-shot or few-shot classification system, including prompt-based models and in-context learning paradigms. Additionally, the framework extends to image classification by replacing textual features with visual embeddings. The invention is implemented on a computing device equipped with a processor, memory, and interfaces for data, user interaction, and network communication, forming a networked system that includes user devices, data vendor servers, and a central server hosting the efficient zero-shot classification module.

### Work Flows

The method for efficient zero-shot text classification begins by receiving a calibration dataset comprising unlabeled texts and a set of candidate class labels. The zero-shot model is used to assign pseudo-labels to the calibration texts. A fast base classifier is then applied to generate predicted labels for each calibration text. Non-conformity scores are computed by comparing the predicted labels with the pseudo-labels—for example, by taking the negative logit of the true class. A non-conformity threshold is derived from the empirical quantile of these scores based on a desired error rate α. At test time, the base classifier processes a new input text to produce predictions over all candidate labels. A second set of non-conformity scores is generated for each label. Labels with scores below the precomputed threshold are included in a reduced label set, which is then used as input to the zero-shot model for final prediction, thereby reducing computational load.

### Example Data Experiment and Performance

The CP-based framework was evaluated on intent classification datasets (SNIPS, ATIS, HWU64) and topic classification datasets (AG’s News, Yahoo! Answers) using a BART-large NLI model and a BERT-base NSP model as zero-shot classifiers. Four base classifiers—CP-Token, CP-Glove, CP-Distil, and CP-CLS—were calibrated using training and validation splits. Empirical coverage (the fraction of test samples where the true zero-shot prediction is in the reduced label set) matched the nominal coverage (1 − α) at α = 0.01, validating the statistical guarantees. The average label set size was reduced by 41.09% (NLI) and 43.38% (NSP). Inference time decreased by 25.6% on average, with greater gains on datasets with more labels (e.g., HWU64 with 64 classes). CP-Token achieved the best speedup on smaller datasets due to minimal overhead, while CP-CLS and CP-Distil yielded smaller label sets but required more computation. Accuracy was preserved or slightly improved, indicating that label filtering removes noise. The experiments confirm that the CP framework effectively enhances efficiency without sacrificing reliability or performance, making it suitable for real-world deployment.
