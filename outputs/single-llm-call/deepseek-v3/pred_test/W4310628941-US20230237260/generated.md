# DESCRIPTION

## BACKGROUND

Anomaly detection is a critical task in numerous real-world applications, including identification of manufacturing defects, network security threats, and financial fraud. The field of anomaly detection encompasses several distinct learning paradigms, each with specific advantages and limitations. In the fully supervised setting, labels are available for all samples, including both normal and anomalous instances. This setting typically employs specialized approaches to handle data imbalance, such as weighted loss functions or resampling methods. A particularly important special case occurs when only labeled normal samples exist, which is commonly addressed using one-class classification methods like One-Class Support Vector Machines (OC-SVM) or auto-encoder based approaches.

At the opposite extreme lies the fully unsupervised anomaly detection setting where no labeled data is available whatsoever. While this approach eliminates labeling costs entirely, it often suffers from significant performance degradation compared to supervised methods, limiting its practical applicability. Between these two extremes exists the semi-supervised anomaly detection setting, which aims to achieve high performance while operating within limited labeling budgets. Previous work in semi-supervised anomaly detection has explored various approaches, including positive-unlabeled learning and the use of one-class classifiers or adversarial training techniques.

A fundamental challenge in semi-supervised learning methods is their inherent assumption that labeled and unlabeled data originate from identical distributions. In practical applications, this assumption frequently fails to hold due to distribution mismatch between labeled and unlabeled data. Several real-world scenarios exemplify this challenge. In positive and unlabeled (PU) or negative and unlabeled (NU) settings, the distributions between labeled (either positive or negative) and unlabeled (containing both positive and negative) samples differ substantially. Furthermore, additional unlabeled data collected after initial labeling can introduce distribution shifts, particularly in dynamic environments like manufacturing processes or financial fraud detection where anomaly patterns evolve over time. Human labeling behavior also introduces bias, as labelers tend to be more confident on easy samples, resulting in labeled datasets skewed toward simpler cases while difficult samples remain unlabeled.

Existing semi-supervised learning methods demonstrate suboptimal performance for anomaly detection under distribution mismatch conditions because they fundamentally assume identical distributions between labeled and unlabeled data. The generated pseudo-labels become highly dependent on the small set of labeled data, causing trained models to exhibit bias toward the labeled data distribution. While transfer learning methods and frameworks for handling distribution shifts offer potential alternatives, they have proven ineffective when working with small numbers of source (labeled) samples.

## BRIEF SUMMARY

The present invention discloses a novel semi-supervised anomaly detection framework called SPADE (Semi-supervised Pseudo-labeler Anomaly Detection with Ensembling) that delivers robust performance even under conditions of distribution mismatch. The framework introduces several innovative components that collectively enable effective semi-supervised learning in challenging real-world scenarios.

At its core, SPADE implements a self-training approach that iteratively learns from both labeled and pseudo-labeled data. The framework's key innovation lies in its pseudo-labeling mechanism, which employs an ensemble of one-class classifiers (OCCs) rather than conventional binary classifiers. This design choice prevents overfitting to small amounts of labeled data and enhances robustness against distribution shifts. The pseudo-labeler assigns binary labels to unlabeled data through a consensus mechanism among multiple OCCs, where positive pseudo-labels (indicating anomalies) are assigned only when all OCCs agree, and negative pseudo-labels (indicating normal samples) are assigned under similar unanimous agreement.

SPADE incorporates several critical components: a data encoder that maps input features to latent representations, a predictor that outputs anomaly scores based on these representations, the aforementioned pseudo-labeler, and a projection head that facilitates representation learning. The framework determines optimal threshold parameters (η_p and η_n) through a novel partial matching method that estimates marginal distributions without requiring validation data—a crucial advantage in scenarios with limited labeled samples.

The training process combines multiple loss functions: binary cross-entropy on labeled data, binary cross-entropy on pseudo-labeled data, and self-supervised loss on the entire dataset. These components are optimized jointly through a unified objective function that balances their relative contributions. The framework demonstrates particular effectiveness in handling evolving anomaly patterns, easy-to-label versus hard-to-label sample distributions, and positive-unlabeled learning scenarios.

## DETAILED DESCRIPTION

The SPADE framework represents a comprehensive solution for semi-supervised anomaly detection under conditions of distribution mismatch. The system architecture comprises four principal components: an encoder (502), predictor (504), pseudo-labeler (506), and projection head (508). The encoder transforms input features into latent representations using neural network architectures appropriate for the data modality (e.g., MLPs for tabular data, CNNs for image data). The predictor utilizes these learned representations to generate anomaly scores through a binary classification mechanism.

The pseudo-labeler constitutes a particularly innovative aspect of SPADE, implemented as an ensemble of K one-class classifiers. This ensemble approach enables robust pseudo-label assignment through consensus voting, where samples receive positive pseudo-labels only when all OCCs concur on anomalous classification, and negative pseudo-labels when all OCCs agree on normal classification. Samples without unanimous consensus remain unlabeled. This conservative labeling strategy prevents contamination of the training set with incorrectly pseudo-labeled samples.

The threshold parameters η_p and η_n, which determine pseudo-label assignment boundaries, are optimized through a partial matching method that minimizes Wasserstein distances between distributions of labeled and unlabeled data. This approach eliminates the need for separate validation data, making it particularly valuable in label-scarce scenarios. For cases where only one class of labeled samples exists (PU or NU settings), the framework employs Otsu's method to determine thresholds in an unsupervised manner.

Training proceeds through optimization of a combined loss function incorporating three components: supervised loss on labeled data (L_sup), pseudo-label loss on consensus-labeled data (L_pl), and self-supervised loss (L_ssl) for representation learning. The complete optimization problem is formulated as:

min_{h,g,q} L_sup + αL_pl + βL_ssl

where α and β are hyperparameters controlling the relative weighting of loss components. The self-supervised loss component may implement various pretext tasks depending on application domain, including reconstruction objectives or contrastive learning approaches.

The framework demonstrates particular effectiveness in several challenging real-world scenarios. For evolving anomaly types (where new anomalies appear in unlabeled data after labeling), SPADE significantly outperforms conventional methods by maintaining robust performance on unseen anomaly patterns. In easy-to-label versus hard-to-label sample distributions, the framework shows strong performance even when labeled data contains only straightforward cases. For positive-unlabeled learning scenarios, SPADE achieves superior generalization compared to specialized PU learning methods.

Implementation of SPADE occurs within a computing environment comprising server and user computing devices, data storage systems, and network communication infrastructure. The framework supports distributed execution across multiple processors and can be deployed in various network configurations. System components include instructions stored on computer-readable media for executing the SPADE methodology, including data encoding, pseudo-label generation, model prediction, and representation learning functions.

Experimental evaluations across diverse datasets (tabular and image data) demonstrate SPADE's superior performance compared to existing approaches. On tabular data, the framework achieves up to 10.6% improvement in AUC metrics compared to baseline methods, while on image data improvements reach 3.6%. The framework shows particular strength in real-world fraud detection applications where anomaly patterns evolve over time due to adversarial adaptation.

The SPADE framework's innovations extend beyond algorithmic components to include practical implementation advantages. The partial matching method for threshold determination eliminates need for validation data, crucial for applications with limited labeling budgets. The consensus-based pseudo-labeling provides robustness against distribution mismatch, while the combined loss function enables effective utilization of all available data—labeled, pseudo-labeled, and unlabeled. These characteristics make SPADE particularly valuable for real-world applications where data distributions are non-stationary and labeling resources are constrained.
