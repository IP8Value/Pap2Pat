## DESCRIPTION

### TECHNICAL FIELD

The present invention relates generally to the field of quantum computing and machine learning. More specifically, the invention pertains to methods and systems for quantum-assisted machine learning (QAML) using tensor network (TN) models implemented on noisy intermediate-scale quantum (NISQ) devices. The disclosed techniques enable efficient implementation of machine learning algorithms on quantum computing hardware by leveraging tensor network structures, particularly matrix product states (MPS), to create resource-efficient quantum circuits that can be compiled and optimized for specific quantum hardware architectures.

### BACKGROUND

Current NISQ devices face significant limitations that hinder their practical application in machine learning tasks. These limitations include hardware noise, restricted qubit connectivity, limited gate sets, and short coherence times. Traditional quantum computing approaches designed for error-corrected, large-scale quantum computers are not suitable for NISQ devices due to these constraints. Existing methods for implementing machine learning algorithms on quantum hardware often require deep quantum circuits with numerous entangling gates, which accumulate noise and degrade performance on current quantum processors. Furthermore, conventional approaches lack efficient compilation techniques that can translate classical machine learning models into quantum circuits optimized for specific hardware constraints. There exists a need for quantum-assisted machine learning methods that can overcome these limitations by providing noise-resilient, resource-efficient implementations tailored to the capabilities of NISQ devices.

### BRIEF SUMMARY

The present invention introduces a novel framework for quantum-assisted machine learning (QAML) that utilizes tensor network models, particularly matrix product states (MPS), to bridge classical machine learning with quantum hardware implementations. The invention provides methods for encoding classical data into quantum states, training quantum models with tensor network structures, and compiling these models into optimized quantum circuits for NISQ devices. A key innovation is the application of tensor networks in quantum-assisted machine learning, where classical data is transformed into quantum states embedded in an exponentially large Hilbert space. The tensor network model is learned from quantum training data and interpreted as a sequential preparation scheme involving a small number of readout qubits coupled to ancillary resources. The invention further includes embodiments of apparatus for implementing QAML, comprising processing circuitry for executing QAML instructions, memory for storing QAML data, and interfaces for connecting to quantum computing hardware. The disclosed methods provide significant advantages over existing approaches by enabling highly resource-efficient implementations that require only a constant number of qubits regardless of input data size, while maintaining robustness against noise and hardware limitations characteristic of NISQ devices.

### DETAILED DESCRIPTION

The present invention provides a comprehensive framework for quantum-assisted machine learning using tensor networks on NISQ devices. Non-limiting example embodiments include methods for encoding classical data into quantum states, training tensor network models, compiling these models into quantum circuits, and executing them on quantum hardware. The following detailed description defines terms used in the disclosure and explains the various components and methodologies of the invention.

Tensor networks (TNs) and their application in quantum-assisted machine learning form the foundation of the disclosed methods. Tensor networks represent high-rank tensors describing quantum wave functions as contractions over low-rank tensors, defining families of low-rank approximations whose computational power relates to the maximum dimension of any contracted index (bond dimension). Among various TN topologies, matrix product states (MPSs) are particularly advantageous for QAML due to their one-dimensional structure, well-understood optimization strategies, and ability to be sequentially prepared on quantum hardware. MPSs enable highly quantum resource-efficient implementations where qubit requirements scale logarithmically with bond dimension and remain independent of input data vector length.

The use of tensor networks in noisy intermediate-scale quantum (NISQ) devices is motivated by their robustness against noise and ability to operate within current hardware constraints. The invention describes methods for quantum-assisted machine learning using TNs and classical datasets, where classical data vectors are first mapped to quantum states through embedding maps. The only restriction placed on this encoding is that each classical data vector is encoded in an unentangled product state, ensuring that any entanglement in the quantum model comes from correlations in the data ensemble rather than a priori assumptions.

Optimization methodologies for training TN models on classical devices form another key aspect of the invention. For generative modeling applications, the invention employs a DMRG-style procedure using gradient descent of the negative log-likelihood. The wave function is parameterized as an MPS, and gradients are taken with respect to groups of neighboring tensors. Updates to local tensor blocks can adaptively increase bond dimension based on data requirements. Complete optimization cycles involve sweeping back and forth across the MPS until convergence is achieved. This classical optimization provides a robust training procedure that can be implemented efficiently on conventional computers before deploying the model on quantum hardware.

The deployment of TN models on gate-based quantum devices involves converting classically trained models into quantum circuits. The invention describes a sequential preparation scheme where a single physical (readout) qubit is coupled to a χ-level ancilla, with the physical qubit measured and reinitialized between applications of isometric operations. This scheme requires only O(1) qubits regardless of input data size, making it ideally suited for resource-constrained NISQ devices. The ancilla requirements scale as O(log2χ), where χ is the bond dimension representing model expressivity.

Heuristics for translating TN models into abstract quantum circuits represent another innovative aspect of the invention. The compilation of TN models into quantum programs for NISQ devices leverages several unique properties of the QAML use case: isometric operations are defined on Hilbert spaces that may not match qubit dimensions exactly, ancilla degrees of freedom have no preferred basis, and optimization procedures have finite tolerance. These properties provide freedom that can be utilized to simplify compilation compared to generic quantum compilation approaches.

The advantages of TN-based quantum programs include their resource efficiency, noise resilience, and ability to be optimized specifically for target hardware constraints. The invention describes a framework for designing and optimizing TN-based QAML models that includes translation of classical data into quantum states, classical optimization of the model, conversion to a sequence of isometric operations, and compilation into native hardware operations. A generalized canonical form for matrix product state (MPS) models, called the diagonal gauge, is introduced to optimize compilation by making operations as "diagonal" as possible in the ancilla basis.

Greedy heuristics for compiling TN models with given topology and gate set form another key innovation. The compilation procedure enumerates possible unitaries by constructing a tree of potential circuit structures with continuous parameters to be optimized. A cost function evaluates how well candidate unitaries match target isometries while minimizing entangling gate count. The optimization begins with single-qubit gates and progressively adds entangling gates only as needed to achieve the desired tolerance. This approach typically finds representations with significantly fewer entangling gates compared to generic compilation methods.

The invention includes a solvable benchmark problem for assessing performance of MPS QAML models. This exactly solvable model involves an MPS Born machine encoding probability distributions of classical discrete data vectors. The model demonstrates how tensor network structures can represent classical data distributions while providing clear metrics for evaluating compilation and hardware performance. Studies of this benchmark reveal the impacts of hardware topology and noise fluctuations on model performance, including parametric analyses of depolarization and readout noise effects.
