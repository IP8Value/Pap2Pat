# DESCRIPTION  

## BACKGROUND OF THE INVENTION  

### Technical Field  

The present invention relates generally to magnetoresistive memory devices, and more particularly to spin-orbit torque (SOT) type magnetoresistance effect elements with improved writing efficiency and endurance. The invention specifically addresses challenges in current-driven magnetization reversal for magnetic random access memory (MRAM) applications requiring high-speed operation and reduced power consumption.  

### Description of Related Art  

Conventional magnetoresistive memory technologies have relied primarily on giant magnetoresistance (GMR) elements and tunnel magnetoresistance (TMR) elements. GMR elements utilize the resistance change between parallel and antiparallel magnetization states in ferromagnetic layers separated by a non-magnetic conductive layer. TMR elements employ similar principles but utilize a tunnel barrier layer instead of a conductive spacer, providing higher magnetoresistance ratios.  

Magnetic random access memory (MRAM) incorporating these elements has emerged as a promising non-volatile memory technology. Early MRAM implementations used magnetic field-induced writing, while subsequent developments introduced spin-transfer torque (STT) writing methods. STT-MRAM enables more compact memory cells by utilizing spin-polarized currents to directly manipulate magnetization states.  

Recent advances have explored spin-orbit torque (SOT) writing methods as an alternative to STT approaches. SOT writing generates spin currents through spin-orbit interactions in heavy metal layers, which then transfer torque to adjacent ferromagnetic layers. While SOT writing offers advantages in switching speed and reduced tunnel barrier stress compared to STT methods, conventional SOT implementations suffer from several limitations.  

A significant limitation of current SOT writing methods is the high current density required for reliable magnetization reversal. The substantial current densities needed can lead to excessive power consumption and potential device degradation over time. Additionally, conventional SOT structures often exhibit asymmetric switching characteristics and insufficient thermal stability, limiting their reliability in practical applications.  

## SUMMARY OF THE INVENTION  

The present invention addresses the need for reduced reversal current density in SOT-type magnetoresistance effect elements while maintaining reliable switching characteristics. The disclosed technology achieves this through innovative structural configurations that optimize spin current generation and transfer efficiency.  

### SUMMARY OF THE INVENTION  

The invention provides a novel SOT type magnetoresistance effect element that overcomes the limitations of conventional designs. The fundamental problem addressed by this invention is the excessive current density required for magnetization reversal in existing SOT devices. The solution involves strategic insertion of specialized layers that enhance spin current generation and transfer efficiency.  

A first aspect of the invention relates to a spin current magnetization rotational element comprising a spin-orbit torque wiring layer, ferromagnetic constituent layers, and an inserted layer positioned to optimize spin current transfer. The inserted layer modifies the spin current characteristics to enable more efficient magnetization reversal at reduced current densities.  

A second aspect describes the spin current magnetization rotational element where the inserted layer generates spin currents with opposite polarity to those generated in the spin-orbit torque wiring. This configuration creates complementary spin current contributions that collectively enhance the magnetization reversal efficiency.  

A third aspect involves the spin current magnetization rotational element configured with perpendicular magnetization films. The invention provides specific techniques to prevent magnetization collapse during switching operations, including controlled application of magnetic fields during critical switching phases.  

A fourth aspect extends the principles to a complete spin-orbit torque magnetoresistance effect element suitable for memory applications. This embodiment integrates the improved spin current magnetization rotational element with additional functional layers to form a complete memory cell structure.  

The invention further encompasses magnetic memory devices incorporating arrays of these improved magnetoresistance effect elements. The memory architecture includes optimized write and read operation schemes that leverage the enhanced switching characteristics of the disclosed elements.

### Spin Current Magnetization Rotational Element  

The spin current magnetization rotational element forms the core innovation of this invention. The element fundamentally comprises a spin-orbit torque wiring layer designed to generate spin currents through spin-orbit interactions when charge current flows through it. The spin-orbit torque wiring preferably consists of non-magnetic heavy metals exhibiting strong spin Hall effects, such as tungsten (W), tantalum (Ta), or platinum (Pt).  

In a first embodiment, the spin current magnetization rotational element generates pure spin currents through the spin Hall effect in the spin-orbit torque wiring. When charge current flows through the wiring, spin-orbit interactions cause separation of spin-up and spin-down electrons, creating a transverse spin current. The direction of this spin current depends on both the charge current direction and the material's intrinsic spin Hall angle.  

The generated spin current is injected into adjacent ferromagnetic material layers, where it exerts torque on the local magnetization. The invention introduces a critical innovation through the strategic placement of an inserted layer between the spin-orbit torque wiring and the ferromagnetic layers. This inserted layer modifies the spin current characteristics before it reaches the ferromagnetic material, significantly improving the torque transfer efficiency.  

The ferromagnetic constituent layers are carefully selected to exhibit appropriate magnetic properties for reliable switching. Preferred materials include cobalt-iron-boron (CoFeB) alloys, which combine high spin polarization with tunable magnetic anisotropy. The film thickness of these layers is optimized between 1-3 nm to maintain perpendicular magnetic anisotropy while allowing efficient spin torque transfer.  

A key advantage of the present invention is the substantial reduction in reversal current density achieved through the inserted layer. The inserted layer generates additional spin currents that complement those from the spin-orbit torque wiring. By selecting materials with opposite spin Hall angle polarity for the inserted layer, the invention creates a synergistic effect that enhances the overall spin current efficiency.  

The principle of operation involves coordinated spin current generation in both the spin-orbit torque wiring and the inserted layer. When charge current flows through the wiring, both layers generate spin currents that combine to produce enhanced torque on the ferromagnetic layers. This cooperative effect enables reliable magnetization reversal at significantly lower current densities than conventional SOT devices.  

In a second embodiment, the invention configures the spin-orbit torque wiring and inserted layer to generate spin currents with the same polarity. While this might initially seem counterintuitive, the configuration actually creates beneficial cancellation effects at certain interfaces, leading to more controlled magnetization reversal behavior. The specific arrangement allows precise tuning of the effective torque profile across the ferromagnetic layers.  

The invention provides specialized techniques for different magnetization orientations. For perpendicular magnetization films, the method includes controlled application of magnetic fields during switching to prevent magnetization collapse. For in-plane magnetization films with x-direction orientation, the spin current injection is optimized for coherent rotation rather than direct reversal. Similarly, y-direction oriented films receive tailored spin current profiles that promote efficient rotational switching.  

The spin current magnetization rotational element solves critical problems in conventional SOT devices, particularly regarding spin direction control. The invention introduces magnetic coupling mechanisms between layers that help maintain proper spin alignment throughout the switching process. Additionally, interface Rashba effects are harnessed to provide supplementary spin torque contributions that enhance the overall switching reliability.  

A third embodiment extends the principles to a complete spin-orbit torque magnetoresistance effect element suitable for memory applications. This configuration integrates the improved spin current magnetization rotational element with a second ferromagnetic layer, non-magnetic spacer layer, and antiferromagnetic pinning layer to form a full magnetic tunnel junction structure. The second ferromagnetic layer maintains fixed magnetization direction through exchange coupling with the antiferromagnetic layer, while the free layer (part of the spin current magnetization rotational element) provides the switchable magnetization component.  

The production method for these elements involves precise thin film deposition techniques including sputtering and molecular beam epitaxy. Patterning is achieved through advanced lithography processes followed by ion milling for vertical sidewall definition. Critical interfaces, particularly the tunnel barrier layer, undergo controlled oxidation processes to optimize their electronic and magnetic properties. Post-deposition annealing treatments are carefully designed to enhance crystalline structure and magnetic properties without compromising interface quality.  

A fourth embodiment presents a complete magnetic memory architecture incorporating arrays of the improved spin-orbit torque magnetoresistance effect elements. The memory organization includes optimized word line, source line, and read line arrangements that enable efficient selection and operation of individual memory cells. Write operations utilize the enhanced spin current generation capabilities of the disclosed elements, while read operations leverage the stable magnetoresistance characteristics for reliable state detection.  

The invention encompasses various modifications and adaptations of the basic principles disclosed. These include but are not limited to alternative material selections, layer thickness variations, geometric configurations, and integration schemes with conventional semiconductor technologies. The scope of protection extends to all implementations that utilize the fundamental innovation of inserted layer-enhanced spin current generation for improved magnetization reversal efficiency.
