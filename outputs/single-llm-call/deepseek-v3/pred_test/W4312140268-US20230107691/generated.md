# DESCRIPTION  

## BACKGROUND OF THE INVENTION  

Biometrics refers to the measurement and statistical analysis of an individual's unique physical and behavioral characteristics. Biometric data monitoring has become increasingly important in healthcare, enabling continuous assessment of physiological parameters for disease prevention, diagnosis, and management. Physiological processes such as respiratory rate, heart rate, blood pressure, muscle activity, and internal organ movements generate electric, thermal, chemical, and acoustic energy. These biological signals can be measured using transducers and sensors attached to different parts of the body.  

Biosignals representing aspects of these physiological processes are transmitted as electric potential, pressure difference, mechanical vibrations, or acoustic waves. Detector devices such as wearable and wireless sensors, smartphone-connected technologies, implantable sensors, and lab-on-a-chip nanosensor platforms have been developed to capture these signals. These digital health technologies (DHTs) are capable of recording cardiac activity, blood pressure, respiration, brain activity (EEG), and muscle activity (EMG).  

Cardiovascular measurements can be extracted from wearable DHTs using various methods including electrocardiography (ECG), photoplethysmography (PPG), oscillometry (pulse rate variation), and biochemical sensors. However, contemporary biometric systems face limitations in accuracy, power consumption, memory, and data storage, often resulting in incomplete or inaccurate measurements. For example, consumer wearables may exhibit error rates of up to 10% in reporting heart rate alone.  

The autonomic nervous system plays a critical role in regulating physiological processes, and biofeedback mechanisms can be used to monitor and influence its activity. A closed-loop system that integrates real-time biometric data collection with feedback mechanisms could enable more precise monitoring and intervention. Wearable systems have emerged as a promising platform for continuous biometric monitoring, but existing solutions often lack the accuracy and reliability required for medical-grade applications.  

## SUMMARY OF THE INVENTION  

The present invention introduces a wearable in-ear biosensor system that utilizes in-ear infrasonic hemodynography (IH) technology for continuous and accurate monitoring of cardiovascular activity. The system overcomes limitations of contemporary wearables by providing medical-grade precision in a convenient earbud form factor.  

The in-ear biosensor system includes detector devices embedded within earbuds, which capture infrasonic biosignals associated with cardiac activity. These biosignals are transmitted to a data analysis system that processes the data in real-time, enabling continuous monitoring of physiological states. The system operates as a closed-loop system, providing feedback to the individual based on the analyzed data.  

A key innovation of the invention is the use of IH signals, which are acoustic pressure fluctuations in the infrasonic range (below 20 Hz) detected within the sealed ear canal. The system captures these signals with high fidelity, allowing for precise measurement of interbeat intervals (IBI), heart rate (HR), and heart rate variability (HRV). The continuous data stream generated by the system enables comprehensive monitoring of autonomic nervous system activity.  

The data analysis system creates a baseline autonomic nervous system profile for the individual by plotting physiological data over time. Machine learning models may be employed to establish this baseline, incorporating data from external sensors or user-provided inputs. The system identifies the individual's current physiological state by comparing real-time biosignals against the baseline profile.  

Once the current physiological state is determined, the system can instruct the individual to adjust their physiological state through biofeedback mechanisms. For example, the system may guide the individual to achieve a target physiological state by suggesting breathing exercises or other interventions. The closed-loop nature of the system enables continuous monitoring and adjustment, facilitating improved health outcomes.  

## DETAILED DESCRIPTION OF THE PREFERRED EMBODIMENTS  

The invention encompasses an in-ear biosensor system and associated methods for continuous cardiovascular monitoring. FIG. 1A illustrates the system architecture, which includes components within and/or in communication with a network cloud. The system comprises computing devices with central processing units (CPUs), microprocessors, and microcontrollers that execute application code. An operating system manages system resources, while application programming interfaces (APIs) facilitate communication between software components.  

The in-ear biosensor system includes earbuds connected to a controller board, which communicates with user devices via wireless communication links. Each earbud contains an infrasonic sensor and a speaker, enabling simultaneous biosignal detection and audio playback. The controller board, housed within a controller housing, includes a battery and manages data acquisition.  

User devices such as smartphones or tablets run a user application that interfaces with the biosensor system. The application displays visual content, presents notification messages, and provides feedback to the individual. An application server processes biosignals and stores data in medical records accessible to healthcare professionals.  

The system utilizes infrasound (acoustic signals below 20 Hz) to detect biosignals associated with cardiovascular activity. Sensors within the earbuds capture these signals with high sensitivity, benefiting from the "stereo effect" of dual-ear measurements. The closed-loop system operates through three primary communication paths (Path A, B, and C), enabling seamless data flow between components.  

Path C involves transmission of biosignals from the earbuds to the controller board, while Path B handles communication between the controller and user devices. The data analysis system receives biosignals via these paths and processes them using machine learning models. The system can update medical records, send notifications to healthcare professionals, and provide real-time feedback to the individual.  

The in-ear biosensor system may incorporate auxiliary sensors, such as those found in ECG systems, wrist-worn wearables, eyeglass user devices, or VR headsets. These additional sensors enhance the system's capability to monitor various physiological parameters. The system architecture supports integration with multiple data sources, enabling comprehensive health assessment.  

A key feature of the invention is its ability to capture IH signals while simultaneously playing audio. The system performs a biosignal sensitivity study, plotting biosignals alongside reference ECG signals and tachograms. Power spectra plots provide frequency domain representations of the signals, with particular focus on low-frequency (0.04-0.15 Hz) and high-frequency (0.15-0.4 Hz) bands associated with autonomic nervous system activity.  

The data analysis system computes HR and HRV values from the biosignals, analyzing data quality and identifying peaks in the signal waveforms. The system overcomes limitations of existing wearables by providing accurate, continuous cardiac monitoring. The closed-loop system enables comprehensive cardiac assessment, with IH technology serving as the primary monitoring modality.  

The system illustrates autonomic nervous system activity by analyzing physiological data and its effect on cardiovascular parameters. It can operate with or without auxiliary sensors, creating a baseline autonomic nervous system profile for each individual. This profile combines multiple physiological data points to characterize the individual's autonomic state.  

The data analysis system translates data points into physiological states, representing them along a continuum. The method of operation involves monitoring and accessing biosignals, identifying physiological data, creating baseline profiles, and storing this information to medical records. As new biosignals are collected, the system identifies current physiological states and maps them against the baseline profile.  

Complex mapping of physiological data may employ machine learning and deep learning methods. The system obtains multiple instances of biosignals and physiological data to account for individual variability. It synchronizes time-stamped data from various sources, including external sensors and user-provided inputs, to create comprehensive profiles.  

Trained machine learning models specific to each individual process new biosignals and physiological data to identify current states. The system then instructs individuals to perform actions—either direct interventions like breathing exercises or indirect measures like environmental adjustments—to achieve target physiological states. Successful actions are recorded to update personalized response profiles.  

The invention has diverse applications, including advertising refinement based on physiological states, music selection tailored to autonomic profiles, workspace optimization, and social media/dating compatibility assessments. The system presents current physiological states and baseline profiles to users, enabling them to access target states and receive personalized instructions for physiological adjustment.  

The advantages of the in-ear biosensor system include its non-invasive nature, medical-grade accuracy, and seamless integration into daily life through the earbud form factor. The system's ability to predict changes in physiological states and provide real-time feedback represents a significant advancement in personalized health monitoring and intervention.
