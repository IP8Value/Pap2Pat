# DESCRIPTION  

## BACKGROUND  

Random number generation is a fundamental process utilized across numerous technical fields including cryptography, scientific simulations, and secure communications. High-quality random numbers are essential for cryptographic applications where predictable sequences could compromise security protocols. Traditional deterministic algorithms, often referred to as pseudo-random number generators, cannot produce truly random sequences due to their inherent algorithmic nature. These methods rely on seed values and mathematical operations that, while appearing random, remain entirely predictable if the initial conditions are known.  

The limitations of deterministic approaches have driven the development of hardware-based random number generators that exploit physical processes exhibiting intrinsic randomness. Among these, quantum physical processes provide particularly robust sources of randomness due to the fundamentally probabilistic nature of quantum mechanics. Photon emission processes, governed by quantum mechanics, have emerged as particularly reliable sources for random number generation. However, existing photon-based random number generation technologies face significant limitations.  

Previous implementations utilizing single-photon avalanche diodes (SPADs) suffer from after-pulsing effects, require high operating voltages, and exhibit limited scalability due to large pixel sizes. Conventional CMOS image sensors (CIS), while compatible with standard fabrication processes, demonstrate insufficient photon-counting accuracy and elevated noise levels that degrade randomness quality. These limitations manifest in reduced output data rates and compromised entropy in the generated sequences.  

Photon-emission-based random number generators (RNGs) typically convert the probabilistic nature of photon arrival times or positions into binary sequences. However, these systems often incorporate undesirable noise sources such as dark current and readout noise that introduce thermal dependencies and reduce the quantum purity of the output. An ideal photon-based RNG would maintain high photon-counting accuracy while minimizing extraneous noise sources and maximizing output data rates. Existing technologies fail to simultaneously achieve these objectives, creating a need for improved random number generation architectures.  

## SUMMARY OF SOME EMBODIMENTS  

The disclosed invention introduces a quantum random number generator (QRNG) utilizing a Quanta Image Sensor (QIS) architecture that overcomes limitations of prior approaches. The QIS-based QRNG employs an array of specialized pixel elements called "jots" configured for high-accuracy photon counting. Each jot operates with deep sub-electron read noise (DSERN), typically below 0.15 e− r.m.s., enabling precise discrimination of individual photon events. The system generates random numbers by comparing the output of these jot devices to predetermined threshold levels, with the binary results forming the raw random sequence.  

The QIS configuration incorporates several key components including a photon source, optical conditioning elements, and specialized readout circuitry. An optional photon source provides controlled illumination to the jot array, while optical conditioning elements may include lenses, filters, or diffusers to optimize photon distribution. The system includes comparison circuitry that converts analog jot outputs into binary values by comparing them against threshold levels, typically set between quantization levels of the photon-counting histogram.  

Binary output data generation occurs through a multi-stage process beginning with photon detection in individual jots. Each jot accumulates photoelectrons during an exposure period, with the resulting signal compared to a threshold voltage. The comparison yields a binary output representing whether the detected photon count exceeds the threshold. Optional control circuitry dynamically adjusts system parameters including threshold levels, exposure durations, and photon source intensity to maintain optimal entropy conditions.  

The system may incorporate a randomness extractor to post-process the raw binary output, compensating for any residual bias in the sequence. This extractor applies cryptographic hash functions or other mathematical transformations to distill higher-quality random bits from the raw output. Control subsystems monitor various parameters including photon flux, threshold accuracy, and output entropy, making real-time adjustments to maintain optimal performance.  

Key operational parameters include the quanta exposure H, representing the average number of photoelectrons per jot per frame, typically maintained near 0.7 for optimal entropy. The system adjusts threshold levels to valley points in the photon counting histogram, maximizing sensitivity to quantum randomness while minimizing sensitivity to noise fluctuations. Additional embodiments may incorporate multi-bit jot outputs, where analog-to-digital conversion occurs prior to threshold comparison, or implement in-pixel processing to reduce readout bandwidth requirements.  

For clarity, certain terms are defined herein. "Quanta Image Sensor" refers to a sensor architecture comprising specialized photon-counting pixels (jots) with deep sub-electron read noise capability. "Photon source" encompasses any illumination source including LEDs, lasers, or thermal emitters. "Optical conditioner" includes any element modifying photon distribution including lenses, diffusers, or wavelength-selective filters. "Read noise" refers to the temporal noise in the readout chain, measured in electrons RMS.

The QIS-based QRNG represents a significant advancement over prior SPAD and CIS-based random number generators by combining the photon-counting accuracy of SPADs with the scalability and fabrication compatibility of conventional image sensors. The system generates random numbers through quantum processes by detecting individual photon arrivals in an array of QIS jot devices. Each jot operates as an independent random bit generator, with array-level parallelism enabling exceptionally high data rates.  

The QIS pixel array forms the core of the system, comprising millions of jots each capable of resolving single photon events. Unlike conventional image sensors where noise obscures quantization effects, the QIS maintains sufficient conversion gain and sufficiently low read noise to preserve photoelectron quantization. This enables threshold-based discrimination between discrete photon counts, with the inherent randomness in photon arrival times providing the entropy source.  

An optional photon source illuminates the jot array with controlled intensity, typically adjusted to maintain an average quanta exposure near 0.7 photoelectrons per frame. Optical conditioning elements may homogenize the illumination or restrict wavelengths to optimize detector response. The photon source intensity represents a controllable parameter that the system may adjust to compensate for environmental variations or maintain optimal entropy conditions.  

Control circuitry manages overall system operation including exposure timing, readout sequencing, and parameter adjustments. This circuitry may implement feedback loops that monitor output statistics and dynamically adjust threshold levels, exposure durations, or illumination intensity. The control system ensures stable operation despite environmental fluctuations by maintaining the photon counting histogram in an optimal configuration where threshold levels align with valleys between quantization peaks.  

The readout chain converts charge accumulation in each jot into digital values through a series of amplification, sampling, and digitization stages. In single-bit implementations, the analog signal undergoes comparison against a threshold voltage to generate a binary output. Multi-bit embodiments incorporate analog-to-digital conversion (ADC) prior to threshold comparison, enabling more sophisticated processing in the digital domain. The readout chain design minimizes noise injection while supporting high frame rates necessary for rapid random number generation.  

Jot devices may implement various architectures including the pump-gate design that achieves 0.22 e− r.m.s. read noise at room temperature. These devices employ specialized structures to enhance conversion gain while minimizing noise sources. The jot implementation affects key performance parameters including readout speed, power consumption, and photon detection efficiency, with optimal designs balancing these factors for random number generation applications.  

Binary output generation occurs through comparison of the readout signal against predetermined thresholds. The threshold level Ut is typically set between integer photoelectron values, often at 0.5 e− for single-bit operation. This threshold placement maximizes entropy by positioning the decision point at a minimum in the signal probability distribution. The comparison may occur in the analog domain prior to digitization or in the digital domain following ADC conversion, depending on implementation requirements.  

Multi-bit QIS embodiments provide additional flexibility by preserving photoelectron count information through the digitization process. These implementations process the ADC output through digital comparison circuitry that may implement multiple thresholds or more sophisticated decision algorithms. The digital implementation allows precise threshold adjustment and facilitates advanced monitoring of system performance metrics.  

A randomness extractor may process the raw binary output to compensate for any residual bias or correlations. The extractor configuration depends on the measured entropy of the raw output and the desired quality of the final random sequence, with compression ratios adjusted to achieve target performance metrics.  

Post-ADC digital domain comparison offers several advantages including precise threshold control and adaptability to varying conditions. The randomness extractor implementation may incorporate various cryptographic techniques including hash functions, resilient functions, or other mathematical transformations. Fundamental design principles of the QIS QRNG derive from quantum optics and information theory. The photon arrival process follows Poisson statistics, with the probability of k photoelectrons given by P[k] = (e^-H H^k)/k! where H represents the quanta exposure. The readout signal distribution combines this Poisson distribution with Gaussian read noise, creating a probability density function that forms the basis for threshold selection and entropy calculation.  

The signal distribution characteristics determine key performance parameters including the probability of "1" and "0" states in the binary output. For threshold Ut, these probabilities are given by P[U < Ut] and P[U ≥ Ut] respectively, derived through integration of the combined Poisson-Gaussian distribution. The minimum entropy Smin = -log2[max(P[U ≥ Ut], P[U < Ut])] quantifies the randomness quality, with ideal operation achieving Smin approaching 1 bit per output bit.
