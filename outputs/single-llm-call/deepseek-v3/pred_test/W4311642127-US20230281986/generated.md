# DESCRIPTION

## TECHNICAL FIELD

The present invention relates generally to the field of computer vision and machine learning, with specific applications in video anomaly detection systems. More particularly, the invention discloses a novel zero-shot cross-domain video anomaly detection (zxVAD) system that operates without requiring any target domain training data. The technical field encompasses unsupervised learning methods for identifying anomalous events in video surveillance footage across different domains, where the system is trained exclusively on source domain data containing normal events and optionally task-irrelevant datasets, yet can effectively detect anomalies in target domain videos without adaptation or fine-tuning. This represents a significant advancement over existing cross-domain video anomaly detection systems that typically require access to at least some target domain training data for adaptation.

## BACKGROUND

Current unsupervised video anomaly detection (VAD) methods have gained prominence in security and surveillance applications due to their ability to operate without requiring labeled anomalous training data. These methods train exclusively on videos containing normal events, marking any activities during testing that deviate from the learned normal patterns as anomalies. However, existing approaches face significant limitations when applied in cross-domain settings, where the system trained on source domain data must detect anomalies in a different target domain. Conventional cross-domain VAD (xVAD) systems typically require access to either source and target domain training data or strong supervision from pre-trained object detectors, making them impractical for real-world deployment where target domain data may be unavailable due to privacy concerns or logistical constraints.

The fundamental technical problem addressed by this invention stems from the impractical assumptions made by current xVAD systems regarding access to target domain data. In real-world scenarios, end-users often require systems that can operate "out-of-the-box" without needing to collect and annotate target domain training data. Moreover, third-party corporations may be reluctant to share video data due to intellectual property and security concerns, rendering current xVAD systems ineffective. The present invention specifically addresses these limitations by introducing a zero-shot cross-domain approach that eliminates the need for any target domain training data while maintaining high detection accuracy.

A critical technical challenge overcome by this invention involves the contextual nature of normalcy, where what constitutes normal behavior varies significantly across different domains (e.g., running in playgrounds versus highways). Prior xVAD systems tend to overfit to source domain distributions when trained exclusively on normal events, resulting in poor generalization to target domains. The present invention solves this problem through a novel relative learning strategy that trains the system to distinguish normal from abnormal patterns rather than simply learning normal event features. This approach enables robust anomaly detection across domains without requiring prior knowledge of target domain anomaly types.

## SUMMARY

The present invention provides a zero-shot cross-domain video anomaly detection (zxVAD) system that operates without requiring any target domain training data. The system comprises several key technical components: a future frame prediction module with memory storage, an object-aware anomaly synthesis module using an untrained convolutional neural network (CNN), and a normalcy classifier module with novel loss functions. These components work in concert to enable effective anomaly detection in target domain videos while being trained exclusively on source domain data.

The system operates by first collecting video data containing only normal events from a source domain. The foreground objects are extracted from these videos using an untrained CNN, which localizes objects without requiring any pre-training or additional supervision. The system then trains two neural networks: a first neural network for future frame prediction and a second neural network for anomaly classification. The future frame prediction module employs a generator-discriminator architecture with a memory module to model normal event patterns. The normalcy classifier module introduces four novel loss functions that enable the system to learn relative differences between normal and abnormal patterns rather than simply memorizing normal events.

A key innovation is the object-aware anomaly synthesis module, which generates pseudo-abnormal frames by pasting localized objects from either task-relevant (VAD) or task-irrelevant (TI) datasets onto normal frames at random locations. This allows the system to learn from diverse anomaly types without requiring actual anomalous training data. The normalcy classifier module then processes these pseudo-abnormal frames along with predicted normal frames through several specialized loss functions: normalcy loss, relative normalcy loss, attention affirmation loss, and relative attention affirmation loss. These loss functions collectively train the system to distinguish normal from abnormal patterns based on both classifier predictions and attention maps.

During operation, the system performs video anomaly detection by comparing predicted future frames with actual frames and identifying significant deviations as anomalies. The memory module stores diverse normal patterns, while the normalcy classifier provides additional supervision to prevent overfitting to the source domain. This architecture enables the system to generalize effectively to unseen target domains without requiring any adaptation or fine-tuning, addressing a critical limitation of existing xVAD systems.

### System Overview

The training system of the present invention comprises several interconnected components that collectively enable zero-shot cross-domain video anomaly detection. The system architecture includes a future frame prediction module with integrated memory storage, an object-aware anomaly synthesis module, and a normalcy classifier module, all operating under the control of one or more processors executing stored instructions. The memory storage component maintains a repository of normal event patterns learned during training, while the processor coordinates data flow between modules and executes the training algorithms.

The system processes source domain data consisting exclusively of videos depicting normal events. These normal events represent typical, expected activities within the source domain context, such as pedestrians walking in designated areas or vehicles following traffic patterns. The system extracts foreground objects from these videos using an innovative approach that employs an untrained, randomly initialized CNN rather than pre-trained object detectors. This object extraction method significantly reduces computational overhead while maintaining effective localization capabilities.

The first neural network, responsible for future frame prediction, undergoes training using both reconstruction loss and discriminative loss functions. This network incorporates a generator-discriminator architecture where the generator predicts future frames based on input sequences, and the discriminator distinguishes between predicted and actual frames. The memory module integrated into the generator stores prototypical normal patterns that assist in maintaining consistency across domains. The reconstruction loss measures pixel-level differences between predicted and actual frames, while the discriminative loss trains the discriminator to identify synthetic frames.

The second neural network implements the normalcy classifier module, which introduces several novel technical aspects. This module processes both predicted normal frames and pseudo-abnormal frames generated by the object-aware anomaly synthesis module. The pseudo-abnormal frames are created by localizing objects in input frames (either from VAD or TI data) and pasting them onto normal frames at random locations and sizes. This synthesis process enables the system to learn from diverse anomaly types without requiring actual anomalous training data.

The normalcy classifier employs four specialized loss functions that collectively train the system to understand relative differences between normal and abnormal patterns. The normalcy loss function directly optimizes the classifier to identify normal and pseudo-abnormal frames correctly. The relative normalcy loss enhances this capability by enforcing that normal frames should be more normal than abnormal frames, not just absolutely normal. The attention affirmation loss ensures the classifier focuses on appropriate regions when making decisions, while the relative attention affirmation loss maintains consistent attention patterns for normal frames with varying transformations.

The joint training of both neural networks occurs through an end-to-end optimization process that balances the objectives of accurate frame prediction and effective anomaly classification. During video anomaly detection, the system processes input sequences through both networks, comparing predicted frames with actual frames and identifying significant deviations as anomalies. The attention mechanisms in the normalcy classifier provide additional spatial information about potential anomaly locations within frames.
