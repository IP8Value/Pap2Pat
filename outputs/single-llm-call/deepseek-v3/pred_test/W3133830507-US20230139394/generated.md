# DESCRIPTION  

## TECHNICAL FIELD  

The present invention relates generally to speech recognition systems, and more specifically to an electroencephalography (EEG)-based speech prosthetic system for improving speech recognition accuracy in individuals with speech disorders such as aphasia, apraxia, and dysarthria. The technical field encompasses biomedical signal processing, neural signal analysis, and machine learning techniques applied to speech recognition. The invention combines neural signals with acoustic features to enhance the performance of automatic speech recognition (ASR) systems when processing disordered speech patterns.  

## BACKGROUND  

Speech therapy faces significant challenges in providing effective technological aids for individuals with speech disorders. Current speech recognition technologies perform poorly when processing incomplete, distorted, or broken speech patterns characteristic of aphasia, apraxia, and dysarthria. These neurological speech disorders result from brain injuries or motor planning impairments that affect speech production. Traditional audio-only speech recognition systems demonstrate high word error rates when processing such disordered speech, with reported phoneme error rates reaching 75-89% for severe cases.  

Limitations of conventional audio-only speech recognition become particularly apparent when applied to speech therapy contexts. While research has shown that incorporating ASR technology can improve speech therapy effectiveness, the fundamental accuracy limitations of current systems restrict their clinical utility. The poor performance stems from the systems' inability to interpret the neural intent behind distorted speech sounds.  

Recent neuroscience research has demonstrated that electrophysiological signals such as EEG carry valuable information about speech articulation and perception. However, prior attempts to utilize these neural signals have focused primarily on subjects without speech disorders. The present invention addresses these limitations by developing a novel EEG-based speech recognition system specifically optimized for processing disordered speech patterns through integration of neural signals with acoustic features.  

## SUMMARY  

The invention provides an EEG-based speech prosthetic system that significantly improves speech recognition accuracy for individuals with aphasia, apraxia, and dysarthria. The system operates by combining acoustic features with neural-derived representations of intended speech, enabling more accurate interpretation of disordered speech patterns.  

In a first embodiment, the system obtains both audio signals and EEG signals simultaneously during speech production. The EEG signals are processed to extract neural features that correlate with speech articulation. These neural features are then transformed into acoustic representations using a trained deep learning regression model. The system concatenates these neural-derived acoustic representations with traditional acoustic features extracted from the audio signal. This combined feature set is provided to an automatic speech recognition (ASR) model, which generates text-based output reflecting the intended speech with significantly improved accuracy compared to audio-only approaches.  

The system implements specialized processing for obtaining the acoustic representations from EEG signals. After acquiring raw EEG data, the system removes electromyography (EMG) artifacts using linear regression techniques. It then extracts five distinct neural features per EEG channel: root mean square, zero-crossing rate, moving window average, kurtosis, and power spectral entropy. These features undergo dimensionality reduction using kernel principal component analysis (KPCA) before being input to the deep learning regression model.  

A second embodiment extends this approach to continuous speech recognition. The system employs a connectionist temporal classification (CTC) model architecture with a gated recurrent unit (GRU) encoder and a decoder combining dense layers with a 4-gram language model. This architecture processes the concatenated EEG-derived and audio features to generate continuous text output, demonstrating improved performance over baseline systems in processing disordered continuous speech.

The communication unit 110 operations involve establishing secure data links between the wearable components and processing units. Transmit processing circuitry 115 operations include packetizing neural and audio data streams for efficient transmission. Receive processing circuitry 125 operations involve reconstructing these data streams and performing initial signal conditioning.  

The main processor 140 operations encompass feature extraction, artifact removal, and feature combination algorithms. Input/output interface 145 operations manage user interactions and system status displays. Input/output devices 150 operations provide visual feedback and system control interfaces for users and clinicians.  

The system architecture extends to server 200, which handles computationally intensive model operations. Bus system 205 interconnects server components, including processing device 210 that executes the deep learning models. Storage devices 215 maintain training data and model parameters, while communications unit 220 manages network connectivity. Input/output unit 225 interfaces with external systems, and memory 230 supports runtime operations. Persistent storage 235 maintains long-term data archives for model refinement.  

The processing architecture 300 implements a two-stage approach comprising deep learning regression stage 301 and speech recognition stage 351. The system first obtains EEG signals through dry or wet electrodes, simultaneously capturing audio signals and EMG signals. After removing EMG artifacts from EEG signals using regression techniques, it extracts EEG features including temporal and spectral characteristics. These features undergo dimensionality reduction before being provided to deep learning model 303, which is trained to predict acoustic representations from neural activity.  

The speech recognition stage processes audio input to obtain Mel frequency cepstral coefficients (MFCCs), which are concatenated with the EEG-derived acoustic representations. This combined feature set trains ASR model 360, which incorporates specialized architectures for different recognition tasks. For isolated speech recognition, ASR model 400 employs a GRU layer followed by dropout regularization and dense layers with softmax activation. The training process optimizes categorical cross-entropy loss using adaptive moment estimation.  

Continuous speech recognition utilizes ASR model 500 with a GRU encoder and decoder combining dense layers with a 4-gram language model. This architecture employs connectionist temporal classification loss during training and incorporates beam search decoding during inference. Speaker identification is implemented through ASR model 600, which shares the core GRU architecture but adapts the output layer for speaker classification tasks.  

The real-time speech recognition decoding pipeline processes multiple synchronized data streams. Dry EEG sensor signals and ear EEG sensor signals provide neural inputs, while dry EMG sensor signals enable artifact removal. Audio signals are processed in parallel, with stream generation modules creating synchronized EEG, EMG, and audio data streams. The pipeline removes EMG artifacts, extracts EEG features, and reduces feature dimensionality before combining neural and acoustic representations.  

The EEG-based speech recognition method involves receiving an audio signal while simultaneously obtaining EEG signals during speech production. The system processes these neural signals to obtain acoustic representations of intended speech, then concatenates these neural-derived features with conventional audio features. This enriched feature set is provided to specialized ASR models that generate text-based output with significantly improved accuracy for disordered speech. The method demonstrates particular effectiveness for isolated speech recognition tasks, showing over 50% improvement in accuracy compared to audio-only approaches, while also providing measurable improvements in continuous speech recognition scenarios.
