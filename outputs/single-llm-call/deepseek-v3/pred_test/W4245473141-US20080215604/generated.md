# DESCRIPTION  

## TECHNICAL FIELD  

The present invention relates to Field Programmable Gate Array (FPGA) and Application-Specific Integrated Circuit (ASIC) devices configured for processing genetic pedigree data structures. More particularly, the invention discloses specialized hardware architectures and methods for parallel processing of pedigree information through programmable logic cells and electrical connections arranged in generational layers. The disclosed device enables accelerated computation of genetic probabilities, inbreeding coefficients, and inheritance patterns through synchronous processing of entire pedigree structures within single clock cycles.  

## BACKGROUND ART  

Genetic pedigree analysis requires processing of alleles, which represent variant forms of genes at specific chromosomal loci, and haplotypes, which constitute sets of linked alleles inherited together. Pedigree data structures organize biological relationships between individuals in a hierarchical format where each diploid individual derives exactly two parental alleles through meiotic transmission. Conventional sequential algorithms process these structures through iterative loops that examine individual meioses and inheritance patterns in series, creating computational bottlenecks when handling large pedigrees with complex marriage loops or inbreeding patterns.  

Existing pedigree processing systems face fundamental limitations in processing speed due to their sequential architectures. While cluster computing solutions can parallelize outermost loops across multiple processors, their speedup remains linearly constrained by processor count. The combinatorial nature of pedigree analysis—where evaluation of each meiosis event branches into exponential possibility spaces—makes conventional CPU architectures particularly inefficient for exact maximum likelihood calculations. Even approximate sampling methods like gene dropping algorithms require prohibitive computation times when applied to large-scale pedigrees with partial genotype observations.  

## DISCLOSURE OF INVENTION  

The present invention provides a hardware-based device for representing and processing pedigree data structures through parallel electronic circuitry. The device comprises an array of configurable logic cells interconnected to form modules corresponding to individuals in a pedigree, with electrical pathways arranged to simulate allele transmission between generations. Input circuitry supplies initial allele distributions to founder modules representing individuals without known parents, while output circuitry accumulates statistical results from terminal modules.  

The invention enables simultaneous processing of all meioses within a generational layer during each clock cycle through pipelined electronic pathways. A subset of the pedigree data structure may be loaded into the hardware, with modules representing either complete generations or partial generational segments. Duplicate copies of the pedigree structure can operate concurrently on separate hardware sectors to increase sampling throughput. Each individual module incorporates data counters for allele frequency tracking and authentication circuitry for validating meiotic consistency with observed genotypes.  

A filtering subsystem rejects inconsistent allele configurations by evaluating observed genotype constraints across all layers. The device includes specialized generators for producing paternal and maternal allele pairs according to defined inheritance probabilities, with weighting circuits adjusting sample contributions based on likelihood calculations. The FPGA's reconfiguration capability allows dynamic adaptation to different pedigree topologies and genetic analysis objectives.  

Key advantages of the invention include: fixed-duration processing time independent of pedigree size (constrained only by hardware capacity); synchronous evaluation of all meiotic possibilities within each generational layer; and elimination of sequential iteration bottlenecks through parallelized allele transmission pathways. The hardware implementation achieves speed improvements proportional to the number of individuals in the pedigree when compared to conventional processor architectures.  

## BEST MODE FOR CARRYING OUT THE INVENTION  

The preferred embodiment implements the invention on a Xilinx Spartan 3 FPGA containing approximately 400,000 configurable logic gates operating at 50MHz. Logic blocks are programmed in VHDL to form interconnected modules arranged in generational layers, with layer 0 containing founder modules and subsequent layers containing descendant modules. Each module occupies a physical sector of the FPGA with dedicated electrical connections to parental modules in the preceding layer and progeny modules in subsequent layers.  

Founder modules contain allele pair generators producing either fixed or randomly sampled alleles according to specified frequency distributions. Descendant modules incorporate meiosis indicators that select transmitted alleles through configurable binary switches. Holder modules synchronize allele propagation when individuals contribute to multiple generations, maintaining pipeline coherence across layers. Allelic data transforms through the system with each clock cycle, such that a complete pedigree sample emerges every cycle after initial pipeline filling.  

The gene dropping algorithm embodiment illustrates allele transmission through a three-generation pedigree structure. Founder modules generate unique allele pairs while descendant modules apply pseudo-random meiosis indicators from cellular automata number generators. Comparator circuits in terminal modules evaluate identity-by-descent status for inbreeding coefficient calculations, with valid results incrementing dedicated counters. For genotype probability estimation, a validity testing subsystem checks consistency with observed genotypes across all layers before permitting counter increments.  

In an alternative embodiment, two interconnected FPGAs operate in tandem—one generating pedigree samples while the second performs Metropolis-Hastings accept/reject operations on weighted samples. Central meiosis modules coordinate allele selection through lookup tables and specialized counters for sires, dams, and terminal individuals. A Supervisor soft processor manages sample accumulation and parameter optimization between hardware generations.  

Performance testing demonstrates the invention's superiority over conventional processors. A 60-individual pedigree required 166 fewer clock cycles on FPGA compared to an equivalent 3GHz Pentium 4 implementation. Scaling analysis indicates potential for 17,500x speedup when processing 1,000-individual pedigrees on high-performance Virtex 4 FPGAs. The architecture maintains this advantage when handling multi-locus haplotype analysis and complex constrained genotype scenarios.  

Alternative configurations partition large pedigrees across multiple FPGAs or implement partial pedigree analyses through modular subsets. Ready flags coordinate data passing between segments, while specialized random number generators and inheritance probability weighters adapt to different genetic analysis requirements. The invention's reconfigurable nature supports diverse pedigree analysis algorithms beyond gene dropping, including importance sampling and likelihood approximation methods.
