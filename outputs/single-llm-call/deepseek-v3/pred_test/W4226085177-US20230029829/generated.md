# DESCRIPTION  

## BACKGROUND  

The field of information retrieval has traditionally relied on an ad-hoc retrieval paradigm where users submit a single query and receive a set of results. This one-shot interaction model proves increasingly inadequate given the complexity and diversity of modern textual knowledge sources. Users often struggle to formulate precise queries that capture their information needs, particularly when exploring unfamiliar domains or dealing with multifaceted topics.  

Conversational search represents an advanced paradigm that combines elements of exploratory search, interactive information retrieval, and response generation. Unlike traditional search, conversational systems engage users in multi-turn dialogues that may include mixed-initiative interactions. In this model, the system may ask clarification questions to better understand the user's intent and refine the search process. Current approaches for generating clarification questions fall into two categories: selection-based methods that choose from predefined question pools, and generation-based methods that create questions dynamically using rules or neural networks.  

Prior art in clarification question selection suffers from several limitations. Existing systems often fail to leverage the full context of the conversation and retrieved documents when selecting questions. Many approaches treat clarification questions as isolated entities rather than considering their relationship to both the conversation history and potential answer passages. Furthermore, conventional methods typically employ single-dimensional ranking mechanisms that cannot capture the nuanced relationships between questions, conversations, and relevant text passages.  

## SUMMARY  

The present invention discloses a computer-implemented method for automatically selecting clarification questions during conversational search interactions. The method begins by receiving an ongoing search conversation comprising multiple utterances between a user and a conversational agent. The system then retrieves relevant text passages from a document corpus based on the conversation context. For each retrieved passage, the method identifies candidate clarification questions from a predefined question pool.  

The invention employs two specialized deep learning models to rank the candidate clarification questions. A first model evaluates the strength of association between each candidate question and the search conversation context. A second model assesses the strength of association between each candidate question, the search conversation, and a particular text passage. The system fuses the scores from both models to generate a composite ranking of clarification questions. The highest-ranking candidate question is then provided to the user to refine the search interaction.  

In system embodiments, the invention comprises a conversational search system with several key components: a document index storing the corpus of searchable documents, a clarification question index containing the pool of potential questions, passage retrieval modules, question retrieval modules, and the dual deep learning models for question ranking. The system operates through coordinated interaction between these components to select optimal clarification questions during search conversations.  

The invention further encompasses computer program products comprising non-transitory computer-readable storage media storing program code that, when executed by one or more processors, implements the clarification question selection method. The program code includes instructions for receiving search conversations, retrieving relevant passages and candidate questions, applying the deep learning models to rank questions, and providing the highest-ranking questions to users.  

The deep learning models are trained using a specialized process that involves obtaining human-to-human conversations, identifying relevant text passages for each conversation, and labeling clarification questions and their answers within the conversations. The training system creates distinct training sets for the two models, with the first model learning conversation-question associations and the second model learning conversation-passage-question associations. Both models employ triplet network architectures adapted for BERT-based fine-tuning.  

During operation, the system retrieves top solution documents for a given search conversation and extracts candidate text passages using a sliding window approach. Each passage receives an initial score based on term coverage metrics, with final passage scores calculated through a weighted combination of passage and document scores. The system retrieves candidate clarification questions associated with each high-scoring passage and applies the trained models to rank them.  

Score fusion combines the outputs of both models to produce a unified ranking of clarification questions. The system may present either the single highest-ranking question or multiple top-ranking questions to the user. The entire process operates efficiently to maintain real-time conversational flow, with question ranking typically completing within 1-2 seconds even for large candidate sets.  

## DETAILED DESCRIPTION  

The computer-implemented method for automatic selection of clarification questions operates through several coordinated phases. When a user engages in a search conversation with the system, the method begins by analyzing the conversation context comprising all previous utterances in the current search session. The system embodiment includes specialized components for passage retrieval, question retrieval, and question ranking that work together to select optimal clarification questions.  

The deep learning architecture employs two distinct models that evaluate candidate clarification questions from complementary perspectives. The first model outputs a score denoting the strength of association between a candidate clarification question and the search conversation context alone. This model learns general patterns of how questions relate to conversation topics without considering specific answer passages. The second model outputs a score representing the strength of association between a candidate clarification question, the search conversation context, and a particular retrieved text passage. This model captures how well questions connect conversation topics to potential answer content.  

Score fusion combines the outputs of both models to produce a comprehensive ranking of candidate clarification questions. In preferred embodiments, the fusion uses a Comb-SUM approach that adds the normalized scores from both models. Alternative embodiments may employ other fusion techniques such as weighted combinations or machine-learned fusion models. The fused scores provide a more robust ranking than either model could produce independently, as they incorporate both general conversation-question patterns and specific passage-question relationships.  

The candidate clarification question retrieval process operates in conjunction with passage retrieval. For each high-scoring passage identified as relevant to the current conversation, the system queries a clarification question index using a composite of the passage content and conversation utterances. This ensures retrieved questions have lexical and semantic connections to both the potential answers and the ongoing dialogue. The question pool may be derived from various sources including query logs, frequently asked questions, or curated question sets.  

The training system architecture for the deep learning models includes several key components. A conversation processor extracts and labels clarification question-answer pairs from human-to-human dialogues. A passage retriever identifies relevant text passages for each training conversation using techniques similar to the runtime system. The training data generator creates distinct training sets for the two models, with appropriate positive and negative examples for each.  

Training proceeds through a specialized adaptation of triplet network architectures for BERT-based models. For the first model (BERT-C-cq), training uses triplets comprising a conversation context, a positive clarification question (from the actual dialogue), and a randomly selected negative question. The model learns to distinguish questions that properly match the conversation context from those that do not. For the second model (BERT-C-P-cq), training triplets incorporate passages by concatenating them with conversation contexts using a separator token. The model learns to identify questions that properly connect conversations and passages.  

During operation, the conversational search system receives user queries and maintains conversation state across multiple turns. The clarification-question selection module activates when the system determines a clarification would help refine the search. The module retrieves relevant passages and candidate questions as described, applies the trained models to rank the questions, and returns the top-ranked options for presentation to the user.  

The system implements several optimizations to handle practical constraints. To accommodate BERT's input length limitations, conversation contexts are represented using the most recent utterances that fit within the model's maximum token count. Passage windows are similarly sized to fit model constraints while preserving meaningful content. The system employs efficient indexing and retrieval techniques to maintain real-time performance even with large document and question collections.  

Hardware implementations typically include one or more servers with sufficient processing power and memory to run the deep learning models efficiently. GPU acceleration is preferred for model inference to maintain low latency. The software architecture includes operating system components, deep learning frameworks (such as PyTorch), information retrieval libraries (such as Lucene), and custom modules for conversation handling, passage retrieval, question ranking, and user interface management.  

## EXPERIMENTAL RESULTS  

Evaluation of the disclosed method was conducted using two distinct datasets representing different conversational search scenarios. The ClariQ dataset provides an open-domain information-seeking context with high-quality labeled clarification questions. The Support dataset contains technical customer support conversations requiring specialized processing to identify valid clarification questions.  

Experimental setup employed Apache Lucene for document indexing with BM25 similarity scoring. For the ClariQ dataset, document retrieval used the text field only to avoid bias toward documents with training conversations. The Support dataset utilized both anchor and text fields for retrieval since most documents had associated training conversations. Passage extraction used a 512-character sliding window with standard hyperparameters (λ=0.5 for score combination, μ=2000 for Dirichlet smoothing).  

The BERT models were implemented using PyTorch and Hugging Face's bert-base-uncased architecture (12 layers, 768 hidden dimensions, 12 attention heads). Fine-tuning used maximum sequence lengths of 256 tokens for the conversation-question model and 384 tokens for the conversation-passage-question model, with a learning rate of 2e-5 over 3 training epochs.  

Results on development sets showed significant improvements over baseline information retrieval (IR-Base). On the Support dataset, the conversation-question model (BERT-C-cq) achieved Recall@30=0.538 compared to IR-Base's 0.294 (82% improvement). Similar gains appeared on ClariQ, with fusion of both models' scores yielding additional 2.5% improvement over either model alone (BERT-fusion R@30=0.791 vs. BERT-C-cq's 0.770).  

Official ClariQ test set results placed the fused model approach fourth on the leaderboard and second among team submissions. Analysis revealed the top-performing system benefited from domain-specific optimizations not generally applicable, while the disclosed method maintained robust performance across diverse queries by treating all clarification questions equally.
