# DESCRIPTION

## TECHNOLOGICAL FIELD

The present invention relates to the field of non-volatile memory systems, specifically to resistive crossbar arrays utilized in next-generation computing architectures for high-density data storage and in-memory computation. More particularly, the invention pertains to novel readout methodologies that mitigate the detrimental effects of sneak-path currents in gateless resistive memory arrays by leveraging spatial correlations in sneak-path resistances, memory locality principles, and adaptive thresholding techniques. These methodologies enable error-free, single-access read operations per memory cell without requiring additional transistors or selector devices, thereby preserving the high density and low fabrication complexity inherent to crossbar architectures. The invention is particularly applicable to resistive random-access memory (ReRAM), phase-change memory (PCM), and other memristive technologies where the absence of selectors necessitates sophisticated electrical readout schemes to overcome parasitic current leakage. The disclosed techniques are compatible with standard CMOS readout circuitry and can be integrated into existing memory hierarchies, including cache systems, neuromorphic computing substrates, and edge AI accelerators, where power efficiency, speed, and scalability are paramount. The invention further extends to computing systems that perform sequential block-based data access, such as those found in modern processors, memory controllers, and storage-class memory interfaces, wherein the locality of reference is exploited to amortize the overhead of adaptive threshold estimation across large data blocks.

## BACKGROUND

Resistive crossbar arrays have emerged as a leading candidate for high-density, low-power non-volatile memory due to their simple two-terminal structure, scalability to sub-10 nm dimensions, and compatibility with 3D stacking architectures. However, the absence of selector devices in these gateless arrays introduces a fundamental operational challenge: sneak-path currents. When a voltage is applied across a selected memory cell to read its state, unintended current paths form through parallel resistive elements in the same row and column, resulting in parasitic currents that superimpose upon the desired cell current. These sneak-path currents are data-dependent, non-linear, and spatially correlated, rendering conventional threshold-based readout methods ineffective. In practical arrays, the magnitude of sneak-path currents often exceeds the current difference between the high-resistance (OFF) and low-resistance (ON) states of the target cell, causing severe overlap in the current distributions associated with binary logic levels. As a result, direct readout of individual bits becomes unreliable, necessitating multi-stage, iterative, or redundant read operations that significantly degrade performance and increase power consumption.

Prior art approaches to mitigating sneak-path interference include the use of selector devices such as diodes, transistors, or threshold-switching materials, which add fabrication complexity, reduce cell density, and introduce non-idealities such as leakage and variability. Alternative methods involve applying multi-voltage read schemes, differential sensing, or iterative estimation techniques that require multiple accesses per bit to disambiguate the desired current from the parasitic contributions. These methods, while effective, incur substantial latency penalties and energy overheads, particularly in large arrays where the number of parallel sneak paths scales quadratically with array dimensions. Furthermore, many existing techniques assume uniform device characteristics and ignore the stochastic nature of fabrication variability, operational drift, and data randomness, leading to degraded read margins under real-world conditions. Recent proposals have attempted to exploit the spatial correlation of sneak-path resistances by assuming that row and column resistances remain approximately constant across a given row or column. However, these approaches have not been systematically integrated into a complete readout framework that simultaneously addresses threshold adaptation, power efficiency, hardware overhead, and variability resilience. Moreover, no prior technique has demonstrated a method to achieve a theoretical lower bound of one read operation per bit across an entire array while maintaining error-free operation, minimal hardware overhead, and compatibility with sequential memory access patterns inherent to modern computing systems. The present invention overcomes these limitations by introducing a unified, scalable, and hardware-efficient readout paradigm that leverages the intrinsic correlation of sneak-path resistances, the locality of memory access, and adaptive compensation techniques to enable single-access, sneak-path-immune readout with unprecedented energy efficiency and throughput.

## BRIEF SUMMARY

The present invention provides a novel readout methodology for resistive crossbar memory arrays that enables error-free, single-access read operations per memory cell by exploiting the spatial correlation of sneak-path resistances and the locality of memory access patterns. The invention comprises a system and method for adaptive-threshold readout, wherein the sneak-path resistance components associated with a given row or column are estimated once per block of contiguous data and then reused to compensate for parasitic currents during subsequent read operations within that same row or column. This is achieved through two complementary techniques: the initial-bits readout strategy and the predefined-dummy-bits readout strategy. In the initial-bits strategy, the first bit accessed in each row is read using a multi-stage estimation procedure to determine both the desired cell resistance and the row sneak-path resistance, after which all subsequent bits in that row are read using a single access, with the previously estimated sneak-path resistance used to derive an adaptive threshold. In the predefined-dummy-bits strategy, dedicated memory cells with known resistance values are embedded within each row, allowing the sneak-path resistance to be estimated in a single read operation, thereby eliminating the need for multi-stage estimation and enabling immediate, single-access readout of all other bits in the row. Both strategies are implemented within a connected-terminal crossbar architecture, wherein unused row and column terminals are biased to a sub-threshold voltage to suppress parasitic current flow and enhance the non-linear current-voltage characteristics of the memristive devices, thereby amplifying the signal-to-noise ratio between desired and sneak-path currents. The invention further incorporates a crossbar power optimization scheme that leverages the saturation nonlinearity of memristive devices by biasing unused terminals at VDD/2, which minimizes overall power consumption while maintaining readout fidelity. The system is implemented using a combination of analog current-sensing circuitry and digital threshold-comparison logic, with the entire readout process orchestrated by a computing device that sequences memory accesses according to the locality of data retrieval, ensuring that each bit is read exactly once with no redundant operations. The invention achieves a figure-of-merit that surpasses all prior art techniques by simultaneously maximizing readout speed, minimizing power consumption, and eliminating the need for additional selector devices, thereby enabling scalable, high-density, and energy-efficient memory systems for next-generation computing applications.

## DETAILED DESCRIPTION

### Sneak Paths Analysis

In a resistive crossbar array, the fundamental challenge to reliable readout arises from the presence of unintended current paths, commonly referred to as sneak paths, which form when a voltage is applied across a selected memory cell. These paths originate from the parallel resistive elements in the same row and column as the target cell, and their cumulative conductance allows current to flow through alternative routes that bypass the intended cell. The magnitude and distribution of these sneak-path currents are not fixed; they vary dynamically based on the binary state of all other cells in the row and column, rendering them data-dependent and inherently stochastic. This variability leads to a broadening of the current distributions associated with the ON and OFF states of the target cell, resulting in significant overlap that precludes the use of a static threshold for binary decision-making. The sneak-path network can be modeled as three equivalent resistive components: the row sneak-path resistance (Rr), the column sneak-path resistance (Rc), and the diagonal sneak-path resistance (Ra). In a floating-terminal configuration, all three components contribute to the total parasitic current, but in a connected-terminal configuration, where the unused row and column terminals are tied to a common bias voltage, the diagonal component Ra is effectively shorted out, leaving only Rr and Rc as the dominant contributors to sneak-path interference. The row sneak-path resistance Rr is the parallel combination of all resistive elements in the selected row, excluding the target cell itself. Similarly, Rc is the parallel combination of all resistive elements in the selected column, excluding the target cell. Given that each cell exhibits either a high resistance (Roff) or a low resistance (Ron), the value of Rr and Rc depends on the number of ON and OFF cells in the respective row and column. For a row containing L cells, with Non being the number of ON cells excluding the target, Rr can be expressed as the reciprocal of the sum of the reciprocals of the individual resistances. The variation in Rr across different locations within the same row is governed by the number of ON cells and the OFF-to-ON resistance ratio (ρ) of the memristive devices. When the array is populated with random data, the relative change in Rr due to the replacement of a single cell from ON to OFF or vice versa is proportional to the inverse of the array size and the logarithm of ρ. For arrays of practical dimensions—such as 256 kb or larger—the relative change in Rr between adjacent locations within the same row is negligible, typically less than one percent, even under worst-case data distributions. The same principle applies to Rc, which remains nearly constant across any given column. This spatial invariance is not a consequence of uniform data but rather a statistical property arising from the large number of parallel resistive elements and the randomness of data storage. As a result, Rr and Rc can be treated as quasi-static parameters within a row or column, respectively, and their values, once estimated at a single location, can be reliably reused for all other cells in that row or column. This insight forms the foundation of the adaptive-threshold readout methodology disclosed herein. The independence of Rr and Rc as random variables further ensures that their estimation in one dimension does not introduce systematic bias into the other, allowing for orthogonal compensation strategies in row-wise and column-wise access schemes. The physical realization of this property is enabled by the connected-terminal architecture, which provides a controlled electrical environment where the voltage distribution across the array is deterministic and the sneak-path contributions are isolated and quantifiable. The metal interconnect resistances, while not explicitly modeled in the simplified equivalent circuit, are accounted for in full-scale simulations and do not alter the fundamental conclusion that Rr and Rc exhibit minimal variation across a row or column under realistic operating conditions. This behavior, previously overlooked in conventional readout schemes, is now leveraged to eliminate the need for repeated sensing and iterative estimation, thereby achieving the theoretical limit of one read operation per bit.

### Sneak-Paths Correlation

The spatial correlation of sneak-path resistances is not merely a passive characteristic of the crossbar array but a powerful resource that can be actively harnessed to transform the readout process from a high-overhead, multi-access procedure into a single-access, deterministic operation. This correlation arises from the fact that any two cells located in the same row share all but one of their parallel resistive pathways; similarly, any two cells in the same column share all but one of their vertical current paths. Consequently, the row sneak-path resistance Rr for a cell at position (i,j) differs from that of a cell at position (i,k) only by the resistance of the cell at (i,j) and (i,k), respectively. Given that the OFF-to-ON resistance ratio ρ is typically on the order of 10^3 to 10^5 in state-of-the-art memristive devices, the relative change in Rr due to a single cell state flip is exponentially small, particularly as the array size increases. For example, in a 512×512 array with a balanced distribution of ON and OFF cells, the maximum relative variation in Rr across the row is less than 0.5%, and this value decreases further as the array size grows. This near-constancy of Rr and Rc within a row or column is not an artifact of idealized assumptions but a robust statistical outcome confirmed by extensive SPICE-level simulations across thousands of random data patterns derived from real-world memory workloads, including NIST RAM images and image datasets. The correlation is further amplified by the connected-terminal biasing scheme, which ensures that the voltage drop across each non-targeted cell is sub-threshold, suppressing its contribution to the overall conductance and reducing the sensitivity of Rr and Rc to individual cell variations. This enables the system to treat Rr as a fixed parameter for the entire row and Rc as a fixed parameter for the entire column, effectively decoupling the estimation of the parasitic component from the measurement of the target cell. The implication is profound: once Rr is determined for a given row, it can be used to compute the expected current contribution from sneak paths for every other cell in that row, allowing the desired cell current to be isolated by simple subtraction. The same applies to Rc in column-wise access schemes. This correlation-based compensation is fundamentally different from prior art techniques that attempt to model or predict sneak-path behavior using statistical averages or machine learning algorithms, which require extensive training, storage, and computational overhead. In contrast, the present invention exploits the deterministic, local, and repeatable nature of the correlation to perform real-time, hardware-efficient compensation without any pre-training, lookup tables, or external memory. The correlation is not assumed to be perfect but is treated as a sufficient approximation within the noise margin of the system, and the resulting readout error is shown to be negligible—on the order of 10^-6 bit error rate—when combined with a properly calibrated comparator. The spatial correlation also enables the system to operate in either row-wise or column-wise sequential access modes, depending on the memory controller’s access pattern, without requiring architectural changes. This flexibility ensures compatibility with existing cache line structures, memory controllers, and data prefetching mechanisms, which inherently access contiguous blocks of memory. The correlation property, therefore, is not an incidental feature but the central enabler of the invention’s performance advantages, transforming what was once an intractable problem into a solvable, scalable, and economically viable solution.

### Adaptive-Threshold Readout

The adaptive-threshold readout technique is the core innovation of the present invention, enabling single-access, sneak-path-immune readout by dynamically adjusting the decision threshold for each row or column based on the estimated sneak-path resistance. Unlike conventional readout schemes that rely on a fixed voltage or current threshold to distinguish between ON and OFF states, the adaptive-threshold method computes a unique threshold for each row or column during the initial access and then applies that threshold to all subsequent accesses within the same row or column. This is made possible by the connected-terminal architecture, which ensures that the voltage across the target cell is maximized (VDD) while the voltage across the sneak-path components is minimized (VDD - VB), thereby maximizing the differential current between the desired cell and the parasitic contributions. When the readout circuit is connected to node n1, the sensed current Isense is the sum of the desired cell current Im and the row sneak-path current Ir. The value of Ir, which is determined by Rr and the applied bias, remains constant for all cells in the same row. Therefore, if the value of Ir is known, the desired current Im can be recovered by subtracting Ir from Isense. The challenge lies in estimating Ir without prior knowledge of the target cell’s state. This is resolved by the initial-bits strategy, wherein the first bit accessed in each row is subjected to a multi-stage readout procedure that iteratively probes the cell under varying bias conditions to disentangle the contributions of Im and Ir. Once these two unknowns are solved, the value of Ir is stored in a local register and used as a constant offset for all subsequent reads in that row. For each subsequent bit, a single voltage pulse is applied, the resulting current is measured, and the result is compared against the threshold defined as Vth = Isense(ON) - Ir, where Isense(ON) is the expected current when the target cell is in the ON state. The same principle applies when sensing from node n2, where the column sneak-path current Ic becomes the dominant contributor, and the threshold is adjusted accordingly. The adaptive threshold is not a fixed voltage level but a dynamic reference point that shifts in real time based on the local sneak-path environment, effectively canceling out the data-dependent noise that plagues conventional methods. The threshold adaptation occurs at the granularity of a row or column, aligning perfectly with the memory locality inherent in modern computing systems, where data is accessed in blocks rather than randomly. This alignment ensures that the overhead of threshold estimation is amortized over hundreds or thousands of subsequent read operations, resulting in an average of less than one additional access per bit. The implementation of this technique requires minimal additional hardware: a virtual-ground current-sensing amplifier, a digital processor capable of solving a system of two linear equations to extract Im and Ir, and a comparator with programmable threshold input. The entire readout circuitry can be shared across the entire array, with the threshold values stored in a small, low-power register file that is updated once per row or column. The method is entirely compatible with existing CMOS readout architectures and can be seamlessly integrated into memory controllers, cache hierarchies, and neuromorphic processing units. The key advantage of this approach is its ability to achieve error-free readout with a single access per bit, a feat previously thought impossible without selector devices. The adaptive-threshold technique does not rely on device uniformity, data predictability, or external calibration; it adapts to the actual conditions of the array in real time, making it robust to fabrication variability, aging, and operational drift. The result is a readout system that is not only faster and more power-efficient than any prior art method but also fundamentally scalable to arrays of arbitrary size.

### Multi-Read for Initial Bits

The multi-read strategy employed for the initial bits is a critical component of the adaptive-threshold readout framework, enabling the accurate estimation of both the desired cell current and the row or column sneak-path resistance without prior knowledge of either parameter. This technique is applied exclusively to the first bit accessed in each row (or column, in column-wise mode) and is designed to resolve the two unknowns—Im and Ir (or Ic)—that arise from the superposition of the target current and the sneak-path current. The procedure involves applying a sequence of precisely controlled voltage pulses to the selected cell, each at a different bias condition, and measuring the resulting current response. For example, a first measurement is performed with the full read voltage VDD applied across the selected row and column, yielding a total current Isense1 = Im + Ir. A second measurement is performed with a reduced bias voltage Vbias applied to the row and column terminals, which alters the current-voltage characteristics of the memristive devices due to their inherent non-linear saturation behavior. This second measurement yields Isense2 = Im’ + Ir’, where Im’ and Ir’ are the modified currents under the new bias. Because the memristive devices exhibit a predictable, non-linear relationship between voltage and current, the ratio between Isense1 and Isense2 can be used to solve for Im and Ir using a system of two non-linear equations derived from the device’s i-v characteristics. Alternatively, a third measurement may be taken with the row or column terminal grounded, effectively isolating the contribution of the target cell from the sneak-path network. The resulting set of measurements forms a linearly independent system that can be solved analytically using matrix inversion or iteratively using numerical methods such as Newton-Raphson. The solution yields the exact values of Im and Ir, which are then used to compute the adaptive threshold for the remainder of the row. This multi-read procedure is computationally intensive but is performed only once per row or column, and its overhead is amortized over the hundreds or thousands of subsequent single-access reads. The number of required measurements is typically two or three, and the computational burden is handled by a small, low-power digital processor integrated into the readout circuitry, which requires minimal area and power compared to the memory array itself. Importantly, the multi-read technique does not assume any prior knowledge of the device’s resistance values, its non-linearity, or the data distribution, making it universally applicable across different memristive technologies and fabrication processes. It is also inherently resilient to device variability, as the estimation process is self-calibrating and adapts to the actual characteristics of the cell under test. The method does not require writing or erasing the target cell, ensuring that the stored data remains intact throughout the estimation process. The multi-read procedure is executed only during the initial access of a new data block, and once the threshold is established, all subsequent reads in that block proceed at full speed with a single voltage pulse and a single current measurement. This results in a dramatic reduction in average access latency and energy consumption, particularly in systems that exhibit strong spatial and temporal locality, such as cache hierarchies and neural network inference engines. The multi-read technique, therefore, serves as the enabler of the entire adaptive-threshold paradigm, transforming what would otherwise be an intractable problem into a tractable, efficient, and scalable solution.

### Predefined Dummy Bits

The predefined dummy bits strategy offers an alternative, highly efficient mechanism for estimating the sneak-path resistance without the need for multi-read operations. Instead of using a target memory cell to infer the sneak-path resistance, a dedicated memory cell with a known resistance value is embedded within each row (or column) of the array. This dummy cell is programmed during fabrication to a predetermined state—either fully ON (Ion) or fully OFF (Ioff)—and remains unchanged throughout the operational lifetime of the array. When the system accesses a row for the first time, it reads the dummy cell instead of a data cell, and because the resistance of the dummy cell is known, the resulting current measurement directly reveals the value of the row sneak-path resistance Rr. This is because the total current sensed from the dummy cell is the sum of the known dummy current Idummy and the unknown sneak-path current Ir. Since Idummy is a fixed, pre-characterized value, Ir can be computed by simple subtraction: Ir = Isense_dummy - Idummy. Once Ir is known, it is used to establish the adaptive threshold for all other bits in the row, enabling single-access readout of the remaining data cells. The dummy cell can be implemented as a standard memristive device that is written once during manufacturing and never modified, or as a static resistor fabricated alongside the memory array using standard CMOS processes, eliminating any variability associated with memristive switching. The use of a static resistor as a dummy cell is particularly advantageous, as it provides a perfectly stable reference with no drift, no variability, and no endurance limitations. The dummy cell is strategically placed at a fixed location within each row—typically at the beginning or end—to ensure consistent access timing and to minimize routing overhead. The readout sequence for a data block begins with a single access to the dummy cell, followed by sequential reads of the data cells in the same row, each requiring only one voltage pulse and one current measurement. The total number of accesses per bit is therefore reduced to approximately one, with a negligible overhead of one additional access per row. This overhead is insignificant compared to the multi-read overhead of the initial-bits strategy, particularly in large arrays where the number of rows is much smaller than the number of bits per row. For example, in a 512×512 array, there are 512 rows, each containing 512 data bits, meaning that the dummy-bits strategy requires only 512 extra accesses for the entire array, whereas the initial-bits strategy requires 512 multi-read operations, each involving two or three accesses. The dummy-bits approach, therefore, achieves a lower average access count and higher throughput, albeit at the cost of a small reduction in storage density. This trade-off is favorable, as the storage overhead is typically less than 0.2% for a 256 kb array and decreases further as the array size increases. The dummy-bits technique is fully compatible with the connected-terminal architecture and the adaptive-threshold framework, and it can be combined with the initial-bits strategy in hybrid configurations where some rows use dummy bits and others use multi-read estimation, depending on reliability requirements or manufacturing constraints. The simplicity, speed, and robustness of the dummy-bits approach make it the preferred method for high-performance applications, while the multi-read strategy remains valuable in scenarios where density is paramount and variability is well-controlled. Both methods, however, rely on the same underlying principle: the exploitation of spatial correlation to eliminate the need for repeated sensing, thereby achieving the theoretical limit of one read operation per bit.

### Crossbar Power Consumption

The power consumption of a resistive crossbar array is dominated not by the desired read current but by the parasitic sneak-path currents that flow through the non-targeted cells. Conventional floating-terminal architectures apply full read voltage across all rows and columns simultaneously, causing every cell in the selected row and column to conduct current, regardless of its state. This results in a power dissipation that scales quadratically with array size and is exacerbated by the large number of parallel paths in high-density arrays. The connected-terminal architecture disclosed herein fundamentally alters this paradigm by biasing the unused row and column terminals to a sub-threshold voltage VB, typically set at VDD/2, which suppresses the conduction of non-targeted cells while preserving the full voltage drop across the target cell. This biasing strategy leverages the inherent non-linear saturation behavior of memristive devices, where the current-voltage relationship becomes highly sub-linear at voltages below a certain threshold. By reducing the voltage across each sneak-path cell to VDD - VB = VDD/2, the resistance of those cells increases by orders of magnitude due to their non-linear characteristics, thereby drastically reducing the magnitude of the sneak-path current. Simulations demonstrate that this single modification reduces total power consumption by up to 80% compared to the floating-terminal approach, while maintaining the same readout fidelity. The power savings are even more pronounced in large arrays, where the number of parallel sneak paths is greatest, and the cumulative effect of suppressing each individual path becomes substantial. Importantly, the power reduction is achieved without any increase in access latency or complexity, as the biasing is implemented using simple voltage dividers and switches that require minimal additional circuitry. The optimal bias voltage VB = VDD/2 is determined empirically and analytically by analyzing the trade-off between sneak-path suppression and the signal-to-noise ratio of the target cell. At VB = 0, the full voltage is applied to all cells, maximizing sneak-path current. At VB = VDD, the target cell receives no voltage drop, rendering readout impossible. At VB = VDD/2, the target cell receives the full VDD drop, while the sneak-path cells experience a reduced voltage that maximizes their resistance without compromising the detectability of the target current. This point represents the global minimum in total power consumption, as confirmed by extensive SPICE simulations across thousands of data patterns and array sizes. The power consumption of the connected-terminal architecture with optimal biasing is comparable to that of the floating-terminal architecture in small arrays but becomes dramatically lower as the array scales, due to the exponential suppression of sneak-path currents. In contrast, alternative techniques such as grounded-terminal architectures—which short unused terminals to ground—consume significantly more power because they force the sneak-path cells to conduct at full voltage. The disclosed method, therefore, not only enables error-free readout but also achieves the lowest power consumption of any known gateless crossbar readout technique. Furthermore, the power savings are not offset by the overhead of additional circuitry, as the biasing network is simple, static, and requires no dynamic control. The result is a system that delivers high performance with minimal energy expenditure, making it ideal for battery-powered edge devices, high-throughput data centers, and neuromorphic systems where energy efficiency is as critical as computational speed.

### Figure-of-Merit

The performance of any memory readout technique must be evaluated not in isolation but in relation to its competing alternatives, using a comprehensive figure-of-merit that captures the interplay between speed, power, density, and hardware overhead. The present invention introduces a novel figure-of-merit (FoM) defined as the ratio of readout throughput to total power consumption per bit, normalized by the memory density. This FoM is expressed as FoM = (Throughput / Power) × Density, where throughput is measured in bits per second, power in watts, and density in bits per square millimeter. This metric is chosen because it reflects the practical constraints of real-world systems: high density is necessary for scalability, low power is essential for energy efficiency, and high throughput is required for performance. The proposed adaptive-threshold readout technique achieves a FoM that is seven to twenty-four times higher than the best-performing prior art techniques, including differential sensing, multi-voltage read schemes, and selector-based architectures. This superior performance arises from three synergistic factors: first, the single-access readout per bit eliminates redundant operations, maximizing throughput; second, the connected-terminal biasing with VDD/2 minimizes power consumption by suppressing sneak-path currents; and third, the elimination of selector devices preserves the maximum possible memory density. In contrast, selector-based techniques, while effective at suppressing sneak paths, reduce density by 30–50% due to the additional transistor or diode per cell. Multi-voltage schemes improve readout accuracy but require multiple accesses per bit, reducing throughput and increasing power. Differential sensing techniques require twice the number of sense amplifiers and complex reference circuits, increasing area and power without improving the fundamental access count. The present invention, by contrast, requires no additional cells, no extra transistors, no complex reference networks, and no iterative procedures beyond a single estimation per row or column. The hardware overhead is confined to a small digital processor and a few comparators, which occupy less than 0.1% of the total array area. The FoM advantage is further amplified in large arrays, where the benefits of spatial correlation and adaptive thresholding become more pronounced. Simulations across a range of array sizes—from 1 kb to 256 kb—demonstrate that the FoM of the proposed technique increases with array size, while the FoM of competing methods either plateaus or degrades due to increased sneak-path interference and power consumption. The FoM metric also accounts for variability resilience, as the adaptive-threshold method maintains its performance under conditions of device drift, fabrication non-uniformity, and operational aging, whereas other techniques suffer from increased bit error rates under the same conditions. The result is a technology that not only outperforms existing methods in laboratory benchmarks but also delivers superior real-world performance in practical computing systems. The disclosed FoM is not merely a theoretical construct but a practical metric that has been validated against industry-standard benchmarks and is directly applicable to the design of next-generation memory systems. The invention, therefore, represents not just an incremental improvement but a paradigm shift in crossbar readout architecture, setting a new benchmark for performance, efficiency, and scalability.

### Operations Performed by a Computing Device to Efficiently Perform Readout Operations

The operations performed by a computing device to execute the disclosed readout methodology are orchestrated through a tightly integrated sequence of memory addressing, bias control, current sensing, threshold adaptation, and data decision-making, all coordinated by a dedicated readout controller embedded within the memory subsystem. The process begins when the memory controller issues a read request for a contiguous block of data, such as a cache line or a memory page. The readout controller identifies the starting row and column of the requested block and determines whether the initial-bits or dummy-bits strategy will be employed for that block. If the dummy-bits strategy is selected, the controller first accesses the dummy cell located at a predefined position in the first row of the block. A voltage pulse of known amplitude is applied to the selected row and column, and the resulting current is measured by a virtual-ground current-sensing amplifier. The sensed current is then subtracted from the pre-characterized dummy current to compute the row sneak-path resistance Ir. This value is stored in a local register within the readout circuitry. The controller then sequentially accesses each data cell in the same row, applying a single read voltage pulse to each, measuring the resulting current, and comparing it to the adaptive threshold derived from the known ON and OFF current levels and the computed Ir. The comparison is performed by a programmable comparator that outputs a binary decision for each cell. Once the entire row is processed, the controller moves to the next row, repeating the process: either accessing the dummy cell again to compute a new Ir, or, if using the initial-bits strategy, initiating a multi-read sequence to estimate Ir and Im. The multi-read sequence involves applying a sequence of two or three voltage pulses to the first cell of the row, each at a different bias level, and collecting the corresponding current measurements. These measurements are fed into a small digital processor that solves a system of equations to extract the values of Im and Ir. The processor then computes the adaptive threshold and updates the comparator reference. The controller proceeds to read the remaining cells in the row using single-access operations. This process continues until the entire data block is read. The controller is designed to operate in either row-wise or column-wise mode, depending on the memory layout and access pattern, and automatically switches between modes to optimize throughput. The entire sequence is synchronized with the memory array’s row and column decoders, ensuring that voltage pulses are applied only to the selected row and column, and that the sense amplifier is enabled only during the read window. The controller also manages power sequencing, ensuring that the bias voltage VB is applied to the unused terminals before any read operation begins and is removed after the block is completed to minimize static power. The system is designed for pipelined operation, allowing the estimation of the next row’s sneak-path resistance to occur in parallel with the readout of the current row, thereby eliminating any idle cycles. The controller requires no external memory or software intervention; all logic is implemented in hardware using a finite state machine and a small arithmetic unit. The operations are deterministic, repeatable, and immune to data patterns, ensuring consistent performance across all workloads. The result is a readout system that operates at the theoretical limit of one access per bit, with minimal latency, maximum energy efficiency, and zero error rate under realistic operating conditions. This represents the first time such a system has been realized in a gateless resistive crossbar array, and it enables a new class of memory systems that combine the density of crossbar architectures with the performance and reliability of traditional memory technologies.
