# DESCRIPTION

## TECHNICAL FIELD

The present invention relates generally to the field of digital communication systems, and more specifically to the design and implementation of neural network-based channel encoders and decoders for reliable transmission of digital data over noisy communication channels. The invention introduces a novel deep learning architecture and training methodology that enables the automatic synthesis of channel codes capable of achieving performance levels comparable to or exceeding those of state-of-the-art classical error-correcting codes, such as polar codes and turbo codes, without relying on explicit mathematical modeling of the channel or traditional code design principles. The invention is particularly suited for applications in wireless communication systems, satellite links, deep-space communications, and any scenario where the channel characteristics are unknown, time-varying, or too complex for conventional analytical approaches. The core innovation lies in the integration of list decoding principles—long established in classical coding theory—into the framework of autoencoder-based neural networks, thereby enabling the decoder to generate multiple candidate message hypotheses and select the most probable one based on auxiliary verification mechanisms such as cyclic redundancy check (CRC). This approach fundamentally shifts the paradigm of neural code design from single-output prediction to multi-hypothesis decision-making, significantly enhancing robustness and error correction capability under low signal-to-noise conditions. The invention further extends to a novel incremental redundancy architecture that systematically refines decoding confidence through successive stages of increasingly reliable sub-codes, offering superior performance at small list sizes while maintaining scalability to larger lists. The resulting system is fully trainable end-to-end using gradient-based optimization, operates without prior knowledge of channel statistics, and adapts seamlessly to arbitrary noise distributions, making it uniquely suited for next-generation communication systems requiring adaptive, intelligent, and self-optimizing coding solutions.

## SUMMARY

The invention discloses a novel deep learning framework for channel coding, termed List Autoencoder (ListAE), which fundamentally transforms the way neural networks are employed to encode and decode digital information over noisy channels. Unlike conventional autoencoder-based channel codes that produce a single decoded message estimate, the ListAE architecture enables the decoder to output a list of L candidate message words, where L is a configurable integer greater than one. This list is generated through a neural network decoder that processes the noisy channel output and produces a matrix of real-valued probability estimates, each row corresponding to a candidate hypothesis for the original message. The key innovation lies in the design of a loss function that optimizes the system’s ability to include the true transmitted message within this list, rather than forcing the decoder to commit to a single erroneous prediction. The loss function is formulated as the minimum binary cross-entropy between the transmitted message and each candidate in the list, effectively encouraging the decoder to ensure that at least one candidate closely approximates the true message, even if no single candidate is perfectly accurate. This formulation avoids the non-differentiable operations inherent in direct list membership testing, such as binary rounding and exact comparison, thereby preserving the flow of gradients during backpropagation and enabling stable end-to-end training. Furthermore, the invention introduces a method for emulating the functionality of a genie-aided decoder during testing by appending a cyclic redundancy check (CRC) code to the message bits prior to encoding. At the decoder, each candidate in the output list is validated against the CRC, and the first candidate that passes the CRC test is selected as the final decoded message. This CRC-aided selection mechanism ensures that the system outputs a single, verifiable decision while retaining the robustness benefits of list decoding. The invention further encompasses a novel neural network architecture, termed Incremental Redundancy Autoencoder (IR-AE), which organizes the decoding process into a sequence of iterative stages, each operating on a progressively smaller subset of the received signal with a correspondingly lower effective rate. Each stage refines the list of candidate messages using information from prior stages, mimicking the behavior of successive refinement in classical concatenated coding schemes. The IR-AE architecture employs convolutional neural networks for local feature extraction and interleaving/deinterleaving blocks to introduce long-range dependencies, enabling the system to learn complex, non-linear relationships between channel observations and message bits. The encoder and decoder are trained using a scheduled optimization procedure wherein the encoder and decoder weights are alternately frozen and updated over multiple epochs, preventing premature convergence to poor local minima. The system is trained under batch-wise power normalization to ensure that transmitted codewords maintain unit variance and zero mean, consistent with practical transmission constraints. Experimental results demonstrate that the ListAE framework, when implemented with the IR-AE architecture, achieves superior bit error rate and block error rate performance compared to both traditional turbo autoencoders and state-of-the-art polar codes under identical code rates and block lengths, particularly at low to moderate signal-to-noise ratios and for small list sizes. The invention thus provides a general, scalable, and trainable framework for channel coding that eliminates the need for manual code design, adapts to unknown channel conditions, and outperforms classical codes without requiring explicit knowledge of channel statistics or algebraic structure.

## DETAILED DESCRIPTION

The invention presents a comprehensive system and methodology for the design and implementation of neural network-based channel encoders and decoders that achieve reliable communication over noisy channels through the integration of list decoding principles into deep learning architectures. The system operates as an end-to-end autoencoder, comprising a neural network encoder that maps a binary message word of K bits into a real-valued codeword of N symbols, a noisy channel that corrupts the transmitted signal, and a neural network decoder that reconstructs the original message from the corrupted observations. The core innovation lies in the decoder’s ability to generate not a single estimate of the message, but a list of L candidate message hypotheses, where L is a positive integer greater than one, and in the use of a novel loss function that trains the system to maximize the likelihood that the true message appears within this list. This approach fundamentally departs from conventional autoencoder designs, which are constrained to produce a single output and are therefore vulnerable to catastrophic failure when the decoder makes a single incorrect decision. By allowing the decoder to maintain multiple plausible hypotheses, the system gains resilience against local minima in the decoding space and significantly improves its ability to recover from deep fades or high noise levels. The list of candidates is represented as a K × L matrix, where each column corresponds to a candidate message word and each row corresponds to the estimated probability of a specific bit being one. These probabilities are computed using sigmoid activation functions to ensure that each element lies within the interval [0,1], reflecting a soft estimate of the bit value. During training, the system is optimized using a loss function defined as the minimum binary cross-entropy between the true message word and each of the L candidate hypotheses. This formulation ensures that the decoder is incentivized to produce at least one candidate that closely matches the transmitted message, even if the remaining candidates are inaccurate. The binary cross-entropy between two binary vectors is computed as the average of the logarithmic loss for each bit, penalizing confident but incorrect predictions more heavily than uncertain ones. By taking the minimum over all candidates, the loss function effectively ignores the worst-performing hypotheses and focuses training on the best-performing one, thereby encouraging the decoder to diversify its output and avoid premature convergence to a single, potentially erroneous, solution. Importantly, this loss function is differentiable almost everywhere, as the point of non-differentiability—where two or more candidates yield identical cross-entropy values—occurs with probability zero under continuous random initialization and training dynamics. This property allows the gradients to flow smoothly through the entire network during backpropagation, enabling stable and efficient training using standard optimization algorithms such as Adam or stochastic gradient descent. The training process is further enhanced by a scheduled optimization strategy in which the encoder and decoder networks are alternately frozen and updated over successive epochs. Specifically, for a predetermined number of iterations, the encoder weights are updated while the decoder weights are held fixed, and then the decoder weights are updated while the encoder weights are held fixed. This decoupling prevents the two networks from co-adapting in a way that leads to unstable or suboptimal convergence, a phenomenon commonly observed in joint autoencoder training. The encoder is trained using a fixed signal-to-noise ratio (SNR) to ensure consistent codeword generation, while the decoder is trained using a randomized SNR drawn from a predefined range, enabling it to generalize across varying channel conditions. This dual-phase training strategy, combined with batch-wise power normalization, ensures that the codewords produced by the encoder maintain zero mean and unit variance across the entire training batch, thereby satisfying the physical constraint of constant power transmission. The power normalization is applied to the entire batch of codewords, where the mean and standard deviation of all N × B code symbols—where B is the batch size—are subtracted and scaled, respectively, to produce a normalized codeword that lies on an N-dimensional hypersphere of radius √(N × B). This normalization technique ensures that the transmitted signal adheres to a fixed power budget regardless of the batch composition, and the precomputed mean and standard deviation can be stored and reused during inference to normalize single codewords without requiring batch statistics. The channel model employed during training and testing is not restricted to any specific mathematical form. While the invention is demonstrated using an additive white Gaussian noise (AWGN) channel, in which each received symbol is the sum of the transmitted symbol and an independent Gaussian random variable, the system is fully capable of operating over any channel for which a sufficient number of input-output pairs can be generated. This includes fading channels, impulsive noise channels, nonlinear channels, and even empirical channels derived from real-world measurements. The only requirement is that the channel can be simulated or sampled to produce a large corpus of training data, which is then used to train the encoder and decoder jointly. This adaptability to arbitrary channel models represents a significant departure from classical coding theory, which relies on precise statistical models such as the AWGN or binary symmetric channel to derive code properties analytically. The invention further introduces a novel architecture for the decoder, termed Incremental Redundancy Autoencoder (IR-AE), which organizes the decoding process into a sequence of iterative stages, each operating on a progressively smaller subset of the received signal and refining the list of candidate hypotheses. The IR-AE architecture is inspired by the structure of concatenated codes and iterative decoding schemes in classical coding theory, but is implemented entirely through neural network components. In a rate-1/3 IR-AE, for example, the encoder consists of three parallel sub-encoders, each processing a different interleaved version of the input message word. The outputs of these sub-encoders are combined and normalized to form a codeword of length N = 3K, where K is the length of the original message. The decoder then operates in multiple iterations, each consisting of three decoding blocks, each of which receives a subset of the received signal corresponding to one of the three sub-codewords, along with the current list of candidate hypotheses from the previous iteration. The first decoding block operates on a single sub-codeword and produces an initial refined list, effectively functioning as a rate-1/1 decoder. The second decoding block receives a pair of sub-codewords and operates as a rate-1/2 decoder, using the additional redundancy to refine the list further. The third decoding block receives all three sub-codewords and operates as a rate-1/3 decoder, leveraging the maximum available redundancy to produce the final refined list. Crucially, the rate of each decoding block is non-increasing across iterations, meaning that later iterations use more redundant information than earlier ones, thereby enabling a progressive refinement of the candidate list. This structure mimics the behavior of successive cancellation list decoding in polar codes, where weaker, higher-rate sub-codes are used to generate initial hypotheses, and stronger, lower-rate sub-codes are used to resolve ambiguities. The use of convolutional neural networks (CNNs) in each decoding block enables the system to extract local patterns and correlations in the received signal, while the interleaving and deinterleaving operations introduce long-range dependencies that enhance the effective distance properties of the code. The interleavers are implemented as fixed, randomly generated permutation matrices that are applied column-wise to the candidate list matrix, ensuring that bit positions are shuffled in a consistent manner across iterations. This mimics the role of interleavers in turbo codes, which break up error patterns and improve the convergence of iterative decoding. The deinterleavers reverse this process, aligning the refined hypotheses back to their original bit positions before they are passed to the next decoding stage. The entire architecture is trained end-to-end using the same loss function described earlier, ensuring that the system learns to optimize the inclusion of the true message within the final list. The use of CNNs over fully connected networks or recurrent networks has been empirically shown to yield superior performance, as CNNs are better suited to capturing spatial correlations in the received signal and require fewer parameters than fully connected layers, leading to faster convergence and reduced overfitting. Recurrent architectures such as LSTMs and GRUs were also evaluated but were found to offer marginal gains at significantly increased computational cost and training complexity, making them less practical for deployment. The system is trained over a maximum of 500 epochs, with each epoch consisting of a fixed number of training batches, each containing a set of randomly generated binary message words of length K. For each message, a corresponding noise vector is generated according to the desired channel model and added to the encoded codeword to produce the received signal. The learning rate is kept small throughout training to ensure fine-grained convergence, and the batch size is chosen to be sufficiently large to ensure stable gradient estimates. The training process is initialized with random weights drawn from a Gaussian distribution, and the optimization is performed using the Adam optimizer with default hyperparameters. The system is evaluated using the block error rate (BLER), defined as the fraction of message blocks for which the final decoded message differs from the transmitted message. During testing, the system operates in a manner that emulates the behavior of a genie-aided decoder. Specifically, a cyclic redundancy check (CRC) code of length Z is appended to the original K-Z message bits to form a final message word of length K. The CRC polynomial is chosen to be a standard, well-known generator polynomial, such as g(x) = 1 + x² + x⁴ + x⁶ + x⁷ + x⁸, which is capable of detecting all burst errors up to a certain length. The encoder then maps this K-bit message into the codeword as before. At the decoder, after generating the list of L candidate message words, each candidate is subjected to a CRC verification step. The CRC bits of each candidate are recomputed based on the first K-Z bits of the candidate, and compared to the last Z bits of the candidate. If the recomputed CRC matches the received CRC, the candidate is deemed valid. Among all valid candidates, one is selected at random as the final output. If no candidate passes the CRC, the system defaults to selecting the candidate with the lowest binary cross-entropy score from the list. This CRC-aided selection mechanism ensures that the final output is verifiable and reliable, while preserving the robustness of the list decoding approach. The use of CRC in this context is not merely a post-processing step; it is an integral part of the system’s design philosophy, serving as a mechanism to convert the soft, probabilistic output of the neural network into a hard, deterministic decision that can be trusted in practical applications. The performance of the system is evaluated under both genie-aided and CRC-aided decoding scenarios. Under genie-aided decoding, the system’s performance is measured by the probability that the true message appears in the list, regardless of which candidate is ultimately selected. This metric provides a theoretical upper bound on the system’s capability and is used during training to guide the optimization. Under CRC-aided decoding, the system’s performance is measured by the probability that the final selected candidate matches the transmitted message, which reflects real-world performance. Experimental results demonstrate that the IR-AE architecture with a list size of 64 achieves a coding gain of 0.5 dB over the Turbo-AE architecture and 0.3 dB over state-of-the-art polar codes at a block error rate of 10⁻², under identical code rates and block lengths. This improvement is particularly pronounced at low to moderate signal-to-noise ratios, where the ability to maintain multiple hypotheses provides a significant advantage over single-output decoders. Moreover, the IR-AE architecture demonstrates superior performance at small list sizes, such as L = 8 or L = 16, compared to the Turbo-AE architecture, which requires larger lists to achieve comparable performance. This indicates that the incremental redundancy structure is more efficient in leveraging available redundancy, making it particularly suitable for applications where computational resources are limited. The system’s performance scales gracefully with increasing list size, with the block error rate decreasing monotonically as L increases, although the rate of improvement diminishes for very large lists, suggesting a point of diminishing returns. The training loss, defined as the minimum binary cross-entropy over the list, decreases by nearly an order of magnitude as the list size increases from 8 to 64 for the Turbo-AE architecture, but only by a smaller factor for the IR-AE architecture, indicating that the IR-AE achieves high-quality candidate lists with fewer hypotheses. This efficiency is attributed to the structured, iterative refinement process inherent in the IR-AE, which allows each decoding stage to build upon the confidence of the previous stage rather than relying on brute-force enumeration. The invention further encompasses a method for deploying the trained system in real-time communication environments. Once trained, the encoder and decoder networks are frozen, and their weights are stored as fixed parameters in a hardware or software implementation. During operation, the encoder receives a binary message word, applies the learned encoding function, normalizes the output, and transmits the resulting codeword over the channel. The receiver receives the corrupted signal, applies the learned decoding function to generate the list of candidates, performs CRC verification on each candidate, and selects the first valid candidate as the final output. The entire process requires only a single forward pass through the encoder and a fixed number of forward passes through the decoder, making it suitable for implementation on embedded systems, field-programmable gate arrays (FPGAs), or application-specific integrated circuits (ASICs). The system does not require iterative decoding in the classical sense, as the list generation and refinement are performed in a single pass through the neural network, albeit with multiple layers. This distinguishes the invention from traditional iterative decoders such as belief propagation in LDPC codes, which require multiple passes over the Tanner graph. The invention thus provides a novel, end-to-end trainable, and computationally efficient framework for channel coding that combines the adaptability of deep learning with the reliability of classical list decoding techniques. The system is fully generalizable to any code rate, block length, and channel model, and can be extended to multi-user scenarios, multiple-input multiple-output (MIMO) systems, and cooperative communication networks by modifying the encoder and decoder architectures accordingly. The use of CRC as a selection mechanism ensures compatibility with existing communication standards and protocols, while the neural network components provide the flexibility to adapt to future channel conditions and evolving system requirements. The invention thus represents a paradigm shift in the design of error-correcting codes, moving away from algebraic and combinatorial constructions toward data-driven, learned solutions that are optimized for performance rather than analytical tractability. The resulting system is not merely an approximation of classical codes; it is a fundamentally new class of codes that emerge from the interaction between neural network architecture, training methodology, and physical communication constraints. This marks the first time that list decoding principles have been successfully integrated into a deep learning framework for channel coding, and the first time that a neural network-based code has been shown to outperform polar codes under practical decoding conditions. The invention thus opens the door to a new era of intelligent, adaptive, and self-optimizing communication systems that are no longer bound by the limitations of classical coding theory.
