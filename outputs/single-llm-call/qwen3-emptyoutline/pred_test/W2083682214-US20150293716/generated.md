## TECHNICAL FIELD

The present invention relates generally to non-volatile memory systems, and more particularly to a novel coding architecture for flash memory devices that enables multiple rewrites of stored data while simultaneously correcting a substantial number of bit errors induced by physical degradation mechanisms. The invention integrates polar coding techniques with write-once memory principles to construct a unified error-correcting rewriting code capable of sustaining a large number of write cycles without requiring block erasures, thereby significantly extending the operational lifespan of flash memory arrays. The disclosed system is particularly suited for applications in solid-state drives, embedded storage systems, and other high-reliability storage environments where endurance, data integrity, and power efficiency are critical performance metrics. The invention further extends to multi-level cell architectures and general noisy channel models beyond the binary symmetric channel, providing a scalable and robust foundation for next-generation memory technologies.

## BACKGROUND

Non-volatile memory technologies, particularly flash memory, have become the dominant storage medium in consumer electronics, enterprise data centers, and mobile computing platforms due to their high density, low cost per bit, and mechanical durability. However, a fundamental limitation of flash memory is its finite endurance, typically ranging from 1,000 to 100,000 program/erase cycles, after which cell degradation leads to increased error rates and eventual failure. This endurance constraint arises because each erase operation requires the removal of charge from an entire block of cells, a process that induces physical stress and accelerates wear on the oxide layers surrounding the floating gates. As memory densities continue to increase and cell sizes shrink, the rate of degradation has accelerated, making traditional wear-leveling and error correction techniques increasingly insufficient to ensure long-term data reliability.

To mitigate this issue, researchers have explored the concept of write-once memory (WOM) codes, which permit multiple writes to the same physical memory array without requiring block erasures. In a WOM model, memory cells are binary-valued and can only transition from a low state (0) to a high state (1), but never revert. This unidirectional constraint naturally aligns with the physical behavior of flash cells, where programming increases charge levels but erasing is a destructive, block-level operation. By encoding data such that each rewrite only flips additional bits from 0 to 1, the need for costly erasures is deferred, thereby preserving cell integrity and extending the memory’s usable lifetime. Early WOM codes, based on linear algebraic constructions, tabular mappings, and projective geometry, demonstrated theoretical potential but were limited in rate and scalability.

A breakthrough came with the discovery of polar coding-based WOM codes that achieve the theoretical capacity limit for rewriting. These codes exploit the polarization phenomenon inherent in Arıkan’s polar codes, where a set of synthetic channels derived from a noisy channel exhibit extreme reliability characteristics—some become nearly perfect, while others become nearly useless. The indices corresponding to the unreliable channels are designated as frozen bits, fixed to known values, while the remaining indices carry information. By carefully designing the frozen sets to reflect the constraints of the WOM channel, it became possible to encode successive messages with increasing efficiency, approaching the theoretical maximum sum-rate of log₂(t+1) for t rewrites in the noiseless case.

However, real-world flash memory systems are subject to a variety of noise sources, including read disturb, program disturb, charge leakage, and inter-cell interference, all of which introduce random bit flips that corrupt the stored data. Conventional error-correcting codes (ECCs), such as low-density parity-check (LDPC) codes or Bose-Chaudhuri-Hocquenghem (BCH) codes, are typically applied after data is written and before reading, but they do not account for the rewriting constraint. Existing attempts to combine error correction with rewriting have been limited to correcting only a small number of errors—typically one, two, or three—using ad hoc constructions that lack scalability and theoretical guarantees. These approaches are inadequate for modern flash memories, where error rates can reach 10⁻³ to 10⁻² per bit after moderate usage, necessitating the correction of hundreds or even thousands of errors per codeword.

Furthermore, prior art does not provide a unified framework that simultaneously optimizes for rewriting efficiency and error correction capability under realistic noise models. Most schemes treat rewriting and error correction as separate problems, leading to suboptimal resource allocation and increased overhead. There is a critical need for a coding architecture that integrates the two objectives into a single, coherent framework, leveraging the structural properties of polar codes to exploit the inherent redundancy in both the rewriting constraint and the noise channel. Such a system must be capable of handling arbitrary numbers of rewrites, correcting a substantial number of errors, and maintaining low computational complexity for both encoding and decoding operations. It must also be extensible to multi-level cell (MLC) and triple-level cell (TLC) architectures, where the state space is larger and the noise characteristics are more complex. The present invention fulfills this need by introducing a novel polar coding-based construction that unifies the WOM and error correction objectives through a carefully designed nested structure of frozen sets, enabling both high rewrite capacity and robust error resilience in a single, efficient code design.

## SUMMARY

The present invention discloses a novel coding system for non-volatile memory that enables multiple rewrites of data while simultaneously correcting a substantial number of bit errors, thereby dramatically extending the endurance and reliability of flash memory devices. The system is based on a polar coding framework that jointly models the write-once memory constraint and the binary symmetric channel noise, leveraging the polarization phenomenon to construct a nested structure of frozen sets that simultaneously satisfy the requirements of both rewriting and error correction. The invention operates on an array of binary memory cells, each capable of storing a single bit and transitioning only from a low state to a high state, and supports an arbitrary number of sequential writes without requiring block erasures. For each write operation, the system encodes a new message by modifying only those cells that are currently in the low state, ensuring compliance with the write-once constraint.

The encoding process utilizes a dither sequence, known to both the encoder and decoder, to transform the physical cell states into a virtual representation that enables the application of standard polar decoding techniques. The frozen set of the polar code is constructed based on the characteristics of the WOM channel, defined by the fraction of unprogrammed cells prior to the write and the fraction of those cells that are programmed during the write. Simultaneously, the frozen set for the binary symmetric channel, representing the noise characteristics of the memory, is computed. When the frozen set of the noise channel is contained within the frozen set of the WOM channel, the code exhibits a nested structure, wherein the set of valid cell configurations for each message forms a linear subspace of a larger error-correcting code designed for the noisy channel. This nested structure allows the decoder to recover the transmitted message using a standard successive cancellation decoder, treating the noisy cell states as corrupted codewords of the polar ECC, with the frozen bits constrained to the intersection of the two frozen sets.

In cases where the noise channel’s frozen set is not entirely contained within the WOM channel’s frozen set, the invention provides an extended construction that stores the excess information bits—those corresponding to the difference between the two frozen sets—in a separate set of auxiliary memory cells. These auxiliary cells are protected by a conventional error-correcting code designed for the same noise model, and their values are recovered during decoding prior to the main polar decoding process. This approach ensures that the full information capacity of the system is preserved even when the nested structure condition is not met, while maintaining the efficiency of the primary polar code for the majority of the encoded data.

The invention further provides a method for optimizing the sum-rate across multiple rewrites by selecting, for each write, the optimal fraction of cells to program and the corresponding WOM channel parameters that maximize the cumulative information rate. Analytical lower bounds on the achievable sum-rate are derived based on the mutual information of the WOM and noise channels, and experimental results demonstrate that the system achieves rates approaching these bounds, even for finite-length codes. The system is shown to be highly effective for practical error probabilities encountered in modern flash memories, with the nested structure emerging naturally for typical operating conditions, thereby simplifying implementation and reducing overhead.

The invention is scalable to multi-level cell architectures by extending the binary WOM model to discrete-level transitions and adapting the polar code construction to higher-order modulation schemes. It is also applicable to general memory noise models beyond the binary symmetric channel, including asymmetric channels, burst error models, and time-varying noise profiles. The encoding and decoding algorithms operate in O(N log N) time complexity, making them suitable for real-time implementation in memory controllers. The system requires no modification to the underlying flash memory hardware, and can be implemented entirely in firmware or dedicated logic circuits, making it compatible with existing storage systems. The result is a memory coding architecture that significantly outperforms conventional ECC and wear-leveling techniques by simultaneously maximizing rewrite capacity and error resilience, thereby enabling flash memory to operate reliably for orders of magnitude more write cycles than previously possible.

## DETAILED DESCRIPTION

The present invention introduces a novel coding scheme for non-volatile memory systems that enables multiple rewrites of data while simultaneously correcting a substantial number of bit errors, thereby overcoming the endurance limitations inherent in conventional flash memory architectures. The system operates on an array of binary memory cells, each of which can exist in one of two states, designated as 0 or 1, and is constrained such that a cell may transition from state 0 to state 1 but never revert from state 1 to state 0. This constraint mirrors the physical behavior of flash memory cells, where programming increases the charge level of a floating gate, but erasing requires the simultaneous removal of charge from an entire block of cells, an operation that is both time-consuming and physically destructive. By avoiding block erasures and permitting only unidirectional transitions, the invention significantly extends the operational lifespan of the memory array.

The system is designed to support t sequential writes of messages M₁, M₂, ..., Mₜ, where each message Mⱼ is a binary string of length Mⱼ bits, and the content of prior messages need not be retained after a new write. The memory array consists of N = 2ᵐ cells, where m is a positive integer chosen to ensure sufficient redundancy for reliable encoding and decoding. Prior to the first write, all cells are initialized to the 0 state. Each write operation is governed by an encoding function Eⱼ that maps the current cell state vector sⱼ ∈ {0,1}ᴺ and the new message Mⱼ ∈ {0,1}ᴹʲ to a new cell state vector sⱼ′ ∈ {0,1}ᴺ, such that sⱼ′ ≥ sⱼ component-wise, ensuring that no cell transitions from 1 back to 0. After encoding, the cell state is subject to noise, modeled as a binary symmetric channel (BSC) with crossover probability p, which may flip bits from 0 to 1 or from 1 to 0 with probability p independently across cells. The resulting noisy cell state is denoted cⱼ ∈ {0,1}ᴺ, and the decoding function Dⱼ is responsible for recovering the original message Mⱼ from cⱼ.

The core innovation of the invention lies in the construction of the encoding and decoding functions using polar coding principles, with a novel adaptation that integrates the WOM constraint and the noise channel into a unified framework. Polar codes, originally developed by Arıkan, exploit the phenomenon of channel polarization, wherein a set of N synthetic channels derived from a binary-input discrete memoryless channel exhibit extreme reliability characteristics: a fraction of these channels become nearly perfect, carrying nearly all of the channel capacity, while the remainder become nearly useless, with mutual information approaching zero. The indices corresponding to the nearly useless channels are designated as the frozen set, and the bits at these positions are fixed to predetermined values, typically zero, while the remaining bits carry information. The encoding process involves transforming an information vector into a codeword via a linear transformation based on the Kronecker product of a 2×2 kernel matrix, and the decoding process employs a successive cancellation algorithm that recursively estimates each bit based on previously decoded values and the channel observations.

In the present invention, the frozen set for the WOM channel, denoted F_WOM(α, ε), is constructed based on the parameters α and ε, where α represents the fraction of cells in the 0 state prior to the j-th write, and ε represents the fraction of those 0-state cells that are programmed to 1 during the j-th write. The mutual information of the WOM channel is determined by the entropy of the transition probabilities under these constraints, and the corresponding polar code is designed to achieve capacity for this channel. Simultaneously, the frozen set for the BSC(p) noise channel, denoted F_BSC(p), is constructed to achieve a target block error rate, typically on the order of 10⁻⁵, for the given noise level p. The key insight of the invention is that, for many practical parameter regimes, particularly when p is relatively small and α and ε are chosen appropriately, the frozen set of the noise channel is entirely contained within the frozen set of the WOM channel, i.e., F_BSC(p) ⊆ F_WOM(α, ε). This containment condition enables the construction of a nested code structure, wherein the set of valid cell configurations for each message forms a linear subspace of a larger error-correcting code designed for the BSC(p) channel.

To exploit this nested structure, the invention introduces a dither sequence g ∈ {0,1}ᴺ, which is a pseudo-random binary sequence with independent and uniformly distributed bits, known to both the encoder and the decoder. The dither is used to transform the physical cell state s into a virtual representation v = s ⊕ g, where ⊕ denotes the bitwise XOR operation. Because the dither is uniformly random and independent of the message, the channel seen by the virtual representation v is equivalent to the original BSC(p) channel. This equivalence allows the application of standard polar decoding techniques to the virtual representation, even though the physical cell state s is subject to the WOM constraint. The encoding process begins by computing the virtual representation of the current cell state, v = s ⊕ g, and then determining the set of frozen bits for the WOM channel, F_WOM(α, ε). The bits of the message M are embedded into the non-frozen positions of the polar code, while the frozen bits are assigned values according to a specific rule: the bits in the intersection F_WOM(α, ε) ∩ F_BSC(p) are set to zero, consistent with the assumption that the noise channel’s frozen bits are contained within the WOM channel’s frozen set. The remaining frozen bits in F_WOM(α, ε) \ F_BSC(p) are set to values determined by the dither and the current cell state, ensuring that the resulting cell state s′ satisfies the WOM constraint s′ ≥ s.

The encoding algorithm proceeds in a manner analogous to the standard polar encoder, with the critical distinction that the frozen bits are not all fixed to zero, but are constrained by the intersection of the two frozen sets. The information bits are assigned to the positions outside the WOM frozen set, and the resulting polar codeword u is transformed into the virtual cell state v via the polar transform. The physical cell state s′ is then obtained by reversing the dither: s′ = v ⊕ g. Because the dither is known, the decoder can reconstruct the virtual representation from the noisy cell state c by computing c ⊕ g, and then apply the successive cancellation decoder to recover the information bits. The decoder treats the bits in F_BSC(p) as frozen and fixed to zero, while the bits in F_WOM(α, ε) \ F_BSC(p) are treated as known due to the dither and the WOM constraint, allowing the decoder to accurately reconstruct the message M.

For the case where the containment condition F_BSC(p) ⊆ F_WOM(α, ε) does not hold, the invention provides an extended construction that ensures full information recovery. In this scenario, the set of bits corresponding to F_BSC(p) \ F_WOM(α, ε) cannot be frozen to zero without violating the WOM constraint, as doing so might require a cell to transition from 1 to 0. To resolve this, the invention introduces a set of additional memory cells, denoted N_additional,j, which are used exclusively to store the values of the bits in F_BSC(p) \ F_WOM(α, ε). These additional cells are not subject to the WOM constraint and are protected by a separate error-correcting code, such as a standard polar code or LDPC code, designed for the BSC(p) channel. During encoding, after the main polar encoding process is complete, the values of the bits in F_BSC(p) \ F_WOM(α, ε) are extracted and encoded into the additional cells using the auxiliary ECC. During decoding, the decoder first recovers these bits by applying the auxiliary ECC to the noisy readings of the additional cells, then uses the recovered values to supplement the frozen bits in the main polar decoder. This two-stage decoding process ensures that the full information capacity of the system is preserved, even when the nested structure condition is not satisfied.

The invention further provides a method for optimizing the sum-rate across multiple rewrites by selecting, for each write j, the optimal values of α_{j-1} and ε_j that maximize the cumulative information rate. The sum-rate R_sum is defined as the sum of the individual rates R_j = M_j / N over all t writes. The optimization is performed algorithmically by simulating the performance of the code for various combinations of α and ε, using a target block error rate of 10⁻⁵ and a fixed code length N = 8192. The frozen sets are computed using the method described in prior art for polar code construction, with the WOM channel’s frozen set size determined by the formula |F_WOM(α, ε)| = N(α H(ε) - ΔR), where H(ε) is the binary entropy function and ΔR = 0.025 is a small rate loss introduced to account for finite-length effects. The results demonstrate that the achievable sum-rate increases with the number of rewrites t, and that for practical error probabilities p ≤ 0.016, the system achieves sum-rates that approach the theoretical lower bound derived for infinite-length codes. Moreover, the nested structure condition is found to hold for a wide range of parameters, particularly when α is large and ε is moderate, indicating that the simpler nested construction is sufficient for most practical scenarios.

The analytical foundation of the invention rests on the concept of channel degradation and upgrading, which allows for the derivation of bounds on the relationship between the frozen sets of the WOM and BSC channels. It is shown that if the crossover probability p is less than or equal to αε, then the BSC(p) channel is degraded with respect to the WOM(α, ε) channel, which implies that F_WOM(α, ε) ⊆ F_BSC(p). Conversely, if ε is chosen such that αε = p, then the WOM channel can be viewed as an upgraded version of the BSC(p) channel, leading to F_BSC(p) ⊆ F_WOM(α, ε). These relationships enable the prediction of when the nested structure will emerge, and provide a theoretical guarantee that the system performs optimally under typical operating conditions. Experimental results confirm that for typical flash memory error rates and programming densities, the condition F_BSC(p) ⊆ F_WOM(α, ε) holds with high probability, validating the practicality of the nested construction.

The invention further extends to multi-level cell (MLC) architectures, where each memory cell can store more than one bit by assuming one of several discrete charge levels. In this case, the binary WOM model is generalized to a discrete-state model, where each cell can transition from a lower level to a higher level but not vice versa. The polar code construction is adapted by replacing the binary kernel with a higher-order kernel that operates on the extended alphabet, and the frozen sets are computed based on the transition probabilities between the discrete levels. The dither sequence is generalized to a vector of random values drawn from the same discrete alphabet, and the encoding and decoding processes are modified accordingly. The same principles of nested structure and auxiliary storage apply, allowing the system to achieve high rewrite capacity and error resilience in MLC and TLC flash memories.

The computational complexity of both the encoding and decoding processes is O(N log N), which is comparable to that of standard polar codes and significantly lower than that of LDPC or turbo codes, making the invention suitable for real-time implementation in memory controllers. The system requires no modification to the underlying flash memory hardware and can be implemented entirely in firmware or dedicated logic circuits, ensuring compatibility with existing storage systems. The use of a dither sequence ensures that the system is robust to variations in the noise characteristics and does not rely on precise knowledge of the channel state, making it adaptable to dynamic operating conditions. The invention thus provides a comprehensive solution to the dual challenges of endurance and reliability in non-volatile memory, enabling flash memory to operate reliably for orders of magnitude more write cycles than previously possible, while maintaining high data integrity and low power consumption.

### VII. Additional Example Embodiments

In addition to the primary embodiment described above, the invention encompasses several alternative configurations and enhancements that further expand its applicability, performance, and robustness in diverse storage environments. One such embodiment involves the use of adaptive dither sequences, wherein the dither g is not fixed across all writes but is dynamically updated based on the history of prior writes and the current state of the memory array. In this variant, the dither is generated using a pseudorandom function seeded by a combination of the write index j, the current cell state sⱼ, and a global system key. This approach introduces additional entropy into the system, making it more difficult for persistent noise patterns to correlate with the encoding structure, thereby improving error resilience in environments where noise exhibits temporal or spatial correlations. The decoder is modified to store the sequence of dithers used in prior writes, or to regenerate them using the same deterministic function, ensuring that the virtual representation remains consistent across decoding operations. This embodiment is particularly beneficial in high-endurance applications such as enterprise solid-state drives, where the memory array is subjected to frequent and uneven write patterns.

Another embodiment extends the system to incorporate hybrid error correction, wherein the auxiliary cells used to store the bits in F_BSC(p) \ F_WOM(α, ε) are protected not by a single error-correcting code, but by a concatenated coding scheme combining a short-block Reed-Solomon code with a low-density parity-check (LDPC) code. The Reed-Solomon code is applied to correct burst errors that may arise from localized cell failures or interference between adjacent memory cells, while the LDPC code handles the random bit-flip errors characteristic of the BSC model. The decoding process for the auxiliary cells proceeds in two stages: first, the LDPC decoder estimates the most likely bit values, and then the Reed-Solomon decoder corrects any residual errors that remain after the LDPC decoding. This two-tiered approach significantly improves the reliability of the auxiliary storage, allowing the system to tolerate higher noise levels and larger differences between the frozen sets without compromising the overall sum-rate. The overhead introduced by the auxiliary cells is minimized by dynamically adjusting their number based on the observed mismatch between F_BSC(p) and F_WOM(α, ε), ensuring that the system operates with optimal efficiency under varying conditions.

A further embodiment introduces a feedback mechanism that allows the memory controller to adjust the WOM parameters α and ε in real time based on the observed error rate and the remaining endurance of the memory array. In this variant, the controller monitors the number of bit flips detected during decoding and the frequency of auxiliary cell usage across successive writes. If the error rate exceeds a predefined threshold, the controller reduces the value of ε to program fewer cells per write, thereby decreasing the probability of exceeding the noise tolerance and increasing the likelihood that F_BSC(p) ⊆ F_WOM(α, ε). Conversely, if the memory array is still in good condition and the error rate is low, the controller increases ε to maximize the information rate per write. This adaptive strategy allows the system to balance between high capacity and high reliability, dynamically optimizing the trade-off based on the current state of the memory. The controller may also adjust the code length N by partitioning the memory array into smaller or larger blocks depending on the write workload, enabling the system to scale its performance to match the application’s demands.

In yet another embodiment, the invention is applied to three-dimensional (3D) NAND flash memory architectures, where multiple layers of memory cells are stacked vertically. In this configuration, the dither sequence is extended to include a spatial component, such that the dither applied to cells in different layers is correlated based on their physical proximity and the expected interference patterns between layers. The frozen sets are computed separately for each layer, taking into account the distinct noise characteristics of upper, middle, and lower layers, which may differ due to variations in oxide thickness, programming voltage, and coupling effects. The encoding and decoding processes are performed in parallel across layers, with the auxiliary cells distributed among the layers to balance the storage overhead. This layered approach enables the system to achieve uniform performance across the entire 3D array, even when the noise profile varies significantly between layers, and provides resilience against inter-layer interference, a major source of error in high-density 3D flash memories.

A further enhancement involves the integration of the invention with machine learning-based prediction models that forecast the future error behavior of the memory array based on historical write patterns, temperature profiles, and wear indicators. In this embodiment, a neural network or other predictive model is trained offline using data collected from accelerated aging tests, and deployed on the memory controller to estimate the effective noise level p and the optimal WOM parameters for the next write. The model takes as input the write history, the current temperature, the number of erase cycles per block, and the distribution of programmed cells, and outputs a predicted value of p and recommended values for α and ε. The system then configures the encoder and decoder accordingly, enabling proactive adaptation to changing conditions rather than reactive correction. This embodiment is particularly effective in data center environments, where memory usage patterns are predictable and long-term reliability is paramount.

Another embodiment extends the system to support partial writes, wherein only a subset of the memory array is rewritten during a given operation, rather than the entire array. In this variant, the dither sequence is applied only to the cells within the target region, and the frozen sets are computed locally for that region. The remaining cells are left unchanged, and their state is preserved for future writes. This approach reduces the power consumption and latency of each write operation, making the system suitable for applications with frequent small writes, such as logging systems, transactional databases, and real-time sensor networks. The decoder is modified to identify the region of interest based on metadata stored in a dedicated control area, and to apply the polar decoding process only to the relevant portion of the memory array. This partial-write capability significantly improves the system’s efficiency in scenarios where full-array writes are unnecessary, while maintaining the same level of error correction and rewrite endurance.

The invention also encompasses a variant in which the polar code is replaced by a generalized polar code based on larger kernel matrices, such as the 4×4 or 8×8 kernels proposed in recent literature, which offer faster polarization rates and improved finite-length performance. In this embodiment, the encoding and decoding algorithms are adapted to use the larger kernel, and the frozen sets are computed using the corresponding mutual information functions for the extended kernel. The resulting code achieves higher rates for the same block length, or equivalently, requires fewer cells to achieve the same performance, thereby reducing the overhead of the system. This variant is particularly advantageous in applications where memory density is at a premium, such as mobile devices and embedded systems with strict size constraints.

Finally, the invention includes an embodiment in which the dither sequence is replaced by a structured pseudorandom pattern derived from a cyclic redundancy check (CRC) polynomial or a linear feedback shift register (LFSR) with a known seed. This approach reduces the storage overhead required to maintain the dither, as the sequence can be regenerated on demand using a compact seed and a deterministic algorithm. The decoder is modified to store only the seed and the parameters of the LFSR, rather than the full dither sequence, thereby reducing the memory footprint of the system. This embodiment is especially useful in low-power applications where minimizing storage overhead is critical, and where the deterministic nature of the dither generation ensures consistency and reproducibility across multiple decoding attempts.

Each of these additional embodiments builds upon the core innovation of the invention—the unified polar coding framework for joint rewriting and error correction—and extends its functionality to address specific challenges in modern memory systems. Together, they demonstrate the versatility, scalability, and adaptability of the invention, making it applicable to a broad range of storage technologies and use cases, from consumer electronics to enterprise data centers and beyond.
