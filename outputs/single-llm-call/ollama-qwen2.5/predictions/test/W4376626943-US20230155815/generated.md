- For the comparison protocol's security in the semi-honest model, IND-CPA security of the underlying encryption scheme is sufficient. This ensures that even if one party deviates from the protocol, no additional information beyond the intended output can be gained about the inputs. The proof considers various scenarios where either only the client or both parties learn the comparison result.
- In implementing Cheon et al.'s iterative products computation, a matrix stores intermediate product values to efficiently compute all required products with logarithmic multiplicative depth. This approach minimizes computational overhead by reusing previously computed results and leveraging binary tree structures for both initial product calculations and final aggregations.
- ElGamal encryption, particularly its elliptic curve variant (ECE), is chosen for AHE due to its efficiency and security properties. ECE operates over an elliptic curve group, providing strong security with smaller key sizes compared to traditional ElGamal. The scheme's additive homomorphic property allows ciphertexts of zero to be efficiently detected without decryption, crucial for the comparison protocol.
- Recent works in secure computation have explored protocols based on the arithmetic black-box (ABB) model, which supports addition and multiplication operations over encrypted data. These protocols offer advantages like unconditional security and support for multiple parties but often require offline phases and secure channels. Our scheme, while limited to two parties, avoids these requirements by using a one-time setup phase and single-round communication.
- The decision tree evaluation protocol, implemented in Java, demonstrates significant performance improvements when instantiated with our comparison scheme compared to existing methods like DGK or Veugen. This is particularly evident in scenarios involving multiple comparisons, such as classifying data points against threshold values in private decision trees. The results show promise for practical applications requiring efficient and secure multi-party computations.
- Postponed proofs provide rigorous mathematical foundations for the security and correctness of our comparison protocol. For instance, Theorem 5.2's proof rigorously establishes that IND-CPA security of the encryption scheme ensures semi-honest security of the overall protocol. These proofs are crucial for validating the theoretical underpinnings of our work and ensuring robustness against potential attacks.
- In summary, this research contributes a secure and efficient comparison protocol for two-party computations, supported by rigorous security proofs and practical implementations. The evaluation on decision tree classification tasks highlights its performance benefits over existing methods, positioning it as a promising solution for privacy-preserving applications in various domains requiring secure multi-party computations.
