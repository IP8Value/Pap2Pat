# DESCRIPTION

## BACKGROUND

Parallel imaging techniques have revolutionized magnetic resonance (MR) imaging by enabling faster data acquisition and reducing scan times. These techniques leverage the spatial sensitivity profiles of multiple receiver coils to reconstruct images from undersampled k-space data, effectively accelerating the imaging process. Traditional parallel imaging methods, such as SENSE (Sensitivity Encoding) and GRAPPA (Generalized Autocalibrating Partially Parallel Acquisitions), are linear approaches that have been widely used in clinical settings. However, these linear methods often suffer from limitations such as reduced signal-to-noise ratio (SNR) and increased artifacts, particularly in dynamic imaging scenarios like real-time cardiac cine imaging. These limitations can significantly impact the diagnostic quality of the images, especially when dealing with fast-moving tissues or high temporal resolution requirements.

## BRIEF SUMMARY

The present invention introduces preferred embodiments for a novel parallel imaging technique that incorporates temporal sensitivity estimation to improve image quality and SNR in dynamic MR imaging scenarios. The motivation behind this approach is to address the limitations of linear methods by leveraging the temporal coherence of coil sensitivities. The first aspect of the invention involves an initial reconstruction step using linear techniques to generate a preliminary estimate of the k-space data. The second aspect involves filtering the frames to reduce noise and artifacts, enhancing the quality of the initial reconstruction. The third aspect involves estimating the coil sensitivity information over time, which is then used in a non-linear reconstruction process to refine the image quality. It should be noted that while specific embodiments are described herein, the invention is not limited to these particular configurations and can be adapted for various imaging applications.

## DETAILED DESCRIPTION OF THE DRAWINGS AND PRESENTLY PREFERRED EMBODIMENTS

Linear parallel imaging algorithms have been widely used in MR imaging to accelerate data acquisition. These methods typically involve acquiring a small subset of k-space data and using the spatial sensitivity profiles of multiple receiver coils to reconstruct the full image. However, linear approaches often suffer from limitations such as reduced SNR and increased artifacts, particularly in dynamic imaging scenarios where rapid changes in the anatomy are present. To address these limitations, the present invention introduces self-consistent parallel imaging with temporal sensitivity estimation (TSPIRIT).

TSPIRIT is a novel reconstruction method that incorporates temporal sensitivity information to improve image quality and SNR in dynamic MR imaging. The TSPIRIT reconstruction process involves several key steps: data acquisition, initial linear reconstruction, filtering of frames, temporal sensitivity estimation, and non-linear reconstruction. This method has been particularly effective in applications such as cardiac real-time cine imaging, where high temporal resolution is crucial.

The application of TSPIRIT to cardiac real-time cine imaging demonstrates its potential for improving the quality of exercise stress cine images. In this context, the method can significantly enhance the SNR and reduce artifacts caused by rapid heart rate and exaggerated breathing. The fully automated reconstruction process ensures that the method can be easily integrated into clinical workflows without requiring extensive user intervention.

TSPIRIT has a wide range of clinical uses beyond cardiac imaging. It can be applied to various dynamic imaging scenarios where high temporal resolution and improved SNR are essential, such as neurological imaging, abdominal imaging, and musculoskeletal imaging. The flexibility of the TSPIRIT method allows it to be adapted for different imaging protocols and patient populations.

A flow chart of the method for parallel imaging with temporal sensitivity in magnetic resonance reconstruction is provided to illustrate the steps involved. The process begins with the acquisition of magnetic resonance data using a multi-channel coil system. The k-space data is acquired in an undersampled manner, typically using time-interleaved sampling techniques. Each frame represents different times during the imaging sequence, and the reduction factor determines the degree of undersampling.

The initial reconstruction step involves performing a linear reconstruction to generate a preliminary estimate of the k-space data. This is typically done using methods such as GRAPPA or SENSE. The frames are then filtered to reduce noise and artifacts, enhancing the quality of the initial reconstruction. Temporal filtering techniques can be employed to improve the coherence of the coil sensitivity information over time.

The next step involves estimating the coil sensitivity information, which is a critical component of the TSPIRIT method. This is done using an iterative self-constraint parallel imaging reconstruction calibration process. The non-linear reconstruction step then uses this estimated sensitivity information to refine the image quality. Various non-linear solvers can be employed, including least square matrix inversion and non-linear conjugate gradient methods.

The reconstructed data is combined using techniques such as sum-of-square coil combination to generate the final output images. Further processing of the output data may include post-processing steps such as noise reduction and artifact correction. The output data can be stored in memory or transmitted for further analysis, and it can also be displayed on a monitor for real-time visualization.

The system for parallel imaging with temporal sensitivity in magnetic resonance reconstruction includes an MR system equipped with a multi-channel coil system, a memory unit, a processor, and a display. The MR system is configured to acquire the k-space data using the specified sequence parameters. The memory unit stores the acquired data and intermediate results, while the processor performs the TSPIRIT reconstruction process. The display unit can be used to visualize the reconstructed images in real-time.

The flow chart of the method can be implemented as a program written in various programming languages such as C++, Python, or MATLAB. The system components include the MR scanner, the multi-channel coil system, and the processing unit. Alternative system configurations may also be considered, depending on the specific imaging requirements and clinical settings.

To evaluate the performance of TSPIRIT, the signal-to-noise ratio (SNR) is calculated for a region of interest in the reconstructed images. Images reconstructed using TSPIRIT are compared to those obtained using linear methods such as TGRAPPA. The results show a significant increase in SNR without an increase in ghosting artifacts, demonstrating the advantages of the TSPIRIT method.

In summary, the present invention provides a novel parallel imaging technique that incorporates temporal sensitivity estimation to improve image quality and SNR in dynamic MR imaging scenarios. The TSPIRIT method has been shown to be particularly effective in applications such as cardiac real-time cine imaging, where high temporal resolution and improved SNR are essential.
