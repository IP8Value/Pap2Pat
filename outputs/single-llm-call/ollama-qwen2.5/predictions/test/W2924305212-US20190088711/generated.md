# DESCRIPTION

## BACKGROUND OF THE INVENTION

### Field of the Invention
The present invention relates to spintronic devices, specifically to Spin Current type Memory (SC-Memory) utilizing the Spin-Orbit Torque (SOT) effect for magnetization switching. This technology is particularly relevant in the field of non-volatile memory storage and has significant implications for high-speed, low-power data processing systems.

### Background Art
Conventional magnetic random access memory (MRAM) relies on spin-transfer torque (STT) to switch the magnetization state of a magnetic tunnel junction (MTJ). However, STT-based MRAM faces challenges in achieving high write speed and endurance due to the relatively high current densities required for reliable switching. The Spin-Orbit Torque (SOT) effect offers an alternative mechanism that can potentially overcome these limitations by using spin currents generated from heavy metals like tungsten (W) or tantalum (Ta). SOT-based MRAM has demonstrated superior write speed and endurance, making it a promising candidate for next-generation non-volatile memory.

## Technical Problem
While SOT-based MRAM shows significant potential, there are still technical challenges that need to be addressed. One of the primary issues is the high threshold current density required for magnetization switching, which can lead to Joule heating and damage to the device, particularly at high write speeds. Additionally, achieving consistent and reliable write operations over a large number of cycles remains a challenge due to the variability in the SOT efficiency and the potential for failure mechanisms such as electrical open or short circuits.

### Solution to Problem
The present invention addresses these challenges by introducing an innovative design that reduces the threshold current density required for magnetization switching while maintaining high write endurance. This is achieved through the use of a carefully optimized stack structure and material selection, particularly focusing on the SOT line and the free layer of the MTJ.

## SUMMARY OF THE INVENTION
The invention provides a Spin Current type Memory (SC-Memory) device that utilizes the Spin-Orbit Torque (SOT) effect for magnetization switching. The device includes a magnetic tunnel junction (MTJ) with a top-pinned structure, a heavy metal SOT line, and an optimized stack configuration to reduce the threshold current density and improve write endurance.

### Detailed Description of the Invention

## Technical Field
The invention pertains to the field of spintronic devices, specifically non-volatile memory storage using Spin-Orbit Torque (SOT) for magnetization switching. The device is designed to achieve high-speed, low-power data processing with improved reliability and endurance.

### Background Art
Magnetic random access memory (MRAM) has gained significant attention due to its potential for high-speed, non-volatile data storage. Conventional MRAM relies on spin-transfer torque (STT) for magnetization switching, which involves passing a current through the magnetic tunnel junction (MTJ). However, STT-based MRAM faces limitations in terms of write speed and endurance due to the high current densities required for reliable switching. The Spin-Orbit Torque (SOT) effect offers an alternative mechanism that can potentially overcome these limitations by using spin currents generated from heavy metals like tungsten (W) or tantalum (Ta). SOT-based MRAM has demonstrated superior write speed and endurance, making it a promising candidate for next-generation non-volatile memory.

### Technical Problem
Despite the advantages of SOT-based MRAM, there are still technical challenges that need to be addressed. One of the primary issues is the high threshold current density required for magnetization switching, which can lead to Joule heating and damage to the device, particularly at high write speeds. Additionally, achieving consistent and reliable write operations over a large number of cycles remains a challenge due to the variability in the SOT efficiency and the potential for failure mechanisms such as electrical open or short circuits.

### Solution to Problem
The present invention addresses these challenges by introducing an innovative design that reduces the threshold current density required for magnetization switching while maintaining high write endurance. This is achieved through the use of a carefully optimized stack structure and material selection, particularly focusing on the SOT line and the free layer of the MTJ.

### Configuration of the Invention
The Spin Current type Memory (SC-Memory) device according to the present invention includes the following components:

1. **Magnetic Tunnel Junction (MTJ):** The MTJ is a top-pinned structure with a free layer, a tunnel barrier, and a pinned layer. The free layer's magnetization can be switched using spin currents generated by the SOT line.

2. **SOT Line:** A heavy metal line, typically tungsten (W) or tantalum (Ta), is used to generate spin currents that switch the magnetization of the free layer. The SOT line is optimized for high resistivity and controlled sputtering conditions to achieve efficient spin current generation.

3. **Stack Configuration:** The stack configuration includes a thermal oxide Si substrate, a tungsten layer as the SOT line, a CoFeB-based free layer, an MgO tunnel barrier, a CoFeB-based Synthetic Antiferromagnetic (SAF) pinned layer, and an IrMn capping layer. This configuration is designed to minimize the threshold current density required for magnetization switching.

4. **Optimized Dimensions:** The dimensions of the SOT line and the MTJ are carefully optimized to balance high SOT efficiency with minimal Joule heating. For example, the W-SOT line has a thickness of 3 nm, length of 700 nm, and width of 360 nm, while the MTJ is an ellipse with dimensions 120×360 nm.

5. **Write/Read Circuit:** The device includes a write/read analog circuit controlled by a field-programmable gate array (FPGA) for measurement and control of the write and read operations. This circuit allows for precise control of the write pulse current density, pulse width, and cycle time.

### Effects of the Invention
The Spin Current type Memory (SC-Memory) device according to the present invention achieves several significant benefits:

1. **Reduced Threshold Current Density:** The optimized stack configuration and material selection result in a lower threshold current density required for magnetization switching, reducing Joule heating and improving device reliability.

2. **High Write Endurance:** The device demonstrates high write endurance of up to 10^12 cycles, with minimal drift in the MTJ resistance and sustained TMR ratio.

3. **Reliable Operation:** The optimized design minimizes the risk of electrical open or short circuits, ensuring consistent and reliable write operations over a large number of cycles.

4. **High Speed and Low Power Consumption:** The SOT-based mechanism allows for high-speed switching with low power consumption, making the device suitable for high-performance applications.

### Examples
The following examples illustrate the performance and benefits of the Spin Current type Memory (SC-Memory) device according to the present invention:

1. **Example 1: Single MTJ Element**
   - A single MTJ element was fabricated using the optimized stack configuration described above.
   - The write pulse current density required for magnetization switching was measured at various pulse widths.
   - Results showed a clear relationship between the threshold current density and pulse width, with a comparable threshold current density of 9.7×10^7 A/cm² for 5 ns pulse width.
   - Write endurance tests demonstrated high write endurance up to 10^12 cycles, with minimal drift in MTJ resistance and sustained TMR ratio.

2. **Example 2: 8×8 SC-Memory Array**
   - An 8×8 SC-Memory array was fabricated using the same optimized stack configuration.
   - The write/read analog circuit controlled by an FPGA allowed for precise control of the write and read operations.
   - Accelerated tests with increasing write current density showed that the number of failure elements increased with higher current density, consistent with single MTJ element results.
   - Despite this, the array demonstrated high reliability and endurance, making it suitable for practical applications.

### Conclusion
The Spin Current type Memory (SC-Memory) device according to the present invention represents a significant advancement in non-volatile memory technology. By addressing the challenges of high threshold current density and write endurance, the device offers improved reliability, high speed, and low power consumption, making it a promising candidate for next-generation data storage systems.
