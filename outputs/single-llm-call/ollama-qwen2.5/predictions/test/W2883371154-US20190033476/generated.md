- The study examines if large earthquakes can trigger subsequent seismic events globally using two experimental designs. Experiment 1 looks forward in time from large source events (≥M6.5) to count all triggered events ≥M5.0 within 3 days. Experiment 2 looks backward from potential triggered events (≥M5.0) to identify possible large source events ≥M6.5 in the prior 3 days.
- Aftershocks and foreshocks are removed using a standard declustering technique, with remaining data following a Poisson distribution. The first bin closest to sources is omitted for larger magnitude events to minimize aftershock contamination of statistics.
- P-values are calculated using a cumulative probability function for the binomial distribution in R. Mid p-values are used instead of traditional p-values to avoid bias due to integer earthquake counts. Relative rates are normalized to a common sample size while maintaining the same p-value.
- Experiments 1 and 2 are theoretically independent measures of the same global forcing function, allowing sensitivity analysis of triggering to magnitude of source and triggered events. Results show statistically significant relative rate increases for both experiments at certain arc distances, providing evidence for remote earthquake triggering on a global scale.
