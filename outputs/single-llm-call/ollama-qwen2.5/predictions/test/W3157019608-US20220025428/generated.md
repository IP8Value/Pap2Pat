To test the encoding and decoding algorithms' robustness, simulated origami data with random messages and errors were generated. Messages of varying sizes (from 160 to 12,800 bits) were divided into segments, encoded onto origami along with index, orientation, and error-correcting bits. Ten in silico copies of each unique origami were created, with 0-9 random bit flips introduced to simulate errors. The decoding process followed the described algorithm steps.

The decoding algorithm first corrected errors at the dNAM origami level using parity and checksum bits. It calculated weights for each cell based on discrepancies between expected and actual values. Higher weight values indicated a higher probability of error. A greedy search was performed to correct errors, prioritizing bit flips that minimized overall matrix weight until no mismatches remained or the maximum number of allowed flips was reached.

After correcting errors in individual origami matrices, the algorithm extracted droplet and index data. It maintained a priority queue of droplets based on their degree (number of segments). The algorithm iteratively removed the lowest degree droplet, used it to reduce the degree of other droplets via XOR operations, and re-queued the results. Upon finding a droplet with a degree of one, it stored it as a segment for the final message. If all segments were recovered, the algorithm terminated successfully.

To validate the system's performance, random binary messages of varying sizes were created and divided into segments. Droplets were formed using the fountain code algorithm and encoded onto origami with additional error-correcting bits. Simulated errors were introduced by flipping 0-9 bits at random in ten copies of each unique origami. The decoding process was then applied, demonstrating the system's ability to recover the original message even with significant errors.

The overall research design included simulation tests and a detailed decoding algorithm to ensure robust data recovery from error-prone origami matrices. By systematically introducing errors and testing the decoding process, the study demonstrated the effectiveness of the multi-layer error correction scheme in recovering messages accurately. This approach provides a reliable framework for encoding and decoding large amounts of data using dNAM origami structures.
