# DESCRIPTION

## FIELD

The field of the present invention pertains to photovoltaic (PV) energy systems, particularly to methods and systems for optimizing the power output of PV arrays under partial shading conditions. The invention addresses the challenge of dynamically reconfiguring the connections between PV panels to mitigate the adverse effects of shading, thereby enhancing the overall efficiency and reliability of PV systems.

## BACKGROUND

Photovoltaic (PV) energy systems have become a cornerstone in meeting renewable energy demands over the past decade. However, the performance of PV systems is often compromised by partial shading, which can arise from environmental factors such as clouds, trees, and buildings, as well as man-made obstructions. Partial shading causes voltage and current mismatches, leading to significant power losses and reduced energy supply to the grid.

To mitigate these issues, various strategies have been explored, including the reconfiguration of PV array connections. Traditional PV arrays typically use fixed topologies, such as series-parallel (SP), bridge-link (BL), honeycomb (HC), and total-cross-tied (TCT) configurations. While these topologies offer certain advantages, they are not always optimal under varying shading conditions. Dynamic reconfiguration, which involves altering the electrical connections between panels in real-time, has emerged as a promising solution to enhance power production and maintain consistent energy flows to the utility grid.

Several approaches have been proposed for dynamic reconfiguration, including irradiance equalization, graph clustering, and machine learning (ML) techniques. However, these methods often suffer from scalability issues, computational overhead, and limited generalization capabilities. There is a need for a scalable, efficient, and reliable method to dynamically reconfigure PV arrays based on real-time shading conditions.

## DETAILED DESCRIPTION

### Approach

The present invention provides a cyber-physical system approach for topology reconfiguration in PV arrays using deep neural networks (DNNs). The system leverages data collected from specialized sensors or smart monitoring devices (SMDs) attached to each PV panel. These SMDs communicate wirelessly with a central server, which processes the data and applies a DNN to determine the optimal topology for the current shading conditions. The DNN is designed with regularization techniques, such as dropout and batch normalization, to prevent overfitting and ensure robust performance.

The key steps in the proposed approach are as follows:
1. **Data Collection**: SMDs continuously monitor the irradiance levels of each PV panel and transmit this data to the central server.
2. **Data Preprocessing**: The server preprocesses the data, normalizing the irradiance values and preparing them for input to the DNN.
3. **Topology Prediction**: The DNN processes the preprocessed data and predicts the optimal topology (SP, BL, HC, or TCT) that maximizes power output under the current shading conditions.
4. **Reconfiguration**: The central server sends control signals to the SMDs, which in turn modify the electrical connections between the PV panels to realize the predicted topology.

### Neural Network Model

The DNN used in the present invention is a six-layered, feed-forward network designed to perform topology reconfiguration. The architecture includes the following components:
- **Input Layer**: The input layer receives an n-dimensional vector representing the irradiance levels of the PV panels, where n is the number of panels in the array.
- **Hidden Layers**: The hidden layers consist of fully connected layers with ReLU activation functions. Each layer performs an affine transformation followed by ReLU activation, dropout, and batch normalization.
- **Output Layer**: The output layer uses a softmax activation function to predict the probability distribution over the four possible topologies (SP, BL, HC, and TCT).

The specific design of the DNN includes:
- **Layer Dimensions**: The number of neurons in each layer is 64, 64, 128, 256, 64, and 64, respectively.
- **Regularization Techniques**:
  - **Dropout**: Dropout is applied to layers 2, 3, 4, and 5 with a dropout factor of 20%. This helps prevent overfitting by randomly setting a fraction of the neuron outputs to zero during training.
  - **Batch Normalization**: Batch normalization is applied to layers 2, 3, 4, and 5 to standardize the inputs to each layer, reducing internal covariate shift and accelerating convergence.

The DNN is trained using a dataset of irradiance instances and their corresponding optimal topologies. The dataset is generated by simulating the SP, BL, HC, and TCT topologies for various shading scenarios and determining the topology that produces the maximum power. The DNN is optimized using the categorical cross-entropy loss function and the Adam optimizer for 200 epochs with a learning rate of \(10^{-4}\).

### Results and Discussion

The performance of the proposed DNN-based reconfiguration algorithm was evaluated using a comprehensive dataset of 8,000 irradiance instances. The dataset was split into a training set (90%) and a test set (10%). The DNN achieved an average test accuracy of 81.1% and a macro average F1 score of 0.74, demonstrating its effectiveness in predicting the optimal topology under diverse shading conditions.

The proposed approach was compared against several baseline ML algorithms, including K-Nearest Neighbors (KNN), Support Vector Machines (SVM), Random Forests (RF), and XGBoost. The DNN outperformed these baselines in terms of accuracy and F1 score, highlighting its superior generalization capabilities.

Furthermore, the merit of topology reconfiguration was assessed by analyzing the power improvements achieved by switching from the standard SP topology to the other topologies (BL, HC, and TCT). The results showed that reconfiguration led to significant power improvements in a substantial percentage of cases, with an average power improvement of approximately 11%.

### Computing Device

The computing device used to implement the proposed system includes a central server equipped with a powerful processor, sufficient memory, and a wireless communication module. The server runs the DNN and processes the data collected from the SMDs. The SMDs are low-power, microcontroller-based devices that monitor the irradiance levels of the PV panels and can receive and execute control signals to reconfigure the array.

### Methods

The methods involved in the implementation of the proposed system are as follows:
1. **Data Generation**: Synthetic irradiance instances are generated using a binary mapping scheme, where 0 and 1 represent unshaded and shaded panels, respectively. The irradiance values are drawn from uniform distributions to simulate a wide range of partial shading scenarios.
2. **Simulation Setup**: The PV array is simulated using MATLAB-Simulink, with each panel modeled to include bypass diodes and wiring losses. The wiring losses are represented by resistors placed between the panels.
3. **Training the DNN**: The DNN is trained using the generated dataset, with the optimal topology for each irradiance instance determined by simulating the SP, BL, HC, and TCT topologies and selecting the one that produces the maximum power.
4. **Inference and Reconfiguration**: During inference, the DNN processes the real-time irradiance data from the SMDs and predicts the optimal topology. The central server then sends control signals to the SMDs to reconfigure the array accordingly.

The proposed system offers a scalable, efficient, and reliable solution for topology reconfiguration in PV arrays, significantly enhancing the power output and reliability of PV systems under partial shading conditions.
