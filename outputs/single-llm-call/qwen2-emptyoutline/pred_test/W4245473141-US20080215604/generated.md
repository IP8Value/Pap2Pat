# DESCRIPTION

## TECHNICAL FIELD

The present invention relates to the field of genetic data processing and, more specifically, to the use of Field Programmable Gate Arrays (FPGAs) for the parallel simulation of meiosis events in pedigrees. The invention provides a method and system for efficiently estimating genetic parameters, such as inbreeding coefficients, genotype probabilities, and multi-locus genotype probabilities, by leveraging the parallel processing capabilities of FPGAs.

## BACKGROUND ART

Pedigree data structures are fundamental in genetic studies, combining information from multiple individuals to distinguish genetic effects from environmental effects. In diploid species, each individual has exactly two parents, and each individual may have records of genotype, either molecular markers from a segment on the chromosome or implied genotype through an observed presence or absence of a genetically determined characteristic. Quantitative trait measurements may also exist for some or all individuals.

During meiosis, each diploid individual inherits exactly one allele from each parent. The set of meioses can be represented as a set of meiosis indicators, each taking the value of zero or one. The likelihood of a set of meiosis indicators and associated genotypes for founders is a function of the allele frequencies in the founders and, in the case of multilocus pedigree data, the number of recombinations observed between linked loci.

Sequential algorithms exist to process pedigree data, but they often face computational challenges, especially for large and complex pedigrees. Exact maximum likelihood (ML) methods require evaluating the likelihood for every possible combination of meioses, which is computationally infeasible for large pedigrees. Sampling-based algorithms, such as the gene dropping algorithm, are commonly used to estimate genotype and identity by descent (IBD) probabilities.

Field Programmable Gate Arrays (FPGAs) offer a promising alternative to traditional sequential algorithms. FPGAs consist of an array of reprogrammable logic cells that can be configured to represent fine-grained data structures. This makes FPGAs ideal for simulating meiosis events in pedigrees, as meiosis events for individuals other than direct ancestors do not affect the individual's genotype, allowing for parallel simulation.

## DISCLOSURE OF INVENTION

The present invention provides a method and system for parallel simulation of meiosis events in pedigrees using FPGAs. The method involves representing the pedigree data in layers, where each layer corresponds to one generation. Founders (individuals without known parents) are placed in layer 0, and descendants are placed in subsequent layers. Each individual is represented by a module, and modules are arranged in layers to ensure synchronization during the simulation.

At each clock cycle, alleles for founders are generated, and meiosis indicators are generated for each descendant module. These computations are completed in one clock cycle, during which each descendant receives one allele from each of its parent modules. Holder modules are used to pass on alleles while remaining synchronized with the rest of the alleles dropping through the pedigree. This pipelined approach allows a new sample for the whole pedigree to be generated each clock cycle.

The invention can be applied to various genetic analyses, including the estimation of inbreeding coefficients, genotype probabilities, and multi-locus genotype probabilities. For inbreeding coefficients, the FPGA implementation can estimate the coefficient of inbreeding (F) for an individual as the probability that the alleles carried at a random locus are IBD. For genotype probabilities, the FPGA can estimate single locus genotype probabilities where marker information is available on some individuals. For multi-locus pedigree data, the FPGA can estimate genotype probabilities for multiple linked loci, taking into account the number of recombinations and the assumed recombination rate.

The FPGA implementation offers significant speed improvements over sequential algorithms, making it feasible to process large and complex pedigrees. The invention can be further enhanced by using hybrid circuit boards that combine FPGAs with general-purpose CPUs, allowing for the execution of more sophisticated algorithms.

## BEST MODE FOR CARRYING OUT THE INVENTION

### FPGA Representation of a Pedigree

The essential elements of the FPGA representation of a pedigree include modules arranged in layers, with each layer representing one generation. Founders are placed in layer 0, and descendants are placed in subsequent layers. Each module represents an individual and contains data and storage for the results of computations on the individual. Holder modules are used to pass on alleles while remaining synchronized with the rest of the alleles dropping through the pedigree.

At each clock cycle, alleles for founders are generated, and meiosis indicators are generated for each descendant module. These computations are completed in one clock cycle, during which each descendant receives one allele from each of its parent modules. The holder modules ensure that all alleles in layer i at cycle t dropped through layer (i - 1) at cycle (t - 1) and originated in layer 0 at cycle (t - i), allowing the system to be pipelined. This means that at any clock cycle, modules in the same layer are processing the same sample, but modules in different layers are not, with as many samples propagating through the pedigree as there are layers. When the alleles drop through layer m, the sample is complete, and a new sample for the whole pedigree is generated each clock cycle.

### Example Applications

#### Estimating Inbreeding Coefficients

The first application of the invention is the estimation of inbreeding coefficients. The coefficient of inbreeding (F) for an individual can be described as the probability that the alleles carried at a random locus are IBD. The gene dropping algorithm estimates F as the proportion of samples for which the alleles inherited by an individual are IBD. In the FPGA implementation, the structure of a descendant module includes a comparator to check whether the alleles are IBD and a counter to increment when they are. Founder modules are assigned a constant pair of alleles, with only one copy of each allele occurring in layer 0. Meiosis events can be either pseudo-random or, if computationally feasible, the complete set of possible meiosis events can be enumerated to produce an exact solution. When programmed on an FPGA, the allele transmission between parents and offspring, the comparison for all individuals, and the incrementing of the counters all take place in a single clock cycle. This is regardless of the number of individuals in the pedigree, provided that the FPGA is large enough to store all of the individual modules.

#### Estimating Genotype Probabilities

The second application of the invention is the estimation of single locus genotype probabilities where marker information is available on some individuals. The gene dropping algorithm is applied, but founder modules differ from those used to estimate F in that alleles are no longer unique and are sampled from a distribution. By sampling alleles in the founder layer from the appropriate multinomial distribution, the calculation of the component of the likelihood due to the allele frequencies in the founder layer is avoided, and a test for consistency with the observed data is all that is required. Where inconsistencies between the sampled and observed genotype are identified, the likelihood of the sample is zero, otherwise it is non-zero and the sample can be accumulated. The results can no longer be accumulated in the individual's module because whether the likelihood is zero is not known until alleles have dropped through layer m. The storage for results for all individuals is in a terminal layer of allele counters below layer m, with holder module chains of appropriate length connecting individual modules to modules in the terminal layer.

The valid allele signals from all descendants are compared, and only if they are all valid is the master valid signal set to on, allowing the count of all alleles in the sample to proceed. Founder modules are identical to descendant modules apart from the source of alleles. On completion, the probability that an individual has a particular genotype is the proportion of samples of non-zero likelihood for which the individual had that particular genotype.

#### Multi-Locus Pedigree Data

The final application of the invention is the estimation of genotype probabilities for multiple linked loci. Here, the likelihood is a function of the allele frequency in the founder layer, consistency with observed data, and the number of recombinations in the sample and the assumed recombination rate. The calculation of the component of the likelihood due to the allele frequency in the founder layer is avoided by sampling from the appropriate multinomial distribution. Similarly, the calculation of the component of the likelihood due to recombinations is avoided by sampling recombinations from the appropriate binomial distribution. Instead of counting alleles, the inheritance of haplotypes, or sets of alleles at linked loci on one chromosome, are counted.

### Hardware and Software

The FPGA used for the computations is a Xilinx Spartan 3 (XC3S400) operating at 50 MHz. The software is written in VHDL and Picoblaze TM Assembler. VHDL is a hardware description language that allows any digital electronics circuit to be represented in a text format. The FPGA is configured using VHDL, after pre-processing the pedigree data to identify valid and invalid allele combinations. This is done to minimize the space required for storage of results on the FPGA rather than to speed up the algorithms. The VHDL is adjusted to minimize the size of the FPGA space required. A Picoblaze soft processor is configured to provide an interface to the general-purpose computer. The Picoblaze processor is programmed into the FPGA along with a controlling program. The allele and inheritance generators used cellular automata random number generators, chosen for their suitability for implementation on an FPGA and their ability to produce high-quality pseudo-random numbers.

### Results

#### Estimating Inbreeding Coefficients

For the pedigree of 32 individuals and the pedigree of 60 individuals, the FPGA implementation of the gene dropping algorithm showed a significant speed improvement over the sequential implementation. The FPGA has a speed improvement of 166 times for the tested processors on the pedigree of 60 individuals. For a pedigree of 1000 individuals, the high-performance FPGA is potentially 17,500 times faster than a high-performance CPU.

#### Estimating Genotype Probabilities

The FPGA and sequential implementations of gene dropping for estimating genotype probabilities also showed significant speed improvements. The FPGA implementation was 295 times faster than the general-purpose CPU for the pedigree of 11 individuals, and 495 times faster for the pedigree of 20 individuals. For these pedigrees, 0.0122% and 0.00127% of samples had non-zero likelihood, respectively.

#### Multi-Locus Pedigree Data

For the pedigree of four individuals, the FPGA implementation of the gene dropping algorithm for multi-locus data showed a speed advantage of 322 times with high-performance FPGA. Even for this small pedigree, the speed improvement would be greater for larger pedigrees.

### Discussion

The estimation of allelic, IBD, and haplotype probabilities is becoming increasingly common as more molecular marker data is generated from individuals in human and livestock pedigrees. The FPGA implementation of the gene dropping algorithm offers significant speed improvements over sequential algorithms, making it feasible to process large and complex pedigrees. The custom configuration of FPGAs holds great potential for performance increases for processing highly regular data structures such as pedigrees.

There is an important difference between the estimation of inbreeding coefficients and the other examples presented. With the estimation of inbreeding coefficients, a given number of samples produces estimates of the same level of precision, regardless of the size of the pedigree. This is not the case with the estimation of allelic probabilities. Adding individuals to the pedigree increases the complexity and size of the problem. For example, using gene dropping on pedigrees with a similar proportion of known genotypes, as the number of individuals increases, the proportion of samples that are consistent with the observed data falls, so fewer samples are accumulated. In large datasets, where the complete set of meioses cannot be enumerated, samples of low likelihood may far outnumber samples of moderate or high likelihood. Achieving the speed improvements described here to gene dropping will not be enough to address this problem, even if FPGAs of sufficient size are available.

However, more sophisticated sequential algorithms than gene dropping have been proposed and are currently applied to datasets, although for some of these, the size of the analyses that can be attempted is still restricted. These algorithms operate by enumerating the set of samples of high likelihood or sampling from this set. It is possible that some of these may be implemented on FPGAs, if FPGAs of sufficient size are available, in which case speed improvements similar to those described here should be achievable.

FPGAs are suited to analyses in which the data can be represented in a regular, structured way. Operations such as integer addition, logical and, or, and exclusive or, shift operations, counters, and memory storage can be completed in a single clock cycle, allowing pipelining. Operations such as floating-point arithmetic can also be completed in a single clock cycle, although the clock speed may need to be lowered. The main problem with floating-point operations is the large amount of FPGA circuitry that is required, so algorithms that avoid such operations are favored. For example, where the likelihood (or something proportional to it) must be calculated, an algorithm such as the Metropolis-Hastings algorithm may be preferable to an algorithm such as importance sampling. Although the likelihood is a real number, the storage for results remains the same as for gene dropping algorithms if the Metropolis-Hastings algorithm is used, that is, an integer counter for each allele or haplotype for each individual. With importance sampling, the likelihood, a floating-point number, is added for each allele or haplotype, and the storage requirements are significantly increased.

There is considerable scope to perform computations on pedigree data on the hybrid circuit boards that are now becoming available. These boards contain one or more FPGAs closely coupled to one or more general-purpose CPUs. The design of algorithms that exploit the FPGA for integer and bit operations in parallel while performing floating-point operations on the general-purpose CPU will be challenging, but if successful, systems based on hybrid boards may be superior to either FPGA or CPU-based analysis systems. An FPGA could generate hundreds of millions of samples for a given set of parameters, while on the CPU, a sequential algorithm accumulated the results from previous FPGA runs and determined the optimal set of parameters for the next FPGA run. Some of the hybrid circuit boards are designed to be assembled into arrays, which may help overcome the limitations on the size of pedigree that can be fitted onto a single FPGA. Using an FPGA coupled to a CPU may also allow analyses on pedigrees that are too large to be stored on the FPGA. Subsets of the pedigree may be loaded into the FPGA for processing, in which case the speed advantage of the FPGA could remain constant for pedigrees larger than the maximum that can be stored on the FPGA. If this can be achieved, even the FPGAs that are available today may be suitable for large livestock pedigrees and may offer advantages over sequential algorithms.

In the examples presented, the pedigree and associated genotype data were directly coded in VHDL, and reprogramming of the FPGA was required for each pedigree. Few geneticists currently have skills in programming languages for FPGAs, such as VHDL, which could slow the adoption of FPGAs for analyses on pedigree data, particularly since some knowledge of digital electronics is useful, and learning VHDL is not as easy as learning a new sequential computer language. However, it may be possible to program the basic structure of a general pedigree into an FPGA and have actual pedigree data loaded at run time by people unskilled in programming FPGAs. In addition, it is likely that suites of tools for programming algorithms for pedigree data onto FPGAs will be developed. These may have interfaces closer to the sequential programming languages familiar to many geneticists.

It may not be possible to implement on FPGAs some of the sequential algorithms currently used for analysis of pedigree data. Small increases in the complexity of the modules cause significant reductions in the number of modules that can be accommodated on the FPGA, and the FPGAs available today severely limit the size of the pedigree dataset that can be analyzed. However, as with general-purpose CPUs, the size and speed of FPGAs are increasing, and in the future, FPGAs will be available that allow parallel computations on datasets for which current sequential algorithms cannot produce exact solutions.

### Conclusion

In summary, the present invention provides a method and system for parallel simulation of meiosis events in pedigrees using FPGAs. The FPGA representation of the pedigree allows a new sample for the whole pedigree to be generated each clock cycle, regardless of the size and complexity of the pedigree, provided that the pedigree can be stored on the FPGA. This results in significant speed improvements over sequential implementations, making it feasible to process large and complex pedigrees. The invention can be applied to various genetic analyses, including the estimation of inbreeding coefficients, genotype probabilities, and multi-locus genotype probabilities. The use of hybrid circuit boards that combine FPGAs with general-purpose CPUs offers further potential for enhancing the performance of genetic data processing.
