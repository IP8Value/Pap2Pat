# DESCRIPTION  

## BACKGROUND OF THE INVENTION  

The field of gene expression analysis has long sought methods to improve the accuracy of microarray classification and biomarker discovery by leveraging network-based approaches. Traditional methods analyze gene expression profiles by considering each gene individually, failing to account for the coordinated expression patterns among functionally related genes within biological networks. While existing techniques incorporate protein-protein interaction data, they remain limited by their inability to systematically integrate neighborhood expression values when genes exhibit weak but biologically meaningful differential expression.  

Current network-based approaches rely on conventional ranking algorithms or graph clustering methods, which prove inadequate when analyzing complex, inseparable networks lacking clear modular structures. These limitations become particularly evident in disease-specific protein interaction networks, where functionally related genes may not form distinct clusters yet still exhibit coordinated expression patterns critical for accurate classification. Prior attempts using methods like PageRank-style algorithms or hierarchical clustering fail to capture the nuanced relationships between genes that contribute to disease states when individual expression differentials are below traditional detection thresholds.  

The present invention addresses these shortcomings by introducing Integrative eXpression Profiling (IXP) combined with an advanced network reordering algorithm based on ant colony optimization (ACOR). This novel approach transforms gene expression data by incorporating neighborhood expression values from reordered network positions, thereby amplifying weak but biologically significant signals that would otherwise be lost as noise. The invention demonstrates particular utility in neurodegenerative disease research, exemplified by its application to Alzheimer's disease (AD) classification where it achieves superior accuracy compared to existing methods.  

## SUMMARY OF THE INVENTION  

The present invention provides a system and method for network-based gene expression analysis that significantly improves microarray classification accuracy through integrative expression profiling. At its core, the invention comprises: (1) construction of disease-specific protein-protein interaction networks using seed genes; (2) application of ant colony optimization reordering (ACOR) to systematically arrange network nodes; (3) mapping of gene expression profiles onto the reordered network; and (4) integration of expression values using neighborhood influence functions to generate enhanced classification features.  

The ACOR algorithm represents a critical innovation by simulating ant colony density distributions across network nodes to establish an optimal ordering that simultaneously captures clustering and ranking relationships. This dual capability allows the system to group functionally related genes while maintaining meaningful positional relationships between groups, producing fractal-like patterns in the reordered adjacency matrix that reveal system-level network features. When applied to expression data, this ordered structure enables the detection of coordinated expression among weakly expressed genes that would be missed by conventional methods.  

In practical application, the invention demonstrates remarkable efficacy in disease classification. When tested on Alzheimer's disease microarray data, the ACOR-based IXP approach improved classification accuracy from 74.83% to 82.78% using support vector machine classifiers, outperforming both traditional expression profiling methods and a recently published 1372-probe AD signature that achieved only 61.59% accuracy under identical conditions. The system's performance advantage extends beyond simple accuracy improvements, as it successfully identifies disease-relevant gene groups whose individual expression levels would traditionally be dismissed as insignificant noise.  

## DESCRIPTION OF EMBODIMENTS OF THE PRESENT INVENTION  

In one embodiment, the invention operates through a four-step process for microarray classification using integrative expression profiling. The first step involves selection of disease-associated seed genes from curated databases such as AlzGene and OMIM. For Alzheimer's disease applications, these seed genes form the foundation for constructing a disease-specific protein-protein interaction network using nearest neighbor expansion within comprehensive human PPI databases like the Human Annotated and Predicted Protein Interaction (HAPPI) database.  

The second step applies the ant colony optimization reordering algorithm to the constructed network. The ACOR algorithm treats node reordering as an optimization problem where simulated ants explore network paths iteratively, establishing density distributions that reveal optimal node arrangements. This process generates a reordered adjacency matrix displaying fractal-like patterns that simultaneously reflect clustering and ranking relationships between genes. The algorithm's unique capability to establish relative ranks within clusters proves particularly valuable for expression integration, as it positions functionally related genes in neighboring orders regardless of their individual expression strengths.  

The third embodiment details the expression integration process. Gene expression profiles are mapped onto the ACOR-reordered gene list and integrated using Gaussian influence functions that account for neighborhood expression values. This integration creates new expression peaks formed by groups of weakly expressed genes that would be undetectable individually. For example, three closely ordered genes with individually low differential expression may combine to form a peak exceeding that of a single highly expressed gene. The integration parameters, including the horizontal influence coefficient (r), can be optimized for specific classification tasks, with empirical results showing optimal performance at r = 0.9 for AD classification.  

In a fourth embodiment, the system demonstrates superior classification performance across multiple evaluation metrics. Comparative testing against IXP approaches based on conventional network ranking, graph clustering, and random ordering reveals consistent advantages for the ACOR-based method. The embodiment further includes validation mechanisms such as expression profile visualization that clearly distinguish disease states (e.g., incipient, moderate, and severe AD) based on integrated expression patterns. The system's robustness is evidenced by consistent performance across different microarray platforms and its ability to maintain accuracy when training with substantially smaller datasets (31 samples) than the testing set (151 samples).  

Additional embodiments incorporate advanced features such as gene weighting based on network topology properties, where both local (node degree) and global (ACOR-derived ordering) topological information contribute to classification accuracy. The system's architecture allows integration with various machine learning classifiers, with demonstrated efficacy using support vector machines. Practical applications extend beyond Alzheimer's disease to other complex disorders where weak but coordinated gene expression patterns carry diagnostic significance. The invention further includes implementations for high-throughput analysis pipelines, visualization tools for reordered networks and integrated expression profiles, and interfaces for biological interpretation of results.
