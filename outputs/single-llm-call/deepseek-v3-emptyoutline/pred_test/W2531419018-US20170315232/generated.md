# DESCRIPTION  

## BACKGROUND  

The field of the invention relates generally to tsunami detection systems, and more particularly to systems and methods for detecting tsunamis using high-frequency (HF) radar technology. Tsunamis pose significant threats to coastal communities worldwide, with the potential to cause massive destruction and loss of life. Traditional tsunami detection systems rely primarily on seismic sensors to detect underwater earthquakes and deep-ocean pressure sensors to measure tsunami wave heights. However, these systems have several limitations. Seismic sensors cannot reliably predict whether an underwater earthquake will generate a tsunami, and deep-ocean pressure sensors provide limited coverage and may miss tsunamis that originate closer to shore.  

Existing tsunami warning systems suffer from significant gaps in coverage and accuracy. The current network of deep-ocean assessment and reporting of tsunami (DART) buoys, while valuable, cannot provide comprehensive monitoring of all potential tsunami threats due to their limited deployment in deep ocean waters. Furthermore, these buoys measure only wave height and cannot provide information about the tsunami's orbital velocity, which is critical for accurate intensity prediction near shorelines. Coastal tide gauges, while useful for verification, provide warning only after the tsunami has already arrived, leaving insufficient time for evacuation in many cases.  

HF radar systems have been used for oceanographic observations since the 1960s, primarily for mapping surface currents and monitoring sea state. These systems operate by transmitting vertically polarized radio waves that interact with ocean surface waves. The interaction produces radar echoes that can be analyzed to determine surface current velocities. While HF radars have demonstrated capability in measuring ocean currents, their application to tsunami detection has been limited by the lack of robust algorithms capable of distinguishing tsunami-induced currents from normal oceanographic variability.  

Prior attempts to use HF radar for tsunami detection have faced challenges in reliably identifying tsunami signatures amidst background ocean currents and noise. The development of effective pattern recognition algorithms and methods for distinguishing tsunami-induced velocity patterns from normal oceanographic variability has been a persistent challenge in the field. Additionally, the evaluation of potential radar sites for tsunami detection capability has been hindered by the lack of accurate simulation tools that can predict tsunami velocity patterns based on local bathymetry and other site-specific factors.  

## SUMMARY  

The present invention provides systems and methods for detecting tsunamis using HF radar technology with improved accuracy and reliability. The invention comprises a novel detection algorithm that analyzes patterns in ocean surface current velocities measured by HF radar to identify characteristic signatures of approaching tsunamis. The system operates by continuously monitoring radial current velocities obtained from HF radar echoes and processing these measurements through a multi-step pattern recognition algorithm that identifies tsunami signatures based on correlated velocity oscillations across multiple measurement bands.  

A key aspect of the invention is the q-factor detection algorithm, which analyzes temporal and spatial patterns in measured current velocities to distinguish tsunami-induced currents from normal oceanographic variability. The algorithm operates in three sequential steps: first, it identifies significant velocity changes over consecutive time intervals within individual measurement bands; second, it checks for coincident velocity changes across adjacent bands; and third, it verifies consistent velocity patterns across multiple adjacent bands. When these conditions are met simultaneously, the algorithm generates a q-factor value that, when exceeding a predetermined threshold, indicates a tsunami detection.  

The invention further includes methods for evaluating potential radar sites for tsunami detection capability using simulated tsunami velocity patterns. These methods allow for the assessment of site-specific factors such as offshore bathymetry, background current variability, and noise levels that affect detection performance. The system can generate estimates of minimum detectable tsunami height and velocity at various distances from shore, enabling optimization of detection thresholds and warning times for specific locations.  

Another innovative aspect of the invention is its ability to reduce false alarms through correlation of detection signals from multiple radar sites and integration with seismic event notifications. The system can compare q-factor alerts from geographically proximate radar sites and correlate these with seismic event data to improve detection reliability. This multi-factor verification significantly enhances the system's operational utility as a tsunami warning tool.  

The invention provides several advantages over existing tsunami detection systems. First, it offers the capability to detect tsunamis closer to shore than deep-ocean systems, providing more accurate intensity predictions for specific coastal locations. Second, it measures tsunami orbital velocity directly, which provides earlier detection than systems relying solely on wave height measurements. Third, the system can be implemented using existing HF radar infrastructure with software upgrades, making it cost-effective to deploy. Finally, the invention's robust pattern recognition algorithms and false alarm reduction methods make it suitable for operational warning systems where reliability is critical.  

## DETAILED DESCRIPTION  

The present invention provides a comprehensive system for detecting tsunamis using HF radar technology. The system comprises several interconnected components that work together to provide reliable tsunami detection and warning capabilities. The following detailed description explains the structure, operation, and innovative aspects of the invention.  

The HF radar system employed in the invention operates by transmitting radio waves in the high-frequency band (typically 3-30 MHz) and receiving echoes from ocean surface waves. These echoes contain Doppler shift information that reveals the radial velocity of surface currents. The system processes these echoes to produce measurements of ocean surface current velocity at multiple range cells extending from near-shore to distances typically up to 50 km offshore. The radar operates continuously, providing updated velocity measurements at regular intervals (typically every 4-10 minutes).  

A critical innovation of the invention is the processing of these velocity measurements through a specialized tsunami detection algorithm. The algorithm begins by organizing the radar coverage area into rectangular measurement bands approximately parallel to depth contours. These bands are typically 2 km wide and extend across the radar's coverage area. Within each band, the system calculates average radial velocity components both perpendicular and parallel to the band orientation. This produces time series of band velocities that exhibit characteristic patterns when a tsunami is present.  

The detection algorithm employs a three-step process to identify tsunami signatures in these velocity time series. In the first step, the system monitors each measurement band for significant velocity changes over consecutive time intervals. When the velocity increases or decreases by more than a preset threshold over two consecutive measurements, the system increments a q-factor value for that band. This initial screening identifies potential tsunami-induced velocity changes while filtering out minor fluctuations caused by normal oceanographic processes.  

The second step of the algorithm examines correlations between velocity changes in adjacent measurement bands. The system checks whether maximum or minimum velocities in consecutive bands coincide within a preset tolerance for consecutive time intervals. When this condition is met, the q-factor is further incremented, indicating stronger evidence of a tsunami signature. This spatial correlation analysis is particularly effective at distinguishing tsunami patterns from random current fluctuations.  

The third step of the algorithm extends the correlation analysis to three adjacent measurement bands. The system verifies whether velocity increases or decreases persist across three consecutive bands over two consecutive time intervals. When this broader spatial correlation is present, the q-factor receives an additional increment. This multi-band verification provides robust discrimination against false alarms caused by localized current anomalies.  

The q-factor threshold for tsunami detection is determined through analysis of extended datasets collected under normal ocean conditions. By examining the distribution of q-factor values during periods with no tsunami activity, the system can establish threshold levels that provide an optimal balance between detection probability and false alarm rate. The threshold is typically set to exceed the maximum q-factor values observed during normal conditions by a significant margin, ensuring high confidence in detection alerts.  

The invention includes sophisticated methods for simulating tsunami velocity patterns to evaluate radar site suitability and optimize detection parameters. These simulation methods incorporate both exact solutions of the fundamental tsunami propagation equations and approximate methods based on Green's Law. The exact solutions solve the coupled partial differential equations governing tsunami height and velocity propagation, incorporating local bathymetry data to produce accurate predictions of tsunami velocity patterns at specific coastal locations.  

The simulation system can model tsunami propagation in both one-dimensional and two-dimensional scenarios. One-dimensional simulations are particularly useful for studying tsunami interactions with continental shelf edges, while two-dimensional simulations can model complex refraction patterns around irregular coastlines. The simulations produce normalized tsunami height and velocity profiles that demonstrate how these parameters evolve as the tsunami approaches shore. These simulations reveal that tsunami orbital velocity increases more rapidly than wave height as depth decreases, making velocity measurements particularly sensitive for early detection.  

The approximate simulation methods based on Green's Law provide a computationally efficient alternative for site evaluation. These methods adjust reference tsunami velocity patterns from known events to account for local depth variations at test sites. By applying depth-dependent scaling factors derived from Green's Law, the system can generate realistic simulations of how a tsunami would appear at a new radar location. This allows for preliminary assessment of detection capability before actual tsunami observations are available at the site.  

A key application of these simulation tools is the evaluation of minimum detectable tsunami height and velocity at various distances from shore. The system can determine the smallest tsunami that would produce a detectable signal given local bathymetry and background current conditions. This information is critical for establishing appropriate detection thresholds and estimating potential warning times for specific coastal locations.  

The invention incorporates several innovative methods for reducing false alarms and improving detection reliability. One approach correlates q-factor alerts from multiple nearby radar sites. Since a real tsunami would typically produce correlated signals at adjacent sites within a predictable time window, this spatial verification provides strong confirmation of valid detections. Conversely, isolated alerts without corroboration from neighboring radars can be discounted or flagged as potential false alarms.  

Another false alarm reduction method integrates the radar detection system with seismic event notifications. The system monitors real-time seismic alerts and calculates expected tsunami arrival times based on earthquake location and local bathymetry. Q-factor alerts occurring within predicted arrival windows receive higher confidence ratings, while those occurring outside expected time frames are treated with greater skepticism. This integration of seismic and radar data significantly enhances the system's operational reliability.  

The invention also includes specialized methods for handling challenging detection scenarios. For sites with particularly variable background currents, the system can employ adaptive detection thresholds that adjust based on current conditions. In areas prone to radio frequency interference, the system incorporates interference detection and filtering algorithms to maintain detection capability. These adaptive features ensure robust performance across diverse operational environments.  

Implementation of the invention typically involves software upgrades to existing HF radar systems, making it highly cost-effective to deploy. The system can operate in parallel with conventional current mapping functions, providing continuous tsunami monitoring without disrupting normal radar operations. Detection alerts can be integrated with existing tsunami warning systems to provide comprehensive coastal protection.  

The invention has been successfully tested using data from multiple tsunami events, including the 2011 Tohoku tsunami and the 2013 US East Coast meteotsunami. These tests demonstrated the system's ability to provide advance warning ranging from several minutes to over forty minutes before tsunami arrival at shore, depending on local bathymetry. The system detected tsunamis with wave heights as small as 0.3 meters at tide gauges, demonstrating sensitivity to even moderate events.  

Future enhancements to the invention may include integration with numerical tsunami forecast models to improve intensity predictions and expanded networks of radar sites to provide more comprehensive coastal coverage. The system's modular design allows for continuous improvement of detection algorithms as additional tsunami observations become available.  

In summary, the present invention provides a robust, reliable system for tsunami detection using HF radar technology. By combining advanced pattern recognition algorithms with sophisticated simulation tools and false alarm reduction methods, the system offers significant improvements over existing detection technologies. The invention's ability to provide localized, velocity-based tsunami warnings represents a major advancement in coastal hazard mitigation.
