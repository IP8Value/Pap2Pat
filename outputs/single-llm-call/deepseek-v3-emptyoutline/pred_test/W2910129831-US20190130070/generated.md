# DESCRIPTION  

## TECHNICAL FIELD  

The present invention relates to the field of medical informatics and computational disease modeling, specifically to systems and methods for modeling the progression of chronic diseases using observational clinical data. More particularly, the invention provides a novel framework based on Continuous-Time Hidden Markov Models (CTHMM) to analyze longitudinal patient data and construct probabilistic disease progression models that capture multifaceted symptom evolution across multiple clinical domains. The invention is particularly suited for neurodegenerative disorders such as Huntington's Disease (HD), where progression manifests through complex interactions of motor, cognitive, and functional symptoms over extended time periods. The disclosed methods address critical challenges in disease progression modeling including irregular observation intervals, partial patient trajectories, and multidimensional symptom assessment by providing a data-driven approach to determine disease states, estimate transition probabilities between states, and predict individual patient progression pathways.  

## SUMMARY  

The invention provides a computational framework for constructing comprehensive disease progression models from longitudinal observational data. At the core of the framework is a Continuous-Time Hidden Markov Model (CTHMM) that represents disease progression as transitions between discrete latent states, where each state corresponds to a distinct clinical presentation of the disease. The model incorporates three key innovations: (1) a data-driven method to determine the optimal number of disease states through grid search and likelihood maximization; (2) a constrained transition matrix structure that reflects disease-specific progression patterns while allowing for state skipping; and (3) a multivariate observation model that simultaneously tracks symptom evolution across multiple clinical domains.  

The framework operates through two principal phases. In the first phase, the system determines the number of disease states by training multiple CTHMM instances with varying state counts on a training dataset and selecting the model that maximizes likelihood on a held-out test set. In the second phase, the system estimates all model parameters including state transition rates, state duration distributions, and clinical feature distributions through an Expectation-Maximization algorithm adapted for continuous-time Markov processes. The resulting model provides several clinically valuable outputs: a comprehensive mapping of disease states across the entire progression continuum; quantitative estimates of transition probabilities between states; expected durations for each disease state; and personalized state sequences for individual patients.  

Applied to Huntington's Disease, the framework identified nine distinct disease states organized into three phases: prodromal (states 1-2), transition (states 3-5), and manifest (states 6-9). The model revealed complex progression patterns including parallel pathways during the transition phase and differential progression rates across motor, cognitive and functional domains. The invention represents a significant advance over existing staging systems by providing quantitative, multidimensional progression metrics that are applicable both before and after clinical diagnosis.  

## DETAILED DESCRIPTION  

The detailed description of the invention begins with the mathematical formulation of the Continuous-Time Hidden Markov Model (CTHMM) that forms the core of the disease progression framework. The model assumes that disease progression follows a continuous-time Markov process with M distinct states, where M is determined through the data-driven procedure described subsequently. The progression dynamics are characterized by an M×M transition generator matrix Q, where off-diagonal elements Qij (i≠j) represent the instantaneous transition rate from state i to state j, and diagonal elements Qii are set such that each row sums to zero.  

The transition probability matrix A(δ) over time interval δ is computed through matrix exponentiation: A(δ) = expm(δQ). This continuous-time formulation accommodates irregular observation intervals common in clinical practice. The model constrains the structure of Q to reflect disease-specific progression patterns - for Huntington's Disease, a second-order forward-chain structure was implemented where transitions are permitted only to the next one or two states (Qij = 0 for j > i+2). The last disease state is configured as absorbing (Qij = 0 for all j).  

Each disease state m is associated with probability distributions for clinical features Zk. The base implementation uses independent Gaussian distributions Zk|m ~ N(μmk, σ²mk), though the framework supports any exponential family distribution. The complete parameter set Θ = {Q, π, μ, σ²} includes the transition matrix, initial state probabilities, and observation distribution parameters.  

The estimation procedure employs an Expectation-Maximization (EM) algorithm adapted for continuous-time processes. The E-step computes expected sufficient statistics for state transitions and durations using a forward-backward algorithm extended for continuous time. The M-step updates parameters by maximizing the expected complete-data log-likelihood. For Q, the update combines information across all observed time intervals weighted by their expected transition counts. The observational parameters μ and σ² are updated through weighted averages of feature values.  

A critical innovation is the data-driven determination of the number of disease states M. The system implements a grid search over candidate M values, for each: (1) splitting the dataset into training and test sets, (2) estimating model parameters on the training set, and (3) evaluating the log-likelihood on the test set. The optimal M maximizes this out-of-sample likelihood, balancing model fit and generalizability. For Huntington's Disease, this procedure identified M=9 states as optimal.  

The framework incorporates several preprocessing steps to handle real-world clinical data challenges. For high-dimensional, sparse clinical assessments, the system first applies latent factor analysis to extract lower-dimensional representations spanning motor, cognitive and functional domains. These factors serve as the observed variables Z in the CTHMM. The system handles missing data through complete-case analysis or imputation during preprocessing.  

Applied to an integrated HD dataset comprising 55,782 observations from 16,653 subjects, the framework produced an Integrated Huntington's Disease Progression Model (IHDPM) with nine states showing distinct clinical profiles. The prodromal phase (states 1-2) exhibited subtle cognitive changes preceding motor symptoms. The transition phase (states 3-5) revealed complex progression patterns with differential timing across domains. The manifest phase (states 6-9) showed expected patterns of motor symptom progression including chorea attenuation in late stages.  

The model provides several clinically actionable outputs. Transition probability matrices quantify progression likelihoods over specified time intervals. State duration estimates (e.g., 9.7 years for state 1) enable prognosis prediction. Individual state sequences offer granular progression tracking beyond existing staging systems. The framework's generalizability is demonstrated by its applicability to other chronic diseases through appropriate configuration of the transition matrix structure and clinical domain selection.  

The complete implementation includes computational optimizations for large datasets, including parallel processing for the EM algorithm and efficient matrix exponentiation methods. The system outputs include graphical representations of disease states, transition heatmaps, and individualized progression reports. Clinical applications range from trial recruitment to personalized care planning and therapeutic development.  

While particular embodiments have been described, the framework admits various modifications including alternative observation models (e.g., multivariate distributions), different transition matrix constraints, and incorporation of additional data types such as imaging biomarkers.
