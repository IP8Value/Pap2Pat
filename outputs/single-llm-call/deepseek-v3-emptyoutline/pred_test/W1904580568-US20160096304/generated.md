# DESCRIPTION  

## TECHNICAL FIELD  
The present invention relates to the field of electrospinning, specifically to a high-throughput system and method for fabricating core-sheath micro and nanofibers using a slit-surface electrospinning fixture. The invention enables the production of particle-encapsulating, bicomponent, hollow, or otherwise unelectrospinnable fibers at commercially viable throughputs exceeding 1 L/h. The disclosed technology overcomes limitations of conventional coaxial needle-based electrospinning systems by utilizing a novel slit geometry that facilitates the formation of multiple core-sheath cone-jets under controlled flow conditions. Applications span industries including biomedical devices, drug delivery, textiles, filtration, energy storage, and sensors.  

## SUMMARY OF THE INVENTION  
The invention provides an electrospinning apparatus and method for producing core-sheath fibers through a slit-surface fixture comprising aligned triangular nozzles that co-localize core and sheath solutions along a vertical plane. Upon application of an electric field, the system generates multiple Taylor-like cone-jets along the slit length, wherein viscous shear forces entrain the core solution into the sheath stream, forming a stable core-sheath architecture. Key innovations include:  

1. **Scalable Slit Design**: A 3.5 cm to 14 cm elongated slit-surface accommodates 8–30+ simultaneous jets, enabling throughputs >1 L/h (50–250 g/h polymer mass rates).  
2. **Flow Control Mechanism**: Distinct core-sheath cone-jets form when the sheath flow velocity (*v*<sub>sheath</sub>) exceeds the core flow velocity (*v*<sub>core</sub>), achieved by optimizing flow rates and slit cross-sectional areas.  
3. **Material Versatility**: The process is agnostic to solution miscibility, supporting polymers such as PLGA, PCL, PEO, nylon, PDMS, and cellulose derivatives.  
4. **Parameter Optimization**: Core encapsulation efficiency is tunable via viscosity ratios, slit widths, and flow velocity ratios (*v*<sub>sheath</sub>/*v*<sub>core</sub> ≥ 2.0).  

The invention further includes methods for fabricating hollow fibers (via soluble cores), bicomponent composites (e.g., nylon-PLGA), and fibers from unelectrospinnable materials (e.g., PDMS).  

## DETAILED DESCRIPTION  

### Core Flow Rate  
The core solution flow rate is critical to maintaining a distinct core-sheath interface within the electrospinning jet. Experimental data demonstrate that a core flow rate of 20–40 mL/h, combined with a sheath flow rate of 200 mL/h, yields stable cone-jets (Fig. 4A–4B). At excessive core flow rates (e.g., 60 mL/h), the core disrupts the sheath stream, leading to mixed morphologies. The ratio *v*<sub>sheath</sub>/*v*<sub>core</sub> must exceed unity, with optimal performance observed at ratios ≥2.0. For a 2.2 mm sheath slit width, this corresponds to a sheath-to-core flow rate ratio of 10:1 (200 mL/h sheath, 20 mL/h core).  

### Slit Fixture Geometry Core Slit Width  
The core slit width governs the initial distribution of the core solution prior to entrainment. In the preferred embodiment, the core slit is designed as a narrow aperture (0.5–1.0 mm) to ensure high core flow velocity (*v*<sub>core</sub>). This geometry promotes rapid uptake of the core material by the sheath stream via viscous shear. A narrower core slit also reduces the risk of flow stagnation, which could lead to premature mixing.  

### Sheath Slit Width  
The sheath slit width directly impacts *v*<sub>sheath</sub> and the shear stress applied to the core solution. Tests with widths of 1.5 mm, 2.2 mm (default), and 3.0 mm reveal that narrower slits enhance core encapsulation (Fig. 6). At 3.0 mm, distinct core-sheath jets form only when the core flow rate is reduced to 10 mL/h (*v*<sub>sheath</sub>/*v*<sub>core</sub> = 3.6). The preferred range is 1.5–2.2 mm, balancing throughput and jet stability.  

### Sheath Slit Width and Core Slit Width  
The interplay between sheath and core slit widths determines the fluid dynamics at the interface. A design rule requires the sheath slit cross-sectional area to be ≤50% of the core slit area to ensure *v*<sub>sheath</sub> > *v*<sub>core</sub>. For example, a 2.2 mm sheath slit paired with a 1.0 mm core slit achieves a 4.84:1 area ratio, enabling efficient entrainment.  

### Core Slit Height  
The slit height (depth) influences the residence time of solutions within the fixture. A height of 5–10 mm ensures sufficient contact between core and sheath solutions while minimizing diffusion. Excessive height (>15 mm) may cause homogenization before electrospinning.  

### Viscosities of the Solutions  
The sheath solution viscosity must exceed the core viscosity to generate adequate shear stress. For System C (Fig. 7), a sheath viscosity of 760 cP (16 wt% PCL) successfully entrained a 500 cP core, whereas a 280 cP sheath (12 wt% PCL) failed. The preferred viscosity ratio (*η*<sub>sheath</sub>/*η*<sub>core</sub>) is ≥1.5.  

### Core Sheath Fiber Applications  
The invention enables four primary fiber types:  
1. **Particle-Encapsulating Fibers**: Core solutions loaded with dexamethasone or other actives for drug delivery.  
2. **Bicomponent Fibers**: Coaxial structures (e.g., nylon-PLGA) for textiles with hybrid properties.  
3. **Hollow Fibers**: PEO cores dissolved post-spinning to create tubular membranes for filtration.  
4. **Non-Electrospinnable Material Fibers**: PDMS cores cured within a sacrificial sheath (e.g., PVP).  

### Advantages of the Invention as it Relates to High Throughput Open-Bath Monofiber Fabrication Systems  
Compared to coaxial needle systems, the slit-surface electrospinning fixture offers:  
- **Throughput Scalability**: 1,000× higher output (1 L/h vs. 0.01–0.1 g/h).  
- **Reduced Clogging**: Continuous slit design eliminates needle blockages.  
- **Material Flexibility**: No miscibility requirements between core and sheath solutions.  
- **Process Control**: Tunable core-sheath dimensions via flow velocity and viscosity ratios.  

Industrial applicability is demonstrated by the ability to produce kilometer-length fiber meshes with uniform core-sheath architectures, a critical advancement for commercial adoption.
