# DESCRIPTION  

## BACKGROUND  

The field of image captioning has traditionally relied on training models to maximize textual similarity between generated captions and reference captions. However, reference captions in public datasets often describe only the most salient objects in images, leading to generic and less distinctive captions that fail to capture fine-grained details. Existing approaches, such as those using n-gram or scene-graph-based metrics (e.g., BLEU, CIDEr), struggle to evaluate paraphrased expressions due to limited reference captions. Additionally, conventional training objectives like maximum likelihood estimation (MLE) suffer from exposure bias, where models perform poorly when generating sequences beyond their training distribution.  

Recent advancements in multimodal models, such as CLIP (Contrastive Language-Image Pretraining), have enabled new ways to measure image-text relevance without relying on reference captions. However, CLIP-based captioning models often produce grammatically incorrect outputs due to the lack of explicit language modeling objectives during pretraining. There remains a need for an improved image captioning system that generates distinctive, grammatically correct captions while eliminating dependency on reference captions for reward computation.  

## SUMMARY  

The present invention discloses an image captioning system that leverages CLIP-based rewards to generate distinctive and detailed captions while incorporating grammar-aware finetuning to improve linguistic correctness. The system comprises:  

1. A **CLIP-guided image captioning module** that trains a captioning model using CLIP's multimodal similarity score as a reward, encouraging the generation of captions that capture fine-grained image details.  
2. A **grammar-aware finetuning module** that refines CLIP's text encoder using synthetic negative captions, correcting grammatical errors such as word repetition without requiring additional text annotations.  
3. A **fine-grained evaluation framework (FineCapEval)** that assesses captions across multiple criteria, including background, objects, object relations, and overall descriptiveness.  

By combining CLIP-based rewards with grammar-aware finetuning, the system generates captions that outperform conventional methods in distinctiveness, grammatical correctness, and retrieval performance. Unlike prior approaches that balance self-retrieval and text similarity objectives, the disclosed invention eliminates the need for reference captions entirely, relying instead on CLIP's contrastive learning framework.  

## DETAILED DESCRIPTION  

### Image Search System  

The disclosed image captioning system operates in three primary stages: (1) CLIP-guided training, (2) grammar-aware finetuning, and (3) fine-grained evaluation.  

#### CLIP-Guided Training  
The system employs CLIP's image and text encoders to compute a multimodal similarity score (CLIP-S) between an input image \( I \) and a generated caption \( c \). The reward function is defined as:  

\[
R(I, c) = \text{CLIP-S}(I, c) = w \cdot \frac{f^I(I) \cdot f^T(c)}{||f^I(I)|| \cdot ||f^T(c)||}
\]

where \( f^I \) and \( f^T \) are CLIP's image and text encoders, and \( w \) is a scaling factor (e.g., 2.5). The captioning model \( P_\theta(c|I) \) is trained using reinforcement learning (REINFORCE) with a self-critical baseline, where rewards are normalized against greedy-decoded captions. This encourages the model to generate captions that maximize CLIP-S, thereby capturing distinctive image features not emphasized in reference captions.  

#### Grammar-Aware Finetuning  
To address grammatical errors (e.g., word repetition) in CLIP-guided captions, the system finetunes CLIP's text encoder using synthetic negative captions. These negatives are generated by perturbing reference captions through operations such as:  
- **Token repetition**: Duplicating random words (e.g., "a blue car" → "a blue blue car").  
- **Token removal**: Deleting random words (e.g., "a car parked in front of a house" → "a car parked front of a house").  
- **Token insertion**: Adding irrelevant words (e.g., "a dog runs" → "a dog runs quickly").  
- **Token swapping/shuffling**: Reordering words (e.g., "a sunny day" → "day a sunny").  

A two-layer perceptron classifier is trained to distinguish original captions from synthetic negatives, injecting grammatical knowledge into CLIP's text encoder without additional annotations.  

#### Fine-Grained Evaluation (FineCapEval)  
The system introduces FineCapEval, a dataset for evaluating captions across four criteria:  
1. **Background**: Descriptions of scene context (e.g., "a white house with trees").  
2. **Objects**: Identification of objects and attributes (e.g., "a blue car").  
3. **Object relations**: Spatial or interaction details (e.g., "parked in front of").  
4. **Overall**: Comprehensive captions combining all criteria.  

Performance is measured via:  
- **Word-level recall (\( R_{word} \)**: The fraction of reference words/phrases included in generated captions.  
- **Human evaluation**: Pairwise comparisons assessing preference for distinctiveness and grammar.  

#### Experimental Results  
1. **Distinctiveness**: CLIP-guided captions achieve higher text-to-image retrieval scores than reference captions, confirming their uniqueness.  
2. **Grammar**: Finetuning reduces errors like word repetition, improving CIDEr scores by +60 points.  
3. **FineCapEval**: CLIP-based models outperform CIDEr-optimized models in all criteria, particularly in background and relation descriptions.  

The system is implemented using a CLIP-Res50 Transformer architecture, trained on the MS COCO dataset with reinforcement learning. Inference is performed via beam search, with optional greedy decoding for baseline rewards.  

### Claims  
1. A method for generating image captions, comprising:  
   - Training a captioning model using CLIP's multimodal similarity score as a reinforcement learning reward.  
   - Finetuning CLIP's text encoder with synthetic negative captions to improve grammatical correctness.  
   - Evaluating captions using a fine-grained dataset (FineCapEval) with criteria for background, objects, relations, and overall descriptiveness.  

2. The method of claim 1, wherein the synthetic negative captions are generated by perturbing reference captions via token repetition, removal, insertion, or shuffling.  

3. The method of claim 1, wherein the reward function is computed without reference to human-annotated captions.  

### Industrial Applicability  
The invention is applicable in:  
- **Search engines**: Enhancing text-to-image retrieval with distinctive captions.  
- **Accessibility**: Generating detailed descriptions for visually impaired users.  
- **Content moderation**: Automatically captioning images for compliance checks.  

### Conclusion  
By integrating CLIP-based rewards with grammar-aware finetuning, the disclosed system advances image captioning in distinctiveness, correctness, and evaluation granularity. Future extensions may adapt the framework to multilingual or stylized captioning.
