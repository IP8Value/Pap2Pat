# DESCRIPTION

## TECHNICAL FIELD

The present invention relates to the field of cryptographic systems and authentication protocols, particularly to a class of cryptosystems known as verifiable encryption (VE) that enables the computation of a distance metric between two encrypted data items without requiring decryption. More specifically, the invention provides a novel authentication algorithm based on verifiable encryption that is optimized for low-latency, resource-constrained environments such as Internet of Things (IoT) devices and cloud-based services where digital identity verification must be performed securely and efficiently over a network. The invention further encompasses methods and systems for implementing this authentication protocol using stream ciphers, particularly the one-time pad, to achieve both high security and computational efficiency. The technical domain spans cryptography, secure communications, biometric authentication, digital identity management, and distributed computing systems, with particular relevance to scenarios involving third-party untrusted servers, minimal client-side computational resources, and the need to protect sensitive personal information such as biometric data during transmission and processing.

## BACKGROUND ART

The proliferation of network services, cloud computing platforms, and Internet of Things (IoT) devices has created an urgent need for efficient cryptographic solutions that can process encrypted data at scale while maintaining robust security guarantees. Traditional approaches to data protection typically involve encrypting sensitive information before storage or transmission, but this creates a fundamental tension: while encryption protects data confidentiality, it also prevents meaningful computation on the encrypted data without first decrypting it, which introduces security vulnerabilities and performance bottlenecks. This challenge has been particularly acute in the context of searchable encryption (SE), where the goal is to enable keyword searches on encrypted messages without revealing more information than the search results themselves. Although SE has been studied for approximately two decades and shows promise for cloud service applications, existing implementations suffer from prohibitively high resource costs in terms of computational power, processing time, and memory requirements, making them impractical for widespread deployment in resource-constrained environments.

Digital identity management represents another critical area where existing cryptographic approaches face significant limitations. Digital identity encompasses various forms of personal information used for authentication purposes, including biometric data (fingerprints, facial features), certificates issued by credential service providers, physical cards (credit cards, driver's licenses), and personal knowledge factors (passwords, secret questions). In many current implementations, digital identity information is stored on network storage systems operated by service providers, with users often placing implicit trust in these providers for security and privacy management. However, this trust model is increasingly problematic given the frequency and severity of data breaches affecting major service providers. The fundamental security challenges in digital identity management stem from two primary factors: the identification methodology employed and the underlying cryptographic system used to protect the identity information.

Traditional authentication protocols rely heavily on public key infrastructure (PKI) and interactive proof systems, such as the well-known Fiat-Shamir and Schnorr protocols, which are based on zero-knowledge proof concepts. These protocols typically involve a registration phase where secret information is distributed through public key agreement mechanisms, followed by a verification phase where the authenticity of the claimed identity is verified through multiple rounds of message exchange. While these approaches provide strong security guarantees, they require significant computational resources and introduce substantial latency due to the interactive nature of the verification process and the need for trusted third parties such as certificate authorities (CAs) to manage cryptographic parameters. This makes them unsuitable for scenarios involving frequent authentication requests or resource-constrained devices.

The emergence of new authentication paradigms has further complicated the security landscape. Beyond traditional network-based authentication (used for electronic transactions and secure communications) and local device unlocking (used for smartphones and personal devices), a third category has emerged: unlocking local devices via network. This scenario is particularly relevant in IoT environments where smart devices, groupware systems, and shared infrastructure require authentication that is both secure against network-based attacks and efficient enough to maintain acceptable user experience. In these contexts, devices may be owned by service providers rather than individual users, and multiple users may need to authenticate against the same device. The authentication process typically involves the user sending their digital identity to the device, which then queries a remote server for verification. This creates a unique security challenge: the digital identity must be protected during transmission to prevent eavesdropping, yet the verification process must be fast enough to avoid degrading service quality.

Homomorphic encryption schemes, such as RSA encryption, ElGamal encryption, and fully homomorphic encryption, have been proposed as potential solutions to enable computation on encrypted data. These schemes allow certain mathematical operations (such as addition or multiplication) to be performed directly on ciphertexts, with the result corresponding to the same operation performed on the underlying plaintexts. However, these approaches remain computationally expensive and complex to implement, particularly for general-purpose computations. The need for a more practical solution that balances security, efficiency, and functionality has remained unaddressed in the prior art.

Existing block cipher modes of operation, such as Electronic Codebook (ECB), Cipher Block Chaining (CBC), and Cipher Feedback (CFB) modes, are generally incompatible with the requirement to perform meaningful computations on encrypted data. These modes are designed primarily for confidentiality rather than computability, and they do not support the types of operations needed to compute distance metrics between encrypted data items. While Output Feedback (OFB) mode can be adapted to function as a stream cipher and thus potentially support certain types of encrypted computations, this capability has not been systematically explored or leveraged in the context of authentication protocols.

The one-time pad, while theoretically providing perfect secrecy when implemented correctly, has historically been considered impractical for most real-world applications due to the key management challenges associated with generating, distributing, and storing keys that are as long as the plaintext messages. However, recent advances in pseudorandom number generation and the specific requirements of certain authentication scenarios suggest that the one-time pad may be more viable than previously assumed, particularly when combined with appropriate key management strategies and computational models.

## SUMMARY OF INVENTION

### Technical Problem

The present invention addresses several interrelated technical problems that arise in the context of secure authentication in modern distributed computing environments. First, there exists a fundamental trade-off between security and performance in existing authentication protocols, where strong security guarantees typically require computationally intensive cryptographic operations that introduce unacceptable latency for real-time applications, particularly in resource-constrained IoT devices and mobile platforms. Second, traditional authentication protocols rely on interactive proof systems that require multiple rounds of message exchange between the prover and verifier, which increases network overhead, processing time, and vulnerability to timing attacks. Third, existing approaches to protecting digital identity information during transmission and storage either sacrifice security for performance (as in local device unlocking scenarios where plaintext identity information is processed without encryption) or sacrifice performance for security (as in traditional network-based authentication that requires complex public key infrastructure and certificate validation). Fourth, there is a lack of cryptographic systems that can efficiently compute meaningful metrics (such as distance measures) between encrypted data items without requiring decryption, which is essential for applications involving biometric authentication, similarity matching, and other forms of comparative analysis on encrypted data. Fifth, existing solutions for authentication in scenarios involving untrusted third-party servers either require complex key distribution mechanisms or fail to provide adequate protection against various attack vectors, including impersonation attacks and plaintext attacks.

### Solution to Problem

The present invention provides a comprehensive solution to these technical problems through the introduction of a novel class of cryptosystems called verifiable encryption (VE) and a corresponding authentication algorithm specifically designed for efficient and secure operation in distributed computing environments. The core innovation lies in the definition and implementation of verifiable encryption as a class of cryptosystems that enables the computation of a distance metric between two plaintext messages directly from their encrypted representations, without requiring decryption of the individual messages.

The verifiable encryption framework consists of two cryptosystems operating on the same plaintext space but potentially using different keys, along with a specialized function F that operates on the ciphertext space to produce an encrypted representation of the distance between the original plaintexts. A corresponding decryption function D then allows the legitimate party possessing both keys to recover the actual distance value. This architecture enables secure distance computation on encrypted data while maintaining the confidentiality of the individual data items.

The invention demonstrates that several existing cryptographic protocols, including specific instances of the Fiat-Shamir and Schnorr authentication algorithms, as well as the one-time pad cryptosystem, can be shown to belong to the verifiable encryption class under certain conditions. This theoretical foundation provides both validation of the VE concept and practical implementation pathways.

Building upon this theoretical framework, the invention provides a novel authentication algorithm specifically designed for the "unlocking local devices via network" scenario, which represents a critical gap in existing authentication technologies. This algorithm eliminates the need for interactive proof systems and public key infrastructure by leveraging the verifiable encryption properties of stream ciphers, particularly the one-time pad. The authentication process involves a registration phase where the user's digital identity is encrypted with a device-generated key and stored on an untrusted server, followed by a verification phase where a new instance of the user's digital identity is encrypted with a fresh one-time key, and the server computes an encrypted distance measure between the registered and presented identities without learning either identity or the actual distance value.

The implementation leverages the one-time pad's homomorphic properties with respect to the XOR operation, enabling efficient computation of Hamming distance (or other appropriate distance metrics) between encrypted biometric or other digital identity data. The use of one-time keys for each authentication session ensures forward secrecy and protection against replay attacks, while the separation of key management (handled by the trusted device) from distance computation (performed by the untrusted server) provides a robust security model that protects against various attack vectors.

### Advantageous Effects

The present invention provides numerous advantageous effects that address the limitations of existing authentication technologies. First, the authentication algorithm achieves exceptional computational efficiency, with processing times consistently below 0.003 milliseconds even for large plaintext sizes up to 8192 bits, making it highly suitable for real-time applications and resource-constrained devices. This performance is achieved without compromising security, as the algorithm maintains strong cryptographic guarantees through the use of verifiable encryption principles.

Second, the invention eliminates the need for complex public key infrastructure, certificate authorities, and interactive proof systems, significantly simplifying the authentication architecture and reducing both implementation complexity and operational overhead. This makes the solution particularly attractive for IoT deployments and other scenarios where lightweight cryptographic solutions are essential.

Third, the algorithm provides strong protection against plaintext attacks, as demonstrated by the security analysis showing that even if an attacker gains access to certain ciphertext components, they cannot recover the original plaintext or the encryption keys due to the one-time nature of the keys and the separation of concerns between the device and server.

Fourth, the verifiable encryption framework enables secure distance computation on encrypted data, which is particularly valuable for biometric authentication scenarios where exact matches are rare and similarity-based matching is required. The ability to set threshold values for acceptable distance measures allows for flexible authentication policies that can accommodate natural variations in biometric data while maintaining security.

Fifth, the invention provides a clear separation of trust boundaries, with the trusted device handling all key management and final decision-making, while the untrusted server performs only the computationally intensive distance calculation without access to sensitive information. This architecture minimizes the attack surface and provides defense in depth against various threat models.

Sixth, the deterministic nature of the authentication algorithm (as opposed to probabilistic interactive proofs) provides consistent and predictable performance characteristics, which is essential for real-time systems and quality-of-service guarantees in commercial applications.

Seventh, the framework is extensible and can accommodate various distance metrics and encryption schemes beyond the one-time pad implementation described, providing a foundation for future cryptographic innovations in the verifiable encryption space.

Finally, the invention addresses the specific requirements of the emerging "unlocking local devices via network" authentication paradigm, providing a solution that is simultaneously secure against network-based attacks, efficient enough for frequent use, and practical to implement in real-world deployments involving shared infrastructure and multiple users.

## DESCRIPTION OF EMBODIMENTS

### Outline of Exemplary Embodiments of Present Disclosure

The present invention encompasses several exemplary embodiments that demonstrate the practical implementation and application of verifiable encryption principles to solve real-world authentication challenges. The primary embodiment focuses on an authentication algorithm designed specifically for the "unlocking local devices via network" scenario, which has become increasingly important in the context of IoT deployments, shared infrastructure, and cloud-based services. This embodiment leverages the one-time pad cryptosystem as the foundation for verifiable encryption, taking advantage of its homomorphic properties with respect to the XOR operation to enable efficient distance computation on encrypted data.

In this primary embodiment, the system architecture consists of three main components: a user (Alice), a trusted device (Bob), and an untrusted computation server (S). The trusted device is responsible for all key management operations, including key generation, storage, and final authentication decisions, while the untrusted server handles the computationally intensive task of distance calculation between encrypted digital identity representations. This separation of responsibilities ensures that sensitive information remains protected even when the server is compromised.

The authentication process is divided into two distinct phases: registration and verification. During the registration phase, the user provides their digital identity (which may include biometric data, passwords, or other identifying information) to the trusted device. The device generates a secret key and encrypts the digital identity using the one-time pad scheme, then transmits the resulting ciphertext to the untrusted server for storage. The key itself is never transmitted and remains securely stored on the trusted device.

During the verification phase, the user presents their digital identity again to the trusted device. The device generates a fresh one-time key (different from the registration key) and encrypts the presented identity using this new key. The resulting ciphertext is sent to the untrusted server, which computes an encrypted distance measure between the registered and presented identities using a specialized function F that operates on the ciphertext space. The server returns this encrypted distance measure to the trusted device, which then uses both the original registration key and the new verification key to decrypt the distance measure and make the final authentication decision based on whether the computed distance falls within an acceptable threshold.

Additional embodiments demonstrate the theoretical foundation of verifiable encryption by showing how existing cryptographic protocols can be classified within the VE framework. Specifically, the invention shows that certain instances of the Fiat-Shamir and Schnorr authentication algorithms belong to the verifiable encryption class under specific conditions. For the Fiat-Shamir algorithm, this occurs when the commitment value x equals r² mod n and the challenge bit e equals 1. For the Schnorr algorithm, membership in the VE class is established when the key relationship x = re·p₁ mod n holds and the challenge bit e equals 1. These theoretical connections provide validation of the verifiable encryption concept and demonstrate its broad applicability across different cryptographic paradigms.

Another embodiment extends the verifiable encryption framework to include the one-time pad cryptosystem, proving that it naturally belongs to the VE class due to its homomorphic properties. This embodiment is particularly significant because it provides a practical implementation pathway that combines theoretical elegance with computational efficiency. The one-time pad's perfect secrecy properties, when combined with proper key management practices, provide strong security guarantees while maintaining the computational simplicity required for real-world deployment.

The invention also encompasses embodiments that address specific attack scenarios and security considerations. For instance, one embodiment specifically addresses the threat of plaintext attacks by demonstrating that even if an attacker gains access to certain ciphertext components (such as when the attacker presents an all-zero plaintext), the one-time nature of the keys and the separation of key management from computation ensure that the original plaintext and keys remain protected. Another embodiment addresses the limitations of block cipher modes of operation, showing that while most modes (ECB, CBC, CFB) are incompatible with verifiable encryption requirements, the OFB mode can be adapted to function within the VE framework when used as a stream cipher.

The experimental validation provided in the invention demonstrates the practical viability of the proposed approach across various plaintext lengths, from 128 bits to 8192 bits, with consistent performance characteristics that make it suitable for a wide range of applications. The implementation uses advanced pseudorandom number generation techniques, specifically the QP-DYN generator based on non-commutative algebra and ergodic theory, to ensure high-quality key material while maintaining computational efficiency.

### Principles of Exemplary Embodiments of Present Disclosure

The exemplary embodiments of the present invention are founded upon several key cryptographic principles that work together to achieve the desired balance of security, efficiency, and functionality. The central principle is verifiable encryption itself, which is defined as a class of cryptosystems that enables the computation of a distance metric between two plaintext messages directly from their encrypted representations. This principle is mathematically formalized through the existence of two cryptosystems C₁ = (P, C, K, E, D) and C₂ = (P, C, K', E', D') operating on the same plaintext space P, along with a function F: C × C → C that maps pairs of ciphertexts to another ciphertext, and a corresponding decryption function D: C → ℝ⁺ that recovers the distance metric V: P × P → ℝ⁺ between the original plaintexts.

The mathematical foundation of verifiable encryption relies on the preservation of distance relationships through the encryption and computation processes. Specifically, for any two plaintexts p₁, p₂ ∈ P and corresponding keys k, k' ∈ K × K', the following relationship must hold: D_{k,k'}(F(E_k(p₁), E'_k'(p₂))) = V(p₁, p₂). This equation ensures that the distance computed on the encrypted data corresponds exactly to the distance that would be computed on the original plaintext data, while maintaining the confidentiality of the individual data items throughout the process.

The one-time pad embodiment leverages the homomorphic properties of the XOR operation to achieve verifiable encryption. In this implementation, the encryption function E_k(p) is defined as p ⊕ k, where ⊕ denotes bitwise exclusive OR, and k is a random key of the same length as the plaintext p. The distance function F(c₁, c₂) is defined as c₁ ⊕ c₂, which corresponds to (p₁ ⊕ k₁) ⊕ (p₂ ⊕ k₂) = (p₁ ⊕ p₂) ⊕ (k₁ ⊕ k₂). The decryption function D_{k₁,k₂}(c_d) then computes c_d ⊕ (k₁ ⊕ k₂) = p₁ ⊕ p₂, which represents the Hamming distance between the original plaintexts when interpreted appropriately. This elegant mathematical structure enables efficient distance computation while maintaining the perfect secrecy properties of the one-time pad.

The security principles underlying the exemplary embodiments emphasize the separation of trust boundaries and the minimization of attack surfaces. By confining all key management operations to the trusted device and limiting the untrusted server's role to pure computation on encrypted data, the system ensures that compromise of the server does not lead to exposure of sensitive information. The use of one-time keys for each authentication session provides forward secrecy, ensuring that compromise of one session's key does not affect the security of other sessions. Additionally, the deterministic nature of the authentication algorithm eliminates the vulnerabilities associated with probabilistic interactive proofs, such as timing attacks and side-channel information leakage.

The performance principles focus on achieving constant-time operations regardless of plaintext length, which is made possible by the bitwise nature of the XOR operations used in the one-time pad implementation. This characteristic ensures that the authentication algorithm scales efficiently with increasing data sizes, making it suitable for applications involving large biometric templates or other high-dimensional identity representations. The elimination of interactive message exchanges and public key operations further contributes to the algorithm's exceptional performance characteristics.

The flexibility principles enable the adaptation of the verifiable encryption framework to various distance metrics and application requirements. While the primary implementation uses Hamming distance for binary data, the framework can be extended to other distance measures appropriate for different types of digital identity information. The ability to set threshold values for acceptable distances allows for tunable authentication policies that can balance security requirements with usability considerations, particularly in biometric authentication scenarios where natural variations in measurements must be accommodated.

The implementation principles emphasize practical considerations such as pseudorandom number generation quality, key storage security, and resistance to various attack vectors. The use of advanced pseudorandom generators like QP-DYN ensures that the one-time keys possess sufficient entropy and unpredictability to maintain security guarantees. The careful design of the key management process ensures that keys are never transmitted over the network and are properly isolated from potential attack vectors. The comprehensive security analysis addresses both impersonation attacks (which require physical access to the trusted device) and plaintext attacks (which are mitigated by the one-time key property and computational separation).

These principles work together to create a coherent and robust authentication framework that addresses the specific challenges of modern distributed computing environments while maintaining strong cryptographic foundations and practical implementation considerations.
